# 모션 검수 (2단계, 2026-10-08 밤)

기준 캐릭터 v2 몸 위에서 모션을 다시 만든 2단계의 기록이다. **main 합치기(실제 배포) 전**이다. 기준 몸·머리–목 연결은 [기준 캐릭터 검수](기준캐릭터-검수.md), 규칙은 [아바타 제작 기준](아바타-제작기준.md)을 따른다.

작업 방식: 동작을 여섯 묶음(걷기·달리기 / 앉기 / 점프 / 인사·기뻐하기·고개 인사 / 사다리 / 정지 화면)으로 나누었다. 묶음마다 따로 만든 뒤 하나로 합쳤다. 합친 코드에서 검사를 다시 돌리고 모음 사진을 다시 찍었다. 1차 결과에서 부족한 점은 2차에서 고친다(아래 '남은 점').

## 자동 검사 (합친 코드, 클라우드 소프트웨어 렌더)

- `verify-foundation-model.cjs`: 성공. 6720 뼈 표본에서 관절 길이가 그대로이고, 대기 자세는 기준 그림과 같다. 걷기·달리기·점프·인사·기뻐하기·고개 인사·사다리·앉기·정지 계약도 모두 통과했다. 새 계약은 옛 코드에 돌리면 실패한다(묶음별 확인).
- `verify-reference-body.cjs`: 성공. 대기 자세 수치가 1단계 기록과 같다(남 앞 0.9825/0.088, 남 옆 0.9657/0.1217, 남 뒤 0.9854/0.0736, 여 앞 0.9787/0.1511, 여 옆 0.9640/0.1846, 여 뒤 0.9664/0.2204). 노드 수는 동작이 바뀌어도 일정하다(남 178, 여 172. 인사용 숨은 노드가 22개 늘었다).
- `verify-foundation-transitions.cjs`: 성공(288 방향 전환, 다른 픽셀 0).
- `verify-foundation-browser.cjs`: 성공(7680 표본, 정지 화면 16가지, 30명 목록 아바타 변화 0, 동작 줄이기).
- `check-source.cjs`: 성공. 교실·숲 마을 지도 검사 결과는 아래 '지도 검사'.

## 성능 (클라우드 소프트웨어 렌더, 학교 기기 아님)

- 30명 걷기·달리기: 수정 전후 같음(갱신 중앙값 약 40ms).
- 30명 점프: 184~208ms → 32~36ms(자세를 단계별로 미리 그려 둠).
- 30명 사다리: 72~80ms → 38ms(오르는 동안 호흡 흔들림을 없애 그림을 다시 만들지 않음).
- 30명 정지 그리기: 450~565ms → 0.2~0.4ms. 화면에 붙이는 시간은 245~326ms → 355~435ms로 늘었다. 몸이 들어가서다.
- 여러 동작을 섞은 30명: 227~244ms(수정 전 240ms).
- 30명이 모두 다른 방향으로 인사하는 극단 시험: 93~100ms(수정 전 38~42ms, 그림 캐시가 모자람). 지도에서는 인사가 늘 앞모습이라 해당하지 않는다.
- 실제 그램·크롬북 FPS와 네트워크 로딩은 확인하지 않았다.

## 남은 점 (2차에서 고칠 것)

1. **달리기 앞/뒤 팔**: 앞팔이 배 앞에 수평으로 누워 배를 잡은 듯 보이고, 다른 팔은 거의 내려가 있다. 여자 앞모습은 팔이 거의 움직이지 않는다. 뒷모습은 허리에 손을 얹은 듯 보인다. 접힌 아래팔 사본이 아직 붙인 그림처럼 보인다. 걷기 → 달리기 전환 때 기울기·팔이 한 프레임에 바뀐다.
2. **점프 팔**: 옆모습에서 출발·상승 동안 두 팔을 턱 높이로 곧게 내밀어 몽유병 팔처럼 보인다. 뒷모습은 어깨를 으쓱하는 듯 보이고, 앞모습 주먹은 권투 자세처럼 보인다. 웅크림·착지 기울기에 걷기·달리기의 목 꺾기 규칙이 적용되지 않았다. 들어 올린 팔에 손 흔들기의 단단한 소매가 적용되지 않았다.
3. **앉기**: 옆 아빠다리는 무릎이 보이지 않아 신발 뒤에 쪼그려 앉은 듯 보인다. 앞 아빠다리 소매 끝에 가는 선이 있다. 책상 앞모습의 무릎이 두꺼운 맨살 덩어리처럼 보이고, 뒷모습 좌석은 각진 사다리꼴이다. 옆 아래팔은 쟁반을 든 듯 곧다. 앉은 자세는 숨쉬기가 없다.
4. **인사**: 옆 기뻐하기는 손이 머리 위에 얹혀 머리를 긁는 듯 보인다. 지도는 인사를 늘 앞모습으로 보여 주는데, 앞 고개 인사는 120px에서 거의 보이지 않는다. 여자 손 흔들기는 손이 단발 끝과 조금 겹친다. 펼친 손은 새로 그린 그림이며 **사용자 확인 전**이다.
5. **사다리**: 여자 뒷모습의 소매가 옆으로 날개처럼 뻗고 겨드랑이 절단선이 보인다. 여자는 단발이 손을 가린다. 지도에서는 오르는 속도(118px/s)가 팔다리 움직임의 약 6배라 손발이 사다리 칸에서 미끄러진다.
6. **기준 몸 생성기의 채움 자국**(이전부터 있던 문제, 팔이 움직이며 드러남): 남자 옆 셔츠의 어두운 줄, 여자 옆 반바지의 평평한 하늘색 사각형, 여자 뒤 셔츠 겨드랑이 절단선. 원인은 `tools/build-reference-body.py` `refill()`이 팔에 가려졌던 자리를 넓은 범위의 평균색 하나로 채우는 것이다. 생성기에서 고쳐 다시 만든다.
7. **발 미끄러짐**(물리 한계): 광장 카메라에서 땅이 걷기 337.5px/s로 지나가므로, 디딤발을 완전히 고정하려면 걷기 한 주기가 약 93ms여야 한다(현재 480ms). 미끄러짐 비율은 걷기 7.66배 → 5.15배, 달리기 3.42배 → 3.16배로 줄였다. 속도는 사용자가 정한 값이라 그대로 두었다.
8. **교실 의자 높이**: 교실은 옛 아바타의 골반 높이(SVG y 39.25)를 의자에 맞춘다. 새 책상 자세는 발은 그대로 두고 엉덩이만 약 3.4 내려 실제로 의자에 앉는다. 뒤에서 본 교실 화면은 자연스럽다. 기준 몸이 좌석 기준점을 직접 알려 주는 일은 5단계(모든 화면 적용)에서 한다.
9. **정지 화면 크기**: 정지 아바타 하나에 머리 세 방향과 뒷머리가 모두 들어 있어 약 1.1MB다. 30명 목록이면 크롬북에 부담이 될 수 있다(이전에도 같은 크기). 정지 화면에는 앞머리만 넣도록 줄이는 일은 5단계(모든 화면 적용·30명 성능)에서 한다.
10. 다른 머리스타일과 상점 옷은 새 모션에서 아직 보지 않았다(3~5단계).

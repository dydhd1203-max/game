# 퀴즈나라 사이트 배포

2026-10-01 기준 추천은 **Cloudflare Pages 무료 플랜 + GitHub 자동 배포**입니다. 현재 게임은 정적 웹 파일과 Firebase Realtime Database로 작동합니다. Pages의 정적 파일 요청은 무료이며, Firebase 사용량·유료 도메인·추가 서버 비용은 별도입니다. Netlify도 같은 배포 폴더를 사용할 수 있습니다.

한 번 연결하면 **사이트 주소 즐겨찾기 → 접속 → 로그인 → 햇살숲 마을**로 이용합니다. 수정본이 GitHub에 저장되면 Pages가 실행용 파일만 다시 배포합니다. 컴퓨터마다 저장소 ZIP을 받아 압축을 풀거나 `index.html`을 찾아 열 필요가 없습니다. 현재 로컬 `배포용/`도 최신 마을 버전으로 제공하며, 호스팅 계정의 Git 연결과 첫 공개는 별도 단계입니다.

## Cloudflare Pages에서 GitHub 연결

Cloudflare의 새 앱 생성 화면은 **Worker**로 먼저 열릴 수 있습니다. 화면에 **Configure your Worker project**, **Deploy command: npx wrangler deploy**, **Preview command**가 보이면 Worker 생성 단계입니다. 아래 설정은 **Pages**의 **Set up builds and deployments** 화면에서 입력합니다.

공식 [Workers & Pages 목록](https://dash.cloudflare.com/?to=/:account/workers-and-pages)으로 돌아가 **Create application → Pages → Connect to Git**를 선택합니다. UI에 Pages 탭 대신 시작 화면 아래 Pages 안내 링크가 있는 경우에는 해당 링크로 전환합니다. 저장소를 선택한 뒤 나오는 Pages 빌드 설정 화면을 사용합니다.

1. Cloudflare의 **Workers & Pages → Create application → Pages → Connect to Git**에서 Git 저장소를 연결합니다.
2. 저장소 **dydhd1203-max/game**, 배포 브랜치 **main**을 선택합니다.
3. **Build settings**의 Framework preset은 **None**으로 지정합니다. **Root directory (advanced)**를 펼쳐 Path에 **퀴즈나라**를 입력합니다.
4. 같은 Build settings의 Build command는 **node tools/build-deployment.cjs**, Build output directory는 **배포용**으로 지정합니다.
5. 배포 완료 후 제공된 `pages.dev` 주소로 접속합니다. 실제 수업은 `?demo=1` 없이 이용합니다.

이후 GitHub에 최신 버전이 올라가면 Pages가 같은 절차로 자동 배포합니다. 기존 Firebase 프로젝트와 사용자 데이터는 사이트 주소를 바꿔도 유지합니다. 기존 사이트에서 복사한 수업 링크는 새 사이트에서 다시 복사하여 공유합니다.

## 수동으로 배포하기

GitHub의 [최신 전체 ZIP](https://github.com/dydhd1203-max/game/archive/refs/heads/main.zip)을 내려받아 압축을 풉니다. **game-main/퀴즈나라/배포용** 폴더 전체를 Cloudflare Pages Direct Upload 또는 Netlify의 수동 배포 영역에 올립니다. `index.html`만 올리지 않습니다.

GitHub 자동 연결로 만든 Pages 프로젝트와 Direct Upload 프로젝트의 전환에는 제약이 있으므로, 계속 수정할 게임은 처음부터 GitHub 연결을 권장합니다.

개발 파일을 수정한 경우 `퀴즈나라` 폴더에서 다음 명령으로 배포본을 갱신합니다.

```bash
node tools/build-deployment.cjs
node tools/build-deployment.cjs --check
```

배포본에는 실행용 JS·CSS·원화·글꼴·`_headers`가 함께 들어갑니다. 사용자 원본 ZIP과 개발·검수 도구는 업로드하지 않습니다. `배포정보.json`에 각 파일의 크기·SHA-256이 있으므로 최신 개발본과 일치하는지 검사할 수 있습니다.

## Netlify에서 GitHub 연결

Base directory를 **퀴즈나라**로 지정합니다. 포함된 `netlify.toml`이 Build command **node tools/build-deployment.cjs**, Publish directory **배포용**을 설정합니다.

## 확인한 무료 플랜 기준

Cloudflare 공식 문서: [정적 요청 비용](https://developers.cloudflare.com/pages/functions/pricing/), [Pages 제한](https://developers.cloudflare.com/pages/platform/limits/), [Git 연결](https://developers.cloudflare.com/pages/configuration/git-integration/).

무료 Pages는 월 500회 빌드, 최대 20,000개 파일, 파일당 최대 25MiB입니다. 현재 실행 파일은 103개이고 가장 큰 로컬 아바타 데이터 파일은 약 20.2MiB이므로 이 제한 안에 있습니다. 원본 ZIP·에셋 검색 보관함과 개발 도구는 배포하지 않습니다. 웹 주소에서 아바타를 불러올 때는 일반 PNG를 사용하고, 로컬 실행용 데이터 파일은 로컬 파일 실행 등 필요한 경우에만 불러옵니다. 정적 파일 요청은 무료이며 무제한입니다. Functions를 추가하면 별도의 사용량 제한이 적용됩니다.

두 호스팅에 같은 게임을 배포한 속도 비교는 아직 수행하지 않았습니다. Pages도 CDN으로 정적 파일을 제공하며, 게임의 체감 속도는 이미지 크기·학교 네트워크·Firebase 응답의 영향을 함께 받습니다.

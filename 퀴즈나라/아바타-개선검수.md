## 직접 본 미술

이전 커밋 `ee17337014cb846a6e3c4de243c576f3acabc200`의 아바타 소스를 보관해 같은 옷·방향·동작으로 비교했다. 후드·여자 한복·여자 멜빵옷을 장식 없는 상태와 전체 장식 착용 상태로 각각 확인했다. 224px 시안과 실제 76px를 함께 보고 앞·좌우·뒤의 6자세, 장식 없는 착장의 앞·옆·뒤 걷기 8시점 전체, 전체 장식 착장의 대표 보행 시트 4장, 실제 학교의 걷기·대기·C 바닥/책상 앉기를 직접 확인했다. 점프 상승/하강은 포즈 라이브러리 시안으로 확인했다.

허리의 파란 돌출 조각, 멈춘 정면 소매, 발 디딤의 비대칭을 개선했고 한복·멜빵옷의 실루엣과 기존 얼굴·머리는 유지했다. 신발 입구와 가방 어깨끈의 연결도 실제 크기로 확인했다. 모자·안경의 작은 명암 차이는 큰 시안에서 더 잘 보이며 76px에서는 실루엣과 연결의 가독성을 우선한다.

**자동 접촉 검사를 통과한 뒤에도 옆 후드의 중복 피부 조각과 긴바지의 접힌 다리 아래 피부 면을 직접 발견했다.** 피부 다리·먼팔·몸통을 따로 숨긴 화면으로 원인을 구분해 옷에 가려져야 할 피부만 정리했고, 최종 시안과 영향받은 착장 검사를 다시 실행해 통과했다. 최종 직접 검수 범위에는 추가 수정이 필요한 주요 결함이 없었다. 숫자 통과를 미술 완료로 대신하지 않는다. 새 방향별 그림은 SVG 미술이며 정면 PNG와 완전히 같은 칠 질감이라고 표현하지 않는다.

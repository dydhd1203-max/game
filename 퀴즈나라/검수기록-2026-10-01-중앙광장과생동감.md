# 중앙 광장·국소 모션·강줄기 제거 검수

## 참고와 달랐던 이유

`map.zip` 3·4·6·7과 실제 기본 화면을 비교했다. 기존 화면은 잔디·포장의 대비가 높고 광장과 분수의 중심이 달랐다. 집별 연결길이 겹쳤고 벤치·우물의 마당이 구분되지 않았다. 평지 물가에 떠 있는 섬 원본의 깊은 밑면이 그대로 나와 물의 높이도 읽기 어려웠다. 에셋 수보다 소재의 시점·크기와 배치 관계가 문제였다.

## 최종 적용

- 제공 `map.zip` 7번의 `[910,706,180,136]` 잔디, 3번의 `[1380,1000,110,60]` 포장만 부분 표시한다. 원본 바이트를 유지하고 글자·UI·사물을 제외했다. 정확한 파일은 `QPVillageScene.groundSources`와 소재 목록에 기록했다.
- 광장 중심은 raw `(919,950)`, 분수 발 앵커는 `(919,960)`이다. 분수의 실제 바닥 중심을 광장에 맞췄다. 학생 입장은 남쪽 `(919,1055)` 주변에 나누고 분수 둘레를 비웠다.
- 우물·수레는 빵집 마당, 벤치는 잔디 쉼터로 모았다. 새 길과 겹친 나무·바위·꽃은 길 밖으로 옮겼다. 수관이 길에 드리우는 겹침은 유지한다.
- 중앙 계단 원화 폭과 실제 경사를 함께 줄였다. 발 위치와 높이 변화는 원화 계단 면을 따른다.
- **어색했던 긴 강줄기·두 다리·추가 낙수는 제거했다.** 그림뿐 아니라 지형 정의, 물 충돌, 다리의 물 통과 예외, 옛 발견 안내도 정리했다. 높은 길은 다시 이어 붙이고 아래 길은 남겨 둔 연못 북쪽을 지나도록 연결했다.
- 물은 제공 `water.zip`의 **단독 원본 연못 한 곳**과 기존 중앙 분수만 사용한다. 연못은 `0e50` 시트 `[0,331,476,323]`의 얕은 돌 테두리와 수면을 표시한다. 깊고 뾰족한 섬 밑면과 다른 원본의 덧붙인 폭포는 제외했다. 원본 물 픽셀만 고정 경계 안에서 약하게 움직인다.
- 기존 분수 물줄기·수면, 나무 수관과 꽃, 랜턴 유리에 작은 움직임을 더했다. 줄기·뿌리·돌·충돌 위치는 고정한다. 화면 밖 식생, 숨긴 탭·모달·동작 줄이기 설정 및 장면 종료를 처리한다.

## 잘못된 강물 검수를 바로잡은 이력

1차 기능 검수는 15개 입장 위치·18개 목적지, 분수 둘레 이동·충돌, 계단 상승·하강, 상점·교실 연결과 물 진입 차단을 확인했다. 그러나 사용자는 이후 **강물이 길에서 끊겨 보이고 다리가 마른 길 위에 놓인 듯하며 물 그래픽이 어색하다**고 지적했다. 통행 기능 검사가 도로가 물을 덮는 시각 오류를 잡지 못했다.

도로와 수면을 다시 조합한 뒤에도 사용자는 강물 그래픽을 거부하며 제거해도 된다고 했다. 최종본은 강물 보수안이 아니라 위의 **강줄기·다리 제거안**이다. 이전 109파일 빌드와 강물 영상·검사 결과는 최종 물 미술 검수가 아니다. 다리 통과를 요구하던 회귀 검사도 현재 지형의 연결된 땅길과 단독 연못 차단으로 교체한다.

## 현재 검수 범위

실제 Chromium PC 화면과 격리된 체험 모드를 사용한다. Firebase SDK를 차단하며 실제 학생·수업 데이터에는 쓰지 않는다.

- 최종 단독 연못은 실제 이동 후 1366×768·1920×1080 화면을 저장했다. 원본 연못 한 곳, 강줄기·두 다리 제거, 수면 3프레임 변화와 고정 돌 테두리, 정지·동작 줄이기, 물/돌/삭제된 다리 예외 영역의 경계 6건을 확인했다. 브라우저 오류 0건이다. 자료: `검증/원본-연못-최종-2026-10-01/`.
- 분수 물과 수관의 연속 동작·고정 기둥/뿌리, 실제 모달 정지·재개, 재입장 중복 없음, 동작 줄이기·종료 정리는 강물 제거 직전 동일한 ambient 모듈에서 검사했다. 마지막 변경은 물 지형 제거이며 ambient 모듈을 바꾸지 않았다.
- 최종 배포본으로 1366×768·25fps·9초 영상을 다시 기록했다. 긴 강줄기·두 다리가 없는 실제 입장 화면이다. 자료: `검증/마을-생동감-2026-10-01/통합-마을-환경모션-9초.webm`. 이전 같은 이름의 영상은 교체했다.
- 기능·영상 검수 시점의 배포 파일 수: **108**. 빌드 시각(UTC): `2026-10-01T13:16:12.607Z`. manifest SHA-256: `f516941a120f79183f8c32145918b918acd23f0195248c49cfb2cd052f6c554c`.

실제 공개 Cloudflare 주소나 학교 Windows 기기를 검사한 결과는 아니다. 재생성 가능한 `검증/` 출력은 Git에 포함하지 않는다. 최종 연결길·연못·배포 HTTP 검사는 아래에 별도로 기록한다.

## 고정 지침 정비

[숲속마을-디자인지침.md](./숲속마을-디자인지침.md)를 작성하고 `AGENTS.md`·`디자인기준.md`에서 우선 적용하도록 연결했다. 예쁨·정갈함·풍성함·호기심을 화면 결과와 판정 기준으로 정의했다. 기존의 빈 공간 채우기, 큰 바닥을 일괄 미완성으로 보는 표현, 맵 추가 제작, 거리별 임의 축소, 소재 선택 순서 등 다섯 모호한 지침을 교정했다. 현재 강줄기 제거 결정과 소수의 국소 모션 기준도 저장했다.

## 미술상 남은 차이

기존 승인된 건물·나무 원화는 유지했다. 제공 연못과 건물의 붓터치에는 차이가 있고 원본 JPEG 왼쪽의 짧은 직선 암반 경계가 남는다. `map.zip`과 화풍이 완전히 같거나 사용자가 만족한 상태라고 판단하지 않는다. 이음새를 장식으로 가리는 대신, 다음 연못 교체가 필요하다면 해당 지형에 맞는 완결된 원본을 먼저 고른다. 이번 변경은 중심·바닥 대비·동선·접지·국소 움직임과 불필요한 강줄기 제거 패치다. 기능 검사 통과와 사용자의 미술 만족은 별개다.

## ZEP 링크 열람 상태와 기록 정정

사용자가 제공한 `https://zep.us/play/M0vOnp`의 소개 페이지 제목은 ‘아바톡 월드_Copy’다. 이 페이지의 HTTP 자원은 열렸지만 실시간 WebSocket 연결에서 브라우저 인증서 오류가 발생했고 공간 입장 화면에는 `unknown-error`가 표시됐다. **이 시점에는 실제 맵과 애니메이션이 미확인**이었다. 소개 이미지 역시 맵이 아닌 서비스 공간의 안내 이미지다.

사용자가 접속하지 못한 링크를 참고자료로 저장해도 되는지 지적하여, 지침의 모호한 ‘참고 기준’ 표현을 삭제하고 **접속 실패·열람 대기 링크**로 정정했다. ‘깔끔한 배치와 약간의 자연스러운 애니메이션’은 사용자 설명에서 확인한 요구사항으로만 기록했다. ZEP의 실제 배치·화풍·모션을 관찰했다고 주장하거나 현재 패치 검수의 근거로 사용하지 않는다.

이후 기존 환경의 프록시와 인증서 신뢰를 이용한 Node WebSocket 연결로 입장했다. TLS 검증을 끄지 않았고 연결의 authorized=true, WebSocket 오류 0을 확인했다. 실제 첫 광장을 연 뒤 공지창을 닫고 1.5초 간격의 3개 화면을 저장·직접 열었다(`검증/ZEP-첫광장-2026-10-01/`). 넓은 흙길과 조용한 잔디, 중심 단상, 길 가장자리의 안내·소품 배치를 확인했다. 연속 화면에서 나무 주변의 작은 잎 입자, 굴뚝 증기, 포털 빛과 반짝임이 달라지고 지형과 고정 사물은 유지됐다.

**실제 확인한 범위는 첫 광장과 약 3초의 대기 모션뿐**이다. 다른 지역·이동·상호작용은 확인하지 않았다. 초기 미확인 기록을 숨기지 않고 위 추가 관찰 범위만 지침에 반영했다. 외부 맵의 이미지·에셋은 게임에 가져오지 않았다.

## 강물 제거 뒤 최종 배포 검사

`QUIZ_VILLAGE_LAND_WATER_ONLY=1`로 실제 `배포용/index.html`의 관련 검사만 실행해 exit 0을 확인했다. 강물·다리 그림/지형 제거, 높은 길 실제 걷기, 연못 북쪽 산책길 실제 걷기, 단독 연못 클릭·키보드 진입 차단, 상점·교실 연결의 **5개 검사 모두 통과**했다. 연못의 10px 간격 수면 표본 176개가 모두 차단되며 발 반경과 삭제된 다리 예외 영역도 물 진입을 허용하지 않는다. 브라우저 오류와 HTTP 404는 0건이다. 1366×768·1920×1080 캡처와 경로·입력 기록은 `검증/강물제거-단독연못-2026-10-01/`에 있다.

검사 초안의 상류 마지막 목표가 관측탑 벽 안에 있어 실패했으므로 실제 포장된 상류 구간으로 검수 좌표를 수정하고 재실행했다. 런타임 충돌을 완화하거나 지형을 바꾸어 검사를 통과시키지 않았다. 최종 배포본 108개 전체의 소스·배포 파일·실제 HTTP 응답 해시가 일치했다. `check-source`, 소재 목록 일치 검사, 배포본 `--check`, `git diff --check`도 통과했다.

기능 검수 후 조작 도움말과 막힘 안내에 남은 “다리” 표현 두 곳을 “계단·밧줄” 및 “열린 길·계단”으로 수정했다. 이동 로직·지형·미술은 동일하다. 문구 수정 후 `check-source`, 배포본 생성·일치 검사 및 108개 HTTP 해시를 다시 확인했다. 마지막 빌드 시각(UTC)은 `2026-10-01T13:34:03.099Z`, manifest SHA는 `a4d511294d322a87549fc5f678acfc4a4557a8b42ed350358eb1a4fff6967f58`다. 기능 검사는 위 시점의 결과로 유지하며 문구 수정 뒤 전체 이동 검사를 다시 실행했다고 주장하지 않는다.

# 퀴즈나라 개발·실행 환경

갱신: 2026-10-01

이 문서는 `퀴즈나라/` 폴더의 퀴즈 게임만 설명합니다. 사용 순서는 [사용법.md](./사용법.md)를 봅니다.

## 저장소와 기준 파일

저장소는 `https://github.com/dydhd1203-max/game`이며, 개발 기준 파일은 저장소의 `퀴즈나라/index.html`입니다. 기존 게임의 파일이나 배포 폴더를 수정할 필요가 없습니다.

별도 프레임워크 빌드는 없습니다. 브라우저가 HTML, `avatar-pixel.js`, `avatar-clothes.js`, `avatar-effects.js`, `qplay.css`, `button-feedback.css`, `demo.js`와 `assets/`의 원화·글꼴을 읽습니다. 남자·여자 각각 12종 헤어 원화가 있으며 얼굴은 기본 상품을 포함해 8종입니다. 상의 14종과 하의 11종은 별도 세밀 원화를 12색으로 염색합니다. 햇살 천사는 몸·후광과 양 날개를 분리해 CSS로 움직입니다. 피부색 통일, 눈을 감는 모습과 표시 크기는 [디자인기준.md](./디자인기준.md)를 따릅니다. 원화 생성 프롬프트는 `assets/`의 제작 기록에 보관합니다.

## 로컬 미리보기

Node.js가 있는 터미널에서 `퀴즈나라` 폴더로 이동해 실행합니다.

```powershell
node tools/preview-server.cjs
```

`http://127.0.0.1:4173/?demo=1`은 격리된 체험 모드입니다. Firebase 대신 localStorage에 저장하며, 체험 메뉴와 컴퓨터 친구 세 명으로 세 게임과 상점을 확인할 수 있습니다. 친구들은 퀴즈에 답하고 OX를 선택하며 두 팀의 퍼즐을 진행합니다. 실제 Firebase 데이터에는 쓰지 않습니다.

`http://127.0.0.1:4173/`은 실제 모드입니다. HTML 위쪽 Firebase 설정을 사용하고 실제 Firebase SDK를 불러옵니다. 실제 수업의 계정·문제·방·패션왕 데이터는 `quiz` 경로를 사용합니다. 선생님 브라우저가 채점을 진행하므로 수업 중에는 열어 둡니다. 이번 변경에는 백엔드 인증·권한 정책 변경이 포함되지 않습니다.

## 배포용 파일 맞추기

수정 후 아래 개발 파일을 `퀴즈게임/`의 같은 상대 경로에 복사해 일치시킵니다.

`node tools/sync-deployment.cjs`로 `tools/deployment-files.cjs`에 명시한 모든 실행 파일을 함께 복사하고, `node tools/check-source.cjs --deployment`로 일치 여부를 확인할 수 있습니다.

GitHub의 기존 배포 경로는 저장소 루트의 `퀴즈게임/`입니다. 그 경로도 갱신할 때는 `node tools/sync-deployment.cjs --root-deployment`, `node tools/check-source.cjs --root-deployment`를 사용합니다. 두 명령은 퀴즈 실행 파일만 다루며 좀비 게임 폴더에 쓰지 않습니다.

| 개발 기준 | 배포용 |
|---|---|
| `index.html` | `퀴즈게임/index.html` |
| `avatar-pixel.js` | `퀴즈게임/avatar-pixel.js` |
| `avatar-clothes.js` | `퀴즈게임/avatar-clothes.js` |
| `avatar-effects.js` | `퀴즈게임/avatar-effects.js` |
| `qplay.css` | `퀴즈게임/qplay.css` |
| `button-feedback.css` | `퀴즈게임/button-feedback.css` |
| `demo.js` | `퀴즈게임/demo.js` |
| `assets/pixel-heads-v2.png` | `퀴즈게임/assets/pixel-heads-v2.png` |
| `assets/pixel-heads-male-v2.png` | `퀴즈게임/assets/pixel-heads-male-v2.png` |
| `assets/pixel-tops-v3.png` · `pixel-bottoms-v3.png` | `퀴즈게임/assets/` |
| `assets/angel-effect.png` | `퀴즈게임/assets/angel-effect.png` |
| `assets/quiz-studio.webp` | `퀴즈게임/assets/quiz-studio.webp` |
| `assets/fonts/`의 나눔스퀘어라운드 400·700·800과 라이선스·출처 | `퀴즈게임/assets/fonts/` |

Netlify에는 `_headers`를 포함한 **`퀴즈게임/` 폴더 전체**를 업로드합니다. HTML만 업로드하면 이미지나 스타일이 빠집니다. 다른 게임의 사이트와 분리하여 배포합니다.

## 검증 범위

`tools/check-source.cjs`는 개발·배포 HTML과 외부 스크립트의 문법을 확인합니다. `tools/verify-game.cjs`는 격리된 체험 모드의 세 게임과 구매 흐름을 확인하는 브라우저 검증 도구입니다. 브라우저 검증에는 도구가 사용하는 Playwright와 Chrome 실행 환경 및 실행 중인 로컬 미리보기 서버가 필요합니다.

`node tools/verify-demo.cjs`는 체험 메뉴에서 퀴즈 → OX → 팀 퍼즐로 전환하고, 컴퓨터 친구 세 명의 답변·점수와 두 팀의 퍼즐 진행을 확인합니다. 확인 화면은 `검증/체험-퀴즈.png`, `검증/체험-OX.png`, `검증/체험-팀퍼즐.png`에 저장합니다.

`node tools/verify-art.cjs`는 피부색·머리·얼굴·상의·하의를 다르게 조합한 전신 아바타 여섯 명을 크게 표시해 `검증/아바타-디테일.png`에 저장합니다. 이 이미지는 원화와 옷의 선명함, 머리 위치와 피부색을 눈으로 비교하는 자료입니다. 자동 검사만으로 미술 품질을 판정하지 않으며, [디자인기준.md](./디자인기준.md)에 따라 실제 로비·꾸미기·게임 화면도 함께 확인합니다.

`node tools/verify-economy.cjs`는 추가 패키지 없이 실행합니다. 실제 계정 저장·연습 보상·수업 지급·구매 함수로 보상 중첩, 일일 한도, 재시도와 로그인 전환 시 계정 혼동을 검사합니다.

`node tools/verify-avatar-motion.cjs`는 같은 의상을 입은 남녀 아바타의 서로 다른 원화와 뜬 눈·반쯤 감은 눈·감은 눈을 실제 애니메이션 시점별로 확인합니다. `node tools/inspect-outfits.cjs`는 상의·하의 전체 조합을 큰 그림으로 저장합니다. 효과음·BGM 검증은 `node tools/verify-audio.cjs`로 실행합니다.

`node tools/verify-feedback.cjs`는 실제 Chrome에서 첫 클릭의 음향 준비, 버튼 누르기·복원, 주변 배치 유지, Enter·Space, 비활성 버튼, OX 위치·선택음 중복과 모션 줄이기를 확인합니다.

`node tools/verify-clothes.cjs`는 원화 25종의 분리와 125개 색 조합에서 염색·장식·투명도 유지, 다섯 전신의 상의/하의 분리를 확인합니다. `node tools/verify-effects.cjs`는 천사 구매 520골드 차감, 펫 동시 착용, 상점 날갯짓, 벗기와 무료 재착용을 확인합니다.

주 사용 환경은 LG 그램과 크롬북입니다. 1920×1080, 1440×900, 1366×768, 1280×632, 1024×632 크기의 브라우저 화면에서 노트북 배치를 확인합니다. `verify-layout.cjs`는 내 아바타 배경의 경계·가운데 정렬·중복 배경과 스크롤바도 검사합니다. 실제 교실 기기 성능은 해당 기기에서 따로 측정해야 합니다. 기존 다른 게임의 FPS 측정 결과는 이 퀴즈 게임의 성능 근거로 사용하지 않습니다.

## 다른 컴퓨터에서 이어서 작업하기

개발 기준은 이 `퀴즈나라/` 폴더입니다. 저장소 루트의 `index.html`과 `배포용/index.html`은 최적화 중인 좀비 게임이므로 수정하거나 배포에 포함하지 않습니다. 퀴즈의 실행 파일 목록은 `tools/deployment-files.cjs`에 있습니다.

최신 퀴즈에는 세밀한 남녀 아바타, 상의·하의 분리와 12색, 자연스러운 눈 깜박임, 펫과 함께 착용하는 천사 이펙트, 푸른 퀴즈쇼 무대, 나눔스퀘어라운드 글꼴, 칸 안에 맞춘 프로필 배경과 버튼 반응이 들어 있습니다. 사용자 스크린샷과 최소 미술 기준은 `디자인기준/` 및 `디자인기준.md`를 확인합니다. 이미지·글꼴의 출처와 제작 기록은 `assets/`에 보관합니다.

집 컴퓨터에서는 저장소의 최신 버전을 받은 뒤 이 폴더에서 `node tools/preview-server.cjs`를 실행해 미리 봅니다. `?demo=1&scene=quiz`는 실제 수업 데이터에 쓰지 않는 체험 화면입니다. 수정 후 `node tools/sync-deployment.cjs`, `node tools/check-source.cjs --deployment`로 배포 폴더를 맞춥니다. 화면 검증 이미지는 다시 만들 수 있으므로 GitHub 업로드에서 제외합니다.

로컬 실행은 해당 컴퓨터가 켜져 있어야 합니다. 클라우드 작업은 최신 코드와 원화를 사용할 수 있는 저장소 환경에서 별도로 시작해야 하며, 이 저장소를 업데이트하는 것만으로 현재 채팅이 클라우드 작업으로 전환되지는 않습니다.

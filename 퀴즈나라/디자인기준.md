# 퀴즈나라 맵·화면·아바타 디자인 기준

마을의 최신 필수 기준은 [숲속마을-디자인지침.md](./숲속마을-디자인지침.md)다. **예쁨·정갈함·풍성함·호기심**을 실제 화면과 이동으로 판정하며, 맵의 소재 선택·밀도·축척·제작 순서가 아래 과거 참고와 충돌하면 새 지침을 적용한다. 아바타·학생 UI의 별도 품질 기준은 유지한다.

## 최종 맵 소재 제한

2026-10-01 광장·생동감 기준: 분수의 바닥 중심과 광장 중심을 맞추고 주변에 연속 보행 고리와 학생 입장 공간을 확보한다. `map.zip`처럼 조용한 바닥, 일관된 시점·크기, 알아보기 쉬운 중심과 길을 먼저 구성한다. 원본 개수로 풍성함을 판단하지 않는다. 집·정원·쉼터 소품은 용도별로 모으고 짧은 현관길을 주동선에 연결한다. 물가는 평지 높이에 맞춰 원본의 표면·해안 부분만 사용하며 떠 있는 섬의 밑면을 붙이지 않는다. 물·수관·꽃·등불의 국소적인 움직임을 사용하되 건물·돌·줄기·뿌리·충돌 위치는 고정한다. 실제 연속 프레임에서 움직이는 부분과 고정 부분, 숨긴 탭·모달·화면 밖·동작 줄이기 설정을 확인한다.

2026-10-01 사용자 지시: **“맵 디자인은 에셋만을 이용하기로 지침에 넣어.”** 새 맵의 보이는 그래픽은 사용자가 제공한 원본 에셋을 선택·배치·조합해서 만든다. 돌담·길·지형·물·연못을 임의 SVG 그림이나 새 AI 생성 이미지로 대신하지 않는다. 원본의 부분 표시·클리핑·타일 배치와 실제 충돌·길 찾기는 구현할 수 있다. 필요한 소재가 없으면 부족한 종류를 구체적으로 알리고 추가 에셋을 요청한다. `water.zip`의 물·물가 자료를 기본 보관함에 등록한다. 집·나무·벤치의 바닥은 보행로 밖 마당·화단·쉼터에 두고 출입구만 작은 길로 연결한다. 이 지시는 모든 맵 제작에 우선하며, 이미 승인된 아바타 뼈대와 기존 원화 보존은 유지한다.

## 제공 에셋으로 학생 화면을 만드는 순서

최신 사용자 지시(2026-10-01): **PC·노트북 학생 화면에 미술을 집중한다. 모바일은 추가 작업하지 않는다. 교사 화면은 문제 작성과 수업 진행이 편하면 충분하다. 제공한 에셋을 많이 활용해 UI·아바타·맵을 풍성하게 만들되 가독성을 유지한다.** 이 지시는 이전 모바일·교사 장식 작업 기준보다 우선한다.

1. **장소 계획에 맞춰 에셋을 선택한다.** 맵은 장소의 역할·중심·입장 위치·주동선·쉴 여백을 먼저 정한다. [전체 소재 보관함](assets/library/index.html)에서 화면의 목적에 맞는 건물·나무·풀·꽃·소품·아이콘·프레임을 고르고 실제 원본을 연다. 선택한 파일, 사용할 부위와 위치, 준비 상태를 작업 기록에 남긴다. 원본을 직접 쓸 수 있으면 재사용하고 JPEG 시트의 필요한 영역·클리핑·앵커를 준비한다. 맵 소재가 부족하면 필요한 에셋을 요청한다. 파일명이나 자료 수만으로 활용 완료를 판단하지 않는다.
2. **숲속 마을의 장소를 구성한다.** 큰 볼거리와 길을 정하고 전경의 식생·바위, 중경의 집·아바타·퀴즈 사물, 후경의 숲·지형·빛이 겹치게 만든다. 집 옆 화단·간판·울타리, 개울 옆 수초·돌·다리처럼 주변 자료가 연결되어야 한다. 크기·수종·소품 무리를 바꾸고 화면 가장자리까지 자연스럽게 이어간다.
3. **서로 어울리게 조합한다.** 같은 재질·시점·광원·화풍의 자료를 먼저 묶는다. 수관의 밝고 어두운 덩어리, 지붕·벽·바위의 면, 발밑 접촉 그림자를 맞춘다. 매끄러운 SD 아바타와 기존 원화를 유지하며, 도트 자료가 있다는 이유로 아바타 스타일을 바꾸지 않는다.
4. **학생 UI를 풍경과 연결한다.** 메뉴·상점·문제·결과 창은 나무·크림색 종이·금색·이끼 녹색 재질로 묶는다. 잎·꽃·덩굴·버섯·아이콘은 창의 모서리와 주변부에 배치한다. 글씨·선택지·상품·가격·조작 버튼 위에는 장식을 겹치지 않는다. 실제 버튼과 입력은 유지하며 참고 화면 전체를 기능 화면처럼 붙이지 않는다.
5. **아바타를 입힌 상태로 완성한다.** 현재 SD 뼈대·큰 눈·둥근 비율을 유지하고 얼굴·헤어·옷·신발·펫·장식을 부위별로 조합한다. 목·소매·허리·손목을 붙이고 머리장식의 위치와 발바닥 접지를 맞춘다. 뜬 눈·감은 눈과 걷기·점프·앉기에서 옷이나 장식이 뜨거나 표정이 깨지지 않아야 한다.
6. **읽기·이동 공간을 확보한다.** 질문·답안·이름·점수는 밝고 차분한 바탕, 충분한 글자 크기와 명확한 대비를 사용한다. 장식은 주변으로 보내고 이동 길·상호작용 사물·클릭 영역을 확보한다. 맵의 풍경 사물과 실제 충돌·퀴즈 접근이 일치해야 한다.
7. **학생 대표 화면으로 판정한다.** 한 화면을 먼저 완성해 PC·노트북의 실제 기본 시점에서 사용자 참고와 나란히 비교한다. 깊이·입체감·재질·장소의 밀도·가독성·의상 착용을 확인하고 부족한 부분을 다듬은 뒤 확장한다. 사용한 자료와 위치, 변경 전후 화면, 남은 미술 과제를 기록한다. 교사 편집 화면이나 별도 조망 캡처, 자동 검사 통과는 학생 화면의 미술 완료를 대신하지 않는다.

## 상시 최우선 기준

사용자 고정 요청(2026-10-01): **“아이들이 좋아하는 맵과 디자인, 아바타 디자인에 공을 제일 많이 들여야돼. 고정지침에 추가해서 항상 기억해줘.”** 퀴즈나라에서는 맵·UI·아바타의 미술과 놀이 경험에 가장 많은 공을 들인다. 아이들이 화면을 보고 탐험하고 싶고, 자기 아바타를 꾸미고 싶어 하는 세계를 만든다. 기능을 붙인 임시 도형이나 단조로운 배경으로 미술 작업을 끝내지 않는다.

사용자 제공 소재팩에서 어울리는 자산을 먼저 선택해 활용하고, 참고 화면의 배색·재질·구도·세밀함을 맵 원본의 선별·배치·조합에 적용한다. 아바타·UI 원화 제작은 해당 별도 기준을 따른다. 게임 화면은 세계의 깊이와 이동할 공간, 다가가고 싶은 NPC·사물, 또렷한 문제와 조작 버튼을 함께 갖춘다. 미술을 추가할 때도 학생의 이름·팀 색·입력란·점수·타이머를 가리지 않는다. 주 사용 환경인 LG 그램·크롬북의 실제 노트북 화면에서 확인한다.

2026-10-01에 제공한 숲·계곡·마을·산길·Kingshot·도시·숲속 정원 이미지는 **맵의 최소 미술 목표**다. 건물은 같은 원근과 조명 아래 지붕 기와·처마·벽의 두께·창틀·목재 결을 갖추고, 식생은 다른 수종·잎 덩어리·그늘·꽃 군락으로 구성한다. 절벽·개울·다리는 높낮이와 연결 관계를 읽을 수 있게 만든다. 밝은 길과 조용한 이동 공간을 남겨 퀴즈 사물과 아바타가 장식에 묻히지 않게 한다. 참고 이미지와 현재 실제 게임 화면의 품질 차이를 솔직히 기록하며, 자동 검사 통과를 이 미술 목표의 달성으로 바꾸어 보고하지 않는다.

## 다섯 퀴즈 방식의 맵 기준

아래 내용은 이후 맵 수정에서도 지켜야 하는 고정 규칙이다. 같은 문제 묶음을 사용해도 각 방식의 장소와 놀이가 화면에서 구분되어야 한다.

| 방식 | 장소와 필수 표현 | 실제 플레이 검수 |
|---|---|---|
| 순서풀이 (`sequence`) | 울타리 안 고정 숲길, 구불구불 이어지는 경로와 꿀단지 관문. 정답 전에는 닫히고 정답 뒤 자기 관문만 열린다. | 시작 위치에서 다음 관문까지 길을 따라 갈 수 있는지, 오답 때 막히는지, 정답 뒤만 통과하는지 확인한다. 대각 이동·점프로 울타리나 닫힌 관문을 우회하지 못해야 한다. |
| 자유풀이 (`free`) | 성·용암·사막·숲 구역을 갖춘 넓은 2D 탐험 세계. 구역의 지형·장식·NPC를 구분한다. | 각 구역으로 이동해 NPC·사물 가까이에서만 문제를 여는지, 모든 문항에 접근 가능한지 확인한다. 멀리서 사물을 눌러 열리지 않아야 한다. |
| 라운드전 (`round`) | 학생마다 체크무늬 소풍 돗자리 한 장. 시작할 때 아바타가 자기 돗자리 위로 자동으로 걸어 들어간다. | 입장 애니메이션과 실제 도착 위치를 확인한다. 모두 같은 문제·남은 시간을 보고 답하며 공개 뒤 점수와 마지막 순위가 보이는지 확인한다. |
| 팀전 (`team`) | 울타리 안 가을 퀴즈 경기장. 단풍·경기장 장식·팀 색으로 장소와 소속을 쉽게 알아본다. | 경기장 안에서 이동·문제 접근·경계 충돌을 확인한다. 무작위 배정은 팀 간 인원 차이가 최대 한 명인지, 개인 완료와 팀 점수 합산이 구분되는지 확인한다. |
| 협동전 (`coop`) | 함께 도전하는 탐험 맵과 반 공동 정답 수·목표·제한 시간을 보여 주는 안내. | 학생별로 완료가 독립적인지, 반 전체 정답 수가 중복 없이 더해지는지, 마감 전 목표 성공과 시간 종료 결과가 구분되는지 확인한다. |

선 잇기는 고른 짝 사이에 실제 선을 그려 연결을 알아볼 수 있게 한다. 순서 맞추기는 섞인 항목을 직접 옮기거나 위·아래 버튼으로 바꾸고 현재 순서를 읽기 쉽게 표시한다. 일반 퀴즈의 유형은 객관식·주관식·선 잇기·순서 맞추기이며 기존 OX는 별도 화면으로 유지한다.

걷기·점프·앉기는 원화의 팔·다리·몸 포즈로 표현한다. 메인 로비의 **움직임 연습**에서 내 아바타로 조작을 익히고 맵에서도 같은 품질을 유지한다. 이동 중에도 얼굴·옷·신발·펫·천사 이펙트의 세밀함, 눈 깜박임과 숨쉬기를 보존한다.

완료 전 각 방식의 실제 학생 시작 시점, 진행 경로, NPC·관문 앞, 문제 입력, 정답 뒤 이동, 결과 화면을 저장하고 이미지를 직접 연다. 캡처한 화면의 미술, 키보드·화면 버튼의 조작, 이동할 길, 경계와 관문의 충돌을 함께 확인한다. 조망 화면이나 자동 검사 통과만으로 미술·플레이 완성이라고 판단하지 않는다. 구현됨·직접 확인됨·미확인 항목을 구분한다.

## 아바타 미술 기준

2026-10-01 사용자의 최종 선택은 아래의 **일러스트형 SD 아바타**다. 이전 도트 스타일은 폐기하며, 얼굴·피부·의상·꾸미기의 세밀함을 유지하는 아래 원칙은 새 원화에도 적용한다.

- 귀여운 패션 인형처럼 큰 얼굴과 둥근 몸을 그린다. 몸통·손·다리·옷이 사각형을 쌓은 모양으로 보이면 다시 작업한다.
- 부드러운 윤곽과 반투명 가장자리를 유지하면서 눈의 반짝임, 눈썹, 입, 머리카락의 결과 명암을 보존한다. 작은 그림을 과도하게 축소한 뒤 늘려서 디테일을 잃지 않는다.
- 기존 원화의 처리 해상도만 늘린 것으로 미술 개선을 완료했다고 판단하지 않는다. 세밀함이 부족하면 원화의 눈·머리카락·옷 선 자체를 새로 그린다.
- 머리카락과 얼굴의 위치를 맞춘다. 떠 있는 머리 조각, 목 사이의 틈, 겹쳐 보이는 이목구비가 없어야 한다.
- 얼굴·귀·목·팔·손·다리에는 같은 피부 팔레트를 쓴다. 그림자와 볼터치는 의도한 색 변화만 허용한다.
- 상의와 하의를 따로 사고 입힌다. 두 부위가 보일 만큼 몸통과 다리 공간을 확보하고, 어깨선·소매·옷자락·허리선·주름·신발을 구분한다.
- 로비와 꾸미기에서는 전신 디테일이 보일 만큼 크게 표시한다. 게임에서도 얼굴과 착용 의상을 알아볼 수 있어야 한다.
- 얼굴, 헤어, 의상, 장신구, 펫, 이펙트, 액자의 그림 밀도와 윤곽선 스타일을 통일한다.
- 로비·꾸미기·게임에서 계속 숨쉬고 깜빡인다. 게임 화면을 갱신할 때 움직임이 처음부터 반복되어 멈춘 듯 보이지 않게 한다.
- 얼굴·머리카락은 서로 붙은 한 덩어리로 안정적으로 움직인다. 숨쉬기와 펫의 포즈는 부드럽게 이어지고, 눈 깜박임·천사 날갯짓·주변 반짝임을 유지한다. 창 크기와 화면 배율이 바뀌어도 얼굴 떨림이나 원화 깨짐이 없어야 한다.
- 첫 화면과 상점 옆 전신은 과도하게 확대하지 않는다. 로비는 252~280px, 옷장·상점은 280~300px 높이로 표시하고, 원화 준비 전 임시 도형이나 가공 전 얼굴을 노출하지 않는다.
- 상점·옷장·무작위 꾸미기·게임 참가자의 헤어는 선택한 남녀 구분에 맞춘다. 남자는 짧은 머리·스포츠머리·가르마·덥수룩·프렌치 크롭·바가지머리·페이드컷·언더컷·올백머리·곱슬 웨이브·쉼표머리·울프컷 12종, 여자는 단발·긴 머리·양갈래·포니테일·곱슬 단발·만두 머리·히메컷·땋은 머리 8종을 사용한다. 성별을 바꿔도 돈과 소유 아이템은 보존한다. 머리색만 다른 상품을 새 실루엣으로 세지 않는다.
- 펫도 눈·털·귀·발을 구분하는 새 원화로 그린다. 신발은 끈·밑창·버클·재질이 구별되어야 하고 팔·손·다리는 옷과 어울리는 가는 윤곽과 피부 명암을 쓴다. 얼굴만 세밀하고 나머지가 단순한 사각형으로 보이는 조합을 완료로 판단하지 않는다.
- 눈을 감을 때는 반쯤 감은 눈과 완전히 감은 눈을 별도로 그린다. 피부 사각형을 늘려 눈을 덮거나 눈 자체를 납작하게 찌그러뜨리지 않는다. 눈썹·볼터치는 유지하고 짧게 닫혔다 자연스럽게 열린다.
- 남자·여자 얼굴 원화와 몸 표현을 구분한다. 같은 옷을 입혀 비교할 수 있어야 하며, 피부색·소유 아이템·착용 조합은 변경 때 유지한다.
- 최종 확인은 실제 게임에서 밝은 피부와 어두운 피부, 여러 머리색, 상의와 하의, 장신구를 함께 입힌 화면으로 한다. 정지 원화만 확인해서 완료로 판단하지 않는다.
- 얼굴 주변의 머리 색과 피부 경계를 실제 원화의 경계로 구분한다. 머리색을 바꿨을 때 관자놀이·턱 아래에 사각형 색 덩어리가 남거나 눈을 감았을 때 기존 속눈썹이 겹쳐 보이면 수정한다. [신고한 얼굴](디자인기준/14-얼굴겹침-수정기준.png)을 뜬 눈·반쯤 감은 눈·감은 눈으로 비교한다.
- [천사 이펙트 참고](디자인기준/15-천사이펙트-참고.png)처럼 아바타 옆의 노란 동그란 천사에는 몸의 부유와 양 날개의 독립적인 움직임을 넣는다. 펫과 별도로 착용하며 실제 표시 크기에서 얼굴·이름·문제·입력 버튼을 가리지 않게 한다.

제공한 아바타 소재에서 실제 조합할 수 있는 부분을 검토하고 현재 SD 원화와 함께 활용한다. 전체 캐릭터 JPEG 시트는 부위별 착용 레이어가 아니므로 필요한 얼굴·헤어·옷·장식을 준비해야 한다. 현재 예쁜 SD 뼈대·비율을 유지하고 필요한 부분만 제작한다.

## 귀엽고 풍성한 SD 아바타 기준

이 기준이 이전 도트 스타일보다 우선한다. 사용자 요청에 따라 일러스트형 SD 캐릭터로 제작하며, 캐릭터와 의상에 `pixelated`, `crispEdges`나 계단식 픽셀 포즈를 적용하지 않는다.

2026-10-01 사용자가 추가한 여러 의상의 SD 캐릭터 시트를 새로운 아바타 미술 목표로 삼는다. 원본 캐릭터의 복제 대신 귀여운 비율, 풍성한 실루엣, 부드러운 명암, 섬세한 의상 조합을 퀴즈나라의 새 원화로 표현한다. 픽셀 계단식 윤곽을 사용하지 않고 원화의 부드러운 명암·곡선과 색상·부위별 착용 기능을 유지한다.

| 항목 | 구체적인 제작·확인 기준 |
|---|---|
| 얼굴과 비율 | 큰 반짝이는 눈, 둥근 볼과 턱, 작은 코·입, 부드러운 볼터치. 약 2~3등신의 귀여운 인상을 목표로 하되 목·몸통·상의·하의·손발을 구분하고 실제 착용 구조에 맞춘다. |

대표 캐릭터 한 명을 실제 표시 크기로 먼저 검수한 뒤 다양한 피부·성별·머리색·옷으로 확장한다. 자동 검사는 착용·색·구매·모션의 동작 근거이며, 귀여움·입체감·밀도의 달성 근거는 참고와 실제 전신 화면을 직접 비교한 기록이다. 이 지침을 저장한 것과 새 기준의 원화를 제작한 것은 구분한다.

사용자의 추가 교차 검수 요청에 따라 다음 차이를 실제 전신에서 우선 확인한다. 헤어는 큰 다발과 깔끔한 갈색 윤곽, 두세 단계의 부드러운 명암으로 표현한다. 반실사 잔머리·작은 반사광·검은 그늘을 과하게 늘리지 않는다. 얼굴과 세로로 큰 눈이 머리 안에서 또렷하게 읽혀야 하며, 옷은 네온 광택보다 천의 주름과 장식으로 풍성함을 만든다. 머리와 의상만 따로 확대해 통과시키지 않는다.

신발은 신체 배율을 적용한 뒤에도 앞코·발목·밑창 비율이 원화와 맞아야 한다. 후드는 올린 형태를 목 아래의 빈 구멍으로 붙이지 않으며, 내려진 후드 또는 실제 머리를 감싸는 층으로 설계한다. 소매 끝·손·허리·바지·구두의 이음새를 확인해 이중 손이나 납작한 신발을 남기지 않는다.

걷기·점프·앉기는 연속 장면으로 확인한다. 걷기는 발의 교차와 지지, 팔의 반대 박자, 작은 상체 움직임이 연결되어야 한다. 점프는 올라갈 때와 내려올 때의 자세를 구분하고, 앉기는 골반이 내려가며 다리가 굽혀지는 실루엣으로 읽혀야 한다. 얼굴을 눌러 앉기나 점프를 표현하지 않는다. 앞머리와 뒷머리는 같은 머리 위치를 따르고, 옷자락·신발의 원화 비율과 깜박임을 유지한다. 복원·화면 전환 뒤 잔여 변형이 없어야 한다.

| 장소의 이야기 | 집에는 화분·울타리·도구, 물에는 물결·수초·돌·다리, 숲에는 뿌리·버섯·꽃·쓰러진 가지를 배치한다. | 임의의 장식 개수보다 실제 장소의 생활감과 차이가 느껴지는가. |
| 사용성과 시선 | 이동 길·퀴즈 사물·아바타와 메뉴의 읽기 공간을 확보하고 주변 풍경의 대비를 조절한다. | 풍성한 그림을 유지하면서 목표·글씨·입력·조작이 바로 보이는가. |

대표 화면 한 장을 먼저 완성하고 참고와 나란히 비교한다. 숲 배경은 평면 SVG 도형만 늘려 완성하지 않는다. 사용자가 제공한 세밀한 원본과 재사용 가능한 소품을 배치·조합한다. 필요한 맵 소재가 없으면 추가 에셋을 요청한다. 광택·그림자만 일괄 추가한 뒤 원화 품질이나 장면 구성이 해결됐다고 판단하지 않는다.

검수는 노트북의 기본 플레이 크기로 한다. 시작점·길의 각 구간·상호작용·정답 뒤 이동을 직접 확인하며, 변경 전·후 화면과 위 항목의 부족함을 기록한다. 로비는 메뉴가 올라간 실제 화면과 좁은 화면의 배경 잘림을 확인한다. 맵은 사물 충돌·문제 접근·가림을 함께 검수하고 사용자 참고 최소 수준과의 차이를 그대로 보고한다.

## UI · 글꼴 · 음향 기준

**최신 공통 UI 기준(2026-10-01)**은 사용자가 최종 선택한 **숲속 마을**이다. 실제 전달한 [interface.zip 기본 자료](assets/interface-library/README.md)의 나무·로프·양피지 UI와 햇살 든 마법 숲에서 따뜻한 나무결, 크림색 종이, 얇은 금색 테두리, 이끼·옥빛 녹색, 작은 덩굴·꽃 장식을 활용한다. 학생의 로그인·메인 로비·상점·옷장·모든 게임 방식·결과 화면에 미술을 집중한다. 교사 작성/설정/진행 화면은 같은 기본 재질·색상과 읽기 쉬운 입력·조작을 유지한다. 현재 SD 아바타 뼈대·비율, 풍성한 로비 원화와 각 퀴즈 맵의 세계를 유지한다.

옷 가게는 숲속 마을의 작은 옷 가게처럼 나무 간판·진열대·따뜻한 패널과 주변 풍경이 연결되게 만든다. 버튼 색만 녹색으로 바꾸는 것으로 끝내지 않는다. 잎·꽃과 프레임의 입체 장식은 모서리·주변부에 두고 상품·아바타·본문·가격·구매 버튼은 선명하게 읽히게 한다. 숲 배경을 각 상품 안에 반복하여 옷을 가리지 않는다.

- 버튼 윗면에는 둥근 광택과 밝은 하이라이트를 주고, 두툼한 흰색 또는 밝은 경사 테두리로 가장자리를 표현한다. 아래쪽에는 실제 두께가 보이는 색면, 바깥 그림자와 안쪽 그림자를 넣는다. 누를 때 두께가 줄어드는 반응과 손을 떼면 복원되는 모양을 맞춘다.
- 중요한 제목과 행동 버튼은 굵고 둥근 글자와 또렷한 윤곽선으로 표시한다. 메뉴 아이콘은 장난감처럼 부피·재질·빛 방향을 갖춘다. 골드·점수·시간은 크림색 수치판, 진행률은 두꺼운 둥근 캡슐로 표현한다.
- 숲과 나무 간판, 성·용암·사막·가을 경기장 등 각 세계의 색을 살린다. 제공 소재팩의 UI·풍경·소품을 우선 활용하고 필요한 부분을 제작한다. 다른 게임의 로고를 퀴즈나라 이름표로 사용하지 않는다.
- 질문·긴 설명·답안·교사 편집 입력란은 윤곽선이나 광택을 과도하게 넣지 않고 선명한 본문 글꼴로 읽히게 한다. 입력·저장·시작·뒤로가기의 차이가 실제 크기에서 바로 보이며, 좁은 화면에서도 눌러야 할 요소가 잘리지 않아야 한다.

이 최신 숲속 마을 기준은 아래의 이전 캔디 UI·Royal Match 참고보다 우선한다. 이전 자료의 버튼 입체감과 읽기 쉬운 배치는 품질 참고로 유지한다.

추가로 제공한 네 장의 모바일 게임 참고에서 금색 테두리, 입체 도구 아이콘, 크림색 수치 표시, 초록 진행 막대를 골드와 오늘의 연습 표시에도 적용한다. 수치와 진행은 실제 획득 골드와 일일 연습 한도를 사용한다.

이전에 제공한 6장 UI 참고(광택 있는 빨간 아이콘, Chickz, Diamond, Cookie Blast, Candy Blaster, Game UI)의 둥근 입체 버튼·윗면 하이라이트·아랫면 두께·부드러운 그림자는 품질 참고로 유지한다. 현재 전체 재질과 색상은 숲속 마을 기준을 적용한다. 기존 흰색 SVG 아이콘과 `candy-sky`는 이미 연결된 자산이며, 새 작업에서는 제공한 버튼·아이콘·테두리를 먼저 검토해 활용한다. 참고 게임의 로고·워터마크는 퀴즈나라 메뉴 장식으로 사용하지 않는다.

같은 날 추가로 제공한 Wooden GUI 참고는 메인 로비 메뉴의 기준이다. 메인 로비는 숲 배경과 색칠한 나무 질감의 세로 간판 네 개로 구성한다. **청록색 혼자 연습·연두색 수업 참가·노란색 옷 가게·코럴색 우리 반 순위**를 세로로 배치하고, 각 간판에 큰 흰색 주아(Jua) 제목을 표시한다. 로그인·옷장·상점·게임 화면의 최종 재질과 색은 위의 숲속 마을 기준을 따른다.

반 이름은 사용자가 정정한 **3학년 3반**으로 표시한다. 로그인과 메인 로비의 **퀴즈나라** 로고는 추가로 제공한 Where’s My Food 참고처럼 노란 입체 글자, 두툼한 나무 간판과 잎 장식으로 표현한다. 참고 로고의 원본 그림이나 글자를 복사하지 않고 퀴즈나라 이름으로 직접 만든다.

제목과 버튼에는 두툼하고 둥근 주아(Jua) 글꼴을 사용한다. 본문·문제·입력란에는 자소가 선명한 나눔스퀘어라운드를 사용해 긴 문장과 답안을 또렷하게 읽을 수 있어야 한다. 글씨의 실제 굵기를 구분하고 작은 글씨의 겹친 그림자를 줄인다. 화면 크기가 줄어도 읽기·입력·구매 버튼이 잘리지 않게 한다. 아바타 의상은 UI 색과 별개로 다양한 색을 선택할 수 있어야 하며, 위의 아바타 미술 기준은 그대로 유지한다.

메인 로비의 내 아바타 창은 추가로 제공한 Download3.jpg 참고처럼 자연스러운 나무 질감의 청록색 패널과 매달린 주황색 이름 간판을 사용한다. 전신 캐릭터를 나무 그루터기 위에 비율을 유지해 표시하고, 캐릭터·펫·이펙트를 가운데 배치한다. 이름은 위쪽 간판에, 점수는 별도 영역에 표시한다. 창 디자인을 바꾸어도 위의 아바타 원화·의상·움직임 기준은 유지한다.

착용한 아바타 배경은 별도 층으로 미리보기 창 전체를 채우고 프레임의 경계 안에서 잘라 표시한다. 배경의 움직임도 경계 안에서만 보인다. 캐릭터 그림 안에 배경을 중복 표시하지 않으며, 창 표시를 위해 저장된 착용 상태를 바꾸지 않는다.

이전 참고 화면은 배치 참고로 보존한다: [상점](디자인기준/08-상점.png), [옷장](디자인기준/09-옷장.png), [교실](디자인기준/10-교실.png), [퀴즈쇼](디자인기준/11-퀴즈쇼.png), [로비](디자인기준/12-로비.png), [상점 배치](디자인기준/13-상점배치.png). 색·버튼·글꼴 표현은 2026-10-01의 참고를 따르며, 메인 로비 메뉴에는 추가된 Wooden GUI 기준을 우선한다.

버튼은 포인터·키보드로 누를 때 위치와 크기가 살짝 변하고 손을 떼면 복원된다. 주변 배치는 움직이지 않는다. 버튼·정답·오답·구매·게임 시작과 결과에 구별되는 효과음을 넣고 같은 클릭에 소리가 겹치지 않게 한다. 배경 음악과 효과음은 각각 켜고 끌 수 있어야 하며, 첫 사용자 입력 후 재생하고 배경 탭에서 예약음이 누적되어 돌아올 때 몰아 재생되지 않게 한다. 참고 게임의 음원과 로고를 그대로 복사하지 않는다.

최종 확인은 자동 검사와 실제 게임 화면 확인을 함께 진행한다. 노트북 화면 크기에서 로그인·로비·상점·옷장·퀴즈·OX·팀 퍼즐의 색과 버튼 입체감, 제목·문제·입력란의 읽기 편함, 아바타·이펙트의 경계와 배치를 직접 확인한다. 로그인·로비의 로고와 3학년 3반 표시, 아바타 창의 전신·이름 간판·그루터기, 착용 배경의 창 전체 표시와 중복 여부도 확인한다. 자동 검사 통과만으로 미술과 플레이 화면이 완성됐다고 판단하지 않는다.

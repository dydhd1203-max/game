# 퀴즈나라 맵·화면·아바타 디자인 기준

## 상시 최우선 기준

사용자 고정 요청(2026-10-01): **“아이들이 좋아하는 맵과 디자인, 아바타 디자인에 공을 제일 많이 들여야돼. 고정지침에 추가해서 항상 기억해줘.”** 퀴즈나라에서는 맵·UI·아바타의 미술과 놀이 경험에 가장 많은 공을 들인다. 아이들이 화면을 보고 탐험하고 싶고, 자기 아바타를 꾸미고 싶어 하는 세계를 만든다. 기능을 붙인 임시 도형이나 단조로운 배경으로 미술 작업을 끝내지 않는다.

참고 화면에서 배색·재질·구도·세밀함을 배워 직접 만든 자산에 적용한다. 게임 화면은 세계의 깊이와 이동할 공간, 다가가고 싶은 NPC·사물, 또렷한 문제와 조작 버튼을 함께 갖춘다. 미술을 추가할 때도 학생의 이름·팀 색·입력란·점수·타이머를 가리지 않는다. 주 사용 환경인 LG 그램·크롬북의 실제 노트북 화면에서 확인한다.

2026-10-01에 제공한 숲·계곡·마을·산길·Kingshot·도시·숲속 정원 이미지는 **맵의 최소 미술 목표**다. 건물은 같은 원근과 조명 아래 지붕 기와·처마·벽의 두께·창틀·목재 결을 갖추고, 식생은 다른 수종·잎 덩어리·그늘·꽃 군락으로 구성한다. 절벽·개울·다리는 높낮이와 연결 관계를 읽을 수 있게 만든다. 밝은 길과 조용한 이동 공간을 남겨 퀴즈 사물과 아바타가 장식에 묻히지 않게 한다. 참고 이미지와 현재 실제 게임 화면의 품질 차이를 솔직히 기록하며, 자동 검사 통과를 이 미술 목표의 달성으로 바꾸어 보고하지 않는다.

## 다섯 퀴즈 방식의 맵 기준

아래 내용은 이후 맵 수정에서도 지켜야 하는 고정 규칙이다. 같은 문제 묶음을 사용해도 각 방식의 장소와 놀이가 화면에서 구분되어야 한다.

| 방식 | 장소와 필수 표현 | 실제 플레이 검수 |
|---|---|---|
| 순서풀이 (`sequence`) | 울타리 안 고정 숲길, 구불구불 이어지는 경로와 꿀단지 관문. 정답 전에는 닫히고 정답 뒤 자기 관문만 열린다. | 시작 위치에서 다음 관문까지 길을 따라 갈 수 있는지, 오답 때 막히는지, 정답 뒤만 통과하는지 확인한다. 대각 이동·점프로 울타리나 닫힌 관문을 우회하지 못해야 한다. |
| 자유풀이 (`free`) | 성·용암·사막·숲 구역을 갖춘 넓은 2D 탐험 세계. 구역의 지형·장식·NPC를 구분한다. | 각 구역으로 이동해 NPC·사물 가까이에서만 문제를 여는지, 모든 문항에 접근 가능한지 확인한다. 멀리서 사물을 눌러 열리지 않아야 한다. |
| 라운드전 (`round`) | 학생마다 체크무늬 소풍 돗자리 한 장. 시작할 때 아바타가 자기 돗자리 위로 자동으로 걸어 들어간다. | 입장 애니메이션과 실제 도착 위치를 확인한다. 모두 같은 문제·남은 시간을 보고 답하며 공개 뒤 점수와 마지막 순위가 보이는지 확인한다. |
| 팀전 (`team`) | 울타리 안 가을 퀴즈 경기장. 단풍·경기장 장식·팀 색으로 장소와 소속을 쉽게 알아본다. | 경기장 안에서 이동·문제 접근·경계 충돌을 확인한다. 무작위 배정은 팀 간 인원 차이가 최대 한 명인지, 개인 완료와 팀 점수 합산이 구분되는지 확인한다. |
| 협동전 (`coop`) | 함께 도전하는 탐험 맵과 반 공동 정답 수·목표·제한 시간을 보여 주는 안내. | 학생별로 완료가 독립적인지, 반 전체 정답 수가 중복 없이 더해지는지, 마감 전 목표 성공과 시간 종료 결과가 구분되는지 확인한다. |

선 잇기는 고른 짝 사이에 실제 선을 그려 연결을 알아볼 수 있게 한다. 순서 맞추기는 섞인 항목을 직접 옮기거나 위·아래 버튼으로 바꾸고 현재 순서를 읽기 쉽게 표시한다. 일반 퀴즈의 유형은 객관식·주관식·선 잇기·순서 맞추기이며 기존 OX는 별도 화면으로 유지한다.

걷기·점프·앉기는 원화의 팔·다리·몸 포즈로 표현한다. 메인 로비의 **움직임 연습**에서 내 아바타로 조작을 익히고 맵에서도 같은 품질을 유지한다. 이동 중에도 얼굴·옷·신발·펫·천사 이펙트의 세밀함, 눈 깜박임과 숨쉬기를 보존한다.

완료 전 각 방식의 실제 학생 시작 시점, 진행 경로, NPC·관문 앞, 문제 입력, 정답 뒤 이동, 결과 화면을 저장하고 이미지를 직접 연다. 캡처한 화면의 미술, 키보드·화면 버튼의 조작, 이동할 길, 경계와 관문의 충돌을 함께 확인한다. 조망 화면이나 자동 검사 통과만으로 미술·플레이 완성이라고 판단하지 않는다. 구현됨·직접 확인됨·미확인 항목을 구분한다.

## 아바타 미술 기준

2026-09-30 사용자가 제공한 도트 아바타 꾸미기 스크린샷을 **최소 미술 퀄리티 기준**으로 삼는다. 아래 원칙은 다음 아바타·의상 추가에도 적용한다.

- 귀여운 패션 인형처럼 큰 얼굴과 둥근 몸을 그린다. 몸통·손·다리·옷이 사각형을 쌓은 모양으로 보이면 다시 작업한다.
- 도트의 가장자리는 또렷하게 유지하면서 눈의 반짝임, 눈썹, 입, 머리카락의 결과 명암을 보존한다. 작은 그림을 과도하게 축소한 뒤 늘려서 디테일을 잃지 않는다.
- 기존 원화의 처리 해상도만 늘린 것으로 미술 개선을 완료했다고 판단하지 않는다. 세밀함이 부족하면 원화의 눈·머리카락·옷 선 자체를 새로 그린다.
- 머리카락과 얼굴의 위치를 맞춘다. 떠 있는 머리 조각, 목 사이의 틈, 겹쳐 보이는 이목구비가 없어야 한다.
- 얼굴·귀·목·팔·손·다리에는 같은 피부 팔레트를 쓴다. 그림자와 볼터치는 의도한 색 변화만 허용한다.
- 상의와 하의를 따로 사고 입힌다. 두 부위가 보일 만큼 몸통과 다리 공간을 확보하고, 어깨선·소매·옷자락·허리선·주름·신발을 구분한다.
- 로비와 꾸미기에서는 전신 디테일이 보일 만큼 크게 표시한다. 게임에서도 얼굴과 착용 의상을 알아볼 수 있어야 한다.
- 얼굴, 헤어, 의상, 장신구, 펫, 이펙트, 액자의 그림 밀도와 윤곽선 스타일을 통일한다.
- 로비·꾸미기·게임에서 계속 숨쉬고 깜빡인다. 게임 화면을 갱신할 때 움직임이 처음부터 반복되어 멈춘 듯 보이지 않게 한다.
- 얼굴·머리카락을 서로 다른 박자의 미세 회전·소수 픽셀 이동으로 흔들지 않는다. 숨쉬기와 펫의 포즈 변화는 실제 화면의 1픽셀 간격으로 맞추고, 눈 깜박임·천사 날갯짓·주변 반짝임은 유지한다. 창 크기와 화면 배율이 바뀌어도 같은 기준을 적용한다.
- 첫 화면과 상점 옆 전신은 과도하게 확대하지 않는다. 로비는 252~280px, 옷장·상점은 280~300px 높이로 표시하고, 원화 준비 전 임시 도형이나 가공 전 얼굴을 노출하지 않는다.
- 상점·옷장·무작위 꾸미기·게임 참가자의 헤어는 선택한 남녀 구분에 맞춘다. 남자는 짧은 머리·가르마·덥수룩·스포츠 머리, 여자는 단발·긴 머리·양갈래·포니테일·곱슬 단발·만두 머리·히메컷·땋은 머리를 사용한다. 성별을 바꿔도 돈과 소유 아이템은 보존한다.
- 펫도 눈·털·귀·발을 구분하는 새 원화로 그린다. 신발은 끈·밑창·버클·재질이 구별되어야 하고 팔·손·다리는 옷과 어울리는 가는 윤곽과 피부 명암을 쓴다. 얼굴만 세밀하고 나머지가 큰 사각 도트로 보이는 조합을 완료로 판단하지 않는다.
- 눈을 감을 때는 반쯤 감은 눈과 완전히 감은 눈을 별도로 그린다. 피부 사각형을 늘려 눈을 덮거나 눈 자체를 납작하게 찌그러뜨리지 않는다. 눈썹·볼터치는 유지하고 짧게 닫혔다 자연스럽게 열린다.
- 남자·여자 얼굴 원화와 몸 표현을 구분한다. 같은 옷을 입혀 비교할 수 있어야 하며, 피부색·소유 아이템·착용 조합은 변경 때 유지한다.
- 최종 확인은 실제 게임에서 밝은 피부와 어두운 피부, 여러 머리색, 상의와 하의, 장신구를 함께 입힌 화면으로 한다. 정지 원화만 확인해서 완료로 판단하지 않는다.
- 얼굴 주변의 머리 색과 피부 경계를 실제 원화의 경계로 구분한다. 머리색을 바꿨을 때 관자놀이·턱 아래에 사각형 색 덩어리가 남거나 눈을 감았을 때 기존 속눈썹이 겹쳐 보이면 수정한다. [신고한 얼굴](디자인기준/14-얼굴겹침-수정기준.png)을 뜬 눈·반쯤 감은 눈·감은 눈으로 비교한다.
- [천사 이펙트 참고](디자인기준/15-천사이펙트-참고.png)처럼 아바타 옆의 노란 동그란 천사에는 몸의 부유와 양 날개의 독립적인 움직임을 넣는다. 펫과 별도로 착용하며 실제 표시 크기에서 얼굴·이름·문제·입력 버튼을 가리지 않게 한다.

참고 그림은 디자인 검토에 사용하며 게임의 원본 자산으로 복사해 넣지 않는다. 게임에는 새로 만든 원화를 사용한다.

## UI · 글꼴 · 음향 기준

**최신 공통 UI 기준(2026-10-01)**은 사용자가 제공한 Royal Match 수중 화면의 밝고 예쁜 색감과 입체 재질이다. 로그인·메인 로비·상점·옷장·모든 게임 방식·결과·교사 작성/설정/진행 화면에 적용한다. 맵과 나무 로비의 장소·기존 원화는 보존하고, 각 장소에 어울리는 색과 재질로 같은 수준의 완성도를 만든다.

- 버튼 윗면에는 둥근 광택과 밝은 하이라이트를 주고, 두툼한 흰색 또는 밝은 경사 테두리로 가장자리를 표현한다. 아래쪽에는 실제 두께가 보이는 색면, 바깥 그림자와 안쪽 그림자를 넣는다. 누를 때 두께가 줄어드는 반응과 손을 떼면 복원되는 모양을 맞춘다.
- 중요한 제목과 행동 버튼은 굵고 둥근 글자와 또렷한 윤곽선으로 표시한다. 메뉴 아이콘은 장난감처럼 부피·재질·빛 방향을 갖춘다. 골드·점수·시간은 크림색 수치판, 진행률은 두꺼운 둥근 캡슐로 표현한다.
- 숲과 나무 간판, 성·용암·사막·가을 경기장 등 각 세계의 색을 살린다. 참고 화면의 로고·캐릭터·원본 자산을 복사하지 않고 퀴즈나라 자산을 직접 만든다.
- 질문·긴 설명·답안·교사 편집 입력란은 윤곽선이나 광택을 과도하게 넣지 않고 선명한 본문 글꼴로 읽히게 한다. 입력·저장·시작·뒤로가기의 차이가 실제 크기에서 바로 보이며, 좁은 화면에서도 눌러야 할 요소가 잘리지 않아야 한다.

이 최신 기준은 아래의 이전 UI 참고 위에 공통 재질·색감·입체감 기준으로 적용한다.

추가로 제공한 네 장의 모바일 게임 참고에서 금색 테두리, 입체 도구 아이콘, 크림색 수치 표시, 초록 진행 막대를 골드와 오늘의 연습 표시에도 적용한다. 수치와 진행은 실제 획득 골드와 일일 연습 한도를 사용한다.

2026-10-01 사용자가 제공한 6장 UI 참고(광택 있는 빨간 아이콘, Chickz, Diamond, Cookie Blast, Candy Blaster, Game UI)를 기준으로 로그인·옷장·상점·게임 화면에 밝은 캔디 세계를 표현한다. 흰 테두리의 둥근 입체 버튼, 라임·시안·보라·골드·코럴의 광택과 부드러운 그림자를 적용한다. 버튼과 메뉴에는 흰색 SVG 아이콘을 사용하고, 배경은 직접 만든 `candy-sky` SVG로 구성한다. 참고 화면의 로고·워터마크·유료 원화는 복사해 넣지 않는다.

같은 날 추가로 제공한 Wooden GUI 참고는 메인 로비 메뉴의 최신 기준이다. 메인 로비는 숲 배경과 색칠한 나무 질감의 세로 간판 네 개로 구성한다. **청록색 혼자 연습·연두색 수업 참가·노란색 옷 가게·코럴색 우리 반 순위**를 세로로 배치하고, 각 간판에 큰 흰색 주아(Jua) 제목을 표시한다. 로그인·옷장·상점·게임 화면은 위의 캔디 UI 기준을 유지한다.

반 이름은 사용자가 정정한 **3학년 3반**으로 표시한다. 로그인과 메인 로비의 **퀴즈나라** 로고는 추가로 제공한 Where’s My Food 참고처럼 노란 입체 글자, 두툼한 나무 간판과 잎 장식으로 표현한다. 참고 로고의 원본 그림이나 글자를 복사하지 않고 퀴즈나라 이름으로 직접 만든다.

제목과 버튼에는 두툼하고 둥근 주아(Jua) 글꼴을 사용한다. 본문·문제·입력란에는 자소가 선명한 나눔스퀘어라운드를 사용해 긴 문장과 답안을 또렷하게 읽을 수 있어야 한다. 글씨의 실제 굵기를 구분하고 작은 글씨의 겹친 그림자를 줄인다. 화면 크기가 줄어도 읽기·입력·구매 버튼이 잘리지 않게 한다. 아바타 의상은 UI 색과 별개로 다양한 색을 선택할 수 있어야 하며, 위의 아바타 미술 기준은 그대로 유지한다.

메인 로비의 내 아바타 창은 추가로 제공한 Download3.jpg 참고처럼 자연스러운 나무 질감의 청록색 패널과 매달린 주황색 이름 간판을 사용한다. 전신 캐릭터를 나무 그루터기 위에 비율을 유지해 표시하고, 캐릭터·펫·이펙트를 가운데 배치한다. 이름은 위쪽 간판에, 점수는 별도 영역에 표시한다. 창 디자인을 바꾸어도 위의 아바타 원화·의상·움직임 기준은 유지한다.

착용한 아바타 배경은 별도 층으로 미리보기 창 전체를 채우고 프레임의 경계 안에서 잘라 표시한다. 배경의 움직임도 경계 안에서만 보인다. 캐릭터 그림 안에 배경을 중복 표시하지 않으며, 창 표시를 위해 저장된 착용 상태를 바꾸지 않는다.

버튼은 포인터·키보드로 누를 때 위치와 크기가 살짝 변하고 손을 떼면 복원된다. 주변 배치는 움직이지 않는다. 버튼·정답·오답·구매·게임 시작과 결과에 구별되는 효과음을 넣고 같은 클릭에 소리가 겹치지 않게 한다. 배경 음악과 효과음은 각각 켜고 끌 수 있어야 하며, 첫 사용자 입력 후 재생하고 배경 탭에서 예약음이 누적되어 돌아올 때 몰아 재생되지 않게 한다. 참고 게임의 음원과 로고를 그대로 복사하지 않는다.

최종 확인은 자동 검사와 실제 게임 화면 확인을 함께 진행한다. 노트북 화면 크기에서 로그인·로비·상점·옷장·퀴즈·OX·팀 퍼즐의 색과 버튼 입체감, 제목·문제·입력란의 읽기 편함, 아바타·이펙트의 경계와 배치를 직접 확인한다. 로그인·로비의 로고와 3학년 3반 표시, 아바타 창의 전신·이름 간판·그루터기, 착용 배경의 창 전체 표시와 중복 여부도 확인한다. 자동 검사 통과만으로 미술과 플레이 화면이 완성됐다고 판단하지 않는다.

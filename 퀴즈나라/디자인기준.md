# 퀴즈나라 아바타 미술 기준

2026-09-30 사용자가 제공한 도트 아바타 꾸미기 스크린샷을 **최소 미술 퀄리티 기준**으로 삼는다. 아래 원칙은 다음 아바타·의상 추가에도 적용한다.

- 귀여운 패션 인형처럼 큰 얼굴과 둥근 몸을 그린다. 몸통·손·다리·옷이 사각형을 쌓은 모양으로 보이면 다시 작업한다.
- 도트의 가장자리는 또렷하게 유지하면서 눈의 반짝임, 눈썹, 입, 머리카락의 결과 명암을 보존한다. 작은 그림을 과도하게 축소한 뒤 늘려서 디테일을 잃지 않는다.
- 기존 원화의 처리 해상도만 늘린 것으로 미술 개선을 완료했다고 판단하지 않는다. 세밀함이 부족하면 원화의 눈·머리카락·옷 선 자체를 새로 그린다.
- 머리카락과 얼굴의 위치를 맞춘다. 떠 있는 머리 조각, 목 사이의 틈, 겹쳐 보이는 이목구비가 없어야 한다.
- 얼굴·귀·목·팔·손·다리에는 같은 피부 팔레트를 쓴다. 그림자와 볼터치는 의도한 색 변화만 허용한다.
- 상의와 하의를 따로 사고 입힌다. 두 부위가 보일 만큼 몸통과 다리 공간을 확보하고, 어깨선·소매·옷자락·허리선·주름·신발을 구분한다.
- 로비와 꾸미기에서는 전신 디테일이 보일 만큼 크게 표시한다. 게임에서도 얼굴과 착용 의상을 알아볼 수 있어야 한다.
- 얼굴, 헤어, 의상, 장신구, 펫, 이펙트, 액자의 그림 밀도와 윤곽선 스타일을 통일한다.
- 로비·꾸미기·게임에서 계속 숨쉬고 깜빡인다. 게임 화면을 갱신할 때 움직임이 처음부터 반복되어 멈춘 듯 보이지 않게 한다.
- 눈을 감을 때는 반쯤 감은 눈과 완전히 감은 눈을 별도로 그린다. 피부 사각형을 늘려 눈을 덮거나 눈 자체를 납작하게 찌그러뜨리지 않는다. 눈썹·볼터치는 유지하고 짧게 닫혔다 자연스럽게 열린다.
- 남자·여자 얼굴 원화와 몸 표현을 구분한다. 같은 옷을 입혀 비교할 수 있어야 하며, 피부색·소유 아이템·착용 조합은 변경 때 유지한다.
- 최종 확인은 실제 게임에서 밝은 피부와 어두운 피부, 여러 머리색, 상의와 하의, 장신구를 함께 입힌 화면으로 한다. 정지 원화만 확인해서 완료로 판단하지 않는다.
- 얼굴 주변의 머리 색과 피부 경계를 실제 원화의 경계로 구분한다. 머리색을 바꿨을 때 관자놀이·턱 아래에 사각형 색 덩어리가 남거나 눈을 감았을 때 기존 속눈썹이 겹쳐 보이면 수정한다. [신고한 얼굴](디자인기준/14-얼굴겹침-수정기준.png)을 뜬 눈·반쯤 감은 눈·감은 눈으로 비교한다.
- [천사 이펙트 참고](디자인기준/15-천사이펙트-참고.png)처럼 아바타 옆의 노란 동그란 천사에는 몸의 부유와 양 날개의 독립적인 움직임을 넣는다. 펫과 별도로 착용하며 실제 표시 크기에서 얼굴·이름·문제·입력 버튼을 가리지 않게 한다.

참고 그림은 디자인 검토에 사용하며 게임의 원본 자산으로 복사해 넣지 않는다. 게임에는 새로 만든 원화를 사용한다.

## UI · 글꼴 · 음향 기준

추가로 제공한 6장 UI 참고를 기준으로 푸른 입체 패널, 청록빛 광택 프레임, 남색 인셋, 흰 상품 그림칸과 노란 강조 버튼을 적용한다. 로비·옷장·상점·퀴즈 화면은 같은 시각 언어를 사용한다. 글씨는 둥글면서 자소가 선명한 나눔스퀘어라운드를 사용한다. 설명·메뉴·문제의 실제 굵기를 구분하고 작은 글씨의 겹친 그림자를 줄인다. 화면 크기가 줄어도 읽기·입력·구매 버튼이 잘리지 않게 한다. 아바타 의상은 UI 색과 별개로 다양한 색을 선택할 수 있어야 한다.

내 아바타 배경은 미리보기 칸 전체를 채우되 칸의 경계 밖으로 나오지 않는다. 캐릭터와 이펙트는 비율을 유지하며 가운데에 배치하고 이름·점수는 아래에 별도로 표시한다. 배경의 움직임도 경계 안에서만 보인다.

참고 화면: [상점](디자인기준/08-상점.png), [옷장](디자인기준/09-옷장.png), [교실](디자인기준/10-교실.png), [퀴즈쇼](디자인기준/11-퀴즈쇼.png), [로비](디자인기준/12-로비.png), [상점 배치](디자인기준/13-상점배치.png).

버튼은 포인터·키보드로 누를 때 위치와 크기가 살짝 변하고 손을 떼면 복원된다. 주변 배치는 움직이지 않는다. 버튼·정답·오답·구매·게임 시작과 결과에 구별되는 효과음을 넣고 같은 클릭에 소리가 겹치지 않게 한다. 배경 음악과 효과음은 각각 켜고 끌 수 있어야 하며, 첫 사용자 입력 후 재생하고 배경 탭에서 예약음이 누적되어 돌아올 때 몰아 재생되지 않게 한다. 참고 게임의 음원과 로고를 그대로 복사하지 않는다.

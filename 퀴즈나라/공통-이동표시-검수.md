# 공통 이동 표시·책상·나무 부분 가림 검수

2026-10-04. 기존 원본 맵 복원 작업 뒤의 별도 변경이다. 최신 요청인 **마을광장 크기로 통일 / 속도50% 추가 증가 / 나무와 겹친 신체 부분만 반투명**을 기준으로 한다.

## 확인한 원인과 수정

- 같은120px 입력을 맵별 카메라가 서로 다르게 확대했다. 동일 아바타의 SVG 화면 높이는 교실145.70px, 운동장122.22px, 광장100.96px였다. 렌더와 원화 비율을 유지하고 공통 표시 그룹에 `0.76 / camera.scale`을 적용했다. 현재 기준은 화면91.2px, SVG의 여백을 포함하면 약100.96px다. 지도 확대/축소와 창 크기를 바꿔도 본인·친구의 표시 크기는 유지한다.
- 교실의 좁은 통로는 기존27~28px였고, 의자 주변 빈 바닥까지62×90 클릭 영역에 포함됐다. 30개 원본 가구를 열45px/행50px 통로로 배치하고 클릭 판정을 실제 의자34×35로 좁혔다. 가구별 충돌·착석·출구·기본 입장점을 함께 옮겼으며 통행 반경7은 유지했다.
- 의자 전체가 앉은 아바타 뒤에 그려졌다. 원본 `[109,506,62,90]`의 등받이 나무 판과 금속 테두리만 별도 앞 레이어로 분리했다. 실제 몸 비율/앉기 변환을 거친 골반 위치를 측정하여 원본 좌판에 맞춘다. 등받이 내부 나무 판을 빈 구멍으로 잘라내지 않는다.
- 일부 나무만 불투명 전경으로 다시 덮어 그렸기 때문에 머리/신발만 남거나, 다른 나무 위로 아바타가 불투명하게 보였다. 해당 전경 복사와 전용 알파 캔버스를 퇴역하고, 공통 나무 윤곽·깊이·부분 마스크로 교체했다. 나무 원본 PNG는 바꾸지 않았다.
- 사용자의 최종 정정에 따라 전체 아바타 opacity 방식도 퇴역했다. **나무 밖 부분은 불투명도1, 겹친 부분은 약0.38**이다. 이름·말풍선은 유지하고 나무 앞으로 나오면 마스크를 해제한다. 수관 데이터는 공간 버킷으로 조회하며, 동일한 마스크/위치는 다시 쓰지 않는다. 높은 데크/사다리는 지면 나무 판정과 구분한다.
- 공통 입력 설정은 걷기337.5px/s·달리기506.25px/s로 변경했다. 각각 기존225/337.5 대비1.5배다. 걷기/달리기 주기도 같은 비율로 빨라지며 실제 달리기 포즈를 유지한다. 대각선 정규화와 최대3px 충돌 분할은 그대로다.

## 실행 검증

실제 Firebase 요청을 차단한 `?demo=1`에서 개발환경의 Playwright 실행 도우미를 사용했다. 계정·골드·보유품·원화·교실/운동장 원본 PNG는 변경하지 않았다.

- `tools/check-source.cjs`: 소스 파싱, 필수 파일·원본 내장 데이터 검사 통과.
- `tools/verify-school-avatar-size.cjs`: 9개 공용 공간×1366/1920 PC 화면×본인/친구 크기 비교, 라이브 리사이즈/줌, 30개 좌석 접근, 세로9/가로2 통로 경로, 실제 방향키5개 통로 통과, 의자 옆 바닥 클릭, 두 학생 C 착석/일어서기, 골반·좌판 높이, 걷기/달리기/대각선 속도 통과.
- 속도는 실제 키 입력 후 프레임별 위치를 측정했다. 기존35ms 프레임 상한을 반영한 시뮬레이션 시간과 실제 경과 시간을 보고서에 각각 기록한다. 부하가 있는 브라우저의 실시간 속도를 항상 일정하다고 보장하지 않는다.
- 같은 검사에서 주황/분홍/단풍/캠핑장 나무 뒤와 앞을 실제로 이동했다. 본인/친구의 부분 마스크와 이름 가독성, 앞에서 마스크 해제를 확인했다. 운동장·비밀정원·나무집·하늘섬도 등록 윤곽과 실제 화면을 확인했다. 모험숲의 높은 데크·사다리와 접근할 수 없는 배경 숲은 지면 가림 사례로 세지 않는다.
- **부분 가림 픽셀 회귀**: 같은 동작을 멈춘 채 배경만/정상 아바타/부분 가림/전체 opacity 실패 대조를 촬영했다. 두 해상도에서 노출된 머리의 합성 비율 중앙값1, 겹친 몸 약0.381이었다. 이전 전체 opacity 방식은 머리도 약0.38로 내려가므로 실패로 검출한다. 부분 가림 캡처를 직접 열어 머리와 옆으로 나온 신체 부위를 확인했다.
- `tools/verify-auto-portals.cjs`: 19개 접촉 출입구, 도착 잠금·왕복, F로 이동하지 않음 검사 통과.
- `tools/verify-forest-climbing.cjs`: 모험숲 사다리 ↑/정지/↓·다리·C·돌/버섯·동작 줄이기·종료 정리 검사 통과.
- `node tools/build-deployment.cjs` 및 `--check`: 실행 파일130개 원본/배포본 일치 확인. `/배포용/?demo=1`에서도 같은 공통 표시/부분 가림 브라우저 검사를 실제 실행해 통과했다.

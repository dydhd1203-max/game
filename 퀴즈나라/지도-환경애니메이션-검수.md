# 지도·상단 UI·맵별 환경 움직임 검수

## 현재 구현

공용9공간에 작은 위치 지도와 `M` 큰 지도를 추가했다. 지도에는 현재 전체 그림·나·같은 공간의 친구·화면 범위·출입구 번호가 표시된다. 장소를 선택하면 현재 출입구 그래프의 경로와 첫 입구를 안내한다. 지도 선택으로 순간이동하지 않는다. Esc/M/닫기 및 기본 dialog 키보드 초점 관리를 사용하고, 지도에서 돌아오면 이동 화면으로 초점을 복원한다.

상단은 숲색 목재와 밝은 종이색 버튼으로 정리하고 소리·마을·내 정보·옷 가게·순위 이름을 붙였다. 소리 상태를 갱신해도 이름이 남는다. 제공 UI 시트의 양피지 테두리와 두루마리를 실제로 추출해 사용했다. 처음 확인한 회색 시트 찌꺼기와 CSS가 버튼 이름을 감추는 문제는 수정했다. 작은 지도는 접을 수 있다. 교실은 하단66px를 조작 영역으로 확보하고, 첫 입장점이 기본 카메라 밖이면 따라보도록 하여 아바타가 버튼에 가려 시작하지 않게 했다.

| 공간 | 움직임 |
|---|---|
| 중앙광장 | 기존 수관 내부의 잎, 원래 꽃무리·풀 |
| 비밀정원 | 기존 나무와 작은 꽃무리 |
| 달빛 나무집 | 수관·담쟁이·밑동 주변 식생 |
| 구름 위 버섯섬 | 기존 나무·꽃·풀, 기존 구멍3개의 두더지 |
| 반딧불 모험숲 | 수관·꽃, 기존 반딧불 효과 유지 |
| 단풍 소풍공원 | 단풍 수관, 원본 모닥불과 작은 불티 |
| 별빛 캠핑장 | 소나무·호숫가 식생, 원본 모닥불과 작은 불티 |
| 학교 운동장 | 현재 조립 원본에서 뽑은 수관 내부 잎 |
| 교실 | 창문 안의 미세한 햇빛 변화 |

원본 지도 PNG와 사물 배치·충돌은 바꾸지 않았다. 배경에 박힌 나무를 통째로 회전·복제하는 방식 대신 경계가 고정된 작은 영역 안에서 원본 픽셀을 변형한다. 그림 크기는 반올림한 맵 경계가 아닌 실제 렌더 크기/배율로 변환한다. 나무에 겹친 신체 부분만 투명해지는 기존 마스크는 유지한다. 효과는 클릭을 받지 않는다. 화면 밖·숨긴 탭·모달·동작 줄이기에서 정지하고 종료 시 이벤트/canvas를 정리한다.

## 두더지 후속 수정

사용자가 처음 후보의 크기·화풍을 지적한 뒤 원화를 다시 편집했다. 사실적인 털과 큰 유리눈을 줄이고 구름섬의 둥글고 매끈한 면 채색으로 바꿨다. 이전 큰 털 원화는 게임과 배포본에서 사용하지 않는다. 현재 원본은 `assets/world-life/sources/mole-original.png`, 실행본은 투명 여백을 정리해 비례 축소한 `mole.webp`다.

원본1912×1106 그림의 실제 갈색 구멍 영역은 각각 `[364,226,424,261]`, `[1260,546,1320,581]`, `[1036,738,1096,773]`이다. 폭60원본px=30논리px, 중심은 `(197,121.75)`, `(645,281.75)`, `(533,377.75)`다. 세 번째 구멍의 예전 중심 오차도 바로잡았다. 원화 표시 폭은24논리px 이하이고 alpha와 ±2도 둘러보기까지 계산한 머리 폭은 구멍의 최대 약81.7%다. 1920px 검수 화면에서 좌우 흙 테두리에 약5.1/5.9px 이상 여유가 있었다. 현재 흙 테두리는 원본 그대로 남고 아래 몸은 구멍에 들어간다.

이전46px 표시 폭을 다시 넣은 실패 대조는 같은 검사에서 거부된다. 같은 카메라·교정된 구멍 중심·최고 자세에 이전 그림/크기를 재생한 통제 비교와 수정 후 화면을 함께 저장했다. 이는 통제 비교이며 이전 실제 캡처와 구분한다. 세 마리는 각기 다른 주기로 올라오기·둘러보기·내려가기·완전 숨기를 반복한다.

## 파일과 출처

- `world-map.js`: 실제 장면 그래프·썸네일·위치·모달 지도.
- `world-explorer.css`: 공용 공간에만 적용되는 상단과 지도 디자인, 작은 환경 효과.
- `world-life.js`, `world-life-school.js`: 등록된 원본 움직임·두더지·화면 밖/혼잡도 제어.
- `school-room-world.js`: 지도/환경 생명주기와 카메라 안전 위치 연결.
- `index.html`, `tools/deployment-files.cjs`: 로드 순서·버튼 이름·배포 의존성.
- `assets/world-life/provenance.json`, README: 제공 원본 UI, 실제 장면 썸네일/식생 crop, 새 두더지 원화와 실행 축소본의 구분.
- `tools/build-world-map-previews.cjs`, `build-world-ui-assets.py`: 기존 조립 장면 캡처 및 파생물 재생성.

원본/축소/생성 과정을 구분했으며 원본을50%에서100%로 완전히 복원했다고 주장하지 않는다. 새 UI 파생물 제작은 기존 학교/마을 원화의 교체가 아니다.

## 실제 실행 결과

검수 산출물은 `/workspace/quiz-cloud/atlas-life/`에 저장했으며 Git에는 넣지 않았다. 모든 브라우저는 `?demo=1`, 실제 Firebase SDK/DB 차단으로 검사했다.

- `verify-world-explorer.cjs`: 소스와 배포 폴더에서9공간·81경로, 1366/1920/1024폭, 버튼 이름/겹침, 실제 위치/친구, 지도 M/Esc·키보드 초점·이동 정지, 장면 교체, 두더지3개의 실제 전 주기, 원본 불 픽셀 변화, 동작 줄이기, 계정/착장/재화 불변, 콘솔·자원 오류 없음 확인. 이후 두더지 그림/크기만 후속 검사로 다시 검증했다.
- `verify-world-life-budget.cjs`: 화면 밖은 프레임 갱신하지 않음, 지도 모달에서 실제 canvas 픽셀 정지, 고정 영역, 장면 종료 시 canvas 버퍼 해제, 처음부터 동작 줄이기인 교실의 햇빛 투명도 확인.
- `verify-school-avatar-size.cjs`: 소스와 배포에서 공통 본인/친구 크기, 책상 통로·30의자·실제 C 착석/등받이, 걷기337.5/달리기506.25/대각선, 나무에 겹친 부분만 반투명, 계정 불변 PASS. 배포 검사는 교실 하단 영역을 조정한 뒤 실행했다.
- `verify-mole-fit.cjs`: 후속 새 원화로 실제3마리 전 주기, 독립적인 원본 구멍 경계·중심과 alpha 머리 폭 대조, 양옆 여유, 상승/최고 좌우/하강, 이전 과대 크기 실패 대조 PASS.

직접 본 화면: 최초 UI 전후,9공간 실제 카메라, 큰 지도/경로,1366/1920/1024 상단, 교실 첫 입장, 원본 불, 두더지 새 원화의 전체 맵·각 동작과 이전 후보 비교. 꽃/풀 좌표는 원본 crop을 확대해 실제 소재인지 확인하며 바닥·벤치·자전거를 잘못 골랐던 초기 후보를 제거했다.

### 로컬 효과 부하

동일1366×768, 가상 친구1/10/30명, 조건별90프레임으로 측정했다. 다른 무거운 브라우저 검사는 병렬로 실행하지 않았다.

| 인원 | 효과 켬 프레임 중앙값 / p95 | 환경 그리기 p95 | 동시 변형 영역 |
|---|---|---|---|
| 1 | 16.7 / 16.8ms | 1.4ms | 18 |
| 10 | 16.7 / 16.7ms | 1.2ms | 12 |
| 30 | 33.3 / 50.0ms | 0.9ms | 8 |

30명은 효과를 꺼도 프레임 중앙값33.3ms였다. 30명60fps를 달성했다고 해석하지 않는다. 혼잡도에 따라 장식만 약20→14→11Hz로 줄이며 아바타 입력·카메라 갱신·이동속도는 유지한다. 실제 학교 기기나 Firebase30명 동시 접속 검사는 하지 않았다.

최종 배포 폴더에서도 `verify-mole-fit.cjs`의 수정 원화 전 주기·폭/중심/양옆 여유·과대 크기 실패 대조·초기 동작 줄이기에서 조용히 내민 세 마리 표시가 통과했다(`mole-final/report.json`). `verify-auto-portals.cjs`의19개 실제 접촉 출입구와 방향키 유지 이동도 통과했다(`portals/report.json`, 오류 없음). 최종148개 배포 파일은 `build-deployment.cjs --check`로 소스 해시 일치를 확인했다. Git 최종 반영 결과는 대화의 커밋/push 보고와 구분하며 Cloudflare 공개 사이트 반영은 별도로 확인해야 한다.

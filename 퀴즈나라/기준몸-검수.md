# 남녀 기준 몸 검수

2026-10-03. 현재 단계는 **옷보다 기본 몸을 먼저 만드는 1단계**다. 남녀 원래 얼굴·앞/옆/뒤 머리를 사용하고, 같은 목·어깨·팔꿈치·손목·골반·무릎·발목 구조를 적용했다. 검수용 중성색 가림 외에 대표 착장·전체 상품을 새 구조로 옮기는 작업은 아직 하지 않았다. 일반 계정은 기존 착장을 유지한다.

## 구현 범위

- `avatar-foundation.js`: 고정 관절과 부위별 몸. 피부·골반·좌우 팔·좌우 다리·발은 각 소속에서 한 번만 그린다. 의상 입력으로 관절을 이동하지 않는다. 옆·뒤는 기존 방향별 머리 원화를 사용한다.
- 서 있을 때 팔은 몸 옆으로 편하게 내리고 손은 골반 옆에 둔다. 걷기/달리기의 팔 흔들림, 점프와 인사의 벌림은 동작에 한정한다.
- **바닥 앉기는 아빠다리**다. `assets/seating-library/originals/`의 앞·좌·우·뒤 참고 네 장을 직접 확대해 확인했다. 양옆 무릎과 안으로 돌아오는 종아리·교차한 발의 전용 윤곽을 사용한다. 뒤에서는 발이 골반에 가려진다. 원본 PNG와 참고 캐릭터는 변경하지 않았다.
- 책상 앉기는 좌판에 앉고 다리를 아래로 내리는 별도 자세다. 바닥 아빠다리와 혼용하지 않는다.
- 원래 머리의 표시 범위를 각 SVG 내부에 독립적으로 넣어 목 아래의 검은 원화 조각과 다른 아바타의 clip ID 의존을 제거했다. 얼굴·머리 PNG 자체는 보존한다.
- `avatar-run-input.js` 및 학교 제어기: 같은 방향을 250ms 안에 두 번 눌러 유지하면 달리기337.5px/s, 한 번 누르면 걷기225px/s. 화살표/WASD를 지원하고 키 반복은 두 번 누름으로 세지 않는다. 키 놓기·C·화면 이탈에서 달리기를 해제한다. 친구의 run 상태도 표시한다.
- `avatar-standard.html`: 남녀 기본 몸을 280px/96px로 함께 보고 피부·동작·네 방향·관절·동작 시점을 확인한다. 실제 교실/운동장 링크는 `?demo=1&avatar=foundation&screen=campus` / `screen=playground`다.

## 다음 단계와 제한

기본 반팔·반바지·신발을 이 몸의 부위에 맞춰 제작한 뒤 후드+긴바지·한벌옷으로 확대한다. 기존 의류의 남아 있는 어깨·소매·바짓단·신발 문제는 새 구조로의 전환에서 해결해야 하며, 이번 기준 몸 화면의 통과를 전체 상품의 완료로 옮겨 적지 않는다.

현재 몸의 명암과 접힌 자세 윤곽은 관절 검수용이다. 착장 단계에서 기존 의상 원화의 질감과 맞추고, 앉기/일어서기의 중간 자세와 걷기/달리기/점프 전환을 계속 다듬어야 한다. 비대칭 장식은 단순 반전으로 완성하지 않는다. 실제 학교 기기·실제 Firebase 다중 접속·공개 Cloudflare 배포 상태는 이번 검사에 포함하지 않았다.

이전 규칙 중 옷마다 몸을 바꾸거나 복제해 덮는 제작 지침은 폐기했다. 현행 제작 지침은 `아바타-제작기준.md` 하나로 모았고, 과거 검수 보고서는 원화·작업 이력으로만 보존한다.

기존 의류 소매 재검수에서 바닥 앉기20건의 테두리 덮임을 발견했다. 앉기만 피부를 별도로 회전시키던 경로를 공통 소매+팔 경로로 연결했다. 검사 임계값·원본 소맷부리 fixture는 변경하지 않았다. 최종 전수240건은 실패0으로 통과했다. 여자 반팔·후드의 224/96px 동작 비교 화면도 직접 열어 확인했다. 새 기준 몸은 이 기존 의류 경로를 사용하지 않는다.

걷기·정면 달리기·인사의 여섯 시점을 나란히 비교하며 정면 달리기의 양팔이 몸통 뒤로 숨는 문제를 수정했다. 굽힌 팔은 배 앞에 그리며 관절이나 부위 개수는 바꾸지 않는다. 실행 폴더의 기준 화면·운동장 C·일반 계정의 기존 착장 유지도 직접 브라우저로 확인했다.

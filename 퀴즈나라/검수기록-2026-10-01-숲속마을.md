# 숲속 마을·상점 실내 검수

2026-10-01. 학생이 로그인하면 작은 SD 아바타로 친구를 만나고, 건물까지 걸어가 교실·퀴즈·상점을 이용한다. 사용자 요청에 따라 마을을 넓히고 건물은 서로 떨어뜨리며, 남는 공간에는 장소에 맞는 자연 풍경을 배치했다. 배포는 미뤄 두고 개발 기준 소스만 갱신한다.

## 소재와 직접 본 화면

사용자 건물·풀·농장 시트는 원본을 보존하고 실제 확인한 자료의 재질·시점·소품 구성을 참고했다. 기존 투명 `painted-forest-props.png`의 참나무·바위·우물과 상점 프레임·숲 풍경을 재사용했다. 부족한 나무 종류·건물·이동 지형·가게 가구는 새 투명 원화를 제작했다. `assets/forest-town-*.png`는 생성 PNG의 바이트를 그대로 보존하며 source 영역·바닥 앵커·SHA·참고 자료를 같은 이름의 JSON과 제작 기록에 저장했다.

실제 로그인 광장, 물가·폭포와 돌다리, 계단 상단, 서쪽 나무계단·동굴 앞, 나무집 교실 입구, 통나무 등반 중간·정상, 상점 입장·직원 대화·거울 복귀 화면을 열어 확인했다. 건물은 교실의 책·상점의 가위와 실·관측탑의 망원경과 별로 실루엣이 구별된다. 주요 원화에는 둥근 잎 덩어리, 지붕·목재·석재 재질, 이끼·꽃·등불과 접촉 그림자가 있다. 지형 바닥·절벽·강과 작은 새는 SVG로 그린 부분이며, 전체 배경이 한 장의 회화 원화인 것은 아니다. 평면 지형의 재질·유기적인 경계는 이후 더 다듬을 여지가 있어 제공 참고 게임 전체와 같은 미술 수준을 달성했다고 판단하지 않는다.

## 실행 검수

실제 Firebase SDK 요청을 차단한 `?demo=1`의 격리 데이터로 확인했다. 보상·구매 및 다른 반의 실제 데이터에는 쓰지 않았다.

- `node tools/check-source.cjs`: 실행·원화·글꼴·호스팅 파일 86개 확인, 인라인·모듈 문법 정상, 로컬 아바타 데이터와 기존 원본 PNG 9개 일치.
- `node tools/verify-economy.cjs`: 기존 계정 보상·구매 검사 7개 통과.
- `node tools/verify-village-presence.cjs`: 연결·정리·재연결·이동 전송·권한 실패·서버 시각을 포함한 7개 그룹 통과. 사용자 시계가 서버와 ±60초 달라도 접속·인사를 처리한다.
- `tools/verify-login-focus.cjs`: 개발 기준 소스의 7개 로그인·비밀번호·Tab·마을 입장 검사 통과, 브라우저 예외 0건. 배포 폴더 검사는 이번에 실행하지 않았다.
- `tools/verify-village-wave.cjs`: 인사 90, 등반 80, 인사 원상 복원 18, 등반 원상 복원 20, 끄덕임·기쁨 발 접지 180 등 총 388개 검사 통과. 기존 착용 34조합·포즈 120개도 통과.
- `tools/verify-village-world.cjs`: 두 학생의 실제 걷기·친구 인사·물/절벽/가구 충돌, 카메라, 돌계단·나무계단·다리, 교실 목록→참가→정답 100점 저장, 상점 직원→상품/피팅/옷장→복귀, 착용의 친구 반영, 줄 오르내리기·원격 모션, 같은 계정 여러 탭과 로그아웃을 확인했다. 12개 그룹·18개 실제 경로·23개 캡처, 브라우저 예외 0건.
- PC 1024×632·1280×632·1366×768·1920×1080에서 마을·상점 총 8개 배치의 메뉴 겹침·잘림·가로 넘침 없음. 직원 간판은 실내 입장 아바타의 이름판과 겹치지 않게 옆으로 옮겼다.
- 첫 스냅샷부터 내려가는 친구와 기존 친구의 손 포즈가 같은 높이에서 일치한다. 등반 모달 800ms 중 높이는 유지하고 재개 후 조금씩 이어서 이동한다. 밧줄 경로 밖의 공중 좌표는 친구 표시에서 제외한다.

자동 검사의 캡처·JSON은 재생성 가능한 `검증/`에 저장하며 GitHub에 올리지 않는다. 실제 이동 기록은 `검증/숲속마을-최종판/숲속마을-검증.json`, 별도 입장 배치는 `검증/숲속마을-최종배치/숲속마을-최종배치.json`, 독립 재현 검토는 `검증/숲속마을/리뷰.json`에 있다. 이전 판의 결과·실패 캡처는 별도 폴더에 보존한다.

마지막 높이 기준 포즈 변경 후 밧줄 경로를 별도로 재검수했다. 자기 오름·내림 각 143프레임, 친구 오름 133·내림 142프레임에서 발 진행과 손 포즈 진행의 최대 차이는 각각 0.001818·0.0000162이며 정상 착지한다. `숲속마을-밧줄-최종.json`에 기록했다. 일부 전체 페이지 캡처에서 상단 내부가 위로 잘린 모습은 DOM 위치·스크롤이 정상인 상태에서 재현되지 않았다. 전망·주인 대화의 추가 전체/화면 캡처와 연속 두 화면 캡처의 상단 픽셀 차이는 0이었고 직접 열어 정상을 확인했다. 정확한 일회 캡처 원인은 확정하지 않았으며 정상 증거는 `마을-전망-추가-viewport-A.png`와 `옷가게-주인대화-추가-viewport-A.png`다.

## 검수 범위와 다음 확장

실제 배포 사이트의 Firebase 권한·다중 접속은 이번 격리 검사로 확인한 항목이 아니다. 서비스에 연결할 때 기존 Database 규칙이 새 `quiz/village` 경로의 읽기·쓰기를 허용하는지 확인한다. 외부 Database 규칙은 변경하지 않았다. 현재 원화는 정면과 좌우 방향을 사용하며 여러 방향의 뒷모습·교실 좌석·교실 실내 공동 활동·자유 채팅·동굴 내부는 이후 확장 항목이다.

사용자가 배포를 미뤘으므로 기존 `배포용/`은 이전 묶음으로 유지한다. 새 실행 파일 목록은 `tools/deployment-files.cjs`에 반영했고, 다음 배포 준비 때 전체 묶음을 다시 생성하고 확인한다.

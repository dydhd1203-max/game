# 아바타 착용·상점·교사 운영 검수

사용자 최우선 요구는 아바타의 몸·옷이 자연스럽게 연결되고 살아 있는 듯 움직이는 것이다. 처음 수정 시안도 신발 분리·팔 가림 때문에 사용자가 거부했다. 알파 픽셀의 일부 접촉만으로 자연스러움을 판단하지 않고, 지적한 어두운 피부 남자·꽃 민소매·청바지·운동화 조합부터 실제 크기로 다시 확인했다. 이후 사용자가 “훨씬 자연스럽다”고 확인했다.

## 최종 변경

- 옷의 회색 목 구멍을 피부로 오인하는 부분을 제거하고 목·어깨·소매·허리 위치를 맞췄다. 어깨와 드러난 팔·손을 앞뒤 레이어로 나누어 꽃 민소매 밑단에 손이 묻히지 않게 했다.
- 겹쳐진 신발 한 쌍을 중앙에서 나누던 구조가 떨어진 밑창 조각의 원인이었다. 원래 9종 그림은 보존하고, 같은 디자인의 좌우 18개 독립 원화와 발목 입구·접지 메타데이터를 추가했다. 허벅지·무릎·정강이·신발을 연결해 걷기 중 발목이 벌어지지 않게 했다.
- 작은 호흡은 발바닥을 기준으로 움직이고 머리와 뒷머리는 같은 주기를 쓴다. 걷기 양방향, 점프 상승·하강·착지 복귀, 바닥 쪼그림을 실제 키보드 입력으로 확인했다. 현재 앉기는 바닥 쪼그림이며, 향후 교실 의자에 앉는 전용 동작을 구현한 것으로 간주하지 않는다. 확대하면 쪼그림의 골반 아래 원화 경계가 조금 남는다.
- 남자 머리를 4종에서 실루엣이 구분되는 12종으로 늘렸다. 여자 8종, 기존 구매·소유권·성별 호환·염색을 보존했다.
- 상점에 목재 간판, 피팅 아치·받침, 옷걸이·화분, 재봉 소품과 선반을 배치했다. 사용자가 올린 프레임 소재를 실제 선반 테두리에 사용하고, 제공한 프레임·상점·아이콘 참고로 새 투명 소품을 제작했다. 상품명·가격·작은 버튼은 NanumSquareRound의 진한 글자를 쓰고 두꺼운 외곽선·겹친 그림자를 제거했다.
- 교사 화면은 내 퀴즈·수업 관리·학생 관리와 새 퀴즈 만들기로 정리했다. 내 퀴즈에서 문제를 수정하고 같은 문제로 실시간 또는 혼자 풀기를 연다. 기존 OX 저장 자료는 보존하며 이전 퀴즈룸 탭을 일상 화면에 표시하지 않는다.
- 로그인에는 실제 비밀번호 입력 칸을 두어 Tab이 아이디→비밀번호→입장 순서로 이동한다. 아이디 입력 중 숫자가 비밀번호에 들어가던 전역 키 입력도 정리했다.
- 퀴즈 입장 실패는 Firebase의 일회성 읽기 이후 캐시 해제로 존재하는 수업도 거래 시작 때 `null`이 되는 경우를 실제 SDK 10.12.2의 읽기 전용 거래로 재현했다. 참가·답변·진도 거래가 끝날 때까지 구독을 유지하며 실패한 입장으로 빈 수업을 만들지 않는다.

## 검증

모든 게임 동작 검사는 실제 Firebase 쓰기를 차단한 체험 저장소에서 실행했다. 실제 SDK 원인 재현은 읽기 전용으로 수행했다.

| 대상 | 실행 도구·결과 |
|---|---|
| 착용·관절·각 신발의 실제 접촉과 분리 조각 | `verify-avatar-fitting.cjs`: 상품 34조합·동작 120조합 통과, 오류 0. 각 발목·바짓단 접촉과 온전한 한 발 윤곽을 별도로 검사 |
| 실제 움직임 | 연속 호흡·머리/뒷머리 5샘플 동기화, 키보드 좌우 걷기·점프·착지·쪼그림 통과. 실제 224px 화면과 280px 연속 자세·신발 9종·의상 12조합 직접 확인 |
| 얼굴·머리·염색·깜박임 | `verify-sd-avatar.cjs`: 648색상·340개 눈 보호·40개 깜박임 사례 통과, 남자 실루엣 12개 고유 |
| 성별·소유·결제 | `verify-avatar-gender.cjs`: 남자 12종·여자 8종, 기존 호환, 울프컷 구입 240골드 정확히 한 번 차감·재착용·재접속 통과. `verify-economy.cjs` 7그룹 통과 |
| 상점 가독성·선택 | `verify-shop-readable.cjs`: PC 4크기에서 15분류·글자 14px 이상·키보드 포커스·안 쓰기 후 색 선택 통과 |
| 교사 운영 | `verify-teacher-management.cjs`: PC 4크기·16화면, 작성·저장·수정·재열기, 같은 문제의 실시간/혼자 풀기 생성 5그룹 통과. `/배포용/` 경로도 확인 |
| 퀴즈 입장 | `verify-quiz-entry.cjs`: cold-cache 8그룹, 교사 실제 작성·발행→학생 2명 목록 입장·답변·재접속 진도 보존. `/배포용/` 경로도 통과. 기존 `verify-classroom.cjs` 9그룹도 통과 |
| 로그인 | `verify-login-focus.cjs`: PC 3크기·7그룹, 실제 포커스·PIN 키 입력·등록·실패 복구 통과. `/배포용/` 경로도 확인 |
| 기존 퀴즈 무대 | `verify-layout.cjs`: PC 5크기, 24명·7줄 답변, 입력/제출·스크롤 보존·글꼴·줄인 모션 통과. 체험용 숨김 진행자는 교사의 삭제된 탭에 의존하지 않게 수정 |
| 새 신발의 안전한 이미지 로딩 | `verify-file-avatar.cjs`: 호스팅·실제 불투명 출처에서 18발 로딩 및 원화 픽셀 일치, 전신 그림 28개·상품 그림 29개. 새 원화를 로컬 이미지 허용 목록과 9 PNG 바이트 묶음에 함께 추가 |
| 완전한 배포본 | `check-source.cjs`, `build-deployment.cjs --check`, `verify-deployment.cjs`: 71개 파일 SHA-256 원본·배포본·HTTP 일치, 누락 0·브라우저 오류 0. CSS의 로컬 이미지도 배포 목록에 포함되는지 검사 |

검증 결과·화면·연속 영상은 재생성 가능한 `검증/` 및 클라우드 검수 폴더에 보관하며 Git에 올리지 않는다. 실제 클라우드 Chromium의 관리 정책은 `file://` 이동을 차단하므로 Windows에서 파일을 더블클릭한 검증을 수행했다고 보고하지 않는다. 불투명 출처의 실제 보안 제한을 유지한 대체 검사를 통과했다.

## 배포와 다음 공간

`퀴즈나라/배포용/` 전체를 배포한다. 실행 파일·원화·글꼴·헤더와 배포 정보가 함께 있어야 한다. Cloudflare Pages 무료 플랜과 GitHub 자동 연결을 추천하며 설정은 `배포안내.md`에 저장했다. Cloudflare/Netlify 외부 계정의 실제 사이트 배포나 두 서비스의 실측 속도 비교를 완료한 것으로 보고하지 않는다.

다음 단계는 접속하면 우리 반 친구가 언제든 모이는 숲속 마을이다. 사용자가 요청한 작은 아바타, 오르내리는 숲길·나무집·다리·폭포·동굴·숨은 길, 건물로 연결되는 교실·퀴즈·상점, 다가가 인사·손 흔들기·감정 표현을 `AGENTS.md`에 저장했다. 현재 수정본에 이 마을이나 실시간 친구 동기화까지 구현한 상태는 아니다.

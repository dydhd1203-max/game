# SD 아바타·의상 착용·로비 개선 기록

사용자 요청: 아바타와 상점 그림이 안 나오는 오류를 고치고, 게임 제목·풍성한 숲 로비를 다듬는다. 도트 스타일을 폐기하고 제공한 SD 의상 시트의 얼굴·헤어·의상 느낌을 사용한다. 실제 전신을 참고와 교차 비교하며 기본 이동·점프·앉기를 자연스럽게 만들고, 옷이 몸에서 떠 보이는 목선·소매·허리 연결을 맞춘다.

작성한 변경은 `퀴즈나라/`에 한정한다. 원격의 다른 게임 작업을 두 차례 받아 최신 `835d14d`까지 보존했다. 아래 상태는 이번 추가 작업의 범위이며 기존 다섯 방식의 전체 맵을 다시 만든 것으로 해석하지 않는다.

직접 열어 본 최종 자료에는 실제 로비·상점, 의상 전신 5개, 신발 전신 4개, 실제 키 입력의 전신 포즈, 남녀 헤어·밝고 어두운 피부의 뜬 눈·반쯤 감은 눈·감은 눈이 포함된다. 초안에서 보였던 사각형·격자 같은 피부 패치와 겹친 속눈썹을 수정한 뒤 확대 화면을 다시 확인했다. 발바닥에 맞춰 접지 그림자도 옮겼다. 자동 검사 통과와 원화 자체의 미술 평가는 구분했다.

마지막 별도 확인: 묶은 머리 원화는 온전하지만 얼굴 중심으로 배치한 처리 영역의 오른쪽 끝에서 잘렸음을 발견했다. 눈 중앙을 기준으로 좌·우 각각이 표시 영역 안에 들어오게 배율을 맞춘 뒤, 노출 헤어 12종 모두 양쪽 Canvas 가장자리의 불투명 픽셀 0개를 확인했고 실제 280px 전신을 직접 열어 머리 끝과 목선을 확인했다. 이 별도 확인은 앞의 전체 색상 검사 재실행으로 표시하지 않는다.

상점 정리는 1366×768·390×844에서 부위 15개 각각의 상품을 실제로 선택한 30개 경우와 가로 탭 이동을 확인했다. 모바일 탭 높이는 198→63px, 옷장 상품 공간은 66→238px가 되었다. 옷장에 가진 세 색이 함께 표시되고 상점으로 돌아오면 12색 선택이 복원되며, 상품 키·가격은 유지된다. 화면 넘침과 실행 오류가 없었다.

숲 마을 UI에서 기존 편집기의 높은 우선순위로 남은 파란 미리보기·보라색 선택 카드·파란 하단 바를 나무·크림·녹색으로 맞췄다. 테두리가 제목 위로 올라온 상점은 측면 프레임 두께를 줄였고 실제 화면을 다시 열어 확인했다. 프레임의 가운데는 투명하며 버튼 입력을 받지 않는다.

최종 스타일 후 기존 게임과 레이아웃 검사를 동시에 돌렸을 때 숨쉬기 시간 증가와 제출 버튼 영역 검사에서 한 차례씩 실패했다. 원인은 확정하지 않았다. 실제 노드·Animation 객체·표시 여부·rAF 시간·버튼 경계를 계측한 순차 진단과 계측 없는 원본 검사 재실행은 모두 통과했다. 숨쉬기는 같은 Animation 객체에서 80ms 대기 구간에 약 100ms 진행했고, 답안 버튼은 5해상도 모두 표시·활성·연결 상태와 화면 안 경계를 확인했다. 검증 조건을 완화하거나 런타임을 추측 수정하지 않았다.

각 보관함의 실제 검색·분류·이미지 표시와 원본 ZIP/이미지 바이트 일치를 확인했다. 이 결과는 자료 보관·검색 완료이며, 사용자 JPEG를 투명 소품·착용 부위·가변 테두리로 준비하거나 모든 게임 맵에 적용한 결과가 아니다. 현재 런타임의 SD 원화·소품·풍성한 로비·새 프레임은 별도로 유지한다. 최신 사용자 지시 이후 추가한 아이콘·테두리·통합 보관함 검수는 PC를 기준으로 한다.

재생성 가능한 이미지·JSON은 `검증/` 및 현재 클라우드의 `/workspace/quiz-cloud/`에 있으며 Git 커밋에는 포함하지 않는다. 기본 검사 명령과 목적은 [개발환경.md](./개발환경.md)에 있다.

## 확인 범위의 한계

검사는 클라우드 Chromium의 격리된 `?demo=1`과 실제 Firebase SDK 차단으로 실행한다. 실제 수업 데이터에 쓰지 않는다. 이 클라우드에서 `file://` 주소 탐색은 관리 정책으로 차단되므로 학교 Windows의 직접 더블클릭 실행을 확인했다고 보고하지 않는다. 원점 없는 실제 sandbox에서 동일한 Canvas 보안 오류를 재현하고 원본 픽셀·투명도 일치를 검사한다.

메인 로비와 아바타·의상의 이번 미술 개선을 모든 퀴즈 맵이 참고 수준을 달성한 것으로 확대하지 않는다. 자유풀이의 기존 성·포장·NPC, 라운드의 넓은 평면 공간·작은 아바타 등은 기존 미술 보강 과제로 남는다. 실제 그램·크롬북 성능과 실제 Firebase 교실 접속은 이번 클라우드 검수의 범위가 아니다.

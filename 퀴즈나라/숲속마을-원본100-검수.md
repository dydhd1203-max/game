# 100% 원본 복원·가을공원·캠핑장 검수

2026-10-04. 현재 중앙광장은 원본 소풍 맵이다. 아래 내용은 이번에 실제 실행한 결과이며 예전 집/큰 나무/개울의 PASS를 인용하지 않는다. 아바타 제작, 실제 학교 교실/운동장 원화와 저장 데이터는 변경하지 않았다.

## 반영 내용

- 중앙광장1~5를 겹치는 한 지도에 정합했다. 원본 연못·벚나무·돗자리·탁자·자판기·선착장을 복원하고 추가 집·큰 나무·개울·우물을 실행 장면에서 제거했다. 학교가는 길 표지판은 출입구 옆에 유지했다.
- 교실숲/나무집/퀴즈공원/가을공원/캠핑장도 제공100% 캡처로 교체했다. 가을공원은 중앙광장 북동쪽 입구, 캠핑장은 가을공원 동쪽과 달빛 나무집 밑동 동쪽 입구로 연결한다. 자동 접촉 이동과 도착 직후 왕복 방지를 유지한다.
- 광장 오른쪽 반딧불 모험숲에는 구름다리/사다리 두 개, 밟는 버섯6개, 발견하는 달빛 돌3개, 통나무 쉼터를 배치했다. 발견 상태는 해당 공간 방문 중에만 유지하며 골드/보유 아이템을 변경하지 않는다. 생성 원화는 제공 원본 맵과 별도 출처로 기록했다.
- 주황 나무 전경에서 잔디까지 불투명하게 덮던 문제는 실제 나뭇잎/줄기 픽셀을 유지하고 녹색 배경 알파를 제거했다. 원본 배경/전경 등록 좌표는 동일하다. 마스크는 원본 해상도로 한 번 만들어 캐시한다.
- 사용하지 않는 저해상도 광장/추가 사물22개는 실행 파일 목록에서 제외했다. 원본 보관함의 자료는 삭제하지 않았다. 새 여섯 맵/모험숲/표지판은 실행 파일 목록에 포함한다.

## 해상도와 출처의 한계

원본 ZIP6개/사진20개를 바이트/해시와 함께 보존했다. 19장은 정수 위치로 복사하고 캠핑장4는 캡처 배율 차이 약0.218%를 명시적으로 정합했다. 새로운 디테일을 AI로 복원하지 않았다. 주요 이미지 크기는2230×1472(광장),2244×1504(가을),2678×1500(캠핑)이다.

| 맵 | 100% 자료 사용 면적 | 기존 자료가 남는 이유 |
|---|---:|---|
| 중앙광장 | 95.28% | 외곽 및 모든 캡처에서 가려진 일부 영역 |
| 나무집 | 96.44% | 외곽/일부 UI 영역 |
| 퀴즈공원 | 90.03% | 하늘 외곽, UI 영역. 잔여 깃발은 제공 사진의 빈 하늘로 정리 |
| 교실숲 | 82.10% | 상단 UI 구석. 서로 다른 반쪽 수관을 섞지 않고 기존 온전한 나무 묶음을 보존 |
| 가을공원 | 93.00% | 외곽 및 겹치지 않는 UI 구석 |
| 캠핑장 | 90.67% | 외곽/UI 구석. 이 수치는 정합한4번 사진도 포함 |

`original-resolution/sources.json`, `build.json`, 각 provenance PNG가 실제 범위를 기록한다. 따라서 ‘모든 픽셀100% 복원’으로 보고하지 않는다. 캠핑장 하단 물의 약한 직사각형 명암 경계는4번 제공 사진 내부에도 존재하며, 해당 부분은 사진4 픽셀로 이어져 있다. 원본에 이미 있는 물 표현을 합성 절단으로 오인해 새 그림으로 덮지 않았다.

## 실제 실행

환경: 관리형 Linux Chromium, 실제 Firebase SDK/주소를 차단한 `?demo=1`. 1366×768/1920×1080, 사다리 공유 검사는 동일 체험 세션의 학생2명이다.

- `check-source.cjs`: 현재129개 실행 파일 및 원화 데이터 일치, 구문 확인.
- `verify-original-forest-maps.py`: 여섯 맵/사진20장의 해시·픽셀 출처·제외 메뉴/촬영 인물·온전한 기존 나무 묶음·삭제 실패 대조 통과. 출력 `/workspace/quiz-cloud/original-resolution/provenance`.
- `verify-forest-village.cjs`: 현재7공간의26개 검수 경로와 출입구 접근/도착 위치, 광장 추가 사물 제거, 주황 수관 알파, 가을공원/캠핑장 실제 걷기·C·인사, 두 PC 해상도 캡처 통과. 원본과 배포 경로 모두 실행했다.
- `verify-auto-portals.cjs`: 숲15개와 학교4개, 총19개 출입 지점 실제 이동/도착 잠금, F 비이동, 계정 보존, 누른 방향키 유지 이동 통과. 원본과 배포 경로 모두 실행했다.
- `verify-forest-climbing.cjs`: 새 모험숲의 ↑↓ 부착/상하 이동/중간 정지/역방향, 등진 표시와 친구 높이, 두 데크 사이 걷기, C 앉기, 버섯6개/달빛 돌3개 실제 방문, 모션 줄이기·정지·재접속·종료 정리 통과. 원본 경로에서 실행했다.
- `build-deployment.cjs`와 `--check`: 배포본129개가 소스와 정확히 일치한다.

주요 결과는 `/workspace/quiz-cloud/original-resolution/{village,portals,adventure,release-village,release-portals}`의 JSON/PNG다. 재생성 가능한 캡처는 Git에 넣지 않는다. `school-room-scene.js`, `playground-scene.js`, avatar 모듈 및 교실/운동장 원화는 Git diff가 없다.

## 직접 연 화면과 남은 구분

전체 합성6장을 직접 열어 메뉴/촬영 인물 제거와 주요 접합을 확인했다. 플레이 화면에서는 원본 벚나무 광장, 주황 수관 뒤와 가장자리, 학교 표지판, 가을 입구/그네/텐트 길, 캠핑 모닥불/호수, 교실숲, 나무집, 하늘섬, 모험숲 달빛 돌/사다리 중간/양쪽 데크를 확인했다. 배포 경로에서도 가을 입구, 캠핑 모닥불(1920px), 광장 입장 화면을 열었다. 캡처 밖으로 나간 사물은 절단 결함으로 판정하지 않는다.

현재 합성/이동 검사를 아바타 착장 전체나 모든 나무의 모든 방향 가림 검사로 확대하지 않는다. 기존 나무집/하늘섬의 보행 사다리를 새 모험숲의 전용 등반 검사와 혼동하지 않는다. 실제 수업 Firebase, 학교 기기/30명 성능, Cloudflare 공개 배포 완료는 이번 로컬 검사로 확인하지 않았다.

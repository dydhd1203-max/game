## 원화와 실행 파일

새 남자 원화는 기존 의상의 부드러운 선·천 명암·봉제·소매 안감에 맞춘 별도 생성 원화다. 제작 요약, 투명 셀·목구멍 마스크·소매 앵커·고정 색·표시 영역은 `assets/sd-clothes-male.json`에 기록했다. 목구멍 안에 남은 작은 불투명 조각은 원본 PNG를 다시 칠하지 않고 보수적인 내부 마스크로만 제거한다. 기존 얼굴·앞/옆/뒤 머리와 여자 의상 PNG는 바꾸지 않는다.

당시 남자 PNG는 1,622,605bytes이며 SHA256은 `eb4649ac2a8b5c50ef279efa71c07f9b6317cbb4059a50f5b7f954815af67d81`이다. 로컬/불투명 원점용 데이터는 `avatar-file-data-male.js`로 분리했다. 기존 13원본 번들의 바이트는 유지하고 새 번들도 Pages의 파일당 25MiB 제한 아래로 관리한다. 배포 실행 파일은 97개다.

2026-10-03 복원 주의: 위 해시의 남자 원화는 환경 중단 후 발견되지 않았다. 사용자 허가로 이전 프롬프트와 기존 그림체를 참고해 다시 제작한 현재 원화는 1983×793이며 SHA256 `8532abf862b870ae497c9a8589d00a43700e7e7730708915bea66b84eaa3ef2c`다. 기존 이미지와 동일한 복원본이 아니다. 현재 실행 목록과 새 몸 단계는 [기준 몸 검수](기준몸-검수.md)를 따른다.

- 상점 실제 UI 12개 흐름: 남녀 진열·고정 색·과거 보유·한벌옷 입기/벗기/분리 전환·성별 전환·무작위 꾸미기·피부 구매/재접속/재착용/잔액 부족·최초 선택·지연 구매 중 모달 종료와 착장 변경 차단·옛 한복 치마만 가진 계정의 무료 한벌 착용을 확인했다. 경제 저장 14개 경우와 남자 12/여자 8개 헤어·실제 성별 썸네일 검사도 통과했다.
- 가독성은 1024×768, 1280×720, 1366×768, 1860×900에서 16개 탭·본문·키보드 포커스·넘침을 확인했다. 한벌옷 상품 썸네일은 실제 몸 레이어만 사용하여 머리가 섞이지 않는다.

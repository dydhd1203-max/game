# 큐플레이 목표 — 퀴즈 푸는 방식과 화면 디자인

2026-10-08 사용자 지정: **“내가 추구하는 게임 스타일, 디자인은 바로 이 큐플레이야.”** 퀴즈나라의 퀴즈 진행·방·아바타·상점 설계는 이 문서를 목표로 삼는다. 새 퀴즈 화면을 만들거나 고치기 전에 이 문서를 먼저 읽는다. 참고 모음 사진은 [디자인기준/16-큐플레이-참고모음.webp](디자인기준/16-큐플레이-참고모음.webp)이다.

이 문서는 조사·목표 기록이다. 여기에 적었다고 구현된 것이 아니며, 구현과 검수는 각 검수 기록에 따로 남긴다.

## 1. 큐플레이는 무엇인가

- 넥슨의 온라인 퀴즈·퍼즐·아바타 커뮤니티 게임. 1999년 10월 **퀴즈퀴즈**로 시작해 2001년 **퀴즈퀴즈 플러스**(세계 최초 부분유료화), 2003년 **큐플레이**로 개편, 2015년 12월 31일 종료.
- 2023년 1월 넥슨타운의 **서바이벌 OX** 이벤트, 2024년 11월 메이플스토리 월드의 **큐플레이 아카이브/리턴즈**(최대 100명, PC·모바일)로 다시 열렸다.
- 핵심 순환: **로비·채팅에서 친구를 만난다 → 방에 들어가 여러 명이 같은 퀴즈를 겨룬다 → 이겨서 사이버머니를 번다 → 아바타 옷·머리·장신구를 사서 꾸민다 → 레벨(초기 IQ 지수)로 실력을 보여 준다.**
- 아이템은 대부분 외형용이며 “내 아바타가 멋지고 똑똑해 보이게” 하는 것이 동기다. 일부 아이템은 IQ·레벨 조건이 있었다.

## 2. 퀴즈 방식 (조사 결과)

| 게임 | 진행 | 입력 | 승패·보상 |
|---|---|---|---|
| 서바이벌 OX | 정기적으로 열리는 큰 방. 문제 15개. 최대 32명(넥슨타운·리턴즈는 대규모) | F1/F2로 캐릭터를 O 또는 X 쪽으로 옮김. 이벤트판은 방향키로 직접 이동 | 틀리면 그 자리에서 탈락. 끝까지 남으면 보상 |
| 서바이벌 XO | OX와 같되 **일부러 틀린 쪽**을 고름 | F1/F2 | 끝까지 남으면 더 큰 보상, 중도 탈락은 없음 |
| 올라올라 | 역사·정치 중심 문제. 참가자가 통(버킷)에 올라탄 채 답함 | 선택 | 오답 탈락 |
| 올라타자 | 주어진 문장을 그대로 타이핑 | 키보드 타이핑 | 한 글자라도 틀리면 탈락. 가장 인기 있던 서바이벌 |
| 퀴즈의 달인 | 채널에 방 하나. 1명이 도전하고 4명이 대기 | 사지선다 15문제 | 15문제를 모두 맞히면 채널 전체에 “○○님이 퀴즈의 달인” 공지와 보상 |
| 스피드 퀴즈 | 60초 동안 약 20문제 | 바로바로 답, **패스** 가능 | 정답 +, 오답 −, 패스 0. **연속 정답 콤보**가 높을수록 고득점 |
| 연상퀴즈 | 힌트 6개를 보고 답을 떠올림 | 단답 입력 | 적은 힌트로 맞힐수록 유리 |
| 가로세로 | 크로스워드 | 낱말 입력 | 칸 채우기 |
| 빙고빙고 | 빙고판을 퀴즈로 채움 | 칸 선택 | 줄 완성 |
| 브레인 써바써바 | 방송 예능 형식. 개인전은 일정 시간마다 방이 다시 열림 | 선택 | 생존 |

방 구조: 서바이벌은 **정기 생성 방**에 들어가고, 퀴즈퀴즈 게임은 **사용자가 방을 만든다**. 채팅 채널에는 이야기방·개인샵·교환방이 있었다.

## 3. 화면 디자인 (참고 모음 사진 분석)

- **퀴즈 방 = 무대.** 위쪽 가운데에 큰 문제판(글·그림 문제), 아래쪽에 참가자 아바타가 **전신으로 한 줄** 서 있다. 각자 작은 단상·이름표·점수 칸이 있고, 정답·오답 표시가 머리 위에 뜬다. 옆에는 점수·순위 목록이 세로로 붙는다.
- **번호로 답한다.** 사지선다는 화면 아래 큰 1·2·3·4 버튼과 키보드 숫자를 함께 쓴다. 남은 시간은 막대·숫자 타이머(예: 03:23)로 보인다.
- **OX는 땅 위의 두 구역.** 넓은 잔디·맵에 큰 O(동그라미)와 X 구역을 칠하고, 캐릭터가 직접 걸어가 선다. 틀린 쪽 무리가 한꺼번에 떨어지는 장면이 재미의 중심이다.
- **대기실은 좌석 격자.** 방 목록과, 들어간 방의 2줄 × 8칸 정도 좌석에 아바타 얼굴/전신이 들어간 칸, 방장·준비 상태, 큰 나가기(EXIT) 버튼.
- **창(UI) 재질.** 원작은 광택 있는 코발트·하늘색 창틀, 흰 테두리, 짙은 파랑 머리띠, 작은 아이콘이 촘촘한 2000년대 창 구성이다. 로고는 노랑·주황 고리 모양 Q와 둥근 파랑 글자다.
- **아바타.** 큰 머리의 SD 비율, 또렷한 외곽선, 밝은 원색 옷. 방·로비·상점 어디서나 같은 아바타가 전신으로 보이며, 꾸민 모습이 곧 자랑거리다.
- **상점·교환.** 아이템 칸을 격자로 늘어놓고 옆에 입어 본 아바타를 크게 보여 준다.

## 4. 퀴즈나라에 적용할 목표

이미 있는 것과 큐플레이 목표를 구분한다. 3학년 교실 수업용이므로 **탈락으로 오래 구경만 하게 만들지 않고**, 교사가 수업 중에 진행할 수 있어야 한다.

| 큐플레이 요소 | 퀴즈나라 현재 | 목표 |
|---|---|---|
| 무대형 퀴즈 방(문제판 위, 아바타 한 줄 아래, 머리 위 O/X) | 라운드전 소풍 돗자리, 퀴즈 맵 | 일반 퀴즈의 기본 화면을 **무대형**으로: 문제판·타이머·1~4 큰 버튼, 참가자 전신 줄, 정답 공개 때 머리 위 표시와 기뻐하기/아쉬워하기 동작 |
| 서바이벌 OX | 별도 OX 화면(유지 중) | 마을·운동장 같은 맵에 O/X 구역, 직접 걸어서 선택. 틀려도 관중석에서 계속 답을 맞혀 보는 **부활·연습 칸**으로 교실 참여 유지 |
| 스피드 퀴즈 | 없음 | 60초·패스·콤보 점수. 콤보 숫자를 크게 보여 줌 |
| 퀴즈의 달인 | 없음(혼자 풀기 있음) | 혼자 풀기의 도전 모드: 연속 정답 사다리, 완주 시 반 전체 알림 |
| 연상퀴즈 | 없음 | 힌트를 하나씩 공개, 짧은 답 입력 |
| 가로세로 | 팀 가로세로 있음 | 유지 |
| 대기실 좌석 격자 | 수업 참가·대기 화면 | 들어온 친구의 아바타가 좌석 칸에 차오르고, 준비 상태와 교사 시작을 보여 줌 |
| 사이버머니로 꾸미기, 레벨 | 골드·옷 가게·오늘의 연습 | 유지. 레벨/배지로 “똑똑해 보이는” 자랑 요소를 검토 |

디자인 원칙:

1. **아바타가 주인공이다.** 퀴즈 중에도 내 아바타와 친구 아바타가 전신으로 보이고, 정답·오답에 반응한다. 꾸민 옷이 퀴즈 화면에서 보여야 꾸밀 이유가 생긴다.
2. **한눈에 읽히는 무대.** 문제판은 크고 밝게, 답 버튼은 번호와 함께 크게, 시간은 늘 보이게. 장식은 무대 가장자리로 보낸다.
3. **결과는 장면으로 보여 준다.** 점수표만 띄우지 않고 맞힌 친구의 기뻐하기, OX 구역의 이동처럼 몸으로 보여 준다.
4. **채팅·인사로 모인다.** 로비·마을에서 친구에게 다가가 인사하는 기존 방향은 큐플레이의 채팅 광장과 같은 목적이다.

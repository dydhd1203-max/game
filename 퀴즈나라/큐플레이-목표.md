# 큐플레이 목표 — 퀴즈 푸는 방식과 화면 디자인

2026-10-08 사용자 지정: **“내가 추구하는 게임 스타일, 디자인은 바로 이 큐플레이야.”** 퀴즈나라의 퀴즈 진행·방·아바타·상점 설계는 이 문서를 목표로 삼는다. 새 퀴즈 화면을 만들거나 고치기 전에 이 문서를 먼저 읽는다. 참고 모음 사진은 [디자인기준/16-큐플레이-참고모음.webp](디자인기준/16-큐플레이-참고모음.webp)이다.

이 문서는 조사·목표 기록이다. 여기에 적었다고 구현된 것이 아니며, 구현과 검수는 각 검수 기록에 따로 남긴다.

## 1. 큐플레이는 무엇인가

- 넥슨의 온라인 퀴즈·퍼즐·아바타 커뮤니티 게임. 1999년 10월 **퀴즈퀴즈**로 시작해 2001년 **퀴즈퀴즈 플러스**(세계 최초 부분유료화), 2003년 **큐플레이**로 개편, 2015년 12월 31일 종료.
- 2023년 1월 넥슨타운의 **서바이벌 OX** 이벤트, 2024년 11월 메이플스토리 월드의 **큐플레이 아카이브/리턴즈**(최대 100명, PC·모바일)로 다시 열렸다.
- 핵심 순환: **로비·채팅에서 친구를 만난다 → 방에 들어가 여러 명이 같은 퀴즈를 겨룬다 → 이겨서 사이버머니를 번다 → 아바타 옷·머리·장신구를 사서 꾸민다 → 레벨(초기 IQ 지수)로 실력을 보여 준다.**
- 아이템은 대부분 외형용이며 “내 아바타가 멋지고 똑똑해 보이게” 하는 것이 동기다. 일부 아이템은 IQ·레벨 조건이 있었다.

## 3. 화면 디자인 (참고 모음 사진 분석)

- **퀴즈 방 = 무대.** 위쪽 가운데에 큰 문제판(글·그림 문제), 아래쪽에 참가자 아바타가 **전신으로 한 줄** 서 있다. 각자 작은 단상·이름표·점수 칸이 있고, 정답·오답 표시가 머리 위에 뜬다. 옆에는 점수·순위 목록이 세로로 붙는다.
- **번호로 답한다.** 사지선다는 화면 아래 큰 1·2·3·4 버튼과 키보드 숫자를 함께 쓴다. 남은 시간은 막대·숫자 타이머(예: 03:23)로 보인다.
- **OX는 땅 위의 두 구역.** 넓은 잔디·맵에 큰 O(동그라미)와 X 구역을 칠하고, 캐릭터가 직접 걸어가 선다. 틀린 쪽 무리가 한꺼번에 떨어지는 장면이 재미의 중심이다.
- **대기실은 좌석 격자.** 방 목록과, 들어간 방의 2줄 × 8칸 정도 좌석에 아바타 얼굴/전신이 들어간 칸, 방장·준비 상태, 큰 나가기(EXIT) 버튼.
- **창(UI) 재질.** 원작은 광택 있는 코발트·하늘색 창틀, 흰 테두리, 짙은 파랑 머리띠, 작은 아이콘이 촘촘한 2000년대 창 구성이다. 로고는 노랑·주황 고리 모양 Q와 둥근 파랑 글자다.
- **아바타.** 큰 머리의 SD 비율, 또렷한 외곽선, 밝은 원색 옷. 방·로비·상점 어디서나 같은 아바타가 전신으로 보이며, 꾸민 모습이 곧 자랑거리다.
- **상점·교환.** 아이템 칸을 격자로 늘어놓고 옆에 입어 본 아바타를 크게 보여 준다.

## 4. 퀴즈나라에 적용할 목표

이미 있는 것과 큐플레이 목표를 구분한다. 3학년 교실 수업용이므로 **탈락으로 오래 구경만 하게 만들지 않고**, 교사가 수업 중에 진행할 수 있어야 한다.

| 큐플레이 요소 | 퀴즈나라 현재 | 목표 |
|---|---|---|
| 무대형 퀴즈 방(문제판 위, 아바타 한 줄 아래, 머리 위 O/X) | 라운드전 소풍 돗자리, 퀴즈 맵 | 일반 퀴즈의 기본 화면을 **무대형**으로: 문제판·타이머·1~4 큰 버튼, 참가자 전신 줄, 정답 공개 때 머리 위 표시와 기뻐하기/아쉬워하기 동작 |
| 서바이벌 OX | 별도 OX 화면(유지 중) | 마을·운동장 같은 맵에 O/X 구역, 직접 걸어서 선택. 틀려도 관중석에서 계속 답을 맞혀 보는 **부활·연습 칸**으로 교실 참여 유지 |
| 스피드 퀴즈 | 없음 | 60초·패스·콤보 점수. 콤보 숫자를 크게 보여 줌 |
| 퀴즈의 달인 | 없음(혼자 풀기 있음) | 혼자 풀기의 도전 모드: 연속 정답 사다리, 완주 시 반 전체 알림 |
| 연상퀴즈 | 없음 | 힌트를 하나씩 공개, 짧은 답 입력 |
| 가로세로 | 팀 가로세로 있음 | 유지 |
| 대기실 좌석 격자 | 수업 참가·대기 화면 | 들어온 친구의 아바타가 좌석 칸에 차오르고, 준비 상태와 교사 시작을 보여 줌 |
| 사이버머니로 꾸미기, 레벨 | 골드·옷 가게·오늘의 연습 | 유지. 레벨/배지로 “똑똑해 보이는” 자랑 요소를 검토 |

디자인 원칙:

1. **아바타가 주인공이다.** 퀴즈 중에도 내 아바타와 친구 아바타가 전신으로 보이고, 정답·오답에 반응한다. 꾸민 옷이 퀴즈 화면에서 보여야 꾸밀 이유가 생긴다.
2. **한눈에 읽히는 무대.** 문제판은 크고 밝게, 답 버튼은 번호와 함께 크게, 시간은 늘 보이게. 장식은 무대 가장자리로 보낸다.
3. **결과는 장면으로 보여 준다.** 점수표만 띄우지 않고 맞힌 친구의 기뻐하기, OX 구역의 이동처럼 몸으로 보여 준다.
4. **채팅·인사로 모인다.** 로비·마을에서 친구에게 다가가 인사하는 기존 방향은 큐플레이의 채팅 광장과 같은 목적이다.

### 서바이벌 XO = 땅 위 O/X 구역 (44~82초)

- 위에서 내려다본 **리벳 박힌 금속 바닥**. 왼쪽 큰 분홍 **X 구역**, 가운데 **? 대기 구역**, 오른쪽 큰 파란 **O 고리**. 둘레에 배관·밸브, 오른쪽 위 창에 **진행자 캐릭터**(가면 쓴 기관사).
- 참가자는 아바타 대신 **둥근 털뭉치/슬라임**으로 위쪽 출발선에 서 있다가 걸어서 구역으로 들어간다. 머리 위 말풍선 채팅.
- 가운데 위 점수판 **`00 VS 05`** = 지금 X 구역 인원 대 O 구역 인원을 실시간으로 센다.
- 문제판 순서: “서바이벌 XO에 오신 것을 환영합니다” → 규칙(“일부러 틀려야 하는 게임”, “끝까지 살아남으면 큰 보상”) → `<문제 1> '상식'에 관한 문제` → 문제와 “맞으면 O, 틀리면 X” → **“3초 안에 결정하세요!!” + HURRY UP 자명종** → `[정답] 정답은 X (정답률 98% 문제)`.
- 공개 때 **탈락 구역 바닥이 용암처럼 끓는 그림으로 바뀌고**, 살아남은 쪽 머리 위에 반짝 놀람 표시. 잠시 뒤 바닥이 원래대로 돌아오고 다음 분야 안내.

### 그림·연출에서 배울 점

- **손그림 화풍:** 굵고 진한 외곽선, 평평한 채색에 한 단계 그림자, 장난감 같은 기계 소품(문어 기계·배관·밸브·자명종). 사진 질감이나 매끈한 3D가 없다.
- **장면마다 주인공 연출이 하나:** 시작 제목 그림, HURRY UP 자명종, 큰 O/X, 물 차오름·용암 바닥. 짧고 크게 보여 주고 바로 사라진다.
- **상태를 머리 위 기호로:** 고민 중(물음표 동전) → 정답/오답(O/X) → 탈락(잠김/떨어짐). 점수표를 따로 읽지 않아도 누가 어떤지 보인다.
- **문제판은 한 곳:** 안내·규칙·분야·문제·정답·정답률·설명이 모두 같은 판에서 차례로 바뀐다.
- **탈락해도 함께 있다:** 잠긴 아바타가 화면에 남아 채팅한다. 교실에서는 이것을 “관중석에서 계속 맞혀 보기”로 살린다.

### 퀴즈나라 적용 설계 (숲속 마을 색 유지)

**들어가는 길 — QUIZQUIZ 로비 (2026-10-08 사용자 확정)**

1. 로그인하면 지금처럼 **숲속 마을**에 들어간다.
2. 화면 위 UI의 **QUIZQUIZ 탭**을 누르면 큐플레이 첫 화면 같은 **퀴즈 로비**가 열린다: 대기실(방) 목록, **방 만들기 / 바로 시작 / 대기방 보기**, 로비 채팅, 내 아바타 카드(이름·레벨·골드), 접속한 친구 목록.
3. **학생도 친구끼리 하려고 방을 만들 수 있고, 선생님도 방을 만든다.** 수업 때는 선생님이 방을 만들고 학생들이 그 방에 들어온다.
4. 방에 들어가면 좌석 칸에 아바타가 차오르는 대기실 → 방장이 시작 → 무대 퀴즈 또는 서바이벌 OX → 결과 → 대기실로 돌아온다.

**무대형 일반 퀴즈** — 꼬로록의 구성을 숲 무대로 옮긴다.

- 위: 나무 간판 위 크림 종이 **문제판**(안내 → 문제 → 정답·정답률·설명이 차례로 바뀜). 무대 양옆 장식은 숲 소품.
- 가운데: 학생 아바타가 **2~3줄의 무대 칸**(나무 그루터기·잎 장식 칸)에 전신으로 서고 칸 아래 이름표. 21~30명이 한 화면에 들어가야 한다.
- 아래: **1·2·3·4 큰 번호 버튼**(키보드 1~4), 객관식이 아닌 문항은 기존 입력 UI. 남은 시간 막대와 마지막 몇 초의 **자명종 + “서둘러요!”**.
- 연출: 답을 고르면 머리 위 **물음표**, 공개 때 머리 위 **O/X**와 무대 가운데 큰 O/X, 맞힌 아이는 **깡충**, 틀린 아이는 **잎사귀 소나기/물방울을 맞고 털썩**(탈락 없음, 점수만 다름). 끝나면 순위.
- 시작·끝에 큰 제목 그림(“무대 퀴즈”)이 튀어나왔다 사라짐.

**서바이벌 OX** — 꼬로록·XO의 연출을 마을 맵 위에서.

- 기존 맵(운동장 또는 소풍공원)의 넓은 바닥에 **O 구역·X 구역·가운데 대기 구역**을 표시하고, 학생은 자기 아바타로 직접 걸어가 선다. 위쪽에 **`O 7 : 5 X` 실시간 인원판**.
- 문제판 순서와 “3초 안에 결정” 자명종을 그대로 따른다. 공개 때 틀린 구역에 **물웅덩이/낙엽 더미가 덮치는 장면**, 틀린 아이는 가운데 **관중석(구경 칸)**으로 옮겨져 계속 답을 골라 보며 연습 점수를 얻는다. 끝까지 남은 아이가 우승, 교사는 언제든 “모두 부활”로 다시 시작할 수 있다.
- 맵 소재 규칙: 바닥·지형은 제공 에셋을 쓰고, O/X 구역 표시는 게임 UI 층으로 둔다.

**손그림 느낌 구현 원칙**

- 새 UI 그림(문제판·답 버튼·자명종·O/X·물음표)은 굵은 외곽선과 평평한 채색으로 그린다. 강한 광택·유리 반사·블러 글로를 쓰지 않는다.
- 연출 애니메이션은 `steps()` 계단식 타이밍(초당 8~12장 느낌)과 과장된 준비·여운 자세를 쓴다. 아바타의 깡충·털썩도 같은 박자로 맞춘다.
- `prefers-reduced-motion`이면 큰 움직임을 줄이고 결과 표시만 남긴다.

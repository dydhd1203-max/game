# 양반다리(바닥 앉기) 원화 검수 (2026-10-14)

**main 합치기(실제 배포) 전**이다. 체험 주소(`?demo=1&avatar=foundation`)에서만 보인다.

## 사용자 결정

- 원본 그림에 없는 모양은 수치 조정 전에 바로 원화를 요청한다. 그림 검수에서 두 번 실패하면 수치 조정을 멈춘다.
- 바닥 앉기에서는 머리만 게임 그림을 쓰고, 목 아래(셔츠·팔·반바지·다리·신발)는 원화를 그대로 쓴다.

## 구현

| 항목 | 위치 | 상태 |
|---|---|---|
| 원화 보관 | `assets/pose-references/`(남 정면·옆, 여 정면·옆, 남 뒤) | 구현됨 |
| 자르기 | `tools/seated-cut-body.py`: 피부 층(피부색 입힘, 옷 아래로 3px 늘림, 목은 머리 밑으로 12행 늘림)과 옷 층. 턱 아래 첫 8행의 원화 외곽선은 뺀다 | 구현됨 |
| 런타임 | `avatar-foundation.js` `SEATED_ART`·`seatDrawing`·`seatDrawn`. 원화가 있는 옷 조합(`top:tee`·`bottom:shorts`·`shoes:sneaker`)에서만 쓴다. 노드를 더하지 않고 다리 그림 두 장을 다시 쓴다. `seat`로 머리 높이를 원화에 맞춘다 | 구현됨 |
| 비교 검사 | `tools/verify-seated-art.py`: 원화를 같은 배율로 겹쳐 셔츠·반바지·피부·신발 영역 겹침(IoU, 기준 .6/.6/.6/.5)과 셔츠 밑단 높이를 재고, 280px 비교판(`검증/앉기-원화/`)을 만든다 | 구현됨 |

## 직접 확인 (클라우드 소프트웨어 렌더)

- 검사: 남 정면·오른쪽·왼쪽·뒤, 여 정면·오른쪽·왼쪽 모두 통과. 셔츠 .94~.99, 반바지 .76~.98, 피부 .79~.91, 신발 .59~.93, 밑단 차이 0.
- 280px 비교판 7장, 목 이음새 확대, 피부 톤 4(200px), 120px 시트를 직접 보았다.
- 렌더 서명: 바닥 앉기 표본만 달라졌다. 걷는 아바타 기록은 바닥 앉기 뒤 숨은 다리 윤곽 값이 달라져 뒤 표본도 달라진다(보이는 그림은 같음).

## 잘못 보고했던 것

- 옆모습(조각 붙이기 방식)을 '원화대로 잘 나온다'고 보고했다. 실제로는 게임 셔츠가 원화보다 두껍고 길어 반바지·허벅지를 가렸다(검사로 재면 셔츠 겹침 .30). 확대 사진만 보고 실제 크기 전체를 원화와 나란히 보지 않았다. 비교 검사를 만든 이유다.

## 남은 점

1. 여자 뒷모습: 원화가 대화 그림으로만 와서 파일이 없다. 지금은 예전 자세다.
2. 다른 옷 조합은 예전 자세로 돌아간다. 상점 옷마다 앉은 원화(정면·옆·뒤)가 필요하다. 요청은 묶어서 드린다.
3. 앉은 숨쉬기는 머리만 움직인다(몸 그림은 고정).
4. 실제 기기(그램·크롬북)와 지도 30명 화면은 보지 않았다.

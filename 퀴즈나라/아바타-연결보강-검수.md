# 아바타 연결 보강과 기준 관리 — 2026-10-04

현재 단계는 **공통 몸과 기본 착장 검수 중**이다. 기준 캐릭터의 최종 미술 완료나 전체 의류 전환 완료를 뜻하지 않는다. 제작 순서는 [아바타 제작 기준](아바타-제작기준.md)의 **고정 몸/관절 → 남녀 기본 착장과 필수 동작 → 기존 의류 전환 → 새 아이템**을 유지한다.

## 실제 구현과 확인된 원인

- 일반 게임은 `avatar-pixel.js`·`avatar-direction.js`·`avatar-poses.js`와 기존 의류를 사용한다. `avatar-foundation.js`·`avatar-foundation-outfit.js`는 공통 뼈대 연구 렌더이며 `avatar-standard.html` 또는 명시적 체험 주소 `?demo=1&avatar=foundation`에서만 사용한다. 두 결과를 혼동하지 않는다.
- 기존 측면·뒷머리 PNG에는 목까지 그려져 있다. 몸통이 다시 목을 그리면서 아래쪽 검은 목 테두리가 남았다. 기본 남자 짧은 머리/여자 단발에 원본별 곡선 마스크를 적용하고 목의 따뜻한 그림자를 머리색으로 염색하던 분류를 수정했다. 원본 PNG·머리 크기·얼굴 위치는 유지한다. 다른 머리형 전체의 목 교체까지 완료한 것은 아니다.
- 기존 정면 소매의 실제 입구 방향과 피부 단면이 달랐고, 움직이는 피부가 소매보다 나중에 표시되었다. 피부 뿌리를 원본 입구 평면에 맞추고 피부→앞 소매→손 순서를 유지했다. 옆/뒤 소매는 어깨→팔꿈치로 방향을 구하며 아래팔에 남던 소매 끝 복제 조각을 제거했다.
- 무릎 피부를 여러 잘라낸 그림으로 회전시킬 때 꺾인 경계가 보였다. 한 피부 윤곽을 고관절·무릎·발목에 연결하고 급격한 팔꿈치/무릎 굽힘에서 자기 교차를 줄였다. 후면 사다리 다리는 깊이 방향으로 접히며 양옆으로 벌어지는 IK를 사용하지 않는다. 팔꿈치와 손목은 같은 변환을 따른다.
- 달리기는 걷기 배속과 구분되는 지지/회수/공중 구간을 사용한다. 실제 두 번 누르기 입력과 사다리 ↑↓·정지·반전·친구 높이를 검사했다.

## 원화 보강과 Higgsfield

`assets/avatar-reference-candidates/body-study-2026-10-04.png`는 기존 남녀 모습을 참고한 앞/옆/뒤 **원화 후보**다. 목깃·편안한 어깨·소매·종아리·신발 입구의 형태를 보강했다. 얼굴과 비율에 차이가 있고 가장자리 색 잔여물도 있어, 원래 얼굴·머리를 대체하거나 게임에 완성 아바타로 적용하지 않았다. 출처·해시·남은 결함은 같은 폴더 `manifest.json`에 기록했다. 실행/배포 파일 목록에 들어가지 않는다.

Higgsfield MCP에서 AutoSprite의 PNG 프레임 생성 규격을 확인하고 오른쪽 남자 한 명을 참조로 12프레임 달리기를 요청했다. 비용 조회는 일반 오류, 실제 생성은 `Job set type not supported: autosprite`로 거절되어 **작업 ID와 생성 결과가 없다**. 같은 서비스의 원화 생성도 `Requires basic plan or higher`로 거절되었다. 플랜·결제는 변경하지 않았다. 원화 후보는 사용 가능한 OpenAI 이미지 도구로 만들었다. Higgsfield 모션을 검증하거나 게임에 적용했다고 보고하지 않는다.

사용자의 후속 지시에 따라 Higgsfield 사용/재시도는 중단했다. 위 내용은 이미 종료된 실패 시도의 기록이며, 앞으로의 필수 제작 절차가 아니다. 남은 작업은 공통 뼈대에 맞는 자세별 원화 보강과 직접 착장 검수다.

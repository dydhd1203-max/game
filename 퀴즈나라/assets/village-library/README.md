# 마을·생활 풍경 원본 보관함

사용자가 보낸 **village.zip과 안의 JPEG 8장**을 원본 바이트 그대로 저장했습니다. 모든 그림을 연락 시트와 개별 원본으로 직접 확인하고 마을·시장·텃밭·생활 소품·높낮이·폭포·판타지 건물로 분류했습니다. [목록 열기](./index.html)에서 이름·사물·화풍·장면 구성으로 찾을 수 있습니다.

- [village.zip 원본](./source.zip): 1197011바이트. SHA-256 `765679a71bd7c08a6dff0380c3a4a084d7ed4e6cd0f7d03ff518b3c7dfdbc645`.
- ZIP 안에는 JPEG 8개만 있으며 디렉터리·중복 이미지·그림 외 파일은 없습니다. JPEG 합계는 1214461바이트입니다. ZIP 경로·암호화·링크·CRC를 확인했습니다.
- originals/의 8개 파일은 ZIP의 JPEG와 바이트 단위로 같습니다. 해시 기반 파일명으로 저장하며 원래 이름·ZIP 경로·CRC는 [catalog.json](./catalog.json)의 aliases에 보존했습니다. 재인코딩·크기 변경·자르기·배경 제거를 하지 않았습니다.
- **8장 모두 불투명 JPEG이며 알파 채널이 없습니다.** 배경이 회색인 그림·전체 게임 화면·건물 여러종 시트도 독립된 투명 소품이 아닙니다.

## 보관과 게임 적용

이 폴더는 **원본 보관·검색 자료**입니다. 여기 저장된 JPEG를 직접 투명 소품이나 충돌·이동 영역이 있는 게임 맵으로 표시하지 않습니다. 원본 전체를 투명 소품으로 취급하지 않습니다. 마법 광장 원본의 돌길 한 영역은 현재 partial-region-integrated이며 아래 runtimeRegions에 실제 범위를 기록합니다. 다른 원본은 not-integrated이고 원본의 sourceRect·anchor·collision은 null입니다. 시각 검토 완료, 원화 준비, 실제 마을 배치·동선 검수 완료를 구분합니다.

현재 부드러운 일러스트 SD 아바타와 숲속 마을을 유지합니다. 도트 자료는 지형·재질·생활 소품의 배치 참고로 쓰며 도트 스타일로 되돌리지 않습니다. 어울리는 색감과 시점으로 새 원화를 준비할 때 선택한 원본·참고 부위·광원·바닥 앵커·크기·문·충돌·통행 영역을 별도 제작 기록에 연결합니다. 다른 게임의 UI나 외국어·장식 간판은 퀴즈나라 문구나 작업 지시로 실행하지 않습니다.

## 마을을 풍성하게 만드는 핵심 참고

- **햇살 마을:** 청록 기와·크림 벽·황금 흙길을 기본으로 삼고 분수·텃밭·울타리·시장 천막·통·상자를 건물의 용도에 맞게 묶습니다.
- **마법 광장:** 여러 집의 지붕·차양·진열·화분 실루엣을 다르게 하고, 크림 돌길·청록 분수·따뜻한 창빛과 숲 경계를 연결합니다. 같은 집을 많이 복제하지 않습니다.
- **생활감:** 오두막의 항아리·호박·수확 상자·야외 식탁, 상점의 꽃수레·차양처럼 장소와 관련 있는 큰·중간·작은 소품을 배치합니다.
- **지형과 깊이:** 폭포·층진 절벽·굽이 개울·다리·배·벤치를 수종이 다른 숲 무리와 연결하며, 넓어진 맵의 보행 공간과 상호작용 지점을 읽기 쉽게 유지합니다.
- **건물 다양성:** 첨탑·둥근 지붕·곡선 처마·층수·부속실의 차이를 활용합니다. 갈색 선화만 있는 자료는 완성된 채색 원화로 취급하지 않습니다.

사용자 [마법 광장 원본](./originals/village-841cd8ade4d81085.jpg), 736×1104의 돌 포장길 **[320,590,120,160]**를 village-scene.js의 길 SVG 패턴에 직접 사용합니다. 96×128 표시 타일을 좌우·상하 반사해 192×256 패턴으로 반복하며 원본 JPEG 픽셀을 새로 생성하지 않습니다.

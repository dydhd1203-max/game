## 사용 방법

따뜻한 밝은 나무와 얇은 크림색 안쪽 경사, 금색 가장자리로 판의 두께를 만듭니다. 모서리는 작은 녹색 덩굴·잎·데이지와 버섯·열매로 꾸밉니다. 기존 숲 로비와 같은 왼쪽 위 햇빛, 아이들이 보기 편한 밝고 부드러운 재질을 사용합니다. 중앙은 비워 두고 UI의 글자·입력·상품·아바타는 실제 HTML로 표시합니다.

CSS `border-image`의 소스 slice는 위·오른쪽·아래·왼쪽 순서로 `240 385 240 385` 픽셀입니다. `fill`을 사용하지 않습니다. 긴 가운데 레일만 늘어나며 꽃과 버섯이 있는 네 모서리는 유지됩니다. 권장 화면 두께는 PC 38px, 작은 화면 28px부터 실제 화면을 보며 조절합니다. 안쪽 크림 배경은 CSS에서 따로 만들고 내용에는 프레임 두께에 맞는 여백을 줍니다. 작은 상품 카드마다 프레임을 반복하기보다 상점·옷장·문제·안내 같은 큰 판에 적용합니다.

```css
border-image-source: url('assets/forest-village-frame.png');
border-image-slice: 240 385 240 385;
border-image-width: 38px;
border-image-repeat: stretch;
```

알파 확인에서 가운데 픽셀은 RGBA `[0, 0, 0, 0]`이며 중앙에 불투명 픽셀이 없습니다. 원본에는 가장자리의 부드러운 반투명 빛이 있으며 소스 중앙에도 소량의 아주 약한 알파가 있습니다. 중앙 fill을 쓰지 않으므로 이 부분은 판 내부에 그리지 않습니다. 원본의 알파 최대값은 254입니다.

실제 측정에서 가로·세로 중앙 70%와 9-slice 중앙의 알파 범위는 모두 0~1, 알파 8 이상인 픽셀은 0개입니다. CSS로 가로 780 × 560 판과 세로 370 × 720 판을 숲 원화 위에 그려 직접 확인했습니다. 네 모서리 장식이 늘어나지 않고 긴 변의 목재 레일이 연결되며, 중앙의 제목·상품·버튼에 그림이 겹치지 않았습니다. 이 확인은 공통 프레임 단독 미리보기이며 각 실제 앱 화면의 적용 검수를 대신하지 않습니다.

## 생성 지침

하나의 가로 3:2 공통 UI 패널을 위한 투명한 빈 프레임. 밝고 아늑한 어린이용 숲속마을에 어울리는 섬세한 손그림 재질, 밝은 꿀빛 밤나무 목재, 제한된 금색 테두리와 얇은 아이보리 안쪽 경사. 왼쪽 위 조명과 부드러운 두께·목재 결. 네 모서리에 작은 녹색 잎과 짧은 덩굴, 흰 데이지, 왼쪽 아래 주황 버섯, 오른쪽 아래 열매. 중앙 가로·세로 70% 이상은 비우고 긴 변의 중간은 9-slice 확대를 위한 단순 연속 목재로 유지. 사람·문자·숫자·게임 콘텐츠·아이콘·버튼·전체 풍경을 포함하지 않음. 거친 평면 벡터나 지나치게 어두운 전투 UI를 피하고 따뜻하고 밝은 판으로 제작.

자동 알파 검사와 실제 화면의 미술 판단은 별개입니다. 각 적용 화면의 글자·입력란·아바타를 가리지 않는지 PC와 모바일에서 확인해야 합니다.

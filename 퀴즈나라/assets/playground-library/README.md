## 게임 적용

`playground-scene.js`가 원본 영역을 표시·클리핑·조합한다. 운동장 전체 트랙과 코트의 원·중앙선을 원본의 깨끗한 픽셀로 연결했다. 코트 선과 트랙 대부분은 원래 크기이며, 아래 트랙의 일부는 같은 위치의 50% 조망을 정확히 2배 표시한다. 이전에 사용했던 반대쪽 원 조각·짧은 선 조각·체육관의 반복 벽 타일 패치를 제거했다. 다른 화풍·새 AI 그림·새 지형·새 경기선으로 대체하지 않았다.

추가 전체 조망을 좌표 기준으로 삼아 기존 좌표에 **x+269, y−244**를 적용했다. 현재 세계는 **3714×1808**, 학교 문 앞 도착점은 **(1559,676)**이다. 학생 기본 입장은 교실이며, 교실 문에서 운동장으로 나갔다가 학교 문으로 돌아온다. 기존 작은 일러스트 SD 아바타와 몸·옷·모션 비율을 유지한다.

- 울타리 안쪽 이동 영역과 학교·체육관·강당·양쪽 화단의 경계를 유지한다.
- 벤치 15개는 원본 배경 그림이다. 자동 착석·전용 모션·벤치 충돌을 사용하지 않으며 그 위치로 걸어갈 수 있다.
- 학생은 현재 위치에서 C를 눌러 기존 기본 앉기 자세로 앉고 다시 C를 눌러 일어난다.
- 학교 앞·축구장·트랙·아래 울타리 길을 실제 1366×768 학생 렌더로 대조했다. 벤치 배경 15곳을 실제 클릭해 자동 착석이 생기지 않음을 확인하고, C 기본 앉기와 다시 C로 일어나기를 각각 확인했다.
- 실제 교실↔운동장 연결과 배포본 검사 기록은 [운동장 준비 상태](../../운동장-준비상태.md)에 함께 정리한다.

## 원본 해상도와 가림 보완

여섯 장은 원래 배율로 표시한다. native 캡처 밖인 아래 잔디 일부·남동 보행로/울타리·강당 지붕 일부, 캡처 색 띠를 제외한 아래 트랙 일부와 이름에 가렸던 체육관 창/벽·나무 조각은 **50% 전체 조망의 실제 같은 위치 픽셀을 정확히 2배** 표시했다. 원본 전체가 100% 해상도로 확보됐다고 주장하지 않는다.

코트 선은 새 native 캡처의 깨끗한 원본으로 교체했다. 추가 캡처의 인물·이름은 기존 캡처의 같은 위치 픽셀로 제외했다. 추가 1.png의 왼쪽 324픽셀은 색 띠·툴바·포인터가 포함돼 사용 영역에서 제외하고, 기존 깨끗한 캡처와 같은 위치의 조망으로 연결했다. 울타리 밖의 서비스 UI가 가린 잔디는 제공 원본의 깨끗한 잔디 재질로 보완하며, 가려진 픽셀을 정확히 복원한 것으로 기록하지 않는다.

[사용 영역·배율·앵커·충돌·검수 기록](./extracted/room-source-regions.json)에 이 구분을 남긴다. 사용자 최종 미술 승인, 실제 30명 Firebase 동시 접속, 학교 기기 성능을 이번 검사로 완료했다고 표시하지 않는다. 제작 순서는 **교실 → 운동장 → 옷 가게 → 숲 마을**이며 옷 가게·숲 마을은 다음 공간이다.

## 제작과 적용 상태

- 제작 순서는 **교실 → 운동장 → 옷 가게 → 숲 마을**이다. 숲 마을에서 공간들을 마지막에 연결한다.
- 원본 저장·다섯 구간 시각 검토: 완료. 실제 운동장 제작·충돌·이동·기능 적용은 아직 완료하지 않았다.
- 전부 RGBA PNG지만 알파는 모두 255다. 배경을 포함한 불투명 캡처이며 독립 투명 소품 팩으로 표시하지 않는다.
- 사용자가 허용한 원본 부분 표시·윤곽 클리핑으로 깨끗한 구역을 준비할 수 있다. 별도 PNG팩을 사용 전제 조건으로 요구하지 않는다. 전체 스크린샷을 게임 배경으로 붙이거나 가린 그림을 새로 그리지 않는다.
- 학교·계단·트랙·잔디구장·벤치·화단·울타리를 같은 시점과 축척으로 연결하고 기존 일러스트 SD 아바타를 유지한다. 실제 맵의 같은 카메라 시점으로 원본과 비교한 뒤 이동·충돌을 별도로 검수한다.
- 추가로 **트랙 오른쪽 아래 곡선·흙 운동장 아래쪽 경계·바깥 울타리가 함께 보이는 캡처**가 필요하다. 기존 화면과 일부 겹치게 아래·오른쪽으로 이동한 원본을 받아야 운동장 윤곽을 그대로 완성할 수 있다. 사용자에게 필요 구간을 즉시 알렸으며 없는 부분을 새 그림으로 채우지 않는다.
- 같은 축척의 이동량과 원본 사용 구간을 기록한다. 원본 준비·개발용 시안·일반 학생 적용·플레이 검수는 구분하며, 자세한 진행과 다음 작업은 [운동장 준비 상태](../../운동장-준비상태.md)를 따른다.

[확보 구간의 개발용 시안](./preview.html)은 기준 소스의 미리보기 서버에서 확인한다. 학교 앞·계단·축구장을 원본으로 준비했으며 실제 학생 출입은 연결하지 않았다. [등록·사용 영역](./extracted/room-source-regions.json)에 좌표와 부품 재사용·누락 구간·남은 검수 사항을 기록한다.

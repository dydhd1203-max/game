- [interface.zip 원본](./interface.zip): 531,851바이트, SHA-256 `736a28502961b0b1d0d33d17f917e6467da7d1dbb839a7df3f07260bc2caafb6`.
- [catalog.json](./catalog.json): 원래 파일 이름·ZIP 내부 경로·실제 이미지 크기·바이트 수·해시·화면 구성과 활용할 부분을 기록합니다.
- 세 JPEG의 보관 바이트는 ZIP 안의 원본과 일치합니다. 원본을 다시 인코딩하거나 자르지 않았습니다. JPEG 세 장에는 알파 채널이 없으며, 투명 버튼·분리된 카드·실행 가능한 화면을 생성한 것으로 표시하지 않습니다.

## 공통 화면에 적용하는 기준

[qplay-theme.css](../../qplay-theme.css)가 공통 테마(2026-10-08부터 큐플레이 파란 UI)입니다. 이 숲 UI 자료는 보관용입니다. 원본 그림 자체와 구현된 CSS는 구분하며, 적용·검수 상태는 실제 화면 확인 기록을 따릅니다.

1. **배경은 숲 마을의 깊이와 빛을 갖춥니다.** 앞쪽 나무·꽃·잎, 중간의 아바타·펫 공간, 뒤의 나무와 안개를 나눕니다. 캐릭터 옆에 장식만 늘리지 않고 실제 공터와 길이 이어지게 합니다.
2. **판은 목재·크림색 종이·금갈색 테두리로 묶습니다.** 짙은 녹색·따뜻한 갈색·황금빛·크림색을 중심으로, 진행·선택에는 청록 계열을 사용합니다. 판의 두께·윗면 빛·아래 그림자를 일관되게 맞춥니다.
3. **꽃과 덩굴은 모서리와 주변으로 보냅니다.** 제목·학생 이름·문제·답안·교사 입력란의 읽기 공간을 남깁니다. 큰 주요 버튼과 작은 기능 버튼이 바로 구분되도록 합니다.
4. **모든 화면의 재질은 이어지고, 정보의 우선순위는 다릅니다.** 로그인·로비·상점·옷장·퀴즈·결과·교사 화면에 같은 분위기를 적용하되, 퀴즈 문제와 교사 편집에는 선명한 크림색 영역과 충분한 입력 공간을 둡니다.
5. **현재 SD 아바타와 실제 조작을 유지합니다.** 그림 속 인물로 기존 얼굴·머리·옷·펫을 통째로 대체하지 않습니다. 버튼·탭·수치·문제·입력은 실제 HTML/CSS와 데이터로 동작해야 합니다.

대표 로비·상점·학생 퀴즈·교사 편집 화면을 노트북과 작은 화면에서 먼저 비교합니다. 배경과 패널의 대비, 제목 읽기, 실제 입력·스크롤·버튼, 아바타와 펫의 가림을 확인한 뒤 다른 화면으로 확장합니다. 원본 자료를 저장한 것만으로 공통 테마 적용이나 모든 화면 검수가 끝났다고 보고하지 않습니다.

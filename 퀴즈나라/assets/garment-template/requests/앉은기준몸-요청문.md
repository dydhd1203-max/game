# 앉은 기준 몸 원화 요청 (남녀 각 1장)

옷 층 방식([옷층-계획](../옷층-계획.md) 1단계)의 바탕이 되는 몸입니다. 옷이 작아질 때(민소매·치마 등) 드러나는 몸통·허벅지·발을 이 그림으로 채웁니다.

남자는 `앉은옷/기준-m.webp`, 여자는 `앉은옷/기준-f.webp`를 첨부해서 **각각 새 대화**에서 요청해 주세요. 결과는 **이미지 파일로** 올려 주세요.

---

첨부한 그림의 세 장면(앞모습·옆모습·뒷모습)을 **똑같은 자세, 똑같은 배치·크기·여백**으로 다시 그리되, 옷만 아래처럼 바꿔 주세요.

- 상의: 몸에 맞는 **흰색 민소매 속옷**(무늬 없음, 목둘레와 팔 둘레가 깔끔한 것)
- 하의: 몸에 맞는 짧은 **흰색 속바지**(허벅지 위쪽까지만)
- **맨발**(양말·신발 없음). 발과 발가락이 자연스럽게 보이게, 발 위치는 원래 신발이 있던 자리 그대로
- 얼굴·머리·피부색·손·팔·다리 위치·자세·크기는 첨부 그림과 똑같이 둡니다. 소매가 없어져 드러나는 팔과 어깨, 반바지가 없어져 드러나는 허벅지도 같은 피부색과 그림체로 자연스럽게 그립니다.
- 원래 그림과 같은 부드러운 손그림 채색과 외곽선을 유지합니다.
- 흰 배경, 그림자·글자·테두리 없이. 세 장면만 그립니다.

---

## 실패하면

- 자세나 위치가 바뀌었으면: "첨부 그림과 똑같은 자세·위치·크기로, 옷만 흰 민소매와 흰 속바지로 바꾸고 맨발로 다시 그려 주세요."
- 신발이 남았으면: "신발과 양말 없이 맨발로 다시 그려 주세요."

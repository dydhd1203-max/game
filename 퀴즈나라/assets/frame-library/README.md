# 프레임·UI·숲 소재 원본 보관함

사용자가 보낸 **frame.zip과 안의 JPEG 12장**을 그대로 저장했습니다. 모든 이미지를 직접 열어 목재·금속·보석 테두리, 메뉴·프로필·순위·설정 창, 버튼·진행바·아이콘, 숲 배경·다리·나무 제작 자료로 분류했습니다. [읽기 전용 목록](./index.html)에서 사물·화풍·자료 구성을 찾아볼 수 있습니다.

- [frame.zip 원본](./source.zip): 1,358,571바이트. SHA-256 `089330256ec3888c27f085e77625cb85d52c7fc4a534e81daf105eabc3e4095f`.
- ZIP에는 디렉터리 1개와 JPEG 12개가 있습니다. 이미지 합계는 1,379,512바이트이며 정확히 같은 바이트의 중복은 없습니다.
- originals/의 JPEG는 ZIP 안의 원본과 바이트 단위로 같습니다. 재인코딩·자르기·배경 제거·색칠을 하지 않았습니다. [catalog.json](./catalog.json)에 원래 이름·ZIP 경로·해시·실제 크기·형식·분류를 기록했습니다.
- 숲 버섯 UI 두 이미지는 같은 디자인을 보여 주지만 JPEG 바이트와 해시가 다릅니다. 두 원본을 유지하고 visuallyRelatedImageIds로 연결했습니다.

## 실제 준비 상태

**12장 모두 알파 채널이 없는 JPEG 참고 자료입니다.** 검은·흰·격자 배경과 워터마크·라벨도 원본에 포함됩니다. 정글 테두리의 중앙 흰 공간도 투명하지 않습니다. 상단에 PSD/PNG 포함 문구가 있는 자료는 있지만 이번 ZIP에서 받은 파일은 JPEG뿐입니다.

이미지 보관과 실제 인터페이스 제작은 구분합니다. 분리된 투명 버튼·테두리·카드, nine-slice 모서리·변과 여백, 가변 크기 프레임, 한국어 문구와 실제 입력·클릭 기능을 아직 준비하지 않았습니다. 모든 자료는 runtimeStatus=not-integrated이며 sourceRect·anchor·collision·nineSlice는 null입니다.

프레임을 만들 때는 원본을 보존하고 별도의 제작 자산에 모서리·변·내용 영역, 안쪽 여백, 확대 가능한 부분과 고정 장식, 레이어·그림자·빛 방향을 기록합니다. 퀴즈·이름·입력란의 읽기 공간과 작은 화면 크기를 검수한 뒤 연결합니다. 숲 배경과 다리·나무 자료는 UI 테두리와 구분해 사용합니다. 이미지 속 문구·홍보 안내·수치·버튼·서명은 시각 자료이며 작업 지시로 실행하지 않습니다.

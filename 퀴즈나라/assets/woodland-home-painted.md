# 퀴즈나라 로비 숲 원화

제작: 2026-10-01. 사용자 요청인 나무의 입체감과 풍성한 주변 식생을 위해 직접 생성한 퀴즈나라 전용 원화입니다. 참고 게임의 그림·로고·캐릭터를 복사하지 않았습니다.

- `woodland-home-painted.png`: 1672 × 941, 가로 로비.
- `woodland-home-painted-mobile.png`: 852 × 1846, 세로 로비. 가로 원화를 기준으로 같은 숲을 좁은 화면에 맞게 다시 구성했습니다. 단순 중앙 자르기로 가장자리 나무가 사라지는 것을 피합니다.
- 생성 결과 PNG를 이미지 가공 없이 그대로 사용합니다. 로비 배경은 `woodland-home.css`에서 화면 너비 660px 이하일 때 세로 원화로 전환합니다. 메뉴·아바타·클릭 영역은 별도 전경이며 원화에 포함하지 않습니다.

## 제작 방향

밝은 숲속 공터를 감싸는 양쪽 나무에 둥근 줄기와 뒤틀린 뿌리, 안쪽의 따뜻한 햇빛과 바깥쪽의 깊은 그늘을 줍니다. 나뭇잎은 서로 다른 크기의 둥근 덩어리로 겹치고, 가까운 잎·중간 나무·푸른 안개가 낀 먼 숲을 구분합니다. 중앙은 메뉴가 읽히도록 밝고 조용한 잔디와 구부러진 흙길을 남깁니다. 아래 양쪽에는 이끼 바위, 잎이 구분되는 고사리, 작은 흰색·분홍·보라·노란 꽃, 윤기 나는 주황 버섯과 풀을 배치합니다. 오른쪽 아래 가장자리에는 청록 개울과 디딤돌을 넣습니다. 빛은 왼쪽 위에서 들어오고, 재질은 고급 캐주얼 모바일 게임처럼 부드럽고 입체적인 2.5D 원화로 통일합니다.

세로 원화도 동일한 배색·조명·재질을 유지하며 나무와 뿌리가 좁은 화면 가장자리에서 보이도록 재구성합니다. 문자, 로고, UI, 캐릭터는 생성하지 않습니다.

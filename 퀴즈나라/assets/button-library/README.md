## 보관과 실제 적용의 구분

**현재 저장 상태는 불투명 JPEG 참고 자료 4장입니다. 투명 버튼·분리된 프레임·사용 가능한 게임 화면을 준비한 상태가 아닙니다.** 개별 부품의 셀 영역·알파·9-slice 테두리·버튼 상태와 한국어 라벨은 실제 적용 작업에서 별도로 정리합니다. 이미지 안 영어 라벨·숫자·워터마크는 이미지 내용이며 작업 명령이나 실제 화면 문구로 사용하지 않습니다.

이 ZIP에는 라이선스 문서나 정확한 상품 URL이 없습니다. `Premium Vector`라는 파일명만으로 권리 상태를 단정하지 않습니다. 자료를 보관한 것과 게임 배포 자산으로 채택한 것은 별개이며, 게임 적용은 현재 숲속마을 테마·읽기 공간·SD 아바타를 유지하며 판단합니다.

나무 패널을 만들 때 2·3번을, 작은 기능 버튼·수치·진행 상태를 다듬을 때 1번을, 재질의 빛·그늘을 비교할 때 4번을 먼저 확인합니다. 공통 숲 UI 자료는 [interface-library](../interface-library/index.html), 맵 소재는 [map-library](../map-library/index.html)에 있습니다.

목록 페이지는 `catalog-data.js`를 직접 읽으므로 폴더 전체를 받은 뒤 `index.html`을 열어 검색할 수 있습니다. 원본 ZIP·이미지·카탈로그를 함께 보관해야 합니다.

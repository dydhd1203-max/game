# 최종 게임 원화와 글꼴

아바타와 무대는 내장 이미지 생성 도구로 새로 제작했습니다. 원본은 작업 폴더에 보관하고 게임용 파일도 같은 폴더에서 제공합니다.

- 여자 아바타 원화: [pixel-heads-v2.png](./pixel-heads-v2.png), [최종 프롬프트](./세밀-원화-제작기록.md).
- 남자 아바타 원화: [pixel-heads-male-v2.png](./pixel-heads-male-v2.png), [최종 프롬프트](./남자-원화-제작기록.md).
- 퀴즈쇼 무대 원본: [quiz-studio.png](./quiz-studio.png), 게임용 [quiz-studio.webp](./quiz-studio.webp), [최종 프롬프트](./무대-원화-제작기록.md).
- 상의 14종 원화: [pixel-tops-v3.png](./pixel-tops-v3.png), [최종 프롬프트](./상의-원화-제작기록.md).
- 하의 11종 원화: [pixel-bottoms-v3.png](./pixel-bottoms-v3.png), [최종 프롬프트](./하의-원화-제작기록.md).
- 햇살 천사 이펙트 원화: [angel-effect.png](./angel-effect.png), [최종 프롬프트](./천사-원화-제작기록.md).
- 둥근 한글 글꼴: 네이버 공식 나눔스퀘어라운드 Regular·Bold·ExtraBold, [출처와 라이선스 안내](./fonts/NanumSquareRound-출처.md).

눈을 감는 모습은 게임 렌더러에서 별도로 그립니다. 얼굴·머리카락과 상의·하의의 세부 그림을 새로 만들었고 의상 원화는 파란 천 부분을 12가지 색으로 바꿔 입힙니다. 흰색과 금색 장식은 유지합니다.

# 풀·식생 원본 보관함

사용자가 보낸 **`grass pack.zip` 원본**을 [source.zip](./source.zip)에 그대로 저장했습니다. 안에는 JPG 169개가 있으며, 바이트가 완전히 같은 파일 74개를 묶어 **고유 JPEG 95장**을 [originals/](./originals/)에 보관했습니다. 원래 이름 169개와 ZIP 내부 경로는 [catalog.json](./catalog.json)의 각 자료 `aliases`에 모두 남아 있습니다. 같은 원본을 여러 번 보거나 중복 다운로드하지 않도록 [검색 가능한 미리보기](./index.html)는 95장만 표시합니다.

95장은 **고유 이미지 파일 수**입니다. 서로 다른 풀 디자인 95종 또는 애니메이션 95프레임으로 확인한 숫자가 아닙니다. 모든 원본은 736×1273 RGB JPEG이며 알파 채널이 없습니다. 회색·체커 무늬 등의 배경이 보이더라도 투명 PNG라고 표시하지 않습니다.

| 원본 이름 묶음 | ZIP 파일명 수 | 고유 이미지 수 |
|---|---:|---:|
| `Grass Pack _ Game Asset _ Ev Ganin…` | 157 | 83 |
| `Grass _ Game Asset _ Ev Ganin…` | 11 | 11 |
| `Grass with Clovers _ Game Asset _ Ev Ganin…` | 1 | 1 |
| 합계 | 169 | 95 |

파일 이름과 번호를 바탕으로 자료 묶음을 유지하며, 실제 본 이미지의 시각 확인과 나머지 파일의 메타데이터 등록을 구분합니다. 전체 팩 개요와 대표 확인 목록은 `catalog.json`의 `visualReview`에 기록합니다. 개별로 확인한 자료만 `classificationStatus: "visually-reviewed"`로 표시합니다.

시각 검토는 **18장**을 대상으로 했습니다. 큰 Grass Pack 묶음 83장 중 대표 6장, Grass 묶음 11장 전부, 클로버 묶음 1장을 직접 열었습니다. 남은 **77장은 메타데이터만 등록**한 상태이며, 대표 이미지의 스타일을 그대로 복사해 검수 완료로 표시하지 않았습니다.

직접 본 자료에는 부드러운 손그림 풀·클로버·데이지·민들레·관목, 이끼 바위와 작은 암석 높낮이가 있습니다. 여러 크기와 조합이 한 장에 그려진 정지 소재 시트이며, 현재 따뜻한 SD 숲과 어울리는 대표 자료는 다음과 같습니다.

- [흰 꽃·노란 꽃과 바위 지면](./originals/grass-7c4db405807c5bee.jpg), [꽃밭·바위 테두리](./originals/grass-d6fd0201e4548384.jpg): 숲 가장자리와 길 옆의 풍성한 식생 후보.
- [관목·이끼 바위](./originals/grass-af205735896fd213.jpg), [클로버·바위 군락](./originals/grass-af8d72e12ec83632.jpg): 나무 밑과 큰 바위 주변의 작은·중간 소품 후보.
- [데이지 잔디](./originals/grass-01f0410a594bffdb.jpg), [클로버 식생](./originals/grass-d3d628ec77dbd7e5.jpg): 정원·농장 구역의 낮은 바닥 장식 후보.

시트 안의 회색·크림색 바탕, 제목·출처 글자와 접지 그림자는 원본 픽셀에 포함되어 있습니다. 풀은 보통 지나갈 수 있는 장식으로 다루고, 큰 바위·절벽은 실제 지면 발판과 충돌을 따로 정합니다.

## 보관 검증

- ZIP 크기: 25,695,753바이트.
- ZIP SHA-256: `fbe7dca59c0a44be58c2585847fbd8b7868397748f08bae2557b74f0d8beb473`.
- 원본 JPEG 169개를 모두 합한 크기: 25,763,686바이트. 중복을 묶은 JPEG 95장의 크기: 14,463,443바이트.
- ZIP의 정규 JPEG와 디렉터리만 확인했습니다. 경로 이탈·심볼릭 링크·실행 파일이 없었고, 이미지 파일은 재인코딩·확대·잘라내기 없이 저장했습니다.
- 각 고유 원본의 실제 크기·형식·SHA-256·바이트 수와 모든 별칭의 ZIP 원본 일치를 확인합니다. 이 ZIP에는 별도 README·라이선스 문서가 들어 있지 않습니다. 파일 이름에 있는 출처 표기는 그대로 보관합니다.

원본 ZIP과 고유 이미지의 파일 이름은 그대로 두고, 향후 추가 소품은 별도 파일에 만듭니다. 바이트가 같은 자료는 해시가 같은 보관 원본을 공유합니다. 그림이 비슷하다는 이유만으로 파일을 삭제하거나 하나의 모션으로 묶지 않습니다.

## 기존 맵 자료와 함께 사용하는 방법

[전체 소재 보관함](../library/index.html), [맵 기본 에셋](../map-library/index.html), [숲 마을 UI 자료](../interface-library/index.html)와 함께 사용합니다.

1. 숲·정원·농장·물가 등 만들 장소와 기존 건물·나무의 빛·윤곽·원근을 먼저 정합니다.
2. 이 보관함에서 어울리는 풀 자료를 골라 필요한 소품만 준비합니다. 팩 전체를 한 번에 맵에 자동 배치하지 않습니다.
3. 원본 JPEG를 남긴 채 개별 풀의 소스 영역·알파·바닥 앵커·표시 크기를 별도 기록합니다. 실제 원본 PNG가 추가되면 그것도 별도 보관하고, JPEG에서 잃은 투명도나 경계를 이미 확보했다고 가정하지 않습니다.
4. 작은 풀·꽃은 집·나무·물가 주변의 관련 소품으로 묶습니다. 길·퀴즈 사물·학생 이름·답안 입력 공간은 잘 보이도록 남깁니다. 큰 풀과 작은 풀이 같은 크기나 일정 간격으로만 반복되지 않게 합니다.
5. 대표 구역의 실제 학생 시작 시점에서 접지·가림·밀도와 이동·사물 접근·충돌을 확인한 뒤 같은 기준으로 확장합니다.

현재 `frames`, `sourceRect`, `anchor`, `collision`은 아직 준비하지 않은 상태입니다. 이번 작업은 **원본 보관·중복 이름 연결·팩 단위 목록·미리보기**이며, 투명 게임 소품 분리나 실제 퀴즈 맵 배치까지 완료한 것은 아닙니다.

## 미리보기와 목록 갱신

미리보기는 이 폴더의 `catalog-data.js`를 사용하므로 전체 폴더를 받은 뒤 로컬에서 열 때도 목록을 읽을 수 있습니다. 웹 서버 주소의 미리보기와 운영체제의 파일 실행 정책은 구분합니다.

`catalog.json`을 바꾸면 같은 내용을 `window.QPGrassCatalog`에 넣은 `catalog-data.js`도 갱신합니다. 두 목록은 같은 데이터를 가져야 하며, 미리보기는 원본 경로를 그대로 사용합니다. 이 폴더를 다른 곳으로 옮기면 `originals/`, `source.zip`, 목록과 미리보기를 함께 옮깁니다.

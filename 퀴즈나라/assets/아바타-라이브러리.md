# 아바타 기본 소재와 착용 기준

2026-10-01 사용자 요청: 현재 SD 아바타의 뼈대를 유지하고 얼굴·머리·옷·펫·장식을 부위별로 정리한다. 새 소재를 추가할 때 전신을 다시 그리는 대신 기존 구매·색상 변경·움직임에 연결한다.

## 새 소재 등록

원본 PNG와 제작 기록을 함께 보관한다. 투명도·원본 해상도를 유지하고, 셀의 사각형과 실제 불투명 영역을 구분한다. 상품 ID와 저장 계정의 부위 키를 보존하며 새 그림은 해당 ID의 표시 소재로 연결한다. 실행 시 착용 위치의 기준은 `QPClothes.targets`, `QPShoes.targets`와 렌더의 얼굴·소매 정렬 코드다. 문서에 별도의 착용 좌표를 복제하여 서로 다른 값을 관리하지 않는다.

상의 등록에는 목선, 왼쪽·오른쪽 소매 끝, 손목, 허리·밑단을 확인한다. 하의는 허리와 무릎·발목, 신발은 발바닥을 맞춘다. 머리의 앞·뒷부분은 같은 움직임을 사용한다. 장식은 모자·귀·눈·목·등의 해당 부위에 붙이고, 부유하는 펫·이펙트만 독립 모션을 가진다.

원화 PNG를 바꾸면 `node tools/build-avatar-file-data.cjs`로 로컬 실행 데이터를 다시 생성한다. `avatar-file-data.js`는 원본을 대신하는 새 그림이 아니라 측면·뒷머리를 포함한 PNG 13개의 동일한 바이트를 담은 실행용 파일이다. 측면 의상·장신구의 SVG 정의는 해당 JavaScript 실행 파일에 보관한다.

## 실제 착용으로 확인

신규 아바타·착장은 앞·옆·뒤·앉기·점프 그림과 관절 연결을 한 묶음으로 등록한다. 방향·동작 중 하나라도 없으면 완성 상품으로 추가하지 않는다. 앞쪽 장식은 뒷면에서 숨기고 뒤쪽 등판·끈·주머니를 별도로 구성하며, 앉기·점프는 실제 착용된 상태의 실루엣·관절·접지와 복원을 확인한다.

상품 썸네일과 실제 전신을 모두 확인한다. 부위별 그림만 예뻐도 목·손목·허리에서 틈이 나면 착용 미완성이다. 로비·옷 가게·작은 맵에서 남녀, 피부·머리색·의상색을 바꾸고 걷기·점프의 상승과 하강·착지·앉기를 확인한다. 감은 눈에는 사각형 피부 패치, 남은 동공·흰자, 겹친 속눈썹이 없어야 한다.

검사 도구는 `tools/verify-sd-avatar.cjs`, `tools/verify-avatar-fitting.cjs`, `tools/verify-body.cjs`, `tools/verify-clothes.cjs`다. 실행 결과와 직접 열어 본 화면은 [검수 기록](../검수기록-2026-10-01-SD와로비.md)에 구분해 남긴다.

측면 걷기는 `tools/verify-avatar-direction.cjs`로 확인한다. 정면과 좌우 실루엣, 눈 깜박임, 목·소매·허리·발목 연결, 방향을 유지한 정지와 재생성, 종료 시 원래 SVG 복원을 함께 확인한다. 측면 전용 SVG는 정면 원화·상품을 교체하지 않고 방향 모듈이 선택하며, 몸·옷·신발·장신구가 같은 모션을 따라야 한다. 실제 학교 화면의 복합 착장은 `tools/verify-profile-school-outfits.cjs`로 걷기·C 앉기·일어서기·인사 뒤 방향 복원을 확인한다. 최신 실행 결과와 직접 확인한 그림은 [교실 구현·검수](../교실-구현검수.md)에 기록한다.

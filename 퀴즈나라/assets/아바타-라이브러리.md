# 아바타 기본 소재와 착용 기준

2026-10-02 최신 상품 운영: 남녀 전용 착장 목록·그림, 형태별 고정 색 한 가지, 통합 의상은 **한벌옷**. 원래 팔레트와 색별 소유 ID는 호환용으로 보존하며 사용자 색 선택을 다시 노출하지 않는다. 피부색은 최초 한 톤 무료·이후 다른 톤마다 100골드 영구 구매다. 목깃·소매·팔은 실제 상점 정면으로 검수하며 신규 남자 원화의 출처·셀·정렬점은 제작 기록에 남긴다.

2026-10-01 사용자 요청: 현재 SD 아바타의 뼈대를 유지하고 얼굴·머리·옷·펫·장식을 부위별로 정리한다. 새 소재를 추가할 때 전신을 다시 그리는 대신 기존 구매·색상 변경·움직임에 연결한다.

## 현재 사용할 소재

| 부위 | 원본·정의 | 사용과 정렬 기준 |
|---|---|---|
| 얼굴·머리 | `sd-heads-female.png`, `sd-heads-male.png`, `sd-heads.json`, `sd-heads-male-metadata.json` | 각 성별 12개 원화 셀. 실제 상점은 여자 8종·남자 12종을 표시한다. 남자 순서는 `short,spiky,part,messy,crop,bowl,fade,undercut,slick,curlm,comma,wolf`. 눈·턱·목 위치는 셀마다 실측하여 정렬한다. |
| 옆 얼굴·머리 | `sd-heads-profile-female.png`, `sd-heads-profile-male.png`, `sd-heads-profile.json` | 남녀 각 12종의 실제 옆 얼굴 원화. 한쪽 눈·코·턱·귀·뒤머리를 표시하며 `../avatar-direction.js`가 머리색·피부색·표정과 방향별 앞뒤 레이어를 연결한다. 왼쪽은 같은 측면 원화를 반전하며 정면 얼굴을 반전한 그림이 아니다. |
| 표정 | `../avatar-pixel.js`의 `expressions` | 8종. 피부 염색에서 홍채·동공·흰자·속눈썹을 보호한다. 뜬 눈·반쯤 감은 눈·감은 눈을 같은 얼굴 위에 표시한다. |
| 상의 | `sd-tops.png`, `sd-hood.png`, `sd-wardrobe.json` | 14종. 후드는 별도 내려진 후드 원화를 사용한다. 목선·소매·손목·밑단을 몸에 붙인다. |
| 하의 | `sd-bottoms.png`, `sd-wardrobe.json` | 11종. 바지·치마를 구분하고 허리 시작점에서 앉는 모션을 적용한다. |
| 측면 몸·의상 | `../avatar-pixel.js`의 `renderProfileTorso`, `renderProfileLeg`, `renderProfileGarment`, `renderProfileArm` | 상의 14종·하의 11종을 측면 곡선·앞뒤 밑단·옷깃·소매·주름·장식으로 별도 구성한다. 정면 PNG를 가로로 줄인 그림과 구분한다. 원래 상품 ID·팔레트·정면 원화는 보존한다. |
| 뒤 몸·의상 | `../avatar-pixel.js`의 `renderBackTorso`, `renderBackGarment`, `renderBackArm` | 상의 14종·하의 11종의 등판·뒤 칼라·후드·멜빵 끈·뒤 주머니·주름을 별도로 구성한다. 앞 단추·고름·앞판을 등에 표시하지 않는다. `avatar-direction.js`의 뒤쪽 캐시를 기존 관절에 연결한다. |
| 신발 | `sd-shoes.png`, `sd-shoes-parts.png`, `sd-shoes-parts.json` | 9종·좌우 18개 독립 원화. 원래 한 쌍 그림도 보존한다. 실제 발목 입구와 발바닥 좌표를 맞추고, 겹쳐진 원화를 중앙에서 잘라 사용하지 않는다. 걷기·점프·앉기에서도 각 발의 온전한 윤곽과 종횡비를 유지한다. |
| 측면·뒤 신발 | `../avatar-shoes-profile.js`의 `renderFoot`, `renderBackFoot` | 9종의 측면 발등·뒤꿈치·발끝과 뒤쪽 뒷축·뒤 솔기·밑창을 별도 구성하고 기존 발목과 바닥에 맞춘다. 좌우 발 그림을 관절에 따로 연결하며 왼쪽 측면은 아바타 전체 방향을 반전한다. 뒤에서 앞의 끈·꽃·토끼 얼굴을 반복하지 않는다. |

| 천사 | `angel-effect.png`, `../avatar-effects.js` | 펫과 별도 착용. 몸·후광과 양 날개의 독립 모션을 유지한다. |
| 모자·안경·얼굴장식·귀걸이·목걸이·등장식 | 정면은 `../avatar-pixel.js`와 `../index.html`의 카탈로그, 측면·뒤는 `../avatar-accessory-direction.js` | 모자 20·안경 12·얼굴 12·귀 9·목 9·등 9종. 측면은 머리·눈·코·귀·목·등 위치와 앞뒤 겹침을 따로 구성한다. 뒤쪽 모자·귀·목·등 47종의 뒷면을 따로 준비하고 안경·얼굴장식·앞 펜던트는 뒤에서 숨긴다. 모든 종류가 등록된 것과 실제 착용·미술 검수가 통과한 것은 구분한다. |
| 배경·액자 | `../avatar-pixel.js`의 `background`, `frames` | 전신과 별도 관리한다. 착용 부위나 모션에 배경을 포함하지 않는다. |

## 새 소재 등록과 실제 착용 검수

원본 PNG·출처·해시·소스 영역을 보존한다. 새 소재의 관절·부위 소속·방향·자세·가림·검수 규격은 [아바타 제작 기준](../아바타-제작기준.md) 하나에서 관리한다. 위 표의 기존 의류 렌더러와 과거 검수 도구는 전환 전 구현 목록이며 새 공통 뼈대의 완료 기준이 아니다.

남자 전용 정면 원화 `sd-clothes-male.png`와 `sd-clothes-male.json`, 로컬 원본 번들 `avatar-file-data-male.js`는 보존한다. 기준 캐릭터는 동일한 기본복으로 남녀 뼈대를 검증하며 상점의 전체 성별 상품 목록을 변경하지 않는다.

기준 캐릭터 v2의 몸·기본복은 기준 그림 `avatar-reference-candidates/body-study-2026-10-04.png`에서 `../tools/build-reference-body.py`로 잘라 만든 `sd-foundation-ref-{shirt,sleeves,shorts,shoes,arms,legs,neck}.png`와 관절·영역 데이터 `sd-foundation-ref-data.js`다(생성물, 손으로 고치지 않음). 로컬 번들은 `avatar-file-data-foundation.js`다. 이전 기본 착장(`sd-foundation-basic` 등)은 삭제했으며 git 기록에 있다. 검수는 [기준 캐릭터 검수](../기준캐릭터-검수.md)를 따른다.


기존 남녀 반팔·후드의 큰 인사에는 `sd-wardrobe-wave.png`의 해당 소매/겨드랑이만 사용한다. 몸통·장식 원본은 유지하며 원화 기록은 `sd-wardrobe-wave.json`이다. 기존 신발 원본은 `sd-shoes-parts.png` 그대로이고,18개 입구/발등 영역은 `avatar-shoes.js`에서 메모리 마스크로 구분한다. 측면·후면 신발은 기존 `avatar-shoes-profile.js`의 방향별 SVG 그림이다. 피부·칼라·끈·밑창을 분리하며 완전한 공통 뼈대 전환과 혼동하지 않는다.

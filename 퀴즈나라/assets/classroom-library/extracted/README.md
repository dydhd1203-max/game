# 교실 스크린샷 원본 픽셀 추출 시안

`교실 공간2.png`의 학생 책상·의자와 교탁을 **원본 픽셀 그대로** SVG 소스 영역과 윤곽 클리핑으로 표시한다. 새 가구 그림이나 가려진 부분을 만들지 않았다. 원본 파일은 `../originals/classroom-4dcb960dde3f19d2.png`이며 측정 영역·SHA·앵커는 `source-regions.json`에 있다.

- `student-desk.svg`: 상판과 보이는 양측 다리.
- `student-chair.svg`: 보이는 의자의 위·아래 두 레이어. 원본 책상에 가려진 위쪽·뒤쪽은 없다.
- `student-desk-chair.svg`: 두 가구를 원본 겹침 상태로 함께 표시. 다리 사이 바닥은 제외한다.
- `lectern.svg`: 교탁 전체의 보이는 윤곽.

이 자료는 투명 원본 스프라이트가 아니라 **불투명 스크린샷에서 분리 표시한 시안**이다. 윤곽의 1px 색 혼합과 원본에 포함된 어두운 음영은 남으며, 62×90 원본 가구를 크게 늘리면 해상도가 부족하다. 실제 착석 때 아바타와의 앞뒤 겹침을 따로 검수해야 한다. 이 확인 전에는 완성된 착석용 에셋이라고 보고하지 않는다.

외부 PNG를 참조하므로 SVG를 `img`로 불러오면 브라우저가 원본 참조를 막을 수 있다. 기존 맵처럼 SVG를 DOM에 넣고 `image.href`를 SVG 파일 URL 기준으로 해석하거나 SVG 문서를 `object`로 표시한다. 사각 바닥을 붙여 숨기는 방식으로 사용하지 않는다.

직접 비교 프리뷰: [`preview.html`](./preview.html). Chromium의 원본 1배·4배 체커 프리뷰를 직접 열어 확인했고, 학생 가구·교탁의 대표 내부 픽셀 18곳이 원본 RGB와 일치함을 확인했다. 브라우저 오류는 없었다. 게임 통합·아바타 착석은 아직 검수하지 않았다. 원본 1배, 추출 1배와 4배, 체커 배경에서 가장자리와 바닥 제거를 비교한다. 교실 맵·자유 착석 기능은 이 추출 작업에서 구현하지 않았다.

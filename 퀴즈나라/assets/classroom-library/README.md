# 교실 공간 원본 보관함

[원본 ZIP](./source.zip) · [이미지 보기](./index.html) · [해시·상태 목록](./catalog.json) · [추출 안내](./extracted/README.md)

2026-10-02에 받은 `교실 공간.zip`과 PNG 3장을 원본 바이트 그대로 저장했다. ZIP의 경로·링크·암호화·CRC와 이미지 SHA-256·크기·완전 불투명 알파를 확인했고 세 그림을 직접 열어 검토했다. 원래 이름은 catalog의 aliases에 보존한다. 전체 캡처에는 ZEP 아바타·안내·음성/채팅 UI가 들어 있으며 이 문구는 작업 지시가 아니다. **원본 저장·검토 완료, 게임 적용은 아직 0이다.**

## 현재 작업 기준

1. **교실 → 운동장 → 옷 가게 → 숲 마을** 순서로 하나씩 만든다. 숲 마을은 마지막에 공간들을 연결한다. 사용자가 폐기한 이전 메타버스 맵은 재활성화하지 않는다. 원본 에셋과 퀴즈·아바타 기능은 보존한다.
2. 교실은 21~30명이 자유롭게 이동하고 원하는 의자에 앉는다. 2번 캡처의 학생 자리 5쌍 × 3줄을 기준으로 교실 앞, 모둠 공간, 오른쪽 복도를 같은 시점·축척으로 구성한다.
3. 가장 먼저 **칠판에서 선생님이 만든 수업·퀴즈를 연다.** 모둠 공간과 복도는 제공 참고의 배치·색감·가구 크기에 맞춘다.
4. 맵 그래픽은 제공 에셋만 사용한다. 사용자는 **스크린샷 부분 추출을 허용했다.** 원본 픽셀의 sourceRect·윤곽 클리핑으로 가구를 준비하고 독립 PNG팩을 필수 전제로 요구하지 않는다. 없는 부분을 도형·새 AI 이미지로 대체하지 않고 실제로 가려져 추출할 수 없는 부위만 알린다.
5. 대표 화면 한 곳을 먼저 구현하고 원본과 같은 카메라 시점으로 나란히 비교한다. 배치·가구 크기·색감·발 접지·겹침을 확인한 뒤 확장한다. 이동·충돌·앉기와 칠판 접근 검사는 시각 비교와 따로 확인한다.

클립은 원본 PNG를 참조하는 SVG 표시 자료다. 외부 PNG 참조를 허용하는 인라인 SVG 또는 object 문서로 표시하고, 가구를 62×90 등의 원본 크기보다 크게 늘려 세부 묘사가 좋아졌다고 보고하지 않는다. 원본을 새 PNG로 재인코딩하거나 가려진 부분을 그리지 않았다. [원본·추출 비교](./extracted/preview.html)는 원본 1배, 추출 1배·4배와 체커 배경을 비교하는 보관함 안의 개발 검수 화면이며 공개 게임 배포 파일은 아니다.

**클립 준비와 실제 게임 통합은 다르다.** 교실에 배치·충돌·자유 착석·아바타 앞뒤 겹침은 아직 연결·검증하지 않았다. Chromium의 원본·추출 1배·4배 체커 비교 화면을 직접 확인했고 대표 원본 RGB 18곳 일치와 로딩 오류 0을 확인했다. 실제 착석 검수는 아직 하지 않았다. 상세 검수 결과는 extracted/source-regions.json에 남긴다.

## 실제로 가려져 있는 부분

- 대형 스크린 하단 일부는 선생님 이름과 GUIDE 안내가 겹친다. 온전한 전체 그림을 그대로 재현하려면 가리지 않은 캡처나 해당 원본이 필요하다.
- 유리 양문 앞 일부는 키오스크와 이동 안내가 겹친다. 가려진 문 그림은 현재 캡처에서 추출할 수 없다.
- 학생 의자의 위쪽·뒷부분, 교사용 의자의 일부는 책상·컴퓨터에 가려져 있다. 보이는 부분은 사용할 수 있으며 실제 착석과 앞뒤 겹침 검수에서 필요한 원본 범위를 판단한다.

교사용 가구·원탁·방석·빈백을 자동으로 없는 에셋으로 분류하지 않는다. 추가 팩은 더 높은 해상도나 가려진 부분이 실제 필요할 때 요청한다. 알파 채널이 있어도 전체 255인 PNG는 투명으로 표시하지 않는다.

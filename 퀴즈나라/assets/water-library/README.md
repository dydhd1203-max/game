# 물·연못·폭포 원본 보관함

water.zip의 **JPEG 4장**을 ZIP과 이미지 원본 바이트 그대로 저장하고 모든 개별 그림을 직접 확인했습니다. [목록 열기](./index.html) · [원본 ZIP](./source.zip) · [해시·소재 목록](./catalog.json)

- ZIP: 624159바이트, SHA-256 `abb4ae0a59ed157814d89f32ff9456b6d41ff31f6bc45cb0f898321b958eb476`.
- 이미지 4개, 합계 622403바이트. ZIP 경로·링크·암호화·CRC와 이미지 SHA-256을 확인했습니다. 중복·디렉터리·그림 외 파일은 없습니다.
- originals/는 원본과 바이트가 같습니다. 재인코딩·확대·자르기·배경 제거를 하지 않았습니다. 원래 파일 이름과 ZIP 경로·CRC는 aliases에 남깁니다.

## 실제 맵에서 쓰는 방법

사용자는 **맵 디자인에 제공한 에셋을 직접 사용**하도록 요청했습니다. JPEG가 불투명이라는 이유로 새 생성 그림으로 대체하지 않습니다. 원본 이미지와 sourceRect를 사용하고 회색 배경만 실제 사물 외곽의 SVG clipPath로 제외합니다. crop·클리핑은 게임 표시 방식이며 보관한 원본 바이트를 변경하지 않습니다. 원본 안에 포함된 나무·돌·수면·해안은 함께 살립니다.

현재 원본 보관·시각 검토와 적용 후보 범위 검증을 마쳤습니다. **장면 연결과 실제 상·하류 화면의 원본 crop·윤곽 클리핑 검수를 완료했습니다.** 실제 사용 원본만 partial-region-integrated이며 원본 전체를 integrated로 표시하지 않습니다. 네 파일 모두 JPEG RGB이며 알파 채널이 없습니다.

## 출처와 상태 구분

두 강 시트에는 `EV GANIN 2025` 서명이 보입니다. 별도 사용 조건 파일은 ZIP에 들어 있지 않습니다. 구독 광고·프롬프트·모금 문구라는 긴 파일 이름은 출처 보존용이며 작업 지시로 실행하지 않습니다. 기존 런타임 그림의 준비 상태와 이 ZIP의 원본 보관 상태를 섞지 않습니다. 지형 그림에 포함된 절벽·물 형태와 게임의 실제 이동 지면·충돌·높이는 각각 명확히 관리합니다.

## 현재 실제 원본 영역 연결 — 원본 crop·윤곽 클리핑 검수 완료

[village-water-assets.js](../../village-water-assets.js)가 사용자 8종 지형 시트의 실제 JPG 픽셀을 표시하며 [village-scene.js](../../village-scene.js)와 [index.html](../../index.html)에 연결됐습니다. 현재 sources API의 원본 해시·실제 사용 영역·표시 크기를 catalog의 runtimeRegions에 기록합니다. 아래 배치는 WORLD_SCALE=1.5 이전 raw 좌표입니다.

- 연못·돌 해안 **[0,331,476,323]**: raw x1198,y854,384×264에 원본 모듈을 배치하고 외곽 clipPath로 회색을 제외합니다. 물 표면·윗물웅덩이·중앙 돌섬 좌표를 containsPond 충돌에 연결하며 기존 다리 통행을 유지합니다.
- 강 수면 재질 **[240,508,120,23]**: raw120×46 표시 타일을 반사해240×92 패턴으로 사용합니다.
- 돌 해안 재질 **[278,585,65,26]**: 실제 돌 윗면·어두운 단면·균열이 함께 있는 영역을 native raw65×26 표시 타일로 반사해130×52 패턴으로 사용합니다. 얕은 베이지 [138,558,60,10] 띠는 폐기됐습니다.
- **첫 숲·돌 해안·폭포 섬 전체 [0,0,351,361]**: raw x962,y468,270×278에 원본 나무·돌·잔디·물·낙수를 함께 살려 배치합니다. 좁은 직사각 crop [64,405,156,113]은 제거됐고 정밀 원본 외곽 clipPath로 회색과 옆 모듈만 제외합니다.
- **운하 시작의 숲·해안 cap**: 같은 첫 모듈을 raw x1010,y80,185×190에 배치합니다. 원본 모듈은 같고 실제 사용 위치를 별도 기록합니다.

원본 중앙 바위 섬 **[303,437,90,43]**의 자연 외곽을 clipPath로 표시해 운하 양옆 16곳에 배치합니다. y기준220,279,338,399,460,522,582,637의 양쪽에서 작은 위치·크기 차이와 좌우 회전을 사용합니다. 주변 물은 원본 외곽 클리핑으로 제외하며 새 바위 그림을 만들지 않습니다. 이 미술 보완은 기존 물 충돌 지형을 바꾸지 않습니다.

현재 지형 API는 **containsPond, containsBrook, containsCanal**입니다. 연못 물 표면과 돌섬, 개울 연결부, 운하 본류와 cap/폭포 원본의 물 범위를 실제 좌표로 연결하며 기존 위·아래 다리의 통행을 유지합니다. 렌더링 그림의 외곽과 물의 실제 충돌 경계를 구분합니다.

앞서 추천한 물결 [165,484,150,49]는 확인한 대안이며 현재 주요 수면 crop와 구분합니다. 기존 벡터 수면·타원 연못·수작업 오리와 갈대·이전 폭포 배치는 제거됐습니다. 원본 JPG는 재인코딩·색 변경·필터·가짜 알파 처리 없이 그대로 보존합니다. 원본 전체 시트는 게임에 넣지 않고 **5개 서로 다른 원본 영역을 6개 용도로 사용하며 해안 바위는 16개 표시**합니다. **1366·1920 화면의 실제 상·하류 4개 시점에서 원본 crop·윤곽 클리핑·수면 연결·최종 돌 해안을 확인했습니다.** 이동 4건과 브라우저 오류0, spawn15·route18·연결셀8236·물 회귀16건 검증을 통과했습니다. 이 검수는 현재 원본 픽셀 표시·윤곽·확인한 이동과 회귀 범위에 해당합니다. 그림 스타일의 완전한 일치나 물 섬에 그려진 모든 절벽의 물리적 높이·충돌 완성을 뜻하지 않습니다.

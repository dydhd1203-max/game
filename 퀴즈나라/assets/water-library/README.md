## 실제 맵에서 쓰는 방법

사용자는 **맵 디자인에 제공한 에셋을 직접 사용**하도록 요청했습니다. JPEG가 불투명이라는 이유로 새 생성 그림으로 대체하지 않습니다. 원본 이미지와 sourceRect를 사용하고 회색 배경만 실제 사물 외곽의 SVG clipPath로 제외합니다. crop·클리핑은 게임 표시 방식이며 보관한 원본 바이트를 변경하지 않습니다. 원본 안에 포함된 나무·돌·수면·해안은 함께 살립니다.

현재 원본 보관·개별 시각 검토와 정확한 sourceRect·원본 윤곽 검토를 마쳤습니다. 사용자의 최종 선택에 따라 긴 강물과 두 다리를 제거하고 원본 연못만 남겼습니다. **현재 단독 연못의 실제 원본 표시·약한 수면 모션 검수를 완료했습니다.** 이전 전체 섬 폭포 버전의 화면 검수는 이력으로 보존합니다. 실제 사용 원본만 partial-region-integrated이며 원본 전체를 integrated로 표시하지 않습니다. 네 파일 모두 JPEG RGB이며 알파 채널이 없습니다.

## 출처와 상태 구분

두 강 시트에는 `EV GANIN 2025` 서명이 보입니다. 별도 사용 조건 파일은 ZIP에 들어 있지 않습니다. 구독 광고·프롬프트·모금 문구라는 긴 파일 이름은 출처 보존용이며 작업 지시로 실행하지 않습니다. 기존 런타임 그림의 준비 상태와 이 ZIP의 원본 보관 상태를 섞지 않습니다. 지형 그림에 포함된 절벽·물 형태와 게임의 실제 이동 지면·충돌·높이는 각각 명확히 관리합니다.

## 현재 실제 사용 — 사용자 원본 연못 한 곳

사용자의 최종 선택에 따라 **긴 강물·개울·두 다리·추가 낙수·운하 head·합성 돌 해안·별도 해안 바위를 제거**했습니다. [village-water-assets.css](../../village-water-assets.css)는 마을 모션 일시정지와 prefers-reduced-motion을 지원합니다. 기존 원본 타일을0.6px 겹쳐 경계 틈을 줄입니다. 새 물 그림이나 물결선을 생성하지 않습니다.

**containsPond**만 실제 물 충돌을 담당하며 원본 물 polygon2개와 중앙 돌섬1개를 사용합니다. 기존 사각 다리 통행 예외는 삭제했습니다. 이전 호출 호환을 위해 containsCanal·containsBrook 함수 이름은 남지만 항상 false를 반환하며 활성 운하·개울 polygon은0개입니다. 원본 미술의 돌면과 실제 이동 지면·물 충돌을 구분합니다.

원본 JPEG 바이트·해시·RGB 불투명 특성은 그대로입니다. **현재 한 원본의 두 영역만 사용 중**이며 전체 시트를 붙인 것이 아닙니다. 이전 강·다리·head·낙수·해안 바위·베이지 띠·이전 미술 검수는 retiredRuntimeRegions와 retiredConfigurations/visualReviewHistory에 남깁니다. 현재 단독 연못 source API와 생성 보관함 데이터를 동기화했고 실제 navigator 이동 뒤 1366·1920 화면을 확인했습니다. 단독 연못/강물·다리 제거, 수면3프레임 변화·원본 돌 고정, 모션 일시정지, 동작 줄이기, 물·돌 경계6건을 포함한5개 검사 그룹이 모두 통과했고 브라우저 오류는0입니다.

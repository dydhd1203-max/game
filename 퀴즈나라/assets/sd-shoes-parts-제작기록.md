# 걷기용 독립 신발 원화

제작일: 2026-10-01

사용자가 지적한 신발 분리는 움직임 축뿐 아니라 원화 구조도 원인이었다. 기존 `sd-shoes.png`의 각 상품에는 겹친 신발 한 쌍이 그려져 있어 중앙에서 나누면 뒤쪽 신발의 가려진 윤곽과 밑창이 잘린다. 기존 상품 원화는 보존하고, 같은 화풍으로 발 하나씩 온전한 원화를 새로 제작했다.

- 원본 PNG: [sd-shoes-parts.png](sd-shoes-parts.png), 1024×1536 RGBA.
- 해시: `60a639ce1ec5a90f2d03f704eabc28228b1364ed9bb74909a2e2a0327b58e62d`.
- 생성 도구: `image_gen.imagegen`. 최종 생성 파일 `exec-cb93cc13-be0d-4d04-9338-8b2553158ff1.png`를 바이트 그대로 복사했다. 자르기·배경 제거·래스터 덧그리기는 하지 않았다.
- 원화 참고: 기존 `sd-shoes.png`의 운동화·로퍼·털 부츠·샌들·하이탑·발레화·장화·토끼 슬리퍼·날개 신발. 파란 염색 영역, 크림색 밑창과 끈, 꽃·잎·금속 장식을 유지했다.

3열×6행의 읽기 순서로 각 상품의 왼발·오른발이 이어진다. 생성 이미지의 실제 행 간격은 정확한 등분이 아니므로 **등분 셀에서 추출하지 않는다.** [sd-shoes-parts.json](sd-shoes-parts.json)의 `shoes[상품][left/right].sourceRect`를 사용한다. 좌우는 화면의 왼발·오른발이며 앞코가 각 바깥쪽을 살짝 향한다.

발목 입구 중심은 원본을 직접 보고 측정한 `ankleOpening`에 원본 전체의 절대 픽셀로 기록했다. `ankleOpeningCrop`은 해당 추출 영역에서의 상대 좌표다. `soleContact`는 주요 불투명 윤곽의 가장 낮은 접지선에 실제로 존재하는 픽셀이고, 같은 좌표를 상대 값으로도 기록했다. 이 앵커는 착용 검수의 시작점이며, 런타임의 발목 축과 다리 끝을 실제 움직임에서 맞춰야 한다.

원화 전체를 직접 열어 18개 모두 앞코·뒤꿈치·발목 입구·밑창이 잘리지 않았고 서로 겹치지 않는 것을 확인했다. 첫 생성의 운동화·로퍼·슬리퍼 오른발은 왼발과 같은 방향이어서 해당 세 발을 이미지 생성 편집으로 다시 제작했다. 최종본은 9짝 모두 좌우 방향을 확인했다. 알파 25 이상 연결성 측정에서는 주요 독립 성분이 정확히 18개이며 배경은 실제 알파 투명이다. 이 원화 준비·검수와 게임의 착용·걷기·점프 검수는 별도다.

생성 지시의 핵심은 **각 칸에 한 개의 완전한 신발, 좌우의 바깥쪽 앞코, 통일된 서 있는 발 시점, 피부·다리 없는 발목 입구, 충분한 투명 여백, 부드러운 일러스트, 파랑 천과 크림·금 장식 보존**이었다. 기존 겹친 한 쌍을 그대로 잘라 쓰지 않도록 명시했다.

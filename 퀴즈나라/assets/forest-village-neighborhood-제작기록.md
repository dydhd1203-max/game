# 햇살숲 마을의 광장·골목·책 쉼터

2026-10-01 사용자가 제공한 `village.zip`과 `map.zip`을 확인하고, 기존 숲속 마을의 지형·이동·아바타를 유지한 채 생활 풍경을 추가했다. 고정 요청은 **“내가 보낸 에셋들을 최대로 활용하여 map 에셋에 나온 느낌처럼 디자인한다.”**이다.

## 최종 제공 소재 사용 지시

마을 원화 준비 도중 사용자가 돌담·길·수면의 단순한 임의 그림과 보행로 위 배치를 지적하고 **“맵 디자인은 에셋만을 이용하기로 지침에 넣어”**라고 확정했다. 이후 새 맵 이미지를 생성하지 않는다. 비교를 위해 만들었던 추가 돌담·포장 생성본은 프로젝트 적용에서 제외했다. 앞서 만든 주택·생활 소품·잔디 원화는 기존 프로젝트 자산으로 유지하고, 최종 돌길·절벽·물·물가에는 아래 사용자 원본을 직접 사용한다. 새로운 SVG 파형·벽돌·새·오리·갈대 그림과 단순 돌다리 그림을 제거했고 기존 원화 랜턴·다리로 연결했다.

| 직접 사용하는 사용자 원본 | 실제 사용 영역 | 표시 위치 |
|---|---|---|
| `village-library/originals/village-841cd8ade4d81085.jpg` | 돌바닥 `[320,590,120,160]` | 큰길·광장·출입구의 짧은 연결길. 원본 영역의 반사 배치로 반복 가장자리 색을 맞춤 |
| `map-library/originals/reference-download-07.jpg` | 자연 절벽 `[332,188,231,81]`과 원본 외곽 클립 | 높은 숲길·나무집 정원의 실제 돌 절벽. 작은 돌면을 크게 반복하던 중간 시안은 사용하지 않음 |
| `water-library/originals/water-0e50bcc49b81bd14.jpg` | 원본 연못·수면·물가·낙수 모듈. 최신 영역·원본 윤곽·SHA는 `village-water-assets.js`의 `sources` | 상류 강·폭포·하류 연못. JPEG의 회색 배경을 원본 윤곽으로 제외 |

집·벤치·우물에는 잔디 마당을 두고 큰길의 폭과 경로를 바꾸어 바닥이 길 한가운데에 놓이는 느낌을 줄였다. 실제 그림의 물 경계와 충돌도 같은 윤곽으로 맞춘다.

| 자료 | 확인한 요소 | 적용 위치 |

| `map.zip`의 `7.png` | 나무 책상·통나무 의자·등불이 있는 숲 교실 | 높은 숲길의 나이테 책 쉼터. 현재 발견 장소이며 공동 좌석 수업은 미구현 |
| `village.zip`의 농가·장터·마을 참고 | 서로 다른 지붕과 창문, 석재 바닥, 건물 주변 이야기 | 빵집·파란 주택·허브집·물레방아집·농가·우체국 원화 및 연결 골목 |
| 앞서 받은 집·풀·소품·인터페이스 자료 | 숲속 마을의 재질·수종·생활 소품과 따뜻한 UI | 기존 `forest-town-*`, `painted-forest-props`, UI 프레임·나무·종이 스타일 재사용 |

원본 JPG/PNG와 ZIP은 `village-library`·`metaverse-map-library`에서 SHA와 함께 보관한다. 이 참고 이미지에는 불투명 배경·브라우저·다른 서비스 UI가 포함되어 있으므로 화면 전체를 배경이나 투명 소품으로 붙이지 않았다. 아래 네 PNG는 참고의 장소 구성과 색감에 맞추어 **별도로 생성한 원화**다. 원본 참고의 픽셀을 직접 사용했다고 설명하지 않는다.

## 새 원화

| PNG | 해상도 | 용도 |
|---|---|---|
| `forest-village-homes.png` | 1536×1024 RGBA | 고유 주택 여섯 채 |
| `forest-village-life.png` | 1536×1024 RGBA | 분수·장터·벤치·텃밭·울타리·수레·랜턴·벌통 |
| `forest-village-grove.png` | 1536×1024 RGBA | 책·등불·통나무 가구가 연결된 나무 쉼터 |
| `painted-grass-ground.png` | 1254×1254 RGBA | 큰 단색 바닥을 줄이는 부드러운 초록 잔디 재질 |

생성 도구의 원본 PNG 바이트를 그대로 보관한다. SHA·표시 범위·바닥 앵커는 같은 이름의 JSON에 기록하며 실제 배치는 `village-neighborhood.js`, 지형은 `village-scene.js`가 담당한다. 집과 생활 소품은 균등한 격자라고 가정하지 않고 실제 그림의 소스 범위를 측정했다. SVG는 그 범위만 표시하므로 옆 셀의 소품이 섞이지 않는다. 보관함의 프로젝트 원화 항목에서 각 부분과 사용 위치를 확인할 수 있다.

## 공간 구성

광장 중심은 학생이 모이는 공간으로 열어 두고 분수·빵집·장터·벤치를 주변에 배치했다. 높은 숲길은 나무집 교실·허브집·우체국·책 쉼터로 이어지고, 물 건너 농가와 텃밭, 아래 물레방아 주택에는 별도 길을 둔다. 나무·수레·울타리를 건물과 관련된 무리로 배치하고 건물 사이를 복제 주택으로 채우지 않는다.

원화 크기는 지형 확대와 분리하고 바닥 앵커에서 그린다. 기존 계단·줄사다리·다리의 물리 좌표를 유지하며 집의 바닥, 분수, 울타리, 통나무 책상·의자에 충돌 영역을 추가한다. 정원사는 학생 접속 명단과 별도 NPC로 대화한다.

## 검수 범위

최종 검수는 실제 학생 PIN 입장 위치의 1366×768·1920×1080 기본 화면, 사물에 걸어가는 화면, 계단·상점·교실 진입으로 한다. 조망 화면이나 이미지 파일의 존재만으로 완료를 판단하지 않는다. 실행 결과와 직접 확인한 사진은 `../검수기록-2026-10-01-마을생활감과방향모션.md`에 기록한다.

새로 만든 주택·분수·책 쉼터는 현재 마을 풍경이다. 집마다 실내에 들어가거나 벤치·통나무 의자에 공동으로 앉는 기능까지 구현한 것은 아니다. 지형의 수로·절벽 일부는 SVG이며 모든 배경을 하나의 완성 원화로 제작한 상태는 아니다.

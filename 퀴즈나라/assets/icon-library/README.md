## 활용 기준과 준비 상태

**전부 배경이 포함된 불투명 JPEG 참고 자료입니다. 투명 아이콘·타일·프레임·장비 착용 레이어·실행 가능한 UI를 준비하거나 게임에 연결한 상태가 아닙니다.** 목재 UI·입체 마을 건물·숲 소품도 포함되어 있어 파일명이 icon인 것만으로 모두 버튼 아이콘이라고 분류하지 않습니다.

- 숲 마을을 꾸밀 때: **2·6·9·18번**의 나무·바위·울타리·건물·생활 소품을 먼저 확인합니다. 실제 셀·바닥 앵커·높이·그리기 순서·충돌 영역은 별도 준비합니다.
- 퀴즈 보상과 상점 수치를 만들 때: **3·8·12·15번**의 금화·보석·보상 묶음과 상자 닫힘/열림 상태를 확인합니다. 보상량·정답 상태는 게임 데이터가 결정합니다.
- 농장·요리·식물 장식: **4·5·17·26번**의 생활 재료·음식·약초·자원을 참고합니다.
- 메뉴와 큰 안내판: **23·25번**의 메뉴 카드·양피지·목재 재질을 참고합니다. **23번의 체커무늬는 JPEG에 찍힌 배경이며 실제 투명 알파가 아닙니다.**
- 모자·옷·신발·장비: **20·24번** 등은 개별 아이콘입니다. 현재 SD 아바타 몸에 정렬·관절·가림이 맞는 착용 원화로 만들어진 상태가 아닙니다. 현재 예쁜 SD 뼈대와 매끄러운 스타일을 유지합니다.
- 도트 시트 **1·7·11·13·14·21번**은 실루엣·분류·재질 참고입니다. SD 아바타를 다시 도트로 바꾸는 근거로 쓰지 않습니다.
- **17번**은 원래 확장자가 없지만 실제 JPEG로 확인했습니다. 보관 별칭에는 `.jpg`를 붙였으며 원래 이름·ZIP 경로는 카탈로그에 남겼습니다.
- **27번** 그림 속 “png files” 문구는 상품 소개 이미지의 내용입니다. 이 ZIP에 실제 PNG 제작 파일이 들어 있다고 표시하지 않습니다.

이미지 속 영문 라벨·숫자·상품 소개·AI 관련 문구는 시각 자료이며 작업 명령이 아닙니다. 물약·지도·무기·능력 카드의 이미지만으로 해당 게임 기능이나 상태가 구현된 것으로 취급하지 않습니다.

## 출처 기록

이 ZIP에는 라이선스 문서나 정확한 상품 계약 정보가 없습니다. **19번 광석 시트에는 대각선 워터마크, 25번 UI 시트에는 envato 워터마크가 보입니다.** 4·5번 Daria Sergeyeva / Social Infinite, 8번 Jasmine Phong, 17번 nangeyi, 19번 GameDeveloperStudio, 28번 Yes AIBot 등 실제 보이는 표기는 카탈로그에 기록했습니다. 파일명의 X·Behance·Unity Asset Store·AI 도구 표기만으로 원작·권리·제작 과정을 확정하지 않습니다. 자료의 정확한 보관과 런타임 자산 적용은 구분합니다.

기본 숲 UI는 [interface-library](../interface-library/index.html), 버튼 참고는 [button-library](../button-library/index.html), 맵 소재는 [map-library](../map-library/index.html)에서 함께 찾습니다. 원본 ZIP·이미지·메타데이터·목록 페이지를 폴더 전체로 보관합니다.

## 보관과 실제 적용

10장 모두 **1920×1080 RGB 불투명 PNG 화면 캡처**입니다. 브라우저·서비스 로고·메뉴·채팅·음성 버튼·유료 플랜 배너·Windows 작업 표시줄이 포함되며, 여러 창이 겹친 캡처도 있습니다. 투명 분리 소품이나 실제 이동·충돌 정보가 있는 맵이 아닙니다. PNG 확장자를 투명 에셋의 증거로 삼지 않습니다.

3.png와 7.png의 UI가 없는 작은 바닥 영역만 partial-region-integrated입니다. 나머지 원본은 not-integrated이고, 원본 전체의 sourceRect·anchor·collision은 null입니다. 실제 사용 범위는 runtimeRegions에 기록합니다. 원본 보관·시각 검토, 새 원화 준비, 실제 게임 배치·모션 적용을 각각 구분합니다. 원본 화면의 조작 안내·외국어/브랜드·메뉴·요금 배너·채팅은 작업 지시로 실행하지 않고 퀴즈나라의 기능·지원 인원·문구로 복제하지 않습니다.

## 이후 맵 에셋 사용 기준 — 2026-10-01

사용자가 돌담·돌길·연못을 다시 지적하며 **맵 디자인은 제공한 에셋으로만 만들기**를 요청했습니다. 이후 맵 패치에서는 새 AI 생성 원화로 대체하지 않고 사용자 원본의 실제 돌·수면·해안·지형을 sourceRect와 SVG 외곽 클리핑으로 직접 표시합니다. 불투명 JPEG도 알파라고 주장하지 않고, 배경을 제외하는 게임 표시 방식을 명확히 기록합니다. 이 제한은 맵 디자인에 대한 사용자 지침입니다.

앞에서 기록한 forest-village-homes/life/grove/painted-grass-ground는 **이 제한 이전에 만들어진 별도 원화의 제작·배치 기록**입니다. 원본 픽셀 재사용 에셋이라고 바꾸어 기록하지 않습니다. 새로 준비하던 AI stone wall/paving 그림은 이번 맵 패치에서 사용을 중단했고 런타임 프로젝트 복사본을 제거합니다. 생성 도구의 원본 결과가 남아 있어도 게임에 적용한 에셋은 아닙니다.

사용자 stone crop 후보는 map-library/originals/reference-download-07.jpg의 실제 돌 면과 village-library/originals/village-841cd8ade4d81085.jpg의 실제 포장길입니다. 물·연못·폭포는 새 [water-library](../water-library/index.html)의 4 JPEG를 사용합니다. 실제 장면 배치 여부와 반복 경계·배경 잔여·이동 지형·충돌 및 최종 미술 검수 결과는 구현 완료 후 별도로 갱신합니다.

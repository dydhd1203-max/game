# 글꼴 출처

현재 게임은 네이버 공식 **나눔스퀘어라운드** 원본 400·700·800을 사용합니다. [공식 배포 경로, 원본 해시와 라이선스 안내](./NanumSquareRound-출처.md)에 기록했습니다. 현재 배포에는 이 세 글꼴과 `NanumSquareRound-OFL.txt`를 포함합니다.

이전 글꼴은 제작 기록으로만 보관하며 현재 실행 파일에서 사용하지 않습니다.

- 주아(Jua): The Jua Project Authors. [Google Fonts 공식 원본](https://github.com/google/fonts/blob/main/ofl/jua/Jua-Regular.ttf). SIL Open Font License 1.1, `Jua-OFL.txt`.
- 갈무리: 이전 제작 기록의 로컬 WOFF2 및 함께 보관한 라이선스.

사용하는 글꼴은 로컬로 제공하므로 별도 폰트 CDN 연결 없이 표시됩니다.

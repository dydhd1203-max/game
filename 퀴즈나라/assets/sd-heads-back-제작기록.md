# 교실용 일러스트 SD 뒷모습 — 2026-10-02

기존 `sd-heads-male.png`·`sd-heads-female.png`를 각각 이미지 편집 도구의 직접 참조로 전달하여, 같은 남녀 헤어 ID에 맞는 전용 머리 뒤쪽 원화를 만들었다. 원본 두 아틀라스는 수정하지 않았다. 신규 원화는 각 12종이며 위치는 기존 4열·3행 순서다. 실제 연결 영역·목덜미 앵커는 `avatar-direction.js`의 `backSheets`에 있다.

사용자 `앉기.zip`의 정면·왼쪽·오른쪽·뒤 스크린샷은 앉은 방향과 책상·의자의 겹침 참고다. 도트 화풍은 따라하지 않고 기존 작은 일러스트 SD 화풍을 유지한다. 뒤 스크린샷처럼 책상에 앉으면 머리 뒤쪽과 어깨가 보이며, 정면 눈·입·안경·얼굴 장식은 보이지 않는다. 모자와 귀 장식, 옷·신발·펫·효과는 기존 착용 데이터로 유지한다.

생성 요청은 “정확히 같은 열·행과 12개 헤어 정체성을 유지한 실제 뒷머리, 크라운·목덜미 방향의 자연스러운 가닥, 따뜻한 밤색과 풍성한 SD 음영, 투명 배경, 눈·입·코·정면 얼굴·새 장식·글자 없음”으로 지정했다. 남자는 짧은 머리·스포츠·가르마·터슬록·크롭·바가지·페이드·언더컷·슬릭·컬·콤마·울프, 여자는 짧은 머리·단발·긴 머리·트윈·포니·컬·양쪽 번·히메·가르마·메시·픽시·양쪽 땋기를 ID 순서대로 요청했다. 직접 열어 24개에 정면 얼굴이 없음을 확인했다.

기존 염색·피부 색 변환은 신규 원화에도 적용한다. 정면 아틀라스를 가로 압축하거나 얼굴을 살색 도형으로 덮은 결과가 아니다. 옷의 전체 뒷면 원화는 이번 변경에서 새로 만들지 않았다. 교실 책상 착석에서는 머리·어깨와 가구 겹침을 실제 화면에서 확인하며, 다른 큰 뒷모습 전신 화면까지 검수한 것으로 취급하지 않는다.

`tools/verify-avatar-back.cjs`는 24개 실제 원화가 모두 연결되는지, 정면 얼굴 숨김·뒷머리 표시·방향 전환·원래 그림 복원·반복 프레임의 불필요한 재생성이 없는지 확인한다. 실제 크기 시안은 `검증/아바타-앉기-뒤/남녀-24헤어-뒷모습-74-180.png`다. 책상 및 바닥에 앉는 몸 포즈의 자료 분류는 `assets/seating-library/`에서 별도로 보관한다.

# 상세4장을 연결한 중앙 마을

사용자가 제공한 `마을파일`~`마을파일4`를 **모두 각각** 기존 plaza/garden의 부드러운 녹색 채색과 얇은 윤곽으로 편집했다. 꽃 울타리는 줄이고 현관·화단에 모았으며 집·다리·물길 구도를 보존했다. `originals`는 제공 바이트 그대로, `panels`는 image_gen 편집본이다. 초기 전체 조망만 편집한 후보는 실행에 사용하지 않는다.

`native-composite.png`는2713×1555의4장 합본이다. 초기 합본에서78.46%는 편집4장의 그대로인 내부다. 네 사진의 중복 나무/다리/물레방아와 겹친 울타리를 접합부에서 보정했으며 원본과 구분한다.

실행 파일 **`village.webp`는5426×3110**이다. 중앙광장 울타리·서쪽 벤치/난간·동쪽 물가·북쪽 다리를 별도 확대 crop으로 image_gen에서 다시 보강하고 실제 고밀도 그림을 합성했다(`detail-repairs.json`). 나머지는4장 합본을2배 보간한 영역이며 전체가 새로운 원본 디테일인 것은 아니다. 품질98 WebP를 사용해 로딩 용량을 제한했다. `village.png`는2713×1555 제작 미리보기이며 배포에 사용하지 않는다. 게임 지형은 최신 사용자 요청에 따라 앞선 배율3에서1.65로 축소하여 문 높이와 아바타 키를 비슷하게 맞췄다. 캐릭터 화면 크기는 유지한다.


`assembly.json`은4장별 배율·위치·선택 영역·기여 면적·해시, `native-panel-mask.png`는 상세 보강 전 합본의 그대로인 내부255/보정0, `panel-owners.png`는 소유 상세 번호를 기록한다. `tools/build-central-village.py`로 재현하고 `tools/verify-central-village-art.py`로 실제4장 픽셀과 원본 해시를 검사한다. 나무/울타리 중복·자연스러운 화풍·문과 아바타 비율은 실제 화면 미술 검수가 추가로 필요하다.

PNG에는 아바타·UI를 굽지 않는다. `central-village.js`, `map-avatar-display.js`, `world-life.js`의 길/나무/빛/수면 좌표는 최종 합본에서 다시 측정했다. 공통 아바타91.2px와 다른 공간은 유지한다. 관련 실행 결과는 `중앙마을-검수.md`를 참고한다.

재생성 가능한 native-composite/미리보기/소유 마스크는 Git에 추가하지 않는다. 새 체크아웃에서는 build-central-village.py를 먼저 실행한 후 art 검사를 실행한다. 최종 실행 원화와 제공/편집 원화·출처만 등록한다.

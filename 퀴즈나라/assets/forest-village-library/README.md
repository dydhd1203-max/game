# 숲속 마을 원본과 추출 기록

`source.zip`은 사용자가 제공한 `숲속마을 컨셉.zip`이다. `sources.json`의 컨셉 사진 두 장은 분위기 참고, 실제 게임 맵 여섯 장은 원본 후보다. 원본 파일은 변경하지 않는다. 사용하지 않는 가을피크닉·캠핑장도 원본 보관함에 보존한다.

게임은 `extracted/`의 등록된 12개 이미지(맵·집·수관·꽃 4종)를 사용한다. `tools/build-forest-village-assets.py`로 재생성하며 모든 사용 영역·원본 해시·수정 마스크·완전한 사물 재배치는 `extractions.json`에 기록한다. 실제 배치·축척·바닥 기준·충돌·전경은 `forest-village-scene.js`에서 관리한다.

사용자의 후속 요청으로 `adapted/flowers-daisy.png`는 제공 풀 시트의 흰 꽃을 현재 피크닉 맵의 화풍으로 **편집한 별도 수정본**이다. 원본 픽셀 추출물이 아니며 `adaptations.json`에 원본/참고 맵 해시, 편집 내용, 원본 생성 결과의 해시와 바닥 기준을 기록한다. 이미지 도구의 원래 RGBA 결과를 그대로 보관하고 런타임에서 축소한다. 원본은 변경하지 않는다. 이 편집본은 추출 스크립트로 재생성하지 않는다.

현재 맵 꽃은 흰색·연보라 꽃무리, 노란 관목 꽃, 작은 주황 들꽃, 화풍 보정한 파란 종꽃·빨간 양귀비·노란 미나리아재비이며 집 앞·물가·정원 잔디에 배치했다. 별도 `grass-library`에는 흰 데이지, 노란 민들레/미나리아재비, 파란 종 모양 꽃, 붉은 꽃 등의 시트도 있다. 보관된 모든 꽃이 현재 게임에 적용되었다는 뜻은 아니다.

지면 색과 빛이 다른 맵은 별도 입출구 F로 왕복한다. 캡처 UI에 가려져 있던 나무의 숨은 그림을 새로 그리지 않고, 영향을 받은 묶음을 전체 윤곽의 제공 나무로 교체한다. 원본 주변 나무·울타리 보호, 수정 마스크 밖 보존, 반쪽 나무 실패 대조는 `tools/verify-forest-silhouettes.py`로 확인하며 확대 패널과 실제 이동 화면은 별도 미술 검수한다.

원본·ZIP·제작 도구·검사 출력은 실행 사이트에 포함하지 않는다. `tools/deployment-files.cjs`에 등록한 실행 이미지와 코드만 `배포용/`으로 보낸다. 실제 결과는 [숲 마을 검수](../../숲속마을-구현검수.md)를 따른다.

2026-10-03 중앙광장 추가: `adaptations.json`의9종 편집본은 원본과 구분한다. 기존 두 집과 새 꽃3종·우물·큰 나무·개울은 `adapted/sources/`에 이미지 도구의 원래 RGBA 편집 결과를 보존하고, `tools/build-forest-village-adaptations.py`로 기록한 crop/비율 축소를 재현한다. 원본 생성 결과를 매번 새로 생성하는 방식이 아니다. `plaza-composition`은 원래 마을 구성과 별도로 사물 전체 제거·길 복원·벤치/의자/꽃덤불 복원을 기록한 파생 지면이다. 분홍 꽃나무는 비밀정원으로 옮겼다. 지면 픽셀·생성 편집본의 provenance를 혼동하지 않는다. 물가와 난간 애니메이션/가림은 같은 편집본의 등록 위치를 사용한다.

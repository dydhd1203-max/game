# 100% 제공 맵 보관·합성

중앙광장5, 나무집3, 퀴즈공원2, 가을공원4, 캠핑장4, 교실숲2: 사진20장과 ZIP6개를 원본 바이트 그대로 보존한다. 실행 파일은 `maps/*.png` 중 provenance를 제외한6개다. `sources.json`에 원본 이름·해시·정합 위치·제외 영역·기존 자료 사용 영역이 있다. `build.json`은 결과 해시·해상도·출처 면적을 기록한다.

`python3 tools/build-original-forest-maps.py`로 재생성한다(Pillow 필요). 원본 사진은 재도색/선명화/AI 복원을 하지 않는다. 캠핑장4의 촬영 배율 차이만 명시된 affine로 정합한다. 사진에 드러나지 않은 일부 모서리는 기존 정리본을 사용하며 특히 교실숲은 부분 나무가 되지 않게 완전한 나무 묶음을 보존한다. 하늘섬 우측 기존 잔여 깃발은 제공 사진의 빈 하늘 영역으로 정리한다. 이 영역은 `sourcePatches`로 따로 기록한다.

provenance PNG: 0=기존50% 자료, 1~N=해당 사진,128+N=같은 사진에서 위치를 옮긴 배경 픽셀. 캠핑장4 소유 픽셀은 배율 정합된 픽셀이다. 소유 영역과 사진 제외 영역을 `verify-original-forest-maps.py`로 검사한다. 자동 검사는 실제 미술 검수를 대신하지 않는다.

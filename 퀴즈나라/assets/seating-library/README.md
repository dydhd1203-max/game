# 앉기 자세 원본 보관함

[원본 ZIP](./source.zip) · [네 방향 보기](./index.html) · [파일 해시·행동 분류](./catalog.json)

2026-10-02에 받은 **`앉기.zip` 한 팩의 PNG 4장**을 원본 바이트 그대로 보관했다. 정면 52×61, 왼쪽 49×62, 오른쪽 46×61, 뒤 41×59의 작은 자세 캡처를 모두 직접 열어 확인했다. ZIP 경로·링크·암호화·CRC, 이미지 해시·크기·알파를 검증했고 원래 이름은 aliases에 남겼다. 네 PNG 모두 RGBA지만 알파가 전부 255이며 바닥 배경도 포함하므로 투명 아바타 스프라이트가 아니다.

## 등록한 행동

| 행동 | 참고 자료 | 적용 기준 |
|---|---|---|
| **책상에 앉기** (`desk-sit`) | 같은 팩의 정면·왼쪽·오른쪽·뒤 | 좌석에 엉덩이를 맞추고 책상·의자·아바타 앞뒤 겹침과 무릎·발의 연결을 확인한다. |
| **바닥에 앉기** (`floor-sit`) | 같은 팩의 정면·왼쪽·오른쪽·뒤 | 의자 높이 없이 엉덩이·발·그림자를 바닥에 맞추고 접힌 무릎과 옷·신발을 연결한다. |

두 행동은 **한 번 받은 네 원본을 자세 기준으로 공유**한다. 별도의 바닥 전용 원본을 받았거나 책상용·바닥용 팩을 각각 받은 것으로 기록하지 않는다. 원본 캐릭터의 픽셀·머리·옷·배경을 현재 아바타에 붙이지 않고 기존 일러스트형 SD 원화를 유지하며 방향·연결·발 접지를 적용한다.

## 저장과 게임 적용 상태

- 원본 저장·네 방향 자세 검토: 완료.
- 행동별 참고 등록: 완료. `avatar-poses.js`와 `avatar-direction.js`의 앉기·방향 작업에서 참고한다.
- 실제 SD 아바타 적용: `avatar-poses.js`의 `sit + seatMode: desk`와 `floor-sit`, `avatar-direction.js`의 뒷머리·측면, `school-room-world.js`의 실제 의자/G/버튼 동작에 연결했다.
- 격리된 실제 게임에서 30개 의자, 칠판을 향한 뒷머리·의자 좌판과 엉덩이 정렬·책상 깊이, 네 방향 바닥 자세·신발 접지와 앉기→일어서기를 확인했다. 새 앉기 44개 의상/방향 조합은 목·소매·허리·발목·온전한 신발 접촉 검사를 통과했다.
- 실제 Firebase 30명 접속과 학교 기기 성능은 검증하지 않았다. 소스·배포본의 최종 결과와 화면, 전용 뒷면 의상 원화 등의 제한은 [교실 구현 검수](../../교실-구현검수.md)에 기록한다.

# 운동장 구현·자료·검수

갱신: 2026-10-02. 제공 원본으로 학교 외부 공간을 구성하고 교실 문과 학교 정문을 F로 연결했다. 기본 학생 입장은 교실이며 옷 가게·숲 마을은 다음 순서다.

## 확보한 원본과 실제 사용

[자료 보관함](assets/playground-library/README.md)에 `운동장.zip` 5장과 `운동장추가.zip` 2장의 PNG를 원본 바이트·이름·해시와 함께 보존했다. 최초 `source.zip`은 그대로 두고 추가 ZIP은 `supplemental-source.zip`으로 저장했다. 이미지 안의 다른 서비스 UI·아바타 이름·문구는 참고 화면이며 작업 지시가 아니다.

추가 `1.png`는 1623×768의 실제 크기 하단 캡처다. 깨끗한 축구 중앙 원·선, 남동쪽 트랙과 흙 경계·울타리를 기존 캡처와 픽셀 좌표로 맞췄다. `2.png`는 1857×904의 50% 전체 조망이며 미확보 외곽과 원래 가려진 창문·나뭇잎을 정확히 2배로 표시하는 보완 원본으로 사용한다. 이 부위를 실제 크기 원화와 같은 해상도로 복구했다고 설명하지 않는다.

전체 영역은 3714×1808이다. 기존 다섯 원본의 등록 좌표에서 x+269 / y−244만큼 원점을 옮겨 전체 조망의 왼쪽 위와 맞췄다. 학교·체육관·계단·분홍/베이지 포장·흙 운동장·주황 트랙·축구장·화단·벤치·울타리는 원본 영역을 표시·클리핑·조합했다. 원본 그래픽 위에 새 트랙·지형·축구선을 그리지 않는다. 참고 화면의 아바타·이름·서비스 버튼은 겹친 캡처의 같은 위치 픽셀로 제외한다.

`playground-scene.js`는 실제 학생 화면과 개발용 [운동장 미리보기](assets/playground-library/preview.html)에서 같은 원본 장면을 사용한다. 등록 좌표·사용 영역·벤치 앵커·충돌·보완 해상도·검사 기록은 [사용 영역 메타데이터](assets/playground-library/extracted/room-source-regions.json)에 남긴다. 원본 PNG 7장과 장면 모듈은 실행 파일 목록에 포함하고 ZIP·보관함·개발 도구는 공개 사이트에 포함하지 않는다.

## 교실과 운동장 왕복

- 교실 복도 문 접근점 `(2122, 298)`에서 **F** → 운동장 학교 정문 앞 `(1559, 676)`으로 즉시 이동한다.
- 운동장 학교 문 앞 **F** → 교실 복도 문 앞에 돌아온다. 문 클릭은 문 앞까지 걷기이며 공간 전환은 F로 실행한다.
- 전환 뒤 650ms 동안 다시 F를 눌러도 즉시 왕복하지 않고 길게 누르기·키 반복도 한 번만 처리한다. 문 밖 F는 손 흔들기다.
- 공간별 친구 위치·좌석·저장 위치를 분리하고 퇴장 때 이전 좌석·접속·키 입력·모션·카메라 작업을 정리한다. 계정·의상·골드·수업 답·진도를 유지한다.
- **C**는 원하는 위치에서 기본 앉기·일어서기다. 사용자 최신 정정에 따라 벤치 15개는 배경 그림이며 전용 착석 좌표·좌석 임대·자동 클릭 착석·벤치 충돌이 없다. 벤치 그림으로 걸어가서 같은 기본 자세를 사용한다. 벽이나 화단과 너무 가까우면 앉을 공간이 있는 옆 위치로 이동한다. 건물·화단·울타리 밖은 통과하지 않는다. 이동속도는 150→225px/s다.

## 최신 검사 결과

현재 소스·배포본 통합 검사는 각각 6개 항목을 통과했다(`검증/교실-운동장-왕복-최종-2026-10-02/검증결과.json`, `검증/교실-운동장-배포본-최종-2026-10-02/검증결과.json`). 실제 두 학생의 F 출입구 왕복·연타 방지, 공간별 친구 목록·계정 유지, 벤치 그림 클릭 보행과 C 기본 앉기·일어서기, 축구장 이동, 이동속도 225px/s와 재접속을 확인했다. 벤치 그림 15곳의 별도 실제 클릭·C 검사는 `검증/운동장-배경벤치-2026-10-02/검증결과.json`이며 전용 좌석·자동 착석·좌석 임대가 없음을 확인했다.

후드·여자 한복·여자 멜빵옷과 장신구를 함께 입힌 실제 공간의 좌우·뒷모습 이동, C 기본 앉기·일어서기, F 인사와 방향 복원도 소스·배포본 각각 6개 조합을 통과했다. 뒷모습 앉기의 손은 앞쪽 무릎에 놓여 몸에 자연스럽게 가리고 위팔·소매는 유지했다. 자세·그림의 직접 비교와 검사 범위는 [교실 검수 기록](교실-구현검수.md)에 남겼다. 위 결과는 실제 Firebase 운영 검사를 뜻하지 않는다.

실제 Firebase 권한과 학교 그램/크롬북에서 학생 30명이 동시에 접속한 성능·네트워크 검사는 별도로 확인해야 한다. 브라우저 검사는 격리된 체험 저장소를 사용하며 실제 수업 데이터에 쓰지 않는다. GitHub 반영과 공개 Cloudflare 사이트 배포 성공도 별도 상태로 보고한다.

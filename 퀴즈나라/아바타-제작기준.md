# 아바타 제작 기준

2026-10-03 확정. 아바타 제작의 유일한 현재 기준이다. 이전 문서의 옷별 좌표 보정·몸 복제·크기 변경 지침을 대신한다. 기존 얼굴·머리 원화와 저장 계정·구매 내역은 보존한다.

## 제작 방식

**4방향 2D 공통 뼈대 + 부위별 의상 + 접힌 자세의 전용 그림**을 사용한다. 정면·측면·후면은 서로 다른 그림이다. 좌우는 대칭 가능한 부위만 반전한다. 비대칭 의상·헤어·장식은 방향별로 준비한다.

남녀 기본 몸과 고정 관절을 먼저 검증했고, 현재는 동일한 초록 반팔·남색 반바지·아이보리 운동화 한 벌을 공통 뼈대에 연결했다. `avatar-standard.html`에서 기본 착장과 몸만 보기를 비교한다. 280px/96px, 방향·동작별 연결과 입구의 실제 픽셀 검사는 [기준 착장 검수](기준착장-검수.md)에 기록한다. 일반 계정의 상품·구매 내역은 유지하고, 이 기준 착장 이후에 후드+긴바지·한벌옷과 전체 의류를 전환한다. 기존 남녀 얼굴·머리와 부드러운 SD 그림체를 유지한다.

## 공통 뼈대와 부위 소속

- 머리 연결점·목·가슴·골반, 양쪽 어깨·팔꿈치·손목·고관절·무릎·발목, 발바닥 접지점을 하나의 좌표계에서 정의한다.
- 남녀는 관절 이름·부위 소속·동작 규약을 공유한다. 기본형의 치수는 고정하며 옷에 맞춰 몸 길이·관절 위치를 임의로 바꾸지 않는다.
- 몸과 옷은 동일한 관절·시간축을 따른다. 관절 모션 위에 별도 몸·머리 흔들기를 더하지 않는다. 표정·깜박임은 원래 얼굴에서 유지한다.
- 옷 몸통·좌우 소매·하의 골반·좌우 바지 다리에는 명확한 소속이 있다. 각 바짓단은 해당 다리에 한 번만 그린다. 몸 전체를 관절마다 복제해 가림 보정을 반복하지 않는다.
- 소매는 입구 뒤쪽 면·빈 공간·앞쪽 테두리를 구분한다. 피부는 소매 안에서 이어지고 필요한 앞 테두리만 피부를 가린다. 불투명한 타원으로 팔 위를 덮지 않는다.
- 신발은 발목 연결점과 바닥 접지점을 따로 가진다. 신발을 발목에서 움직이고, 닫힌 신발 안의 맨발은 숨긴다. 샌들은 노출 피부를 별도로 준비한다.
- 관절 주변 겹침은 어깨·팔꿈치 등 실제 접합부에 한정한다. 큰 굽힘은 별도 자세 그림으로 바꾸며 원화를 과도하게 늘여 대신하지 않는다.

대기 자세의 팔은 어깨 힘을 빼고 몸 옆으로 자연스럽게 내린다. 위팔·팔꿈치·손목은 몸 옆에 놓이고 손은 골반 옆에 온다. 소매에 맞추기 위해 벌어진 팔을 기본 자세로 고정하지 않는다. 걷기는 작은 앞뒤 흔들림, 달리기·점프·인사는 해당 동작에 필요한 굽힘과 벌림을 사용한다.

## 필수 방향과 동작

앞·왼쪽·오른쪽·뒤에서 다음 동작을 확인한다.

| 동작 | 제작·확인 조건 |
|---|---|
| 서기·호흡 | 턱·목·옷깃 연결과 두 발 접지, 한 시간축의 작은 호흡 |
| 걷기 | 디딤·통과·회수, 반대 팔의 박자, 소매·바짓단·발목 연결 |
| 달리기 | 별도 보폭·팔꿈치 굽힘·회수 동작·공중 구간, 걷기와 연속 전환 |
| 바닥 앉기·일어서기 | **아빠다리**: 무릎을 양옆으로 접고 종아리·발을 몸 앞에서 교차한다. 손은 무릎 가까이에 편하게 둔다. 무릎 꿇기와 구분한다. |
| 책상 앉기·일어서기 | 좌판 높이와 가까운/먼 다리의 순서, 칠판을 향한 뒤 모습 |
| 점프·착지 | 상승·정점·하강·착지의 연결과 원래 발 위치 복원 |
| 인사 | 어깨·팔꿈치·손목과 함께 움직이는 소매, 앞뒤 가림 |

걷기는 225px/s. 같은 방향키를 250ms 이내에 두 번 누른 뒤 유지하면 337.5px/s로 달린다. 키 반복 이벤트는 두 번째 누름으로 세지 않는다. 방향키와 WASD에 적용한다. 해당 키를 놓거나 앉기·인사·문 이동·입력창·포커스 이탈로 이동이 중단되면 달리기도 해제한다. 대각선 속도는 정규화하고 달리기도 기존 충돌을 따른다.

바닥 앉기는 사용자가 보낸 `assets/seating-library/originals/`의 네 방향 PNG를 자세 참고로 사용한다. 캡처 속 도트 캐릭터·배경은 붙이지 않는다. 앞에서는 교차한 발, 옆에서는 몸 앞에 접힌 다리, 뒤에서는 골반 뒤로 가려지는 발과 양옆 무릎이 보여야 한다. 책상 앉기는 좌판 위 골반과 아래로 내려간 다리를 갖는 별도 동작이다.

C는 앉기/일어서기, F는 교실 문↔운동장의 두 학교 입구 출입, 인사는 화면 버튼이다. 자동 길찾기는 걷기다. 기존 기능·계정 데이터를 변경하지 않고 기준 캐릭터를 체험 환경에서 검증한다.

## 그림·원화와 표시

원본 PNG와 출처·해시는 보존하고, 부품 영역·관절·가림·방향·자세를 데이터로 기록한다. 기존 원화를 이용할 수 있는 부품과 새 그림이 필요한 부분을 구분한다. 앞 장식이 등판에 남거나 목·어깨·허리·신발에 조각이 뜨면 미완성이다.

큰 눈·얼굴·머리의 정체성, 부드러운 명암·곡선·반투명 가장자리를 유지한다. 몸 공유 비율은 1.18, 교실·운동장의 본인·친구 표시 기준은 96px, 상점 확대 검수는 280px다. 얼굴과 피부 부위의 팔레트를 통일하고 천·데님·신발의 재질과 광원을 맞춘다.

신규 옷은 기준 뼈대에 맞는 부위와 방향·필수 동작을 함께 준비한다. 상의·하의·한벌옷의 소속, 고정 상품색, 과거 구매 ID·보유 내역을 보존한다. 피부색은 최초 한 톤 무료, 이후 다른 톤은 각 100골드 영구 구매다. 남녀 상품 목록과 머리 선택 규칙은 유지한다.

## 완료 조건

측면 바닥 앉기의 치마·긴 한벌옷은 서 있는 옷자락을 세로로 눌러 대신하지 않는다. 허리에서 접힌 무릎 위로 천이 이어지는 별도 형태를 사용하고, 몸통/서 있는 밑단이 함께 남지 않게 한다. 무릎 위 덮임·바닥과의 관계·발 노출·손 위치를96/280px에서 확인하며 책상 앉기와 일어서기 때 복원을 검사한다. 현재 기존 의류 어댑터의 수정 범위와 한계는 [표시와 앉기 검수](아바타-표시와앉기-검수.md)를 따른다.

표시 최적화는 원화·고정색·관절·동작 시간축을 보존한다. 정적 그림 캐시와 살아 있는 손/표정/펫을 구분하고, 새 그림 로딩 실패 때 기존 그림을 유지한다. 화면 밖 아바타가 돌아오는 첫 화면, 착장 교체, 정지/재개, 장면 종료를 검사한다. 성능 개선 비율만으로 다수 표시 합격을 선언하지 않는다.

1. 남녀·밝은/어두운 피부에서 기본 착장을 280px와 실제 96px로 확인한다.
2. 모든 필수 방향·동작과 걷기/달리기 전환을 연속 재생한다. 정지 캡처만으로 자연스러움을 판정하지 않는다.
3. 관절 연결·그림 소속·입구 가림·신발 접지·방향 전환·해제 후 복원을 검사한다. 숫자 PASS는 미술 통과를 뜻하지 않는다.
4. 교실·운동장에서 실제 키 입력·두 번 누르기·C·F·친구 표시·충돌을 확인한다. 체험 모드만 사용하고 실제 Firebase에 쓰지 않는다.
5. 다수 동시 표시 성능과 실행 환경을 기록한다. 클라우드 브라우저 결과를 학교 기기 실측으로 보고하지 않는다.
6. 구현·직접 확인·남은 부족함을 현재 검수 기록에 분리한다. 전체 의류 전환과 기준 캐릭터 완성을 혼동하지 않는다.

## 연결 수정의 실제 작업 순서 — 2026-10-03 사용자 보강

목표는 빈틈 제거뿐 아니라 머리–목–옷과 몸통–어깨–소매가 처음부터 함께 그려진 듯한 윤곽·채색의 연속성이다. 위 공통 뼈대 원칙에 다음 순서를 적용한다.

1. 실제 로드한 원본과 조립 코드를 찾고 머리·목·몸통·소매·팔을 단독 표시한다. 이미지/코드 도형을 구분하고 소매 분리 영역·피벗·배율·가림을 기록한다. 원본 경계와 실행 중 자르기·회전·레이어 문제를 증거로 구분한다.
2. 현재 초록 반팔의 대표 남자 캐릭터, 오른쪽 측면 wave부터 고정한다. 같은 피부색·동작 시점·방향·280px/96px로 수정 전후를 캡처한다. 다른 아이템·장식은 이 단계에서 추가하지 않는다.
3. 목의 실제 곡선·마스크를 확인하고 턱 아래 계단, 직선적인 목 옆선과 목깃을 정리한다. 목을 무조건 줄이거나 머리를 내려 가리지 않는다. 필요한 방향별 형태를 구분하고 원래 얼굴·머리·의도된 체형 비율을 보존한다.
4. 어깨 접합부는 몸통의 어깨를 따르고 소맷부리는 팔을 따른다. 큰 인사 자세에는 전용 소매·겨드랑이 그림과 변형을 사용한다. 원화 결함을 위치 이동·임의 덧칠만으로 해결했다고 하지 않는다. 기존 소매/잘린 테두리 중복은 실제 원본·레이어로 확인한다.
5. 목깃과 소맷부리의 크림 띠는 다른 부위다. 둘 다 보존하고 올바른 앞뒤 순서로 연결한다. 필요한 봉제선은 남기고, 분리/조립에서 생긴 불필요한 테두리만 제거한다.
6. 코드로 그린 목·팔은 얼굴 피부와 색·명암·외곽선의 규칙을 맞춘다. 피부에 옷 질감을 강제하지 않는다. 블러·두꺼운 선·과도한 그림자로 연결 오류를 가리지 않는다.
7. 대표 자세를 검수한 뒤 남녀×앞/우/좌/뒤, 팔을 올리는 중간·최고점·내리는 중간, 실제 크기와 확대 화면을 확인한다. 캡처 밖으로 나간 머리·손과 실제 파츠 소실을 구분한다. 다른 기존 상의는 새 기준 뼈대와의 호환 여부를 먼저 확인하고, 미전환 의상을 검증했다고 보고하지 않는다.
8. 정밀 검사는 입구 피부 노출뿐 아니라 어깨 봉제선 고정, 몸통–소매 연결 영역, 겨드랑이의 열린 경계와 불필요한 테두리까지 포함한다. 과거의 잘못된 회전/마스크를 재현한 음성 대조가 실제 실패해야 한다. 픽셀·좌표 PASS와 미술 판정은 별도로 기록한다.

수정한 파일·확인된 원인·실제 검증한 조합·같은 조건의 전후 이미지·실행하지 못한 검사를 현재 보고서에 남긴다. 맵·UI·상점·재화·인벤토리·저장 데이터와 다른 작업의 변경은 보존한다. `숲속마을맵디자인`은 이 대화의 프로젝트명이며 수정 경로는 기존 `퀴즈나라/` 체크아웃을 유지한다.

## 팔을 들 때 드러나는 천과 목 연결 — 추가 지침

- 소매 아래의 흰 부분은 배경 노출인지, 원화의 밝은 안감인지 실제 알파와 원본을 대조한다. 배경색을 덧칠하거나 팔로 가려서 결함을 숨기지 않는다.
- 소매를 분리하는 마스크로 몸통 옆선·겨드랑이까지 삭제하지 않는다. 팔을 올리면서 드러나는 천이 준비되어 있어야 하며, 그 부위를 삭제하거나 다른 파츠로 가린 상태는 완료가 아니다.
- 어깨 뿌리와 겨드랑이는 몸통에 연결하고 소맷부리는 팔을 따른다. 전체 소매 조각의 강체 회전만으로 접합부를 해결하지 않는다. 기존 원화의 변형으로 충분한지 직접 비교하고, 천이 없거나 주름이 어긋나면 해당 자세 원화를 보강한다.
- 제거한 소매 밑단·피부 조각이 원래 위치에 남아 떠 있지 않은지 확인한다. 몸통 외곽을 따라 배경으로 끊기는 경계, 늘어난 무늬, 접힌 삼각형과 이중 외곽선도 실패로 기록한다.
- 목의 상단은 턱 아래 곡선, 하단은 실제 목깃 안쪽과 맞춘다. 피부색 사각형·목 길이 축소·머리 이동으로 연결을 숨기지 않는다. 앞·옆·뒤의 실제 목 형상과 피부 명암을 따로 확인한다.
- 남녀 기존 반팔·후드는 이번 수정 대상에 포함한다. 기준 초록 착장의 검사 결과를 대신 사용하지 않고, 각 원화의 고정색·문양·목깃·소맷부리를 보존하면서 따로 검수한다.
- 캡처에는 요청 방향과 실제 표시 방향을 구분해 기록한다. `undefined` 또는 정면으로 전환된 인사를 측면 검수로 인정하지 않는다. 같은 조건의 전후, 올리는 중간·최고점·내리는 중간, 280px와96px를 모두 확인한다.

어깨 봉제선의 원화 가장자리를 섞을 때는 **실제로 몸통 천이 뒤에 있는 영역에만** 적용한다. 배경에 노출되는 겨드랑이 바깥 윤곽까지 반투명하게 만들지 않는다. 변형 격자가 뒤집혀 꽃무늬·외곽선이 접히거나 늘어나는 경우에는 접합 성공으로 판정하지 않는다. 반팔 입구는 위팔, 긴소매 입구는 아래팔에 속하므로 검사에서도 그 소유 관절을 구분한다. 숨겨진 옛 복제본의 좌표로 실제 입구를 대신 검사하지 않는다.

## 신발의 착화감과 정밀 검사 — 사용자 추가 지침

- 신발이 다리 위에 겹쳐 있다는 사실만으로 착용 완료로 보지 않는다. 발목이 입구 안으로 이어지고, 뒤쪽 신발 테두리는 피부 뒤에, 앞쪽 테두리는 피부 앞에 보여야 한다.
- 신발의 **발목 관절·입구 중심/깊이·밑창 접지점**을 구분한다. 부츠 입구가 높다고 발목 관절이나 다리 길이를 바꾸지 않는다. 신발의 회전 기준은 발목이며 밑창은 접지 검사에 사용한다.
- 닫힌 신발 안에 가려진 맨발·발바닥·발가락은 숨긴다. 입구가 불투명한 원화 안감으로 막혀 다리를 덮거나, 뒤꿈치/밑창 아래에 맨발이 중복되면 실패다.
- 샌들·발레화·슬리퍼처럼 피부가 노출되는 신발은 해당 발등·뒤꿈치·발가락과 끈의 가림을 따로 갖춘다. 원화의 고정 피부색을 그대로 두거나, 신발 전체/장식을 피부색으로 바꾸지 않는다.
- 남녀·밝은/어두운 피부, 반바지/긴바지, 앞·좌·우·뒤를 확인한다. 서기·걷기·달리기·점프·착지·아빠다리·책상 앉기에서 발목과 신발의 상대 위치가 유지되어야 한다.
- 정밀 검사에는 실제 입구의 피부 노출, 앞 테두리 보존, 맨발 중복, 발목 이탈, 밑창 접지를 넣는다. 신발 원본과 발/다리 단독 화면을 먼저 확인하며 단순 알파 접촉·그림 겹침 판정으로 대신하지 않는다.
- 같은 조건의 수정 전후를 280px와96px로 직접 확인하고, 입구를 다시 막거나 발목 대신 밑창을 회전시킨 실패 대조가 검사에서 걸리는지 확인한다. 기준 착장 신발과 기존 판매 신발의 검사 결과는 따로 기록한다.


## 후면의 어깨·팔 소속과 가림 — 사용자 추가 지침

- 뒤통수와 옷 등판만 바꿔 후면으로 처리하지 않는다. 어깨 뒤쪽·삼두·팔꿈치·손등·소매 뒤 봉제선이 후면의 형태와 광원을 따른다. 정면 소매/손바닥 그림이 남으면 실패다.
- 후면 어깨의 안쪽 접합부는 등판 윤곽 아래에서 연결한다. 양팔을 늘 등판 위에 올려 붙이지 않는다. 걷기·달리기에서 캐릭터 앞으로 나가는 팔은 등판 뒤, 뒤로 돌아오는 팔은 카메라 쪽이라는 깊이 관계를 유지한다.
- 몸통 뒤에 가려지는 팔을 파츠 소실로 판정하지 않는다. 노출돼야 하는 어깨 바깥선·소맷부리·손등의 연속성은 별도로 확인한다. 앉기에서는 앞쪽 무릎에 놓인 손이 등판을 뚫고 보이면 실패다.
- 남녀 × 밝고 어두운 피부 × 반팔/후드 및 기존 긴소매, 대기·걷기/달리기 양쪽 반주기·점프·바닥/책상 앉기를280/96px로 비교한다. 회전 후 정면/측면으로 돌아왔을 때 가림 순서도 복구돼야 한다.
- 전후면 그림 존재 확인, 실제 렌더의 가시 레이어, 몸통 겹침 픽셀과 앞뒤 순서를 함께 검사한다. 과거처럼 양팔을 등판 위에 강제로 올린 실패 대조가 걸려야 한다. 숫자 통과만으로 어깨와 손등 미술 검수를 대신하지 않는다.

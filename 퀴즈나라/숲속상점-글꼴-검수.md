# 숲속 옷 가게 색 · 나눔스퀘어라운드 통일 검수 — 2026-10-08

## 사용자 요청

1. “상점은 지금 보라색풍이잖아. 숲 컨셉 색깔풍으로 바꿔줘.”
2. “글씨체를 이런 스크린샷 글씨체로 통일해줘.” — 첨부 말풍선 글씨를 프로젝트 글꼴로 그려 비교한 결과 **나눔스퀘어라운드 Bold/ExtraBold**와 같은 글꼴이었다.

## 구현

| 항목 | 위치 | 상태 |
|---|---|---|
| 상점 배경을 숲 색으로 | `tools/build-forest-shop-art.cjs`가 별빛 원화의 보라·분홍만 구역별로 바꾼 `assets/forest-shop.png` (리본 이끼색, 커튼 숲 벨벳, 벽 세이지, 무대 이끼 윗면·나무껍질 옆면, 바깥 하늘 숲의 저녁, 별은 반딧불처럼 금색 유지). 나무 틀·양피지·잎·꽃·등불 픽셀은 그대로 | 구현·직접 확인 |
| 버튼 그림 | `assets/forest-shop-buttons.png`: 뒤로·닫기 버섯 빨강, 선택한 분류 옥빛, 구매·입어 보기 초록과 크림 분류는 원래 그림 | 구현·직접 확인 |
| 상점 CSS 색 | `shop-village.css`의 보라·분홍 값 64곳을 나무결·양피지·이끼·옥빛·버섯 빨강으로 교체. 남은 보라색 값 0 | 구현·검사 |
| 제목 | “별빛 아바타 상점” → **“숲속 옷 가게”**(상단 `옷 가게` 버튼과 같은 이름) | 구현 |
| 소리 버튼 | 공용 규칙이 `#tbSnd`를 보라색으로 칠하던 것을 상점에서 크림 나무판으로, 스피커 아이콘 몸통을 보라 → 나무색(`ui-icons.js`, 옥빛 나팔 유지) | 구현·직접 확인 |
| 글꼴 통일 | 제목·버튼용 `QuizDisplay` 글꼴 이름을 나눔스퀘어라운드 ExtraBold 파일에 연결하고, CSS 9개 파일의 주아 14곳을 교체. 주아 글꼴 파일은 배포 목록에서 뺐다(원본 파일은 보존) | 구현·검사 |

출처·해시는 `assets/forest-shop.json`. 원본 `assets/starlight-shop*.png`는 비교용으로 남기고 배포하지 않는다.

## 검사 (이 PC, Windows Chrome 154 헤드리스, `?demo=1`, 외부 요청 차단)

- `verify-starlight-shop.cjs`: PASS. 16개 분류, 미리보기 무저장, 구매 1회 차감, 재착용 무료, 피부색 100골드, 남녀 전환 시 구매 기록 보존, 잔액 부족, 키보드 선택, 1920/1366/1024/768/390 화면의 넘침·버튼 크기·클릭.
- `verify-layout.cjs`: 오류 0, 가로 넘침 0, 나눔스퀘어라운드 400/700/800 모두 로드.
- `check-source.cjs`, `build-deployment.cjs --check`: 149개 실행 파일이 원본과 일치.
- 배포 폴더(`/배포용/`) 주소에서 `verify-starlight-shop.cjs` 다시 PASS.
- 직접 본 화면: 1366×768 여자/남자 기본 상점, 탈의실 쪽 확대(커튼·리본·무대·꽃 보존), 버튼 시트.

- 실제 학교 노트북과 공개 사이트의 표시는 배포 후 확인한다.

# 퀴즈나라 사용법

갱신: 2026-10-01

최신 사용법은 같은 폴더의 [사용법.md](./사용법.md)에 있습니다. 처음 설정, 학생 가입, 문제 입력, 세 게임의 규칙, 골드·상점·내 옷장, 패션왕, 체험 모드와 배포 파일을 안내합니다.

현재 버전은 도트 아바타와 스피드 퀴즈·OX·팀 가로세로를 사용합니다. OX는 탈락 없이 총점으로 순위를 정하고, 가로세로는 팀원들이 공용 퍼즐판을 함께 풉니다. 얼굴과 액자도 상점에서 구매할 수 있습니다.

- 개발·실행·배포 폴더: `퀴즈나라/` 전체
- 다운로드: [최신 전체 ZIP](https://github.com/dydhd1203-max/game/archive/refs/heads/main.zip)을 압축 해제한 뒤 `game-main/퀴즈나라` 폴더 전체 사용
- 로컬 실행: `퀴즈나라` 폴더에서 `node tools/preview-server.cjs`
- 체험 주소: `http://127.0.0.1:4173/?demo=1` — 해당 브라우저에만 체험 데이터 저장
- 실제 수업: `demo=1` 없는 주소, 설정된 Firebase 사용

`퀴즈나라/`에는 `tools/deployment-files.cjs`에 명시한 HTML·스크립트·스타일·원화·나눔스퀘어라운드 글꼴과 `_headers`가 함께 있어야 합니다. `node tools/check-source.cjs`로 확인하고 이 폴더 전체를 Netlify에 업로드합니다. GitHub를 연결한 배포의 게시 디렉터리도 `퀴즈나라`로 지정합니다.

# 마을 생활감·제공 소재·방향 모션 검수

2026-10-01. 사용자 요청은 제공 `map.zip`의 학생 공간처럼 마을을 구성하고, 옆으로 걸을 때 실제 옆모습을 표시하는 것이다. 이어진 정정에 따라 **새 맵 그래픽은 제공 에셋만 배치·조합하며, 부족한 소재는 추가 요청한다.** 이 지침을 `AGENTS.md`와 `디자인기준.md`에 저장하고 이전 맵 생성 허용 문장도 수정했다.

## 적용한 변화와 소재

- 마을에 서로 다른 주택 여섯 채, 분수·장터·텃밭·울타리·수레·벌통·랜턴·책 쉼터와 정원사 대화를 연결했다. 집·벤치·우물에는 잔디 마당을 두고 보행로와 출입구의 연결길을 구분했다.
- 길은 제공 마을 JPG의 실제 돌바닥, 높은 숲길의 절벽은 제공 맵 JPG의 실제 바위 외곽을 사용한다. 기존 벽돌 도형·물결·연못 타원·새·갈대 그림과 지형을 가로지르던 윤곽선을 제거했다.
- `water.zip`의 원본 4장과 ZIP을 바이트 그대로 보관했다. 물·돌 해안·폭포 시트의 실제 수면과 자연 외곽을 상류 강·낙수·하류 연못에 사용하고 동일한 수면 윤곽을 충돌 계산에 연결했다. 원본 영역·SHA·표시 위치는 `village-water-assets.js`와 물 소재 보관함의 catalog에 기록했다.
- 소재 제한을 받기 전에 만든 주택·생활 소품·쉼터·잔디 PNG는 기존 프로젝트 에셋으로 보존한다. 제공 JPG의 픽셀을 직접 재사용한 자료와 별도 생성한 원화는 `assets/forest-village-neighborhood-제작기록.md`에서 구분한다. 중간에 생성한 돌담·포장 비교 이미지는 최종 적용에서 제외했다.
- 아바타는 실제 측면 머리 원화 24종을 사용한다. 몸·옷은 기존 원화를 앞뒤 부위로 투영하고 신발 한 쌍을 반으로 잘라 움직이지 않는다. 좌우 이동·정지 방향을 친구에게도 동기화한다. 위아래 이동과 인사 전환, 의상 변경·재입장·지연 이미지 로딩을 처리하고 점프할 때 이름과 말풍선도 함께 이동한다.

## 직접 확인한 화면과 범위

기본 PC 시점 1366×768과 1920×1080에서 시작 화면, 상류·하류 원본 소재와 출입 동선을 확인한다. `검증/마을-생활감-2026-10-01/`에 배포 폴더의 실제 화면과 결과, `검증/제공-물-에셋/`에 원본 영역과 실제 상·하류, `검증/아바타-측면/`에 연속 보행·좌우·눈 비교를 보관한다. 검증 출력은 재생성 가능하며 GitHub에 올리지 않는다.

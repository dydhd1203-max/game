# 퀴즈나라 사용법

갱신: 2026-10-01

퀴즈를 함께 풀어 골드를 모으고, 도트 아바타를 꾸미는 우리 반 게임입니다. 스피드 퀴즈·OX·팀 가로세로를 선생님이 진행합니다. 학생 계정에 골드, 구매한 아이템과 착용 상태가 저장됩니다.

## 실행과 체험

`http://127.0.0.1:4173/?demo=1&scene=quiz`를 열면 체험 친구 세 명과 푸른 퀴즈쇼 무대에서 바로 시작합니다. 아래쪽 **메뉴 열기**로 OX·팀 퍼즐·꾸미기를 전환할 수 있습니다.

개발·실행·배포에 모두 **`퀴즈나라/` 폴더 하나**를 사용합니다. GitHub의 [최신 전체 ZIP 다운로드](https://github.com/dydhd1203-max/game/archive/refs/heads/main.zip)를 누르고 압축을 푼 뒤 **`game-main/퀴즈나라` 폴더 전체**를 사용하세요. `index.html`만 내려받으면 필요한 이미지·스타일·글꼴이 빠집니다.

Node.js가 설치된 컴퓨터에서 `퀴즈나라` 폴더를 열고 다음 명령을 실행하면 로컬 미리보기를 열 수 있습니다.

```powershell
node tools/preview-server.cjs
```

브라우저에서 `http://127.0.0.1:4173/?demo=1`을 엽니다. 체험 메뉴의 **빠른 퀴즈·OX·팀 퍼즐·꾸미기**를 누르면 컴퓨터 친구 세 명과 기능을 시험할 수 있습니다. 친구들도 답을 보내고 OX 구역을 고르며, 팀 퍼즐을 함께 풉니다. 메뉴를 접었다가 다시 열 수도 있습니다. 체험 계정과 구매 내역은 해당 브라우저의 localStorage에 저장되며, 실제 Firebase에는 쓰지 않습니다.

실제 수업은 `?demo=1`이 없는 주소로 접속합니다. 실제 모드에서는 Firebase SDK와 Realtime Database를 사용하므로 인터넷 연결이 필요합니다.

## 처음 설정하기

`퀴즈나라/index.html` 위쪽의 **선생님 설정 구역**을 수정합니다.

```js
window.TEACHER_CODE = "1234";       // 기본값. 수업에 쓸 암호로 변경
window.CLASS_NAME = "3학년 2반";    // 화면에 표시할 이름
window.FIREBASE_CONFIG = { /* 사용하는 Firebase 프로젝트 설정 */ };
```

Firebase 설정에는 Realtime Database의 `databaseURL`이 포함되어야 합니다. 기존 Firebase 프로젝트를 계속 사용해도 되며, 퀴즈 데이터는 `quiz/users`, `quiz/bank`, `quiz/room`, `quiz/fashion`에 저장됩니다. 현재 교실용 프로토타입은 선생님 브라우저가 채점과 보상을 처리하므로, 게임 중에는 선생님 화면을 열어 두세요.

현재 방식은 클라이언트의 선생님 암호와 기존 Database 규칙을 사용합니다. 암호는 파일에서 확인할 수 있는 값이며, 이번 변경으로 Firebase 인증이나 권한 정책을 바꾸지는 않았습니다. 기존 Database 규칙의 `quiz` 항목은 다음 형식입니다. 같은 프로젝트의 다른 경로 규칙은 유지합니다.

```json
"quiz": { ".read": true, ".write": true }
```

## 첫 수업 순서

1. 선생님은 로그인 화면의 **선생님**을 누르고 설정한 암호로 들어갑니다.
2. **문제 만들기**에서 새 묶음을 만들고 문제를 입력하거나 여러 줄을 붙여넣습니다.
3. **수업 열기**에서 게임 종류, 문제 묶음, 문제 수와 시간을 선택해 **방 열기**를 누릅니다. 가로세로는 자동 퍼즐 주제를 골라도 됩니다.
4. 학생들은 계정으로 로그인하고 **수업 참가하기**를 누릅니다. 처음이라면 **처음이에요 (가입)**에서 아이디와 숫자 네 자리 비밀번호를 두 번 입력합니다.
5. 모두 모이면 선생님이 **시작하기**를 누릅니다. 일반 퀴즈와 OX는 문제 사이에 **다음 문제**를 눌러 진행합니다.
6. 마지막에 **결과 발표·골드 지급**을 누릅니다. 학생들은 **번 골드로 꾸미기**로 상점에 들어갈 수 있습니다.

같은 브라우저에서는 저장한 로그인 정보로 다시 들어올 수 있습니다. 비밀번호를 잊었다면 선생님 화면의 **학생 명단 → 비번 초기화**로 `0000`으로 초기화할 수 있습니다. 현재 실제 수업 방은 반 전체가 공유하는 한 개입니다.

가입할 때 **아바타**에서 남자 또는 여자를 고릅니다. 가입한 뒤에도 옷 가게에서 무료로 바꿀 수 있습니다.

## 세 가지 게임

| 게임 | 진행과 점수 |
|---|---|
| 스피드 퀴즈 | 정답을 채팅처럼 직접 입력하고 Enter 또는 **답 보내기**를 누릅니다. 오답이면 시간 안에 재도전할 수 있습니다. 처음 맞힌 답만 인정하며, 빠를수록 100~160점을 받습니다. 친구가 맞힌 정답 내용은 정답 공개 전까지 가려집니다. |
| OX 게임 | O·X 구역을 눌러 아바타를 이동시킵니다. 마감 전까지 선택을 바꿀 수 있으며 마지막 선택으로 채점합니다. 정답은 100점, 오답은 0점입니다. 탈락 없이 모두 끝까지 참여하고 총점으로 순위를 정합니다. 모두 선택해도 제한 시간을 유지합니다. |
| 팀 가로세로 | 대기실에서 별빛 팀(A)과 달빛 팀(B)을 고릅니다. 인원이 비슷하도록 배정되며 시작 후 팀이 고정됩니다. 두 팀은 같은 문제의 별도 퍼즐판을 받고, 팀원들은 자기 팀의 공용 판을 함께 채웁니다. 낱말 하나를 맞히면 팀에 `100 + 글자 수 × 20`점, 해당 팀원 모두에게 25골드가 지급됩니다. 모든 참여 팀이 완성하거나 시간이 끝나면 정답을 공개합니다. |

가로세로는 칸이나 힌트를 눌러 낱말을 고른 뒤 답을 입력합니다. 한 칸에 가로·세로가 함께 걸리면 다시 눌러 바꿀 수 있습니다. 같은 팀이 이미 맞힌 낱말을 다시 보내도 점수와 골드는 한 번만 지급됩니다. 시작 뒤 입장한 학생은 진행 중인 팀 퍼즐을 관전하고 다음 게임에 참여합니다.

최종 동점자는 같은 순위와 같은 순위 보너스를 받습니다. 팀 퍼즐의 순위 보너스는 팀원들에게 동일하게 지급됩니다.

## 문제 넣기

한 줄에 한 문제를 쓰고 칸은 **탭** 또는 **쉼표**로 나눕니다. 문제에 쉼표가 들어 있다면 탭으로 나누는 편이 편합니다. 엑셀이나 표에서 복사한 내용도 붙여넣을 수 있습니다.

```text
문제	정답	오답 보기들
지구에서 가장 큰 바다는?	태평양	대서양	인도양
7 × 8은?	56
고래는 물고기이다.	X
세종대왕이 만든 글자는?	한글/훈민정음
```

위 예시의 칸 사이는 실제 탭입니다. 둘째 칸이 정답이고, 셋째 칸부터는 선택형 연습 문제의 오답 보기입니다. 수업의 스피드 퀴즈는 보기 유무와 관계없이 직접 입력합니다. 여러 정답은 `한글/훈민정음`처럼 `/`로 나눕니다. 답 비교 시 띄어쓰기, 일반적인 문장 부호, 영어 대소문자와 전각 숫자를 정리합니다.

OX는 정답이 `O` 또는 `X`인 문제를 사용합니다. 가로세로는 2~7글자 낱말이 필요하며, 자동 주제에는 동물·식물·우리 몸·날씨와 계절·우리 고장·수학·국어·학교생활·음식이 있습니다.

## 아바타, 상점과 내 옷장

사용자가 제공한 최신 참고 화면을 **최소 미술 품질 기준**으로 삼고, 새로 제작한 **12종 도트 머리 원화**를 사용합니다. 얼굴·머리카락·의상의 선과 명암을 또렷하게 표시하고, 머리 위치와 전신 피부색을 맞춥니다. 로비와 꾸미기에서는 전신을 크게 보며 상의와 하의의 모양을 따로 확인하고 골라 입습니다. 구체적인 기준과 참고 화면은 [디자인기준.md](./디자인기준.md)에 있습니다.

로그인, 로비, 상점, 퀴즈, OX, 팀 퍼즐과 결과 화면에서 아바타의 작은 움직임을 계속 표시합니다. 얼굴·머리의 자잘한 떨림을 줄이고 숨쉬기와 펫의 포즈를 화면의 1픽셀 간격으로 맞췄습니다. 눈 깜박임, 천사 날갯짓과 배경 장식은 계속 움직입니다. 로비와 상점 옆 전신은 각각 252~280px, 280~300px로 표시해 과대한 확대를 줄였습니다.

꾸미기 항목은 얼굴, 머리, 상의, 하의, 신발, 모자, 안경, 얼굴장식, 귀걸이, 목걸이, 등장식, 펫, 이펙트, 배경과 액자입니다. **얼굴은 기본 얼굴을 포함한 8종**, **액자는 4종**이며, 추가 얼굴과 액자도 골드로 구매합니다.

1. **옷 가게 → 아이템 상점**에서 카테고리와 색을 고르고 미리 입어 봅니다.
2. 골드가 충분하면 **사기**로 구매합니다. 구매한 아이템은 계정에 저장됩니다.
3. **내 옷장**을 누르면 선택한 카테고리에서 가진 아이템을 모든 색상으로 확인할 수 있습니다.
4. 보유 아이템을 선택하고 **이걸로 입기**로 다시 착용합니다. 장신구·펫·배경·액자는 **안 쓰기**로 뺄 수 있습니다.

구매는 거래 처리로 골드 차감과 소유권 저장을 함께 반영합니다. 같은 아이템의 중복 클릭으로 골드를 반복 차감하지 않습니다. 수업·연습 보상에도 계정별 수령 기록을 사용합니다. **피부색** 메뉴에서는 얼굴·손·다리의 색을 함께 바꿀 수 있으며, 눈과 표정은 상점의 얼굴 상품으로 선택합니다.

입어 보기 아래의 **남자 아바타 / 여자 아바타**를 누르면 현재 의상을 입힌 두 아바타를 비교할 수 있습니다. 남자와 여자 헤어 목록은 각각 4종·8종으로 구분하며, 상점·옷장·무작위 꾸미기에 같은 기준을 적용합니다. 성별을 바꾸면 해당 성별의 보유 헤어로 맞추고 의상·피부색·구매 내역·골드는 유지합니다. 성별 변경에는 골드가 들지 않습니다.

최종 원화의 생성 프롬프트는 [세밀 원화](./assets/세밀-원화-제작기록.md), [남자 원화](./assets/남자-원화-제작기록.md), [상의](./assets/상의-원화-제작기록.md), [하의](./assets/하의-원화-제작기록.md), [퀴즈 무대](./assets/무대-원화-제작기록.md)에 있습니다. 상의 14종과 하의 11종은 봉제선·단추·주머니·주름·천의 질감을 새로 그렸으며, 분홍·민트·보라·크림·갈색 등을 포함한 12색으로 각각 선택합니다. 흰 카라와 금색 단추는 염색해도 유지됩니다. 감은 눈과 반쯤 감은 눈을 따로 그려 자연스럽게 깜빡입니다.

팔·손·다리는 가는 윤곽과 피부 명암으로 다시 그리고, 펫 16종과 신발 9종은 별도 세밀한 원화로 바꿨습니다. [펫 제작 기록](./assets/펫-원화-제작기록.md), [신발 제작 기록](./assets/pixel-shoes-v1-제작기록.md)에 그림과 프롬프트를 보관합니다. 기존 종류·가격과 12색 선택은 유지합니다. 원화가 준비될 때까지 불러오는 안내를 표시해 임시 도형 아바타가 먼저 나타나지 않게 합니다.

UI는 푸른 입체 프레임과 아이템 가방 느낌으로 통일하고, 둥글면서 자소가 또렷한 로컬 **나눔스퀘어라운드** 한글 글꼴을 사용합니다. 설명은 보통 굵기, 메뉴는 굵게, 문제와 이름은 더 굵게 표시합니다. 글꼴의 공식 출처와 라이선스는 [폰트 출처](./assets/fonts/NanumSquareRound-출처.md)에 있습니다. 퀴즈쇼 무대의 별과 유리 화면에는 은은한 움직임을 더합니다. 게임 아바타는 노트북 화면 높이에 따라 224~252px로 표시합니다. 오른쪽 내 아바타는 칸 가운데에 배치하고, 배경은 칸을 채우며 칸 밖으로 나오지 않습니다.

버튼은 마우스와 Enter·Space로 누를 때 살짝 내려갔다 돌아오며 짧은 클릭음이 납니다. 선택·정답·구매 소리가 있는 동작에는 일반 클릭음을 겹쳐 재생하지 않습니다. 효과음 끄기와 음량 설정은 그대로 적용됩니다.

**이펙트 → 햇살 천사**는 520골드로 구매합니다. 아바타 옆에서 둥실 떠다니며 두 날개가 따로 펄럭입니다. 펫·배경·액자와 함께 착용할 수 있습니다. 원화와 프롬프트는 [천사 제작 기록](./assets/천사-원화-제작기록.md)에 있습니다.

## 골드와 남아 있는 기능

골드와 제한 시간 기본값은 파일 위쪽 `window.RULES`에서 조정합니다.

| 항목 | 기본값 |
|---|---|
| 가입 골드 | 300 |
| 혼자 연습 | 정답당 10골드, 하루 최대 300골드, 한 판 10문제 |
| 수업 정답 | 정답당 25골드; 팀 퍼즐은 맞힌 낱말마다 팀원 모두 지급 |
| 수업 순위 보너스 | 1·2·3등 120·80·50골드, 동점은 같은 보너스 |
| 한 문제 시간 | 스피드 퀴즈 20초, OX 12초; 방을 만들 때 변경 가능 |
| 패션왕 상금 | 1·2·3등 500·300·150골드, 참가 보상 50골드 |

**혼자 연습하기**는 저장된 문제 묶음을 풉니다. 기존 선택형 문제도 연습에서 사용할 수 있습니다. **우리 반 순위**, 선생님의 학생 명단·비밀번호 초기화·골드 지급 기능도 유지됩니다.

**패션왕**은 선생님이 주제를 정해 대회를 열고, 학생들이 현재 착용 모습으로 참가한 뒤 투표하는 기능입니다. 자신에게 투표할 수 없으며, 선생님이 결과를 발표하면 상금과 참가 보상을 지급합니다. 금요일에는 안내가 표시됩니다.

화면 위 **🔊 소리 설정**에서 효과음과 BGM을 각각 켜고 끄며 볼륨을 조절합니다. 설정은 다음 접속에도 유지됩니다. **소리 들어보기**로 확인할 수 있으며, 브라우저에서 첫 클릭이나 키 입력 후 소리가 시작됩니다. 배경 탭에서는 음악을 멈추고 돌아오면 이어 재생합니다. 버튼·정답·오답·구매·게임 시작·결과에 각각 효과음이 있습니다. 음악과 효과음은 게임에서 직접 합성합니다.

## 배포와 확인

`퀴즈나라` 폴더에서 `node tools/check-source.cjs`로 실행 파일을 확인합니다. Netlify에는 **`퀴즈나라/` 폴더 전체**를 배포합니다. GitHub를 연결한 배포의 게시 디렉터리도 `퀴즈나라`로 지정합니다. 같은 폴더를 수정하고 배포하므로 별도 복사본을 맞출 필요가 없습니다. 필요한 실행 파일과 배포 설정은 다음과 같습니다.

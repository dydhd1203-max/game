# 퀴즈나라 사용법

갱신: 2026-10-01

퀴즈나라에서는 내 일러스트 SD 아바타로 탐험하며 퀴즈를 풉니다. 선생님은 **게임 방식 선택 → 문제 작성 → 수업 설정** 순서로 준비합니다. 같은 문제 묶음을 실시간 수업과 나중에 혼자 풀기에 사용할 수 있으며, 학생 계정별 답변·점수·완료 진도를 저장합니다. 기존 OX·가로세로와 아바타 상점도 별도로 이용합니다.

## 실행과 체험

개발·실행·배포에 모두 **`퀴즈나라/` 폴더 하나**를 사용합니다. GitHub의 [최신 전체 ZIP 다운로드](https://github.com/dydhd1203-max/game/archive/refs/heads/main.zip)를 내려받아 압축을 푼 뒤 **`game-main/퀴즈나라` 폴더 전체**를 사용합니다. `index.html`만 받으면 이미지·스타일·글꼴이 빠집니다.

압축을 모두 푼 뒤 **`game-main/퀴즈나라/index.html`을 더블클릭**하면 브라우저에서 엽니다. 파일로 직접 열어도 아바타·상의·하의·신발·펫과 상품 미리보기를 표시하도록 원본 이미지가 포함된 로컬 실행용 데이터를 함께 제공합니다. 실제 계정 로그인과 수업 데이터 연결에는 인터넷이 필요합니다. ZIP 안에서 바로 실행하거나 `index.html`만 옮기지 마세요.

Node.js가 있는 컴퓨터에서는 `퀴즈나라` 폴더에서 로컬 서버로 실행할 수도 있습니다.

```powershell
node tools/preview-server.cjs
```

브라우저에서 `http://127.0.0.1:4173/?demo=1`을 열면 격리된 체험 모드입니다. 체험 계정과 데이터는 해당 브라우저의 localStorage에 저장하며 실제 Firebase에 쓰지 않습니다. 선생님 화면에서 새 다섯 방식의 문제와 수업을 만들어 확인할 수 있습니다. 기존 체험 메뉴의 **빠른 퀴즈·OX·팀 퍼즐·꾸미기**는 기존 게임 체험용이며 컴퓨터 친구 세 명이 참여합니다.

실제 수업은 `?demo=1`이 없는 주소로 접속합니다. Firebase SDK와 Realtime Database를 사용하므로 인터넷 연결이 필요합니다. 로컬 주소는 실행 중인 그 컴퓨터에서 사용하는 미리보기 주소이며, 학생에게 공유할 실제 사이트 주소는 별도로 배포한 뒤 사용합니다.

## 처음 설정하기

`퀴즈나라/index.html` 위쪽의 **선생님 설정 구역**을 수정합니다.

```js
window.TEACHER_CODE = "1234";       // 수업에 쓸 암호로 변경
window.CLASS_NAME = "3학년 3반";
window.FIREBASE_CONFIG = { /* 사용하는 Firebase 프로젝트 설정 */ };
```

Firebase 설정에는 Realtime Database의 `databaseURL`이 포함되어야 합니다. 기존 프로젝트를 계속 사용할 수 있습니다. 계정은 `quiz/users`, 문제 묶음은 `quiz/bank`, 새 수업과 학생별 진도는 `quiz/classrooms`, 기존 퀴즈룸은 `quiz/room`, 패션왕은 `quiz/fashion`에 저장합니다. 실시간 수업에서는 선생님 화면이 제한 시간 종료와 정답 공개를 진행하므로 수업 중 열어 둡니다.

현재 방식은 파일 안의 선생님 암호와 기존 Database 규칙을 사용합니다. 선생님 암호를 서버 인증으로 처리하는 구조가 아니며, Firebase 인증·권한 정책 변경은 별도 작업입니다. 기존 프로젝트 규칙을 확인할 때 같은 프로젝트의 다른 데이터 경로 규칙은 유지합니다.

## 선생님: 문제를 만들고 수업 열기

1. 로그인 화면의 **선생님**을 누르고 설정한 암호로 들어갑니다.
2. **일반 퀴즈 만들기**에서 순서풀이·자유풀이·라운드전·팀전·협동전 중 하나를 고릅니다. 새 퀴즈를 만들거나 **저장한 문제로 만들기**에서 기존 묶음을 고릅니다.
3. 퀴즈 제목을 쓰고 왼쪽 **문제 추가**에서 객관식·주관식·선 잇기·순서 맞추기를 추가합니다. 문제 카드로 이동하며 작성하고, **학생 화면 미리보기**에서 직접 답해 봅니다. 카드 끌기 또는 위·아래 버튼으로 문제 순서를 바꾸고 복제·삭제할 수 있습니다.
4. **저장**하면 문제 묶음이 보관됩니다. **설정으로 다음**을 눌러 수업 이름, 사용할 문제 수와 진행 방식을 정합니다. 실시간은 **실시간 수업**, 나중에 각자 할 퀴즈는 **혼자 하는 과제**를 고릅니다.
5. 라운드전은 **한 문제 제한 시간**, 탐험 방식은 **전체 제한 시간**을 정합니다. 팀전은 2~6팀과 **무작위로 고르게 배정 / 학생이 원하는 팀 선택**, 협동전은 **우리 반 공동 목표**도 설정합니다. 협동 수업에는 전체 제한 시간을 정합니다.
6. **수업 만들기 / 과제 만들기**를 누르고 **참여 링크 복사**로 학생에게 전달할 주소를 복사합니다. 실시간 수업은 참가자를 확인한 뒤 **수업 시작**을 누릅니다. 혼자 하는 과제는 학생이 링크로 들어와 각자 시작합니다.
7. **수업·혼자 풀기**에서 수업을 다시 열어 학생별 진도와 점수, 팀 점수 또는 공동 목표를 확인합니다. 라운드전은 정답 공개 뒤 **다음 문제**로 진행하며 마지막에 **결과 보기**를 누릅니다. 탐험 수업은 시간·목표 또는 **수업 종료**로 마칩니다.

저장한 문제 묶음은 다른 게임 방식으로도 다시 사용할 수 있습니다. 이미 만든 수업에는 만들 때의 문제 사본을 저장하므로, 문제 묶음을 수정했다면 그 내용으로 새 수업이나 과제를 만듭니다.

## 학생: 참가하고 이어서 풀기

1. 계정으로 로그인합니다. 처음이면 **처음이에요 (가입)**에서 아이디, 이름, 숫자 네 자리 비밀번호와 아바타를 정합니다.
2. 선생님이 준 참여 링크를 열거나 메인 로비의 **수업 참가**에서 **실시간 수업 / 나중에 혼자 풀기** 목록을 고릅니다.
3. 실시간 수업은 선생님이 시작할 때까지 대기합니다. 팀 선택 수업은 자기 팀을 고르고, 무작위 수업은 배정된 팀 색을 확인합니다.
4. 맵에서는 방향키 또는 WASD·화면 방향 버튼으로 움직입니다. NPC·사물 가까이에서 **E / Enter** 또는 문제 열기 버튼으로 답합니다. 객관식은 보기를 고르고, 주관식은 정답을 쓰며, 선 잇기는 짝을 연결하고, 순서 맞추기는 항목을 옮깁니다.
5. 탐험 문제를 틀리면 다시 도전합니다. 맞힌 문제는 내 완료 기록에 저장됩니다. 다시 로그인해 같은 수업·과제를 열면 같은 계정의 진도로 이어 갑니다. 라운드전은 현재 문제의 제한 시간과 제출 상태를 확인합니다.

학생 한 명의 정답은 다른 학생의 관문이나 문항을 완료시키지 않습니다. 팀전에서는 개인 점수만 팀에 더하고, 협동전에서는 학생들이 각자 맞힌 문제 수를 합칩니다.

같은 브라우저에서는 저장한 로그인 정보로 다시 들어올 수 있습니다. 비밀번호를 잊었으면 선생님이 **학생 명단 → 비번 초기화**로 `0000`으로 초기화합니다. 다른 계정으로 로그인하면 그 계정의 진도를 사용합니다.

## 다섯 가지 일반 퀴즈

| 방식 | 플레이 |
|---|---|
| 순서풀이 | 울타리 안 정해진 숲길을 따라 꿀단지 관문을 하나씩 풉니다. 내가 정답을 맞혀야 내 관문이 열려 다음 구간으로 갈 수 있습니다. |
| 자유풀이 | 성·용암·사막·숲이 있는 넓은 2D 맵을 탐험합니다. 원하는 NPC·사물 가까이에서 문제를 열어 자유로운 순서로 풉니다. |
| 라운드전 | 시작하면 아바타가 자기 체크무늬 소풍 돗자리 한 장 위로 걸어 들어갑니다. 실시간 수업에서는 모두 같은 문제를 시간 안에 풀며 정답 공개 뒤 개인 점수를 얻고 마지막 순위를 확인합니다. 혼자 풀기에서는 각 문제를 내 차례에 풉니다. |
| 팀전 | 울타리 안 가을 퀴즈 경기장에서 팀 색을 달고 각자 문제를 풉니다. 무작위 배정은 팀 인원을 고르게 나누며, 개인 점수를 모두 합쳐 팀끼리 겨룹니다. |
| 협동전 | 각자 문제를 풀어 반 전체의 정답 수를 모읍니다. 제한 시간 안에 선생님이 정한 공동 목표에 도달하면 함께 성공합니다. |

탐험 방식은 같은 학생의 같은 정답을 한 번만 점수에 더합니다. 일반 퀴즈의 기본 정답 점수는 100점입니다. 팀전의 팀 점수는 팀원 개인 점수의 합계, 협동전의 목표 수치는 반 전체 학생이 완료한 문항 수의 합계입니다.

## 네 가지 문항 작성

| 유형 | 선생님이 입력할 내용 | 학생이 할 일 |
|---|---|---|
| 객관식 | 질문, 정답 보기 하나, 오답 보기 | 섞인 보기 중 하나를 선택합니다. |
| 주관식 | 질문, 짧은 정답과 추가로 인정할 답 | 정답을 직접 씁니다. `한글/훈민정음`처럼 여러 정답을 허용할 수 있습니다. |
| 선 잇기 | 질문과 같은 줄에 놓은 왼쪽·오른쪽 정답 짝 | 왼쪽 항목과 섞인 오른쪽 항목을 골라 실제 선으로 연결합니다. |
| 순서 맞추기 | 질문과 올바른 순서로 적은 항목 | 섞인 항목을 끌거나 위·아래 버튼으로 순서를 바꿉니다. |

주관식은 띄어쓰기·영어 대소문자·일반 문장 부호와 전각 숫자를 정리해서 비교합니다. 선 잇기와 순서 맞추기는 항목을 두 개 이상 작성하고, 같은 쪽 항목이나 순서 항목이 중복되지 않게 합니다. 이 네 가지에 서술형은 포함하지 않습니다.

## 별도 OX와 기존 퀴즈룸

선생님은 **별도 퀴즈룸**, 학생은 참가 목록의 **별도 OX·기존 퀴즈룸 참가**에서 기존 기능을 엽니다. 기존 OX는 일반 퀴즈의 문항 유형과 별개입니다.

| 게임 | 진행 |
|---|---|
| OX | O·X 구역을 골라 아바타를 이동합니다. 마감 전까지 바꿀 수 있고 마지막 선택으로 채점합니다. 정답 100점·오답 0점이며 탈락 없이 끝까지 참여합니다. |
| 기존 스피드 퀴즈 | 정답을 직접 입력하고 Enter 또는 **답 보내기**로 제출합니다. 시간 안에 재도전할 수 있고 처음 맞힌 정답만 인정합니다. |
| 기존 팀 가로세로 | 두 팀의 공용 퍼즐판에서 칸·힌트를 골라 답을 입력합니다. 맞힌 낱말과 보상은 팀마다 한 번만 반영하며 다음 게임 전에 팀을 고릅니다. |

기존 퀴즈룸은 반 전체가 공유하는 한 개의 방입니다. 일반 퀴즈의 팀전은 각자 풀이의 점수 합산 방식이며, 기존 팀 가로세로의 공용 퍼즐판과는 진행 방법이 다릅니다.

## 내 아바타로 움직임 연습

메인 로비 아바타 창의 **움직임 연습**을 누릅니다. 왼쪽·오른쪽 방향키 또는 A·D로 걷고, **Space / ↑ / W**로 점프하며, **↓ / S**를 누르고 있는 동안 앉습니다. 화면의 방향·점프·앉기 버튼도 사용할 수 있습니다. **처음 위치**로 다시 시작합니다.

탐험 맵에서는 방향키·WASD가 네 방향 이동에 쓰입니다. 문제 입력 중에는 입력란이 키를 받습니다. 아바타의 얼굴·의상·펫·이펙트와 눈 깜박임은 움직임을 연습해도 유지합니다.

## 아바타, 상점과 내 옷장

제작에 쓸 자료는 [전체 소재 보관함](assets/library/index.html)에서 검색합니다. 받은 원본 ZIP·이미지와 종류별 목록을 함께 저장하며, 집에서 이어 쓸 때도 최신 전체 ZIP의 `퀴즈나라` 폴더를 사용합니다.

사용자가 제공한 최신 참고 화면을 **최소 미술 품질 기준**으로 삼고, 새로 제작한 **일러스트형 SD 머리 원화**를 사용합니다. 얼굴·머리카락·의상의 선과 명암을 또렷하게 표시하고, 머리 위치와 전신 피부색을 맞춥니다. 로비와 꾸미기에서는 전신을 크게 보며 상의와 하의의 모양을 따로 확인하고 골라 입습니다. 구체적인 기준과 참고 화면은 [디자인기준.md](./디자인기준.md)에 있습니다.

로그인, 로비, 상점, 퀴즈 맵, OX, 팀 퍼즐과 결과 화면에서 아바타의 작은 움직임을 계속 표시합니다. 얼굴·머리의 자잘한 떨림을 줄이고 숨쉬기와 펫의 포즈가 부드럽게 이어지도록 표시합니다. 눈 깜박임, 천사 날갯짓과 배경 장식은 계속 움직입니다. 로비와 상점 옆 전신은 각각 252~280px, 280~300px로 표시해 과대한 확대를 줄였습니다.

꾸미기 항목은 얼굴, 머리, 상의, 하의, 신발, 모자, 안경, 얼굴장식, 귀걸이, 목걸이, 등장식, 펫, 이펙트, 배경과 액자입니다. **얼굴은 기본 얼굴을 포함한 8종**, **액자는 4종**이며, 추가 얼굴과 액자도 골드로 구매합니다.

1. **옷 가게 → 아이템 상점**에서 카테고리와 색을 고르고 미리 입어 봅니다.
2. 골드가 충분하면 **사기**로 구매합니다. 구매한 아이템은 계정에 저장됩니다.
3. **내 옷장**을 누르면 선택한 카테고리에서 가진 아이템을 모든 색상으로 확인할 수 있습니다.
4. 보유 아이템을 선택하고 **이걸로 입기**로 다시 착용합니다. 장신구·펫·배경·액자는 **안 쓰기**로 뺄 수 있습니다.

구매는 거래 처리로 골드 차감과 소유권 저장을 함께 반영합니다. 같은 아이템의 중복 클릭으로 골드를 반복 차감하지 않습니다. 수업·연습 보상에도 계정별 수령 기록을 사용합니다. **피부색** 메뉴에서는 얼굴·손·다리의 색을 함께 바꿀 수 있으며, 눈과 표정은 상점의 얼굴 상품으로 선택합니다.

입어 보기 아래의 **남자 아바타 / 여자 아바타**를 누르면 현재 의상을 입힌 두 아바타를 비교할 수 있습니다. 남자와 여자 헤어 목록은 각각 4종·8종으로 구분하며, 상점·옷장·무작위 꾸미기에 같은 기준을 적용합니다. 성별을 바꾸면 해당 성별의 보유 헤어로 맞추고 의상·피부색·구매 내역·골드는 유지합니다. 성별 변경에는 골드가 들지 않습니다.

현재 일러스트형 SD 원화는 [머리 제작 기록](./assets/sd-heads-제작기록.md)과 [의상·신발 제작 기록](./assets/sd-wardrobe.md)에 있습니다. 상의 14종과 하의 11종에는 리본·꽃·레이스·단추·주머니·주름을 새로 그렸으며, 분홍·민트·보라·크림·갈색 등을 포함한 12색으로 각각 선택합니다. 흰 카라와 금색 단추는 염색해도 유지됩니다. 실제 눈 위치에 맞춰 반쯤 감은 눈과 감은 눈을 표시합니다.

토끼 후드는 목 아래에 큰 빈 구멍이 남지 않도록 [내려진 후드 원화](./assets/sd-hood.md)를 별도로 입힙니다. 니트·가디건과 바지는 종류마다 몸에 맞는 비율을 적용합니다.

팔·손·다리는 곡선 윤곽과 피부 명암으로 표시합니다. 신발 9종은 새 일러스트 원화의 앞코·끈·버클·밑창을 구별하며 몸에 맞춰 입혀도 원래 비율을 유지합니다. 펫 16종은 기존 [펫 원화](./assets/펫-원화-제작기록.md)를 함께 사용합니다. 기존 종류·가격과 12색 선택은 유지합니다. 원화가 준비될 때까지 불러오는 안내를 표시합니다.

메인 로비는 풍성한 숲 배경과 청록·연두·노랑·코럴색 나무 간판을 사용합니다. 전체 인터페이스의 컨셉은 **숲속 마을**입니다. 옷 가게·로그인·퀴즈·선생님 화면은 따뜻한 나무, 크림색 종이, 이끼·옥빛 버튼과 금색 테두리로 연결합니다. 옷 가게에는 잎·꽃·버섯 장식이 있는 원화 프레임과 숲 풍경을 더합니다. 제목·버튼은 **주아(Jua)**, 문제·설명·입력란은 로컬 **나눔스퀘어라운드** 한글 글꼴로 표시합니다. 반 이름은 **3학년 3반**입니다. 글꼴의 공식 출처와 라이선스는 [폰트 출처](./assets/fonts/NanumSquareRound-출처.md)에 있습니다. 퀴즈쇼 무대의 별과 유리 화면에는 은은한 움직임을 더합니다. 기존 퀴즈쇼의 아바타는 노트북 화면 높이에 따라 224~252px로 표시합니다. 기존 퀴즈쇼 오른쪽 내 아바타는 칸 가운데에 배치하고, 배경은 칸을 채우며 칸 밖으로 나오지 않습니다.

버튼은 마우스와 Enter·Space로 누를 때 살짝 내려갔다 돌아오며 짧은 클릭음이 납니다. 선택·정답·구매 소리가 있는 동작에는 일반 클릭음을 겹쳐 재생하지 않습니다. 효과음 끄기와 음량 설정은 그대로 적용됩니다.

**이펙트 → 햇살 천사**는 520골드로 구매합니다. 아바타 옆에서 둥실 떠다니며 두 날개가 따로 펄럭입니다. 펫·배경·액자와 함께 착용할 수 있습니다. 원화와 프롬프트는 [천사 제작 기록](./assets/천사-원화-제작기록.md)에 있습니다.

## 골드와 기존 생활 기능

가입·기존 연습·기존 퀴즈룸·패션왕의 보상 기본값은 파일 위쪽 `window.RULES`에서 조정합니다. 새 일반 퀴즈의 개인·팀 점수와 계정의 구매용 골드는 별도로 표시합니다.

| 항목 | 기본값 |
|---|---|
| 가입 골드 | 300 |
| 기존 혼자 연습 | 정답당 10골드, 하루 최대 300골드, 한 판 10문제 |
| 기존 퀴즈룸 정답 | 정답당 25골드; 팀 가로세로는 맞힌 낱말마다 팀원 모두 지급 |
| 기존 퀴즈룸 순위 보너스 | 1·2·3등 120·80·50골드, 동점은 같은 보너스 |
| 패션왕 | 1·2·3등 500·300·150골드, 참가 보상 50골드 |

메인 로비의 **혼자 연습**은 기존의 짧은 연습 기능입니다. 선생님이 만든 **나중에 혼자 풀기** 과제는 참가 목록에서 선택하며 학생별 진도를 저장합니다. **우리 반 순위**, 선생님의 학생 명단·비밀번호 초기화·골드 지급 기능도 이용합니다.

**패션왕**은 선생님이 주제를 정해 대회를 열고, 학생이 현재 착용 모습으로 참가한 뒤 투표합니다. 자신에게 투표할 수 없으며 선생님이 결과를 발표하면 상금과 참가 보상을 지급합니다.

화면 위 **소리 설정**에서 효과음과 BGM을 각각 켜고 끄며 음량을 정합니다. 설정은 다음 접속에도 유지합니다. **소리 들어보기**로 확인할 수 있고 브라우저의 첫 클릭·키 입력 후 소리가 시작됩니다. 배경 탭에서는 음악을 멈추고 돌아오면 이어 재생합니다. 버튼·정답·오답·구매·게임 시작·결과에 각각 효과음이 있습니다.

## 배포와 확인

`퀴즈나라` 폴더에서 `node tools/check-source.cjs`로 실행 파일을 검사합니다. 실행 파일 기준 목록은 `tools/deployment-files.cjs`입니다. 새 수업·문항·맵·움직임의 JS/CSS도 필요하므로 목록의 파일과 `_headers`, `assets/`를 포함한 **`퀴즈나라/` 폴더 전체**를 배포합니다. Netlify에 GitHub를 연결한다면 게시 디렉터리를 `퀴즈나라`로 지정합니다. 같은 폴더를 수정하고 배포하며 별도 복사본을 만들지 않습니다.

이 문서의 실행 순서는 배포 성공이나 실기기 검증 기록이 아닙니다. 배포 뒤 실제 사이트에서 `demo=1` 없는 학생 주소와 참여 링크를 확인한 후 수업에 안내합니다. LG 그램·크롬북에서 문제·입력·조작 버튼·맵·아바타·점수판의 배치와 실제 조작을 확인합니다. 개발 검사와 방식별 검수 항목은 [개발환경.md](./개발환경.md)에 있습니다.

# 둥근 기준 캐릭터 · 2026-10-07 후속 검수

## 변경과 적용 범위

검토 시작점은 최신 `origin/main`의 `263298b`(기준 몸·모션 보강 `3ddfc5f` 포함)다. 사용자가 다시 제시한 남녀 앞/옆/뒤 그림을 피부 부품과 체형의 미술 목표로 적용했다. 기존 얼굴·머리 PNG와 최근 보행/달리기/사다리 동작은 보존했다.

현재 적용 화면은 `avatar-standard.html`과 `?demo=1&avatar=foundation`의 공통 몸·기본 착장이다. 남녀는 초록 반팔·남색 반바지·아이보리 운동화 한 벌을 공유한다. 첨부의 도토리 장식/여자 꽃무늬 의류 전체를 이식한 결과는 아니다. 일반 계정의 상점·기존 보유 의류는 기존 렌더를 유지한다. 기본 몸 검수 다음에 후드·긴바지·한벌옷과 기존 의류를 이 몸으로 전환해야 한다.

맵·사다리 경로·카메라·UI·상점 목록·재화·계정·저장 자료는 수정하지 않았다. 공통 표시 입력120px×0.76, 걷기337.5px/s·달리기506.25px/s와 통행 반경도 그대로다.

배포 폴더의 HTTP 기준 화면은 새 피부/측면 목깃을 읽어 남녀 확대·이동 크기4개와 측면 인사를 표시했다. `file://` 직접 열기는 이 클라우드 Chromium의 관리 정책이 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단하여 브라우저 검증하지 못했다. 로컬 번들의 원본 PNG 바이트와 새 로더 등록은 소스 검사로 확인했지만 직접 파일 실행 PASS로 보고하지 않는다.

점프 반복 검사는 고정 wall-clock 대기 대신 실제 시뮬레이션의 종료를 기다린다. 브라우저가 바쁠 때 dt를 제한하는 정상 동작을 자동 재점프로 잘못 판정하지 않게 했다.

30명 동시 이동은 별도 단독 브라우저에서 update 중앙값17.6ms/p95 23.6ms, frame 중앙값33.3ms/p95 50ms였다. 이전 측정과 같이 **30fps 예산 합격은 아니며 학교 기기 성능도 미측정**이다. 연결 검사 PASS를 다중 표시 성능 완료로 해석하지 않는다.

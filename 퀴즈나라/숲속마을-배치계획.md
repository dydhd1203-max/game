# 숲속 마을 배치 계획

2026-10-03. 기준: [숲속마을-디자인지침](숲속마을-디자인지침.md). 제작 중 계획이며 완료 결과는 별도 검수 기록에 남긴다.

## 전체 관계

```mermaid

  lake[물가 피크닉 공원] <--> town[집과 골목 · 만남 마당]
  town <-->|숲길 입출구 F| garden[비밀정원 · 숲의 쉼터]
  town <-->|학교 가는 길 F| school[기존 운동장과 학교]
  school <-->|기존 두 학교 문 F| classroom[기존 교실]
  garden <-->|나무집 입구 F| tree[달빛 큰 나무집 · 데크]
  tree <-->|위쪽 길 F| sky[하늘섬 · 큰 버섯 전망대]
```

낮의 마을은 피크닉동산 원본의 물가·굽은 길·연못·꽃나무·휴식 공간 구도를 유지하는 2230×1472 공간이다. 서쪽의 두 마당에는 서로 다른 꽃집·빵집 원본을 배치하고, 길·벤치·강가와의 관계를 살린다. 집은 풍경용이며 아직 실내 입장 기능은 없다. 남쪽 울타리의 열린 길은 기존 운동장, 북쪽 숲길은 비밀정원으로 이어진다.

비밀정원은 1924×1082의 별도 공간이다. 같은 낮 풍경이어도 잔디색·빛이 달라 큰 사각 경계로 붙이지 않는다. 원본의 숲·모임 그루터기·해먹·나무집·텃밭을 유지하고 남쪽 입구에서 마을로 돌아간다. 나무집 계단 앞에서 큰 달빛 나무집으로 이동한다.

큰 나무집과 하늘섬은 별도 연결 공간이다. 밤 조명·수직 원근·하늘 배경을 가진 원본을 낮의 잔디에 사각 조각으로 붙이지 않고 원본의 장소성을 유지한다. 입구에서 이동을 명확히 알리고 되돌아오는 도착점도 둔다. 사다리·계단은 도달 가능한 보행면 또는 명시한 공간 전환으로 연결하며 전용 등반 애니메이션을 구현했다고 과장하지 않는다.

## 원본 사용 계획

- `피크닉동산.png`: 물가, 연못, 꽃나무, 굽은 길, 피크닉·벤치 묶음을 큰 영역으로 유지한다. 원본 UI·이름·촬영 캐릭터는 제외하고 가려진 단순 지면에는 같은 원본의 깨끗한 지면 영역만 사용한다.
- `숲속 교실.png`: 외곽 숲과 나무집·텃밭·해먹의 관계를 살린 정원이다. 원본의 중앙 그루터기 모임 자리를 유지하되 열린 남쪽 잔디를 친구들이 쉬는 공간으로 사용한다. 학교 교실의 대체물이 아니다.
- 제공 `house.zip`의 `house-0c0b1bd03495c453.jpg`: 컨셉 사진과 어울리는 붉은 지붕·목골조·화분·작은 마당이 이미 묶인 집을 선별한다. 같은 집을 복제하지 않는다. 생활 풍경의 건물이며 옷 가게·게임룸 신규 기능이 구현되었다는 뜻은 아니다.
- `나무집.png`: 밤의 숲, 큰 나무·실내 데크·계단 구도를 유지한다. UI 영역을 피하고 걸을 수 있는 바닥과 벽·높이 경계를 구분한다.
- `퀴즈마을.png`: 하늘섬과 큰 버섯, 여러 높이의 원본 구도를 유지한다. 섬 밖과 절벽은 통과하지 못하게 하고 높이별 이동점을 둔다.
- `가을피크닉.png`, `캠피장소.png`: 이번 연결에서는 보류한다. 낮의 생활 골목에 강한 계절색·눈·황혼을 추가로 섞지 않는다.

원본 파일은 보존한다. 추출 파일은 원본 영역·마스크·해시를 기록한다. 사용자 후속 요청으로 제공 흰 꽃의 화풍 수정본 한 종류를 집 앞 화단에 사용하며 원본 추출과 별도로 기록한다. 새 맵이나 새 사물을 임의 생성하지 않는다. 길·물가·숲의 큰 구도는 원본 그대로 유지한다. 사물을 지울 때는 대상 전체 윤곽을 기록하고, 주변 나무나 울타리를 사각 잔디 패치로 함께 지우지 않는다.

꽃은 위쪽 집 앞의 흰 꽃·연보라·들꽃, 아래 집 옆의 흰색·연보라, 남쪽 물가의 낮은 들꽃, 비밀정원 입구 옆의 노란 꽃밭으로 묶는다. 출입구와 열린 길은 비우고, 같은 화단 전체를 복제하지 않는다.

## 구현·검수 범위

마을 기본 입장, 기존 지정 수업 링크 직접 참가, 운동장 왕복, 기존 두 학교 문 F, C 앉기와 방향키 두 번 달리기, 친구 표시·인사·공간별 구독 해제를 검증한다. 맵 96px 아바타와 기본 카메라에서 접지·출입 방향·반복·빈 구간·가림을 확인한다. 어색한 연결이나 원본 가림 때문에 부족한 부분은 검사 결과에 남긴다. 실제 Firebase 동시 접속·학교 기기 성능·공개 사이트 배포는 별도 검증이다.

# 옷 층 방식 진행 계획 (2026-10-14 사용자 승인)

다른 2D 옷 입히기 게임(메이플스토리 방식)처럼 **고정된 기준 몸 + 옷 층**으로 만든다. 그림은 ChatGPT로 받고, 받은 그림에서 **그 옷 부분만** 잘라 기준 몸에 겹친다. ChatGPT가 다시 그린 나머지(다른 옷·몸)는 버린다. 그래서 옷 하나당 그림 수가 정해지고, 상의·하의·신발 조합이 자유롭다.

## 원칙

- 기준 몸은 자세마다 하나다. 서 있는 몸은 이미 있다(기준 캐릭터 v2). 앉은 몸은 '앉은 기준 몸' 원화로 새로 정한다.
- 옷 하나에 필요한 그림: **서기 1장**(4방향, 이미 쓰는 옷 시트)과 **앉기 1장**(앞·옆·뒤). 걷기·뛰기·점프 등은 서기 그림을 뼈대로 움직인다(지금 방식).
- 옷 층은 '천 층'과 '피부 층'(그 옷 때문에 보이는 손·팔·다리, 피부색을 입힘)으로 나눈다.
- 겹치는 순서(앉기 앞모습 기준): 기준 몸 → 하의(천·다리 피부) → 신발 → 상의(천·손·팔 피부). 옆·뒤는 방향마다 순서를 정해 둔다.
- 원화와 맞는지는 `tools/verify-seated-art.py`로 재고, 280px 비교판을 직접 본 뒤에만 '맞다'고 보고한다.

## 단계

### 1. 앉은 기준 몸 (먼저)

| # | 할 일 | 누가 |
|---|---|---|
| 1-1 | '앉은 기준 몸' 원화 요청: 남녀 각각 지금 앉은 원화와 같은 자세·크기로, **흰 민소매와 흰 속바지, 맨발**. 옷이 작아질 때(민소매·치마 등) 드러나는 몸통·허벅지·발을 채운다 | 작업자가 요청문, 사용자가 ChatGPT |
| 1-2 | 기준 몸을 잘라 피부 층·속옷 층으로 만들고 지금 기본 원화와 위치를 맞춘다 | 작업자 |
| 1-3 | 기본 옷(도토리 반팔·꽃 카라 반팔, 반바지, 운동화)도 같은 규칙으로 옷 층 3개로 나눈다. 기본 옷 모습이 지금 원화와 같아야 통과 | 작업자 |

### 2. 옷 층 자르기 도구

| # | 할 일 |
|---|---|
| 2-1 | 옷 그림을 기준 원화에 맞추는 단계(머리 너비·중심·바닥, 지금 `seated-cut-body.py register`)를 그대로 쓴다 |
| 2-2 | 그 옷 칸(상의·하의·신발·한벌옷)의 영역만 자른다: 칸마다 정해 둔 범위 안에서, 피부가 아닌 화소 + 그 옷과 이어진 부분. 경계가 애매한 옷은 옷마다 손으로 범위를 덧그린 다각형으로 보정한다(그림은 손대지 않음) |
| 2-3 | 검사 추가: 겹친 결과를 받은 원화와 비교(영역 겹침), 칸 밖으로 새는 화소 0, 다른 칸과 겹치는 이음새 틈 0 |
| 2-4 | 런타임: 앉기에서 기준 몸 위에 고른 옷 층을 순서대로 겹친다. 노드 수는 늘리지 않는다 |

### 3. 첫 시험: 후드 집업

- 받은 01번 후드 원화로 2단계 도구를 맞춘다.
- '후드 + 기본 반바지', '후드 + 다른 하의'(하의 원화가 오면) 조합이 되는지 앞·옆·뒤, 280·120px, 피부 5단계에서 본다.
- 통과하면 사용자에게 보여 드리고 확인을 받는다.
- **결과(2026-10-14): 남자 후드 + 기본 반바지 앞·옆·뒤를 사용자가 승인했다("후드 괜찮아").** 후드 밑단 크림색은 원화의 니트 밑단이다. 기본 신발 층은 신발 범위(`SHOE_ZONE`)를 손으로 정해 셔츠·반바지 꽃무늬가 섞이지 않게 했다.

### 4. 상점 옷 옮기기 (5단계와 함께)

- 앉기 시트는 지금 요청문(`인계/앉은옷-요청문.md`)으로 받는다. 서기 시트는 서기 옷 자르기 도구(WP6)가 다시 준비되면 같은 묶음에 더한다(그 전에 받으면 다시 요청할 수 있어 미룬다).
- 한 묶음은 5~8벌(요청문의 묶음 1 상의는 02~08, 09~14로 나눠 받는다). 받는 대로 자르기 → 검사 → 비교판 확인 → 커밋. 묶음 순서: 상의 → 하의 → 신발 → 한벌옷.
- 치마·튜튜·원피스·로브처럼 다리 모양을 덮는 옷은 앉은 경계가 어색할 수 있어 따로 확인한다.

### 5. 그 밖에 남은 일

- 선생님 화면 정리(진행 중): 운영자 계정·운영자 탭, 수업 관리·혼자 풀기 삭제, 칠판 = QUIZQUIZ 로비.
- 3단계 나머지: 옷 섞은 30명 성능 측정, 머리 규칙(H2~H5, 얼굴 크기 비교 승인 필요), 기본 옷 다시 만들기(WP11, 승인 필요), 문서 정리.
- 5단계 학생 화면 전환, 6단계 파란 UI·문제 은행. main 합치기(실제 배포)는 사용자 확인 뒤.

## 하지 않는 것

- 옷 조합마다 몸 전체 원화를 받는 방식(조합 수가 폭발함). 지금 기본 옷 몸 전체 원화는 1단계가 끝날 때까지만 쓴다.
- 수치로 자세를 억지로 만드는 일. 원본에 없는 모양은 원화를 요청한다.

# 상점 UI 큐플레이식 개선 계획 (6단계, 2026-10-14 작성)

6단계에서 한다(사용자 결정 2026-10-14: "나중에 6단계에서해주고"). 상점 옷을 새 아바타로 옮기는 4·5단계가 끝난 뒤 시작한다. 이 문서는 무엇을 바꿀지 정리한 것이고, 시작할 때 아래 '정할 것'부터 확인받는다.

## 지금과 목표 비교

| 부분 | 지금 | 큐플레이식 목표 |
|---|---|---|
| 전체 구도 | 왼쪽 거울 무대(미리보기), 가운데 상품, 오른쪽 '나의 스타일' 목록 | 왼쪽 **나의 캐릭터 + 내 소지금**, 가운데 **상품**, 오른쪽 **아이템가방(내 옷장)** 3단 |
| 창 | 나무 액자·크림 종이 | 코발트 창, 하늘색 광택 테두리, 남색 제목 띠('나의 캐릭터', '아이템가방 1 ◀ ▶') |
| 제목 | 초록 리본 '숲속 옷 가게' | 왼쪽 위 사탕 글씨 로고(예: QUIZ나라 SHOP, QUIZ만 하늘색), 오른쪽 위 둥근 크롬 아이콘(마을·QUIZQUIZ·소리) |
| 분류 | 큰 버튼 두 줄(머리·얼굴, 한벌옷, 상의 …) + 작은 칩 | 창 위쪽에 붙은 **둥근 탭 한 줄**(메인·머리·얼굴·상의·하의·한벌옷·신발·장신구·펫/효과) + 탭 아래 작은 하위 탭, 오른쪽 끝 남/여 둥근 버튼 |
| 상품 칸 | 크림 카드, 큰 초록 '입어 보기' 버튼 | 남색 칸 안 흰 그림 상자, 이름 띠, 금화 아이콘 + 가격, 작은 **입어보기·사기** 알약 버튼, NEW/인기 딱지, 가진 것은 '가진 것' 표시 |
| 추천 | '오늘의 스타일' 큰 카드 | 맨 위 한 줄 '이번 주 추천' 3칸, 그 아래 '새로 나온 옷' 격자(큐플레이의 주간베스트 + 새로 나온 아이템) |
| 넘기기 | 세로 스크롤(1280px에서 아래 줄이 체험 상자에 가려짐) | **쪽 넘김**(좌우 화살표 + 쪽 번호). 한 쪽 8칸, 스크롤 없음 |
| 오른쪽 | '나의 스타일': 지금 입은 것 세로 목록 | **착용 칸**(얼굴·머리·상의·하의·신발·펫 … 빈 칸에는 부위 이름을 흐리게) + **아이템가방** 2×4 격자(빈 칸 EMPTY, 쪽 넘김). '내 옷장' 버튼은 이 가방으로 합친다 |
| 내 정보 | 위쪽 금화 알약만 | 왼쪽 아래 '내 소지금' 표(아이디·골드) + 주황 알약 '피부색' 버튼 |
| 아이템 설명 | 없음 | 칸에 마우스를 올리거나 키보드로 고르면 남색 반투명 설명 상자(이름·가격·한 줄 설명) |
| 아래쪽 | 체험 모드 상자가 상품을 가림 | 큐플레이식 아래 바(뒤로·되돌리기·아무거나), 체험 상자는 아래 바 안으로 넣거나 접힌 채 시작 |

## 지금 것 중 살릴 것

- 꾸민 아바타를 크게 보여 주는 미리보기, 사탕 큰 문구, 작은 반짝임 같은 살아 있는 움직임(동작 줄이기·숨긴 탭에서 멈춤).
- 상점 규칙: 남녀 전용 목록, 상품마다 고정색 하나, 한벌옷은 상·하의와 함께 입지 않음, 피부색 첫 톤 무료·이후 100골드, 미리보기는 저장·결제하지 않음.
- 버튼 판(`qplay-buttons.css`), 글꼴(나눔스퀘어라운드, 버튼은 ExtraBold), 44px 이상 누르는 칸, 글자 대비 4.5:1.

## 정할 것 (6단계 시작 때 확인)

1. **숲속 옷 가게 그림(`forest-shop.png`)을 어떻게 쓸지.** 추천: 바깥 배경과 왼쪽 '나의 캐릭터' 창 안의 무대 그림으로만 쓰고, 창·탭·칸은 파란 큐플레이식으로 바꾼다(2026-10-08 결정 "맵 그림은 그대로, 그 위 UI만 큐플레이식"과 맞음). 다른 안: 그림을 빼고 완전히 파란 화면.
2. **'나의 스타일' 목록을 착용 칸 + 아이템가방으로 바꿀지.** 추천: 바꾼다('내 옷장' 버튼과 합쳐 화면 하나로).
3. **스크롤 대신 쪽 넘김.** 추천: 쪽 넘김(1280px에서도 가려지는 줄이 없음).

## 필요한 에셋

- 지금 가진 것으로 충분하다: 창·탭·칸·아이콘·딱지는 직접 그리는 UI 층이고, 상품 그림은 아바타 그림에서 만든다.
- 정할 것 1에서 '왼쪽 창 안의 무대'가 그림 일부를 잘라 써서 어색하면 그때 무대 배경 그림을 요청한다(요청문을 따로 드림).

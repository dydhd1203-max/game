## 지금 것 중 살릴 것

- 꾸민 아바타를 크게 보여 주는 미리보기, 작은 반짝임 같은 살아 있는 움직임(동작 줄이기·숨긴 탭에서 멈춤).
- 상점 규칙: 남녀 전용 목록, 상품마다 고정색 하나, 한벌옷은 상·하의와 함께 입지 않음, 피부색 첫 톤 무료·이후 100골드, 미리보기는 저장·결제하지 않음.
- 버튼 판(`qplay-buttons.css`), 44px 이상 누르는 칸, 글자 대비 4.5:1(테두리 글씨도 대비를 잰다).

## 사용자 결정 (2026-10-14)

1. **이름은 QUIZSHOP.** 숲속 옷 가게 컨셉은 끝났다. 왼쪽 위 로고를 큐플레이 'Q PLAY SHOP'처럼 굵은 기울임 글자 + 흰·하늘 광택 + 두꺼운 남색 테두리로 만든다(QUIZ만 하늘색 규칙 유지, 원작 로고 그림은 복사하지 않음). `forest-shop.png`·나무 액자·초록 리본은 쓰지 않는다. 왼쪽 창 무대 배경이 필요하면 그때 요청한다.
2. **'나의 스타일' 목록 → 착용 칸 + 아이템가방.** '내 옷장' 버튼은 가방에 합친다.
3. **쪽 넘김.** 스크롤 없음.
4. **남/여 바꾸기는 선생님(운영자) 계정만.** 학생은 처음 고른 성별로 고정한다. 학생 상점에는 남/여 버튼이 없다(지금 `btnGender`). 이미 저장된 학생 성별은 그대로 둔다. 운영자는 자기 아바타만 바꿀 수 있다.
5. **골드 아이콘을 예쁜 것으로.** 위쪽 금화 알약·가격 줄·내 소지금에 같은 새 금화(굵은 외곽선, 반짝임 한 점, 손그림 채색)를 쓴다.
6. **글씨체를 큐플레이처럼.** 제목·탭·버튼·가격처럼 짧고 큰 글자는 **굵은 테두리 글씨**(흰 글자 + 남색 테두리, 큐플레이 UI 글자), 이름·설명·표 내용은 **일반 글씨**로 상황에 맞게 섞는다. 글꼴 자체도 큐플레이 느낌으로 바꾼다: S1에서 무료 상업 사용 가능한 둥글고 굵은 한글 글꼴 후보 2~3개(예: 넥슨 메이플스토리체, Jua, Do Hyeon — 저작권·사용 조건 확인 후)를 시안으로 비교해 고른다. 사탕 큰 문구 규칙(`candy-title.js`)과의 관계도 시안에서 함께 정한다.

## 필요한 에셋

- 창·탭·칸·아이콘·딱지·금화·QUIZSHOP 로고는 직접 그리는 UI 층이다. 상품 그림은 아바타 그림에서 만든다.
- 왼쪽 '나의 캐릭터' 창의 무대 배경이 단색으로 허전하면 그때 배경 그림을 요청한다(요청문을 따로 드림).
- 새 글꼴은 무료 상업 사용 조건을 확인한 파일만 `assets/fonts/`에 넣고 사용 조건 파일을 함께 둔다.

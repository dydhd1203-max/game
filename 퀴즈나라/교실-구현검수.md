학생 기본 입장은 `SCREENS.campus`다. 기존 상품 상점·개인 아바타·골드·교사 운영·퀴즈 방식의 맵은 보존했다. 이전 메타버스 마을/옷 가게 맵은 재활성화하지 않았다. 다음 제작 공간은 운동장이며, 새 운동장·실내 옷 가게·숲 마을 연결은 이번 범위에 포함하지 않는다.

책상 착석은 원래 좌석 앵커를 유지(`sitVisualYOffset: 0`)하고 아바타 깊이를 `deskTop + 63`으로 둔다. 실제 엉덩이는 의자 좌판 영역에 있고 뒷머리는 상판 앞에 보인다. 검수 중 머리를 상판 북쪽으로 올렸던 시안은 서 있거나 떠 보이므로 폐기했다. 머리가 상판 위쪽에 많이 보인다는 수치만으로 자연스러운 착석을 판정하지 않는다. 사용자는 이 교실의 디자인을 확인하고 후속 맵도 예시·제공 에셋·실제 화면 교차검증 방식으로 만들도록 확정했다.

## 검사 방법

- `tools/verify-school-room.cjs`: 격리된 새 체험 저장소, 실제 교사 화면으로 두 수업 발행, 별도로 로그인한 학생 두 명. 순간이동 없이 실제 포인터·키보드로 30자리·모둠 공간·복도를 걷고 앉는다. 책상·벽 충돌, 좌석 경쟁·해제, 네 방향 바닥 자세·발 접지, 칠판 근접·모달 정지·종료 정리, 실제 답 채점·진도·복귀·직접 링크를 검사한다. 1366×768과 1920×1080의 기본 입장·착석·칠판 화면을 저장한다.
- `tools/verify-village-presence.cjs`: 18개 격리 묶음. 30명/30좌석 레코드, 트랜잭션 경쟁·재시도·만료·소유자 해제·재연결·바닥 앉기 공유·늦은 응답 경합을 검사한다. 같은 인사의 150ms 반복 발행은 하나의 시작시각을 유지하며, 만료·새 인사·±60초 시계 차이를 확인한다.
- `tools/verify-avatar-fitting.cjs`: 기존 154개 의상/포즈 + 새 앉기 44개. 실제 래스터의 목·소매·허리·발목 접촉과 온전한 신발을 기존 허용 거리로 검사한다. 앞·뒤 책상, 정면 바닥, 대표 의상 좌우를 포함한다.
- `tools/verify-avatar-direction.cjs`와 `tools/verify-avatar-back.cjs`: 옆모습 96개 착용·8개 추가 포즈, 머리 24개, 방향 복원·연속 프레임 재생성 없음·누락된 측면 원화 폴백. 뒷머리 24개와 눈·입·안경 숨김·정면/측면 복원을 검사한다. 이는 상품에 여자 헤어 12종을 추가했다는 뜻이 아니며 실제 상점은 남자 12종·여자 8종이다.
- `tools/verify-file-avatar.cjs`: 웹 및 실제 불투명 원점(`origin: null`)에서 정면·측면·뒷머리와 책상/바닥 착석 원화 픽셀 일치. 뒷머리 두 파일도 `avatar-image.js`의 보안 폴백과 13개 원본 데이터 번들에 등록했다.
- `tools/verify-school-room-clock.cjs`: 기기와 서버의 시계 차이가 각각 +60초/-60초일 때 실제 F 입력의 발행 시각과 친구 SVG의 인사·말풍선·자연 종료를 확인한다. 자기 모션은 단조 시계, 공유 모션은 presence의 서버 보정 시계를 사용한다.
- 원본 영역 미술 비교와 실제 플레이 화면은 직접 열어 검수한다. 자동 통과·조망 화면만으로 미술을 판단하지 않는다. 재생성 가능한 `검증/` 출력은 커밋하지 않는다.

## 확인한 결과

소스·배포본의 실제 게임 검사는 각각 15개 항목을 통과했다. 양쪽 모두 실제 이동으로 30자리를 확인했고, 브라우저 오류·누락 파일·실패 항목은 0이다. 결과와 플레이 화면은 각 `검증/교실-플레이-2026-10-02/검증결과.json`, `검증/교실-배포본-2026-10-02/검증결과.json`에 남겼다. 의자 좌판과 엉덩이가 맞는 실제 크기 착석 화면도 직접 확인했다.

1366×768과 1920×1080의 교실·착석·칠판을 확인했다. 큰 화면에서도 제공 원본 재질이 교실 화면을 채우도록 최소 카메라 배율을 계산한다. 창 크기를 되돌리면 사용자의 선호 배율을 복원한다. 이전 숲 배경이 아래에 드러나던 문제는 이 방식으로 수정했다.

공유 자리의 해제·인수 반복 검사는 10회 통과했다. 자리 해제와 친구 목록 갱신이 도착한 후 실제 E 입력을 보내 검사하며, 비어 있기 전에 E를 누른 결과를 좌석 인수 실패로 오인하지 않는다. 실행 중·실패 결과를 최종 통과로 보고하지 않는다.

몸을 8% 키운 최종 비율로 착용 198조합, 측면 보행·추가 자세 104조합, 뒷머리 24종을 다시 검사해 실패·브라우저 오류가 없었다. 소스·배포본 교실의 15개 항목도 새 비율로 다시 통과했다. 변경 전/후 남녀의 210px·실제 교실 76px 비교는 `검증/아바타-몸비율-2026-10-02/몸-8퍼센트-앞모습-비교.png`에 남겼고 직접 확인했다.

공유 상태의 반복 인사 타임라인 등 격리 검사 18개와 시계 ±60초의 실제 모션 검사를 통과했다. 배포본의 웹·불투명 출처 원화 검사도 오류가 없었다. `node tools/build-deployment.cjs --check`로 실행 파일 85개의 소스·배포본 SHA-256 일치를 확인했다. 로컬 파일용 원본 PNG 번들은 25,301,948바이트로 Cloudflare Pages의 파일당 25MiB 한도 안이다.

## 실제 확인의 범위

두 학생 브라우저 검사는 같은 격리 BrowserContext의 localStorage/BroadcastChannel 어댑터를 사용한다. 실제 Firebase에 학생 30명이 접속한 검사나 학교 그램/크롬북의 FPS·네트워크 검사가 아니다. 위치 공유 구현과 실제 운영 권한·성능을 구분한다.

맵의 가려진 원본 픽셀을 복원하지 않았다. 스크린·양문은 보이는 깨끗한 원본 부품을 조합했고, 책상·컴퓨터에 숨은 의자 부위는 보이는 부분만 쓴다. 아바타는 실제 일러스트 뒷머리가 있지만 의상 25종의 전용 뒷면 원화를 새로 만든 것은 아니다. 큰 뒷모습에서 기존 옷의 앞 장식이 남는 한계는 이후 방향별 의상 원화 작업 대상이다.

직접 `file://` 실행은 이 클라우드 Chromium의 관리 정책으로 차단되어 미검증이다. 브라우저 보안·캔버스 보호를 해제하지 않았다. 웹과 실제 불투명 출처의 픽셀·폴백은 검증했다. GitHub main 반영과 Cloudflare 공개 사이트 배포 성공은 별도 상태로 보고한다.

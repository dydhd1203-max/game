## 이전 교실 단독 버전의 확인 결과

소스·배포본의 실제 게임 검사는 각각 15개 항목을 통과했다. 양쪽 모두 실제 이동으로 30자리를 확인했고, 브라우저 오류·누락 파일·실패 항목은 0이다. 결과와 플레이 화면은 각 `검증/교실-플레이-2026-10-02/검증결과.json`, `검증/교실-배포본-2026-10-02/검증결과.json`에 남겼다. 의자 좌판과 엉덩이가 맞는 실제 크기 착석 화면도 직접 확인했다.

1366×768과 1920×1080의 교실·착석·칠판을 확인했다. 큰 화면에서도 제공 원본 재질이 교실 화면을 채우도록 최소 카메라 배율을 계산한다. 창 크기를 되돌리면 사용자의 선호 배율을 복원한다. 이전 숲 배경이 아래에 드러나던 문제는 이 방식으로 수정했다.

공유 자리의 해제·인수 반복 검사는 10회 통과했다. 자리 해제와 친구 목록 갱신이 도착한 후 실제 착석 키 입력을 보내 검사하며, 비어 있기 전에 E를 누른 결과를 좌석 인수 실패로 오인하지 않는다. 실행 중·실패 결과를 최종 통과로 보고하지 않는다.

몸을 8% 키운 최종 비율로 착용 198조합, 측면 보행·추가 자세 104조합, 뒷머리 24종을 다시 검사해 실패·브라우저 오류가 없었다. 소스·배포본 교실의 15개 항목도 새 비율로 다시 통과했다. 변경 전/후 남녀의 210px·실제 교실 76px 비교는 `검증/아바타-몸비율-2026-10-02/몸-8퍼센트-앞모습-비교.png`에 남겼고 직접 확인했다.

공유 상태의 반복 인사 타임라인 등 격리 검사 18개와 시계 ±60초의 실제 모션 검사를 통과했다. 배포본의 웹·불투명 출처 원화 검사도 오류가 없었다. `node tools/build-deployment.cjs --check`로 실행 파일 85개의 소스·배포본 SHA-256 일치를 확인했다. 로컬 파일용 원본 PNG 번들은 25,301,948바이트로 Cloudflare Pages의 파일당 25MiB 한도 안이다.

## 최신 C·통로·운동장 패치

책상·의자 30개는 원래 62×90 픽셀 부품·5쌍×3줄을 유지하고 모든 열·행에 통로를 확보했다(짝 사이 28 / 쌍 사이 48 / 줄 사이 27px). 가구의 seat·approach·exit·hitRect·solid·depth를 함께 이동했으며 보이는 책상 다리의 충돌도 맞췄다. 이동속도는 150→225px/s이며 C 앉기·취소·일어서기, E 칠판, F 공간 이동/인사로 분리했다. 지연된 좌석 응답 중 반복 이동키로 착석이 취소되거나 오래된 해제 작업이 새 착석 요청을 해제하는 문제도 고쳤다.

소스·배포본 교실 검사는 각각 15개 항목을 통과했고, 실제 클릭으로 30자리를 걸어가 C로 앉고 일어났다. 현재 결과는 `검증/교실-C통로-최종-2026-10-02/검증결과.json`과 `검증/교실-C통로-배포본-2026-10-02/검증결과.json`이다. 배포본 검사는 두 학생이 차례로 같은 자리에 착석을 시도해 중복 소유 방지와 해제 후 인수를 확인하며, 동시 트랜잭션 경쟁은 별도 공유 어댑터 검사에서 확인한다.

9개 세로 통로의 각 3줄 사이와 2개 가로 통로 전체를 실제 방향키로 통과했다. 모든 좌석 접근점·문부터 경로·일어서는 출구도 합법이다. `검증/교실-입력-2026-10-02/{source,release}/결과.json`의 8개 입력 회귀 항목은 양쪽 모두 통과했다. C 길게 누르기, 이동키를 누른 상태의 지연 착석, 거부·실패·재시도·취소, 오래된 임대 응답 해제, 걷기로 취소, 퇴장 후 응답을 확인했다. 공유 어댑터 20개 검사와 기본 교실·상점 미리보기 검사도 통과했다.

아바타 몸·옷·신발은 이전 1.08배보다 약 9.3% 추가 확대했고 머리 픽셀 크기는 같다. 늘어난 신발이 잘리지 않도록 SVG 높이에 여유를 주면서 실제 머리 크기와 접지 위치를 유지했다. 최신 착용 접촉 검사는 245조합, 측면/추가 자세는 104조합과 24종 측면 머리를 통과했다. 몸/신발 검사는 실제 원화 9쌍·18발·216색 조합과 4개 PC 화면에서 투명도·흰 장식·금속 장식·손 연결을 확인했다. 큰 SVG 상자의 여유를 머리 확대로 오인하던 과거 검수 도구도 실제 머리 배율 기준으로 정리했다.

운동장 벤치는 사용자 최신 정정에 따라 배경 그림으로 전환했다. C는 원하는 위치에서 기본 앉기·일어서기이며 전용 좌석 좌표·자동 착석·벤치 충돌·좌석 임대가 없다. 소스·배포본의 실제 왕복 검사는 각각 6개 항목을 통과했다. 결과는 `검증/교실-운동장-왕복-최종-2026-10-02/검증결과.json`과 `검증/교실-운동장-배포본-최종-2026-10-02/검증결과.json`이다. 기본 자세의 팔과 손은 아래의 방향별 착장 검사와 함께 확인했다.

## 측면 착장 수정

상의 14종·하의 11종은 `avatar-pixel.js`의 별도 측면 SVG 그림을 사용한다. 목깃·소매·허리·앞뒤 옷자락·주름·꽃·리본·주머니를 방향에 맞게 구성하고 원래 정면 원화와 상품 ID·색상은 유지했다. 여자 한복은 교차 깃·고름·넓은 소매, 멜빵옷은 끈·앞판·단추·주머니를 별도로 구성했다. 새로운 PNG 시트를 제작한 것은 아니며 기존 정면 원화를 압축한 측면과도 구분한다.

신발 9종은 `avatar-shoes-profile.js`, 착용 장신구 71종은 `avatar-accessory-direction.js`로 연결했다. 신발 216개 남녀·좌우·서기/걷기/앉기 착용과 늦은 원화 로딩 뒤 보존·정면 복원을 확인했다(`검증/측면신발-2026-10-02/실제착용-검증결과.json`). 장신구는 실제 상품 71종·744색 조합의 누락, 남녀 142개 정면 복원, 좌우 모션·앉기·인사·복귀·정리·240프레임 노드 재사용을 확인했다(`검증/아바타-장신구-측면/결과.json`). 두 검사 모두 브라우저 오류는 없었다.

큰 그림과 실제 76px 시안에서 상의 14종·하의 11종, 신발 9종, 모자·안경·얼굴 장식·귀걸이·목걸이·등 장식의 좌우 착용판을 직접 열어 확인했다. 렌즈와 안경 다리의 눈·귀 연결, 콧수염의 입 위치, 목걸이의 앞가슴 위치, 가방·날개의 등 뒤 겹침을 확인했다. 접촉 검사 통과만으로 미술을 판정하지 않았다.

## 뒷면 착장·앉기 손과 최종 방향 검사

상의 14종·하의 11종에도 별도 뒷면 SVG 그림을 추가했다. 한복은 뒤 깃·등판·주름, 멜빵옷은 뒤 끈·주머니, 후드·로브는 뒤 후드·요크·옷자락을 구성해 앞쪽 고름·단추·앞판이 뒤에서 반복되지 않게 했다. 25종×남녀×서기/걷기/바닥 앉기/책상 앉기/점프의 250개 상태, 300개 색상 그림과 10개 피부색, 목·소매·허리·발목 접촉과 정면/측면 복원을 확인했다. 점프 검사는 아바타 자세 라이브러리 검사이며 학교 공간에 새 점프 키를 추가했다는 뜻은 아니다.

신발 9종은 뒤꿈치 그림도 추가했다. 뒷면 216색·18발 투명도와 실제 남녀·서기/걷기/바닥 앉기/점프·큰 크기/76px의 144개 착용을 확인했다(`검증/뒷모습신발-2026-10-02/실제착용-검증결과.json`). 모자·귀걸이·목걸이·등 장식 47종은 별도 뒷면을 사용하며 안경·얼굴 장식·앞쪽 펜던트가 뒤에 노출되지 않는다. 늦게 로딩된 원화가 새 측면·뒷면 신발과 머리를 지우지 않는지도 검사했다.

기본 바닥 앉기는 몸을 세우고 무릎·신발을 가까이 접는다. 측면 팔꿈치는 무릎 앞을 향해 접히며 뒷모습에서는 손을 앞쪽 무릎에 두고 몸이 자연스럽게 가린다. 팔 전체를 숨기지 않고 양옆의 위팔·소매를 남긴다. 한복·멜빵옷·후드의 네 방향 실제 운동장 12개 자세와 뒷모습 바닥/책상 12개 래스터·12개 복원을 비교했고 기존 책상 착석은 보존했다.

`tools/verify-profile-school-outfits.cjs`는 실제 학교 컨트롤러에서 후드·여자 한복·여자 멜빵옷에 신발·모자·안경·귀걸이·목걸이·등 장식을 함께 입힌 좌우 6개 조합을 검사한다. 실제 이동→C 앉기/일어서기→F 인사→측면 복귀→뒷모습 걷기/앉기→측면 복귀를 확인했고, 소스·배포본 모두 통과했다. 인사 후 방향이 영구히 정면으로 바뀌던 문제도 수정했다. 결과와 전체 아바타 실제 크기 화면은 `검증/앞옆뒤-학교착장-최종-2026-10-02/검증결과.json`과 `검증/앞옆뒤-학교착장-배포본-2026-10-02/검증결과.json`에 남겼다. 오류·누락 파일은 0이다.

측면 360프레임·뒷모습 240프레임의 SVG 재생성은 0이며 그림 노드를 재사용한다. 최종 실행 파일 95개는 `node tools/build-deployment.cjs --check`로 소스·배포본 SHA-256 일치를 확인한다. 이후 추가하는 아바타와 착장은 앞·옆·뒤·앉기·점프를 함께 준비하도록 `AGENTS.md`, `디자인기준.md`, `assets/아바타-라이브러리.md`에 고정했다.

## 실제 확인의 범위

두 학생 브라우저 검사는 같은 격리 BrowserContext의 localStorage/BroadcastChannel 어댑터를 사용한다. 실제 Firebase에 학생 30명이 접속한 검사나 학교 그램/크롬북의 FPS·네트워크 검사가 아니다. 위치 공유 구현과 실제 운영 권한·성능을 구분한다.

맵의 가려진 원본 픽셀을 복원하지 않았다. 스크린·양문은 보이는 깨끗한 원본 부품을 조합했고, 책상·컴퓨터에 숨은 의자 부위는 보이는 부분만 쓴다. 아바타의 새 측면·뒷면 옷·신발·장식은 별도 SVG 그림이며 새 PNG 원화 팩을 확보했다는 뜻은 아니다. 큰 그림과 실제 맵 크기의 직접 검수, 자동 접촉 검사를 구분한다.

직접 `file://` 실행은 이 클라우드 Chromium의 관리 정책으로 차단되어 미검증이다. 브라우저 보안·캔버스 보호를 해제하지 않았다. 웹과 실제 불투명 출처의 픽셀·폴백은 검증했다. GitHub main 반영과 Cloudflare 공개 사이트 배포 성공은 별도 상태로 보고한다.

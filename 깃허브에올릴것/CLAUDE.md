# 좀비의 밤 — 현재 개발 안내

초등학교 3학년 21명이 다섯 모둠으로 협동해 수정을 지키는 Three.js 브라우저 게임이다.
이 문서는 현재 기준만 담는다. 과거 수정의 이유가 필요할 때만 `기록/개발규칙-53차까지.md`와
`../클로드/진행상황.md`에서 관련 항목을 검색한다. 전체 이력을 매번 읽지 않는다.

## 사용자에게 확인한 방향

- 중심 재미는 친구들과 협동해 좀비를 막고 성장하는 것이다. 기존 보스 시스템은 유지한다.
- 사람은 둥글고 귀여운 블록 비율, 원통 머리, 얇은 웃는 얼굴, 실제 구멍이 열린 C자 손이다.
- 동물옷·잠옷·파스텔 꾸미기를 모자/얼굴 장식/옷별로 자유 조합한다. 꾸미기는 입장 전에만 가능하다.
- 1차→2차는 전투 카우보이→황금 보안관, 건설 발명가→천재 발명가, 자원 탐험가→보물 탐험가다. 이와 겹치는 챙 넓은 모자·고글형 안경은 시작 꾸미기에서 제외하고, 저장된 삭제 안경은 해제한다.
- 전직 후에는 직업 모자·의상을 우선 표시한다. 입장 전 꾸미기 저장값은 유지하며 얼굴 볼터치는 함께 표시한다. 실제 게임·미리보기·직업 아이콘은 같은 전용 곡면 기하를 사용한다.
- 전직해도 몸 크기는 그대로 유지한다. 직업별 의상·소품·날개를 바꾸며, 땅에서는 날개를 접고 활공 때 펼친다.
- 날개는 이전 크기에서 15% 줄인 1차 .306·2차 .408 배율이다. 비행 중에는 어깨 부착점을 고정한 채 분명하게 펄럭이며, 조준·착지 때는 부드럽게 접는다.
- 게임 중 가방에는 무기·방어구·물약만 둔다. 기존 저장 아이템 ID를 무단 재정렬하지 않는다.
- UI는 밝은 크림/하늘/민트, 남색 본문, 읽기 쉬운 Noto Sans KR 400~600이다.
- 좀비는 좁은 턱·둥근 두개골·굽은 등·가늘어지는 팔다리로 사람의 네모 몸과 구별한다. 밤 테마별 의상과 먹이 발견 후 달려드는 동작을 사용하며, 피·유혈 표현은 없다.
- 레이싱은 넓은 코스와 속도감을 주되, 서로 부딪히면 조금 밀리는 물리 느낌을 유지한다.
- 넓어진 경주의 진자·바위는 기존 크기/속도의 2배다. 마지막 여섯 발판은 틈 5칸·높낮이 0.15칸이며, 점프 없이 통과할 수 없고 Shift 없이 한 번 점프로 건너도록 검사한다.
- Unity 이식이 아니라 기존 브라우저 게임 개선이다. Roblox풍은 디자인 방향이며 공식 모델 복제라고 설명하지 않는다.

## 유지할 구현 규칙

- 파일 하나를 옮겨 열 수 있어야 한다. 현재 의존성은 CDN의 Three.js 0.160.0이다. 새 프레임워크/빌드 체계를 불필요하게 추가하지 않는다.
- 수치·물리·공격 타이밍은 실제 게임 함수를 실행해 검사한다. 테스트에 계산식을 복사해 같은 답을 만드는 방식은 피한다.
- 화면은 실제 DOM 경계와 렌더 결과를 확인한다. 짧은 화면에서도 설명·가격·구매 버튼을 읽고 누를 수 있어야 한다.
- 실제 동작을 바꾼 뒤에만 검사를 갱신한다. 코드 정리만 하는 경우 실행 구조가 같음을 확인한다.
- `imesh`의 최대 인스턴스 수를 최악 조합으로 검사한다. 칸이 부족해도 오류 없이 그림이 잘릴 수 있다.
- 같은 `bpush` 키에 서로 다른 기하를 섞지 않는다. HUD의 `setTxt`/`setSty` 변경 감지를 유지한다.
- 사람 머리·눈·입·장식에는 같은 변환을 적용한다. 오른손은 모델의 -X 쪽이다. 화면 좌우와 혼동하지 않는다.
- 사람 전용 `R6_*_GEO`를 고칠 때 공용 `RB`/`CYL`까지 바꾸지 않는다. 얼굴 표면 계산은 `R6_HEAD_SEG`와 같아야 한다. 옷 좌표와 저장된 꾸미기 ID는 유지한다.
- 팔꿈치·무릎·신발과 손에 든 장비는 실제 관절 끝에 맞춘다. 접촉 그림자는 몸통 흔들림이 아닌 바닥 높이를 사용하며, 레이싱 빈 공간에는 그리지 않는다.
- 사선 이동에서 팔은 몸통 바깥으로 흔들고 두 발은 서로를 통과하지 않는다. 사람의 얇은 옷·얼굴 장식은 그림자를 주고받지 않으며, 몸은 바닥에 그림자만 드리운다. 직업 모자 챙은 머리 윗면과 간격을 유지한다.
- 사람의 표시용 걸음은 걷기 최대 초당 1.6회·달리기 2회로 제한한다. 발을 세계 좌표에 고정했다가 관절 길이 한계에서 풀지 않고, 접지와 들림의 위치·속도가 이어지는 곡선을 사용한다. 물리 이동 속도와 통신은 그대로 유지한다.
- 닫힌 직업 모자는 머리 윗부분을 실제로 감싸야 한다. 모자 챙만 올려 머리와 모자가 따로 놀게 하지 않으며, 띠의 윤곽과 앞 장식도 모자 표면에 맞춘다.
- 양손 총은 손잡이·부품·강화 효과가 같은 반동 축을 쓴다. 긴 총열은 고정된 뒤끝에서 앞쪽으로만 늘려 몸통을 관통하지 않게 한다.
- 카메라는 점프 중 실제 사람 높이를 따른다. 숨김/복귀 문턱을 분리해 벽 근처 깜빡임을 막는다.
- 사격은 어깨 너머 3인칭을 유지하고 본인 날개를 접어 조준선 주변을 비운다. 벽 때문에 카메라가 가까워지면 본인 몸만 숨기며, 다른 사람의 외형은 유지한다.
- 사격은 화면 중앙의 ray로 적을 선택하고 사람 기준 사거리·전방을 검사한다. 탄약 부족 시 실제 돌 무기를 판정에 전달한다.
- 실제로 나가는 무기는 `wpnEff`가 한 곳에서 정한다. 조준점 잠금과 발사가 같은 무기를 봐야 한다.
- 위치 통신 형식/빈도를 임의로 늘리지 않는다. 보스 체력·AI·보상·등장 규칙은 디자인 수정과 분리한다.
- 좀비의 먹이 발견 자세는 호스트의 실제 `shT`를 따르고, 손님은 기존 이동 데이터에서 추격 자세만 추정한다. 시각 상태가 이동 속도·공격 판정을 추가로 바꾸지 않게 한다.
- 좀비 전용 기하·재질을 공용 `RB`/`FM`과 분리한다. 옷·갑옷·등 장식의 위치는 `drawWolves`의 `TX`/`TY`/`TZ`를 통해 실제 몸통 회전·호흡에 붙인다.
- 좀비의 잔선은 최소화한다. 볼은 얕은 음영, 망토는 한 장의 곡면으로 두고 닫힌 모자 속 머리털을 숨긴다. 겹친 투구 챙·반복 자락·등 주름·작은 공통 패치를 다시 쌓지 않는다.
- 공포 좀비 눈동자는 흰자 안쪽, 짧고 뾰족한 이는 입 안쪽에 둔다. 붕대는 머리·몸통·팔을 한 바퀴 감싸는 얇은 천으로 붙이고 얼굴 앞에 천 조각을 늘어뜨리지 않는다.
- 좀비가 뻗는 손은 손바닥을 아래로 향하고 손끝도 아래로 구부린다. 어깨를 감싼 둥근 천 토시·망토 어깨 덮개는 쓰지 않는다.
- 좀비 길찾기는 `terrH`, 건물은 `bldH`를 사용한다. 높이 도달 제한과 PvP 벽 차폐를 유지한다.
- 테이블 종류는 `boss` 같은 속성으로 구분한다. 번호 범위로 단정하지 않는다. 삭제한 필드는 소비 지점까지 검색한다.
- `Object.assign(window, ...)` 검사 API 이름을 중복 선언하지 않는다.
- 데스크톱 커서 조작은 하지 않는다. 자동 pointer lock을 넣지 않고 초점/탭 이탈 시 입력과 잠금을 해제한다.
- 건설 설계도는 모둠당 12개, 동시 작업 속도는 3명에서 상한이다. 손을 떼어도 진행을 유지하고 90초 방치 시 해제한다.
- 건설 완료·강화·수리·철거·자원 보내기는 호스트에서 현재 자원으로 처리한다. 새 위치/분기/소유자 필드를 건물 저장 시 보존한다.
- 자동문·스프링 함정은 사용자 요청으로 추가하지 않는다. 새 포탑과 특화 공격이 기존 보스 AI·등장·보상을 바꾸지 않게 한다.
- 화살탑은 Lv1~2에서 활을 쓰고, Lv3의 연사 기관총/대형 저격총 선택부터 실제 무장이 바뀐다. `blocksOf` 행의 11번째 값 `gun`인 부품만 회전/반동을 적용한다.
- 숨김 브라우저는 `pw.mjs`로만 실행하고 `finally`에서 종료한다. GPU 속도와 21명 실접속 성능은 교실 기기에서 별도로 측정한다.

## 수정 후 검사

작업 트리 뿌리에서 `node 깃허브에올릴것/검사/check-current.mjs`로 현재 Node 검사를 한 번에 실행한다.
GitHub 에 올리면 `.github/workflows/checks.yml`이 같은 명령을 다시 돌리고, 원본과 배포용의
SHA-256 도 함께 본다. 손으로 돌리는 것을 대신하지는 않는다 — 올리기 전에 먼저 확인한다.
실제 화면까지 확인할 때만 `--render`를 붙인다. 브라우저는 한 개씩 실행하고 결과는 간단히 출력한다.
문법만 볼 때는 `node 깃허브에올릴것/검사/chk.mjs 클로드/index.html`을 사용한다.
수정 범위에 따라 아래 검사를 실행한다. 테스트 라이브러리는 검사 폴더에만 두고 게임 의존성으로 추가하지 않는다.

- `t53-static.mjs`, `t54-avatar-static.mjs`: 사람/얼굴/오른손/직업/날개/모션.
- `t53-shop-static.mjs`, `t55-wardrobe-static.mjs`: 상품 거래/대기실 조합/입장 후 잠금/가방.
- `t54-combat-static.mjs`: 조준/사거리/벽 차폐/카메라 숨김/돌 대체 무기.
- `t54-race-static.mjs`: 경주 seed/발판/실제 점프/21인 출발·복귀/장식 용량.
- `t54-zombie-static.mjs`: 13종/밤별 의상/공격/92마리 인스턴스/기존 전투 수치.
- `input52-static.mjs`: 브라우저 없이 입력 해제와 pointer lock 보호.
- `t54-view.mjs`: 한 개의 숨김 브라우저. 상점 4크기/첫 구매 버튼/실제 구매/점프 30·60·120Hz/사격/군중 충돌/WebGL 그림. OS 마우스·키보드 API는 사용하지 않는다.
- `t56-buildings-static.mjs`, `t56-building-combat-static.mjs`: 모든 건물/단계/분기/테마 기하 한계·부품 수와 실제 공격/범위/감속.
- `t56-build-assist-static.mjs`, `t56-build-coop-static.mjs`: 배치/선택 UI와 두 클라이언트 통신 fixture를 통한 공동 건설·결제·이동·철거 보호.
- `t56-build-view.mjs`: 실제 건설 입력→완성→특화 선택 및 4개 화면 크기의 건설 UI. `t56-buildings-view.mjs`는 외형 갤러리 선택 검사다.
- `t57-avatar-geometry-static.mjs`, `t57-motion-static.mjs`, `t57-render-static.mjs`: 사람 전용 기하·관절 연결·발 접지·재질·접촉 그림자를 현재 소스로 검사한다.

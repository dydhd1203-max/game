# 79차 — 큰 견갑·전투 표시·R/T 조작

## 실제 외형

첫 전직 시안의 작은 테두리 변경은 사용자가 차이를 느끼기 어렵다고 피드백했다. 최종판은 어깨 위와 옆을 덮는 곡면 견갑으로 교체했다. 전투는 금속 깃과 금빛 불티, 건설은 기계 덮개와 청록 연결 조각, 자원은 수정 깃과 보석 반짝임을 쓴다. 2차는 실루엣과 장식이 더 커진다.

견갑 안쪽은 열려 있고 위팔 관절을 따라간다. 조준할 때 머리로 들어오던 첫 형태는 실제 조준 검사에서 발견해 수정했다. `t79-shoulder-static`은 2,304개 이동 자세와 252개 조준·발사·비행·회전 자세에서 팔·머리·총 관통 0, 공유 기하/최대 21명 용량을 확인한다. 기존 `t61` 17/17도 통과했다. `t58-motion-static`은 몸통 장식의 몸통 부착과 견갑의 위팔 부착을 별도로 검사한다(19/19). 몸통 판정을 견갑에 잘못 적용하던 과거 검사 조건을 변경했으며 기존 몸통 제한은 유지했다.

실제 게임 기하로 찍은 [정면 여섯 벌](계획/79차/jobs-gallery.png), [45도 여섯 벌](계획/79차/jobs-angle-gallery.png), [달리기](계획/79차/jobs-run.png), [조준](계획/79차/jobs-aim.png), [비행](계획/79차/jobs-glide.png)을 직접 열어 확인했다. 갤러리는 외형 확인용이며 일반 플레이 카메라로 난이도를 평가한 자료가 아니다.

같은 21명·2차 전직·카메라·화질에서 견갑 추가 전후 그리기 호출은 **324→329**, 삼각형은 **3,029,661→3,085,213(+1.83%)**, 텍스처는 **9→9**였다. 정적 기하 네 종류가 늘었고 추가 조명은 없다. 반짝임은 기존 128칸 풀을 재사용하며 전체 초당 150개 예산 안에서 어깨 전용 초당 30개/18m 거리 제한을 둔다. 21명 30/60/120Hz 실행의 동시 사용은 최대 50/128이었다. [모델 비용](계획/79차/shoulder-view.json), [관통 검사](계획/79차/shoulder-static.json), [효과 예산](계획/79차/shoulder-fx-static.json).

## 체력·탄창 표시

하단 수비대 패널에 현재 탄을 크게, 예비 탄과 탄창 크기를 작게 표시한다. 체력 숫자·최대 체력·긴 막대와 재장전 진행/남은 시간이 같은 위치에 모인다. 짙은 금속 테두리, 수정색 포인트와 크림색 숫자를 사용한다. 기존 탄약/체력 규칙을 바꾸지 않는다.

`t79-combat-hud-view`에서 실제 상태를 바꾸며 체력 증가·피격·빈 탄창·재장전·취소·무기 교체·한 발 무기·무한 탄약·손님·쓰러짐을 확인했다. 대기실/도입/미니게임에서는 숨긴다. 같은 상태의 180프레임 동안 DOM 변경은 0이었다. 데스크톱, 작은 노트북, 390px/320px, 실제 터치 화면 두 크기에서 전투 패널과 도구/터치 버튼의 겹침을 검사했다. [PC](계획/79차/combat-hud-desktop.png), [재장전/낮은 체력](계획/79차/combat-hud-reload.png), [터치](계획/79차/combat-hud-touch.png), [320px](계획/79차/combat-hud-small.png), [실행 결과](계획/79차/combat-hud-results.json).

## 조작 변경

- **R: 재장전.** 총을 든 상태에서 덜 찬 탄창을 기존 재장전 시간으로 채운다. 이미 찼거나 예비 탄약이 없으면 시작하지 않는다. 연타해도 타이머가 다시 시작되지 않는다.
- **T: 수리 도구.** 총을 넣고 수리 도구로 바꾼다.
- **오른쪽 클릭: 총 꺼내기/넣기.** 기존 동작을 유지한다.

도구창·전투 패널·도움말·건물 피격 안내를 같은 키로 갱신했다. `t79-controls-static` 10/10은 원본 keydown과 재장전 함수를 실행하며 반복키·단축키 조합·입력창·한글 조합·일시정지·관전·미니게임·대기실 보호를 검사한다. 실제 브라우저의 DOM keydown/mousedown까지 실행한 `--render`도 11/11 통과했다. 기존 `t66-ctrl` 62/62, `t68-reload` 19/19도 통과했다. [입력 검사](계획/79차/controls-static.json), [실제 브라우저 입력](계획/79차/controls-browser.json).

실제 그램 기기의 프레임률과 학생 21대 네트워크 수업은 미검증이다. 위 수치는 같은 조건의 소프트웨어 WebGL 렌더 비용이며 현장 FPS를 보장하지 않는다.

# 79차 좀비 피격 반응

기존 타격감이 약했던 원인은 짧은 번쩍임, 작은 반동, 던진 돌의 도착보다 먼저 실행되는 반응, 혼잡할 때 생략되는 명중음이었다. 손님 화면의 `hurt`가 정상적으로 끝나지 않는 경로도 있었다.

- `zombieHit79`와 `zombieHitPose79`는 실제 시간으로 약 0.28초의 시각 반동을 관리한다. 몸과 팔·머리가 피격 방향에 반응하며 보스의 반동은 일반의 48%다. 매 타격으로 상태를 무한히 다시 시작하지 않도록 짧은 간격 제한을 둔다.
- `wolfPose`의 실제 보행 계산 이후 표시 반동을 적용한다. 세계 좌표·피해·공격 속도·보스 행동·물리 넉백은 바꾸지 않는다.
- 돌은 기존 고정 풀에서 실제 도착한 프레임에 명중음과 표시 반응을 함께 실행한다. 빗나간 돌에는 명중 반응이 없고, HP 확정과 처치는 기존 호스트 경로를 유지한다.
- 손님은 HP가 줄어든 새 패킷에만 반응한다. 같은 HP 반복 수신이나 탭을 숨겼다 돌아온 뒤 오래된 흰색 번쩍임을 재생하지 않는다.
- 짧은 일반 명중음은 세 소스가 남으면 재생하되, 기존 전체 56소스 상한과 초당 최대 16회 제한을 유지한다. 새 메시·텍스처·조명·통신 패킷은 추가하지 않는다.

## 확인

`t79-hit-feedback-static.mjs` **15/15**, `t79-hit-feedback-view.mjs` **7/7** 통과. 실제 `fireWeapon`의 돌·총·치명타·처치 경로, 실제 손님 패킷, 20/30/60/120Hz 시각 타이머, 돌 풀 포화, 피격 종료를 검사했다.

열린 마당에서 같은 시점·그림자 갱신 조건으로 [피격 전](계획/79차/hit-before.png), [명중 순간](계획/79차/hit-impact.png), [반동](계획/79차/hit-recoil.png), [복귀](계획/79차/hit-recovered.png)를 직접 열어 비교했다. 네 자세 모두 342회 그리기 / 2,703,115삼각형 / 154기하 / 9텍스처로 같았다. 이는 이 고정 장면에서 피격 자세만 바꾼 비교이며 실제 그램 FPS 측정은 아니다.

처음 찍은 사진은 이전 테스트 효과와 울타리가 가려 증거에서 제외했다. 카메라와 플레이어를 실제로 정렬한 최종 화면만 보존했다. 수치 원본은 [정적 결과](계획/79차/hit-static.json), [브라우저 결과](계획/79차/hit-view.json)다.

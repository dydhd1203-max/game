## 실제 화면과 비용

공통 결과: 셰이더/JavaScript 오류 0, 인스턴스 수·정원·삼각형 수 동일, 새 텍스처/광원/드로 뱅크 없음. 피부의 잡음 호출수도 동일하다. 얼굴의 음영과 눈 무늬에 소량의 산술 연산은 추가되므로 “연산 비용 0”으로 설명하지 않는다.

92마리의 표시 갱신 60프레임 짧은 표본은 이전 8.24ms/이후 8.00ms였다. 잡음이 있는 짧은 CPU 표본이며, SwiftShader 캡처 환경은 실제 그램 GPU FPS를 증명하지 않는다. 실제 21대 네트워크 수업 장시간 성능은 이 검사 범위 밖이다.

`artifacts/zombie78`의 전후 PNG 10장 모두 직접 열어 검수했다:

- `before/after-near-day.png`: 낮 근접 플레이 시점.
- `before/after-near-night.png`: 밤 근접 플레이 시점과 붕대 의상.
- `before/after-pursuit.png`: 실제 추격 자세. 일부 개체는 마을 물체나 로컬 캐릭터에 가려지므로 전체 종류의 정면 검수는 보조 시트를 함께 사용한다.
- `before/after-crowd-92.png`: 92마리와 친구20명+로컬1명 고정 장면.
- `before/after-detail-sheet.png`: 13종+밤 의상3종 보조 시트. 이 시트만 별도 검사 카메라·약한 정면 보조광을 사용하며 성능 표에 포함하지 않는다. 종류 순서는 `*-detail-labels.json`에 기록했다.

근접에서 피부·상처 변화가 가장 잘 읽힌다. 먼 군중에서 작은 봉합/홍채까지 보인다고 주장하지 않으며, 원거리의 종류 구분은 기존 실루엣·의상·눈빛이 맡는다.

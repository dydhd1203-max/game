# 73차 · 교실 안정화

21명이 사용하는 교실 환경에서 통신·중복 계산을 줄이고, 공동 결제와 재접속 진행을 안정화한다. 그래픽 프리셋, 화면 해상도, 그림자 해상도·갱신 주기, 모델, 효과 세기는 유지한다.

## 수정한 문제

1. 손님에게 보내던 좀비 HP 백분율을 실제 HP·최대 HP로 바꿨다. 여러 발이 서로 다른 좀비에게 맞아도 각각의 번호·대상·피해를 호스트가 처리한다. 처치 경험치는 호스트가 확정한 누적 보상만 한 번 지급한다.
2. 상점·조합·강화·교환·농장은 건축과 같은 호스트 자원 장부에서 순서대로 결제한다. 승인 전에 물건을 주지 않으며 요청 번호와 영수증으로 재전송·중복 수신을 처리한다. 첫 접속 때 구매가 플레이어 정보보다 먼저 도착해도 정보가 도착하면 처리한다.
3. 같은 브라우저·방·수업 번호(sid)로 재입장하면 학생의 레벨, 직업, 장비, 강화, 탄약, 자원 누적 장부와 미확인 구매를 복구한다. 서버 장부가 로컬 저장보다 앞선 경우 누적값을 병합한다. 새 수업에는 이전 저장을 적용하지 않는다. 다른 기기로 옮기는 클라우드 저장이나 선생님 화면의 호스트 인계는 포함하지 않는다.
4. FPS와 낮·밤 시간은 실제 경과 시간으로 계산한다. 이동·좀비 물리는 작은 단계로 나누고 긴 정지 후 따라잡기는 최대 0.25초로 제한한다. 10 FPS에서 4초 동안 게임 시계도 4초 흐르는지 확인한다.
5. Windows 줄바꿈 때문에 실패하던 정적 검사를 수정하고 Windows·Linux Node 검사 및 핵심 숨김 브라우저 검사를 자동화했다. 손 모션 검사는 실제 프레임 루프를 직접 진행하여 장전·발사·꺼내기 등 14가지 상태를 빠뜨리지 않는다.

나선 계단에서는 계단 내부 공간을 연속적으로 판정하여 층 경계의 1/3인칭 전환을 막는다. 맵 아래로 빠졌을 때의 안전 복귀도 사용자의 yaw·pitch를 보존한다. 탑 지붕 밖에서는 기존 시점으로 돌아간다.

## 화질을 유지한 최적화

- `p`/`pc`의 전체 목록 대신 바뀐 플레이어만 처리한다. 움직이는 위치 전송 주기(6 Hz), 좀비 전송 주기(7 Hz)는 유지하고 변경 없는 패킷만 2초 확인 전송으로 줄인다.
- 좀비·병사 갱신에서 매 개체마다 배열을 다시 찾던 작업을 ID 맵으로 바꿨다.
- 정적 뱅크 메시의 불필요한 행렬 재계산을 끄고, 렌더를 건너뛸 때 인스턴스 업로드 범위가 누적되지 않게 했다.
- 총 발광의 마지막 합성은 총과 번진 빛을 포함하는 화면 영역만 처리한다. 블러 텍스처·횟수·색·세기는 동일하며 근평면과 교차하면 전체 화면 처리로 돌아간다. 발광 원천 패스는 본 패스에서 계산한 세계 행렬을 재사용한다.

## 검증과 한계

2026-09-27 로컬 검증: Node 34개 파일, 핵심 브라우저 4개 파일 모두 통과. 추가 성곽 걷기 57/57, 성곽 동작 27/27, 강화 동작 31/31 통과. 나선 9곳의 하강 샘플에서 yaw 변화·급격한 카메라 거리 전환은 0이었다. 기존 판정도 중앙 경로에서는 실패하지 않았으므로 사용자가 겪은 회전의 동일 재현을 확보한 것은 아니다. 내부 공간 판정과 안전 복귀 시점 보존을 보강했으며 실제 플레이에서 재확인이 필요하다.

- `node 깃허브에올릴것/검사/check-current.mjs`: Node 검사 34개 파일.
- `node 깃허브에올릴것/검사/check-current.mjs --browser-smoke`: 교실 동작, 21 아바타·발광, 손 그립, 성벽 사격 검사 4개를 순서대로 실행한다.
- `t73-network-static`: 실제 게임 함수를 21개 독립 VM에 넣고 지연·중복 전달·재접속·공동 장부를 검사한다. 실제 Firebase 요금이나 교실 인터넷 품질 측정은 아니다.
- 같은 20초 fixture에서 위치 쓰기는 정지 시 10회, 이동 시 109회였다. 정지 중 반복 쓰기가 약 91% 줄었으며 전체 게임 통신량이 91% 줄었다는 뜻은 아니다.
- 7종 무기의 정지·장전 14개 비교에서 같은 발광 텍스처와 배경 위 합성 결과의 픽셀 차이는 0개였다. 해당 합성 영역은 화면의 약 15~25%였다. 전체 장면이나 전체 GPU 작업이 그 비율로 줄었다는 뜻은 아니다.
- 소프트웨어 렌더러 SwiftShader의 CPU 시간은 그램 실기기의 FPS가 아니다. 21대 교실 실접속에서의 프레임 시간·지연은 별도로 확인해야 한다.
- 브라우저는 `pw.mjs`의 숨김 실행·커서 잠금 차단을 사용하고 종료 시 닫는다.

## 배포와 다음 작업

`packSim`은 v2의 8칸 좀비 데이터다. **선생님·학생 모두 최신 파일로 새로고침하고 새 방을 만든다.** 서로 다른 `GAME_VER`의 방 입장은 막는다.

원본 `클로드/index.html`과 `클로드/배포용/index.html`은 바이트 단위로 맞춘다. 작업 완료 때 원격 변경 확인·GitHub 푸시·집 바탕화면 `좀비의 밤` 배포본 업데이트를 함께 수행한다. 클로드의 병행 변경을 덮어쓰지 않는다.

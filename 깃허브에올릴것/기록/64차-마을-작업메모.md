# 64차 — 마을을 진짜 마을답게 (작업 메모)

선생님 말: "장식물이 난잡해 아늑한 느낌이 없다. 마을 크기를 늘려서 제대로 된 마을을 꾸며라.
미적으로 뛰어나게. 아이들이 '우와 동산이다, 동물의 숲이다, 아늑하다, 귀엽다, 좋다' 느낄 수 있게.
미적인 것들을 많이 추가하니까 그에 맞게 마을을 넓혀줘."

이 메모는 줄 번호를 안 적는다. 함수 이름·상수 이름으로 찾는다.

## 1. 진단 (63차 화면을 내장 브라우저로 찍어 본 것)
1. 집이 한 채도 없고 작은 세간(등·울타리·표지·수레·벤치)만 수백 개.
2. 크기 위계가 없다 — 전부 사람 키 안팎, 랜드마크 없음.
3. 수풀·꽃·돌·자원이 난수로 고르게 흩뿌려져 뭉침·여백이 없다.
4. 색이 너무 많다(모둠색 5 + 파스텔 문턱 + 꽃 6색 + 분홍 연석).
5. 광장이 '원 고리 + 바퀴살' 도형으로 보인다.
6. 산이 회색 레고 절벽이다.
7. 마을이 반지름 17 안에만 있고 그 밖은 자원만 있는 빈 들판.

## 2. 결정한 것
- **집은 땅이다.** `VILLAGE_HOUSES` 표(집 11채·여관·풍차, 정수 칸 발자국)를 두고 `villagePlan()` 이 벽 발자국의
  `terrH` 를 `GY+HOUSE_WALL_H(3)` 로 올린다. 63차 규칙 ①('terrH 를 안 건드린다')의 유일한 예외다.
  좀비 길찾기 `walkable`(GY≤t≤GY+1)이 집을 돌아가고, 사람 `blockedAt` 이 벽에 막히고, `canPlace` 가
  '마을 집 자리예요' 로 거절한다. `buildWorldMesh()` 뒤에 올려서 돌기둥이 안 그려지고, `placeNodes()` 앞에
  올려서 나무·바위가 집 안에 안 생긴다. 발자국 합계 155칸(마당 3%).
- **마당을 피하는 것**: `houseNear(x,z,pad)` — placeNodes 2.2 · scatterDecor 1.2 · villageStreets stFree 1.6 ·
  villageNight okLamp 1.8 · villageWater 화단 띠 1.2 · villageLife 풀포기 1.0 · spawnPoint 1.0.
- **풍경 덩어리 피하기**: `VILLAGE_AVOID` [x,z,r] 를 `villageLandscape()` 가 채우고 `avoidNear()` 로
  거리 세간·길등이 비켜 간다. 짓는 순서: villageSquare → villageLandscape → villageStreets → villageWater →
  villageTeamYards → villageHouses → villageNight → villageLife.
- **마을을 넓혔다**: `ARENA_R`/`RING_A` 40→46, `RING_D` 53→59, `FIELD_R` 62→68, `GATE_T` 45→51, `SPAWN_R` 56→62.
  여섯을 같이 6칸 밀어 성문·협곡·산 오르막의 상대 거리는 그대로다. `SEG = FIELD_R*2`, `SH_R` 46→52,
  자원 고리 `NODE_R0/1` 17/37.5 → 19/43.5, 산 위 장식 숲 165→200, 거리 연석·어귀 등돌·길등 `R_OUT`·
  화단 띠·보물 상자·반딧불이 범위를 `ARENA_R` 기준으로. 사람 출발 자리는 `ARENA_R-14~-7`, 집 마당을 피해 다시 뽑는다.
- 미니맵에 집 발자국을 지붕색 네모로 그린다(`miniStatic`).
- 검사 `t56-build-coop-static` fixture 에 `houseNear=()=>false` 를 더했다(canPlace 가 그 이름을 본다).

## 6. 결과 (2차 PR)
- **집 열한 채·여관·풍차** (`villageHouses`): 크림 회벽·짙은 골조·계단식 박공(모래색 단)·산호/이끼/슬레이트/꿀색 지붕·돌 굴뚝·
  둥근 아치문·십자 창살 창(밤에 켜짐, 열쇠 `hsGlow`)·다락 마름모 창·꽃상자·우편함·문등·문 앞 디딤돌 3장. 집마다 소품 하나
  (N2 빨래줄 · P2 벌통 · Q1 사과 궤짓 · S1 고양이 밥 · W1 벤치 · E2 장작더미). 여관은 간판·등불·통·탁자·화분. 풍차는 3단 탑, 날개가
  `updVillage` 에서 돈다(V_box 81/96, 날개 끝 10.45 로 마을 최고). 굴뚝 연기 셋(N1·W1·여관, spark).
- **풍경** (`villageLandscape`, `scatterDecor` 재작성): 큰 나무 둘(벤치·그네·돗자리), 과수원(사과 6·돌담·사다리), 집 뒤 숲 덩이,
  집 마당 꽃무더기, 흰 울타리 ㄱ자 4곳, 바깥 숲 띠(oct 38~45 ≈140그루 + 덩이 4), 북서 꽃동산. 흩뿌리기 700 → 뭉치 30 + 꽃밭 6 + 산자락 관목 띠.
- **걷어낸 것**: 연석 ≈150, 가로등 15, 울타리, 알림판, 길가 화단 띠 122, 곁길 디딤돌 전부(상인·대장간·농장·연못), 남쪽 거리 돌줄 19,
  길등 25→≈13, 빛 웅덩이 낮색을 잔디색(0x6aeb9c)으로. 선생님: "가로등 밑 갈색 판·길 따라 깔린 돌이 지저분하다."
- **광장** (`villageSquare`): 고리 넷 → 사암 격자 마당(흙길 위도 덮음), 산울타리 고리 r 9.3(`plzHedge`), 문턱은 사암 한 장 + 모둠색 띠,
  가로등 4, 파스텔 깃발줄, 모닥불 걸상 5 + 삼발이 냄비, 원탁 셋, 우물 지붕 산호색·게시판 지붕 꿀색.
- **산**: `MT_ROCK/MT_ROCKTOP/MT_MOSS/MT_CRACK/MT_DIRT` 를 따뜻한 회록으로, 풀 뚜껑 GY+7 까지, 이끼 7/17. `MT_GRASS`·`MT_SNOW` 는 t32 가 세므로 그대로.
- **수치**: 인스턴스 22.8k → 25.8k, 재질 54 그대로, 새 InstancedMesh 0, 투명 재질 0. 자원 9/9/4 ×5, 좀비 미도달 0, check-current 22/22.

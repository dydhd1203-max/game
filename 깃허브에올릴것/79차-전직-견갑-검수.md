# 79차 전직 견갑 재설계

이전 작은 어깨 장식은 사용자가 실제 갤러리를 보고 변화가 보이지 않는다고 거절했다. 아래 내용은 그 이후의 큰 견갑 재설계다. 기존 작은 장식이나 이전 갤러리를 완료 증거로 사용하지 않는다.

1차부터 어깨 윗면과 바깥쪽을 덮는 두꺼운 곡면 견갑을 착용한다. 전투는 은청색 금속과 금색 가장자리·별 문양, 건설은 짙은 기계 외장과 청록 연결부, 자원은 녹색 견갑과 수정 문양이다. 2차는 각각 금속 겹깃, 빛나는 이중 기계부, 큰 수정 군집으로 실루엣을 구분한다. 기존 직업 모자·옷·날개는 유지한다.

속이 찬 상자를 팔 위에 얹지 않았다. 실제 안쪽 공간과 두께를 가진 곡면을 만들고, 아래팔이 접히는 앞부분과 목 방향 안쪽을 열었다. 렌더링한 위팔 관절 행렬을 그대로 따라가므로 걷기·조준·점프·공중 회전에서도 팔과 따로 흔들리지 않는다. 피부와 거의 같은 평면을 겹치는 방식은 쓰지 않는다.

어깨 효과는 같은 프레임에 실제 그린 두 견갑의 바깥 좌표에서 발생한다. 전투는 금빛 불티, 건설은 청록 연결빛, 자원은 보석 조각이다. 기존 128칸 효과 풀과 전체 초당150개 한도를 공유하며 어깨용 추가 상한은 초당30개+초기8개다. 멀리 있거나 쓰러졌거나 실제 그려지지 않은 캐릭터는 방출하지 않는다. 새 실시간 조명은 없다.

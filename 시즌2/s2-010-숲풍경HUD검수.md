# s2-010 숲 풍경·HUD 검수

2026-10-14 · 사용자가 제공한 숲 RPG 화면을 참고한 시즌2 표시 개선. 기존 s2-009의 마을·캐릭터·플레이 흐름을 유지한다.

## 구현과 참고 화면의 연결

| 요청 | 구현 |
| --- | --- |
| 숲으로 둘러싸인 마을 | 붓결을 넣은 공유 잎 텍스처, 갈라진 활엽수 가지, 작은 가지가 층층이 뻗는 침엽수, 낮은 관목·풀·흰색/산호색 꽃 |
| 빈 공간과 바위 주변 자연스러운 연결 | 길 어깨·건물 주변·바위 틈에 크기와 깊이가 다른 식재. 남쪽 장식 능선은 낮추고 땅에 묻어 긴 회색 벽을 줄임 |
| 따뜻한 흙길과 깊이 있는 원경 | 바닥에 흙·풀·나무 그림자를 한 번 그린 텍스처, 드문 마모된 디딤돌, 높이가 다른 세 겹 산과 구름. 안개는 산기슭 색에 맞춤 |
| 참고 화면의 작은 게임 UI | 왼쪽 위 목표, 오른쪽 위 원형 지도, 왼쪽 아래 빨간 체력/청록 기력, 오른쪽 아래 수첩·설정·성능 카드. 교사 저장/일시정지 기능 유지 |
| 성능 우선 | 공간별 정적 묶음, 공유 재질·텍스처, 고정된 식생. 추가 조명·실시간 그림자·후처리 없음. 미니맵은 캐시한 2D 지도를 최대 5Hz로 갱신 |

`src/woodland-atlas.mjs`와 `woodland-flora.mjs`는 잎·꽃의 텍스처와 공간별 묶음을, `woodland-ground.mjs`는 땅·원경을 담당한다. 기존 `village-nature.mjs`·`forest-nature.mjs`가 같은 잎 텍스처를 공유한다. UI는 `ui.mjs`·`style.css`, 지도는 `minimap.mjs`다. 참고 화면의 배치를 현재 기능에 맞췄으며 가짜 가방·장비 버튼은 추가하지 않았다.

## 보존·비용

RELEASE는 `s2-010`, BUILD·저장·통신은 `s2-008`이다. 시즌1 원본/배포본과 시즌2의 캐릭터·카메라·달리기/점프·시뮬레이션·저장·통신 코드는 기준판과 동일하다. 콘텐츠의 실제 위치·충돌·난수 규칙은 변경하지 않았다. [소스 확인](검수/s2-010/source-checks.json)에 해시와 검사 범위를 기록했다. 새 네 직업·다섯 던전 구현은 이 작업에 포함하지 않는다.

미니맵은 320×736 지도를 한 번 만들고 256×256 캔버스에 표시한다. 별도 WebGL 렌더, 타이머, 매 프레임 지형 재생성은 없다. 위치가 같거나 HUD가 숨겨졌으면 그리지 않는다. 전체 지도에는 마을·보스 구역 모서리의 친구까지 포함하며, 확대 시 안내문을 지도 밖으로 옮긴다.

숲 텍스처는 1024×512, 바닥은 1024×1024 한 장씩 추가한다. 원본 RGBA 기준 합계 6MiB이며 밉맵·Canvas 사본·GPU 내부 표현은 별도다. 마을 자연물은 총 10개 묶음·57,034삼각형으로 구성되고 새 식재의 흔들림·재생성은 없다. 기존 마을 나무 8그루의 카메라 가림 판정은 유지하며, 가림 상태가 바뀔 때만 해당 인스턴스 행렬을 갱신한다. 텍스처 잘라내기와 MSAA 경계 처리는 픽셀 비용이 있으므로 삼각형 감소만으로 FPS 개선을 단정하지 않는다.

원경의 가장 가까운 산 반경은 128m다. 실제 이동 경계와 최대 줌·질주·어깨 카메라까지 보수적으로 합친 범위보다 최소 8m 밖에 두어 보스 구역에서 배경 면이 카메라를 가리지 않는다.

## 직접 검수

[상세 화면 기록](검수/s2-010/woodland/visual-review.md)에서 변경 전, 중간 시도, 최종 확인을 구분한다. 실제 입장·WASD·우클릭을 사용하며 조망 카메라·순간이동·숨긴 HUD로 미술 검수를 대신하지 않는다.

- 첫 실행판에서 실제 달리기·기력 감소/회복·2단 점프·착지, 지도 이동/확대, 수첩·설정·성능, 저장·불러오기·일시정지·재개와 UI 종료 후 이동을 확인했다. 1366×768, 820×600, 560×700 화면도 확인했다.
- 사진에서 발견한 파란 안개 구멍, 누런 식생, 남쪽의 회색 벽, 가까운 침엽수의 큰 판 모양과 확대 지도의 안내 겹침을 후속 수정했다.
- 중간 after2 경로는 나무 충돌에 닿아 04 촬영이 중단됐다. 제품의 정상 충돌을 우회하도록 검수 횡단 경로에 여유를 주었고 실패 기록은 보존한다.

[최종 실행 파일](배포용/index.html)은 4,675,969바이트, SHA-256 `53de75da8aeb2045b34fb3608e9ddefcbd269080816661c9da756adaf7fecf4d`다. [최종 출발 미리보기](검수/s2-010/woodland/final-preview/01-village-spawn.png)와 [보고서](검수/s2-010/woodland/final-preview/report.json)는 마지막 파일 해시와 일치하며 실제 입장·시작 후 기본 카메라로 촬영했다. 직전 후보(`86cc1372…`)의 [마을·지도 검사](검수/s2-010/woodland/after3/report.json)는 5항목·3장, 실행/자산 오류 0으로 통과했다. [출발 화면](검수/s2-010/woodland/after3/01-village-spawn.png)·[확대 지도](검수/s2-010/woodland/after3/02-expanded-map-clear-notice.png)·[가까운 침엽수](검수/s2-010/woodland/after3/04-village-northwest-edge.png)를 직접 열었다. 04는 경계 관목이 몸통을 가리는 근접 자연물 검수 사진이며 대표 출발 화면과 구분한다. 초기에 안내를 숨긴다고 잘못 가정했던 하네스는 실제 사각형의 겹침 여부를 검사하도록 고쳤다.

[실제 숲 진입 검사](검수/s2-010/nature-final/report.json)도 같은 후보에서 5항목·5장, 오류 0으로 통과했다. [북쪽 숲길](검수/s2-010/nature-final/02-village-north-trees.png)과 [숲 진입](검수/s2-010/nature-final/03-forest-entry.png)을 직접 열어 새 식생·원경·숲 HUD를 확인했다. 이후 가까운 침엽수 가지의 폭과 기울기 두 값만 조정했으며 카드·삼각형·묶음 수와 기능 코드는 같다. 마지막 `53de75da…` 파일의 [근접 재검수](검수/s2-010/woodland/after4/report.json)와 [사진](검수/s2-010/woodland/after4/04-village-northwest-edge.png)에서 실제 이동·기본 화질·오류 없음과 아래로 처진 가지를 다시 확인했다. 이전 후보 화면의 해시를 마지막 파일의 전체 재검수로 혼동하지 않는다.

실행 규칙·저장·카메라·모션·지도·모델과 관련된 Node 검사 파일 7개가 통과했다. 미니맵 검사는 북쪽 끝 친구 표시, 갱신 상한, 숨긴 HUD와 정지 상태에서 재그리기 생략을 포함한다.

## 동일 화질·21명 성능 비교

[최종 성능 보고서](검수/s2-010/performance/performance.json)는 시즌1·고정한 s2-009(`dabe689`)·현재판을 새로 측정했다. 1366×768·DPR1·그리기 배율 .85·MSAA4와 기본 FOV70·pitch −.22·zoom3.2 카메라, 동일 상대 배치의 합성 캐릭터 21명을 사용한다. 실제 입장 동선 사진과 합성 성능 배치를 구분한다. 측정된 현재 소스 33개의 해시가 최종 파일을 만든 소스와 일치한다.

| 장면 | 시즌1 호출 / 삼각형 | s2-009 호출 / 삼각형 | s2-010 호출 / 삼각형 |
| --- | ---: | ---: | ---: |
| 마을 | 246 / 824,608 | 83 / 417,934 | 106 / 370,069 |
| 숲 전투 | 330 / 1,126,903 | 70 / 355,078 | 81 / 335,191 |
| 첫 보스 | 직접 비교 장면 없음 | 63 / 342,160 | 70 / 324,929 |

식생/재질 묶음이 추가되어 이전판보다 호출 수는 증가했고, 삼각형은 마을 약 11%·숲/보스 약 5~6% 줄었다. 마을·숲 전투의 두 수치 모두 시즌1 예산 안이다. 이는 제출 작업량 비교이며 FPS 향상률이나 비용 증가가 전혀 없다는 뜻은 아니다. 시즌2의 반복 측정 후 geometry·texture 증가는 모든 장면에서 0이다.

CPU 작업 평균은 이전판→현재판으로 마을 0.65→0.75ms, 숲 전투 1.43→1.12ms, 보스 1.25→1.19ms였다. p95는 각각 1.4→1.2ms, 3.5→2.1ms, 3.8→4.1ms다. 3회×120프레임 표본이며 WebGL 제출·시뮬레이션·통신은 제외한다. 별도 소프트웨어 드라이버 제출 시간도 보고서에 기록했지만 실제 GPU 시간이나 노트북 FPS로 해석하지 않는다. 미니맵 이동·기력 표시는 실제 입력 검사에서 별도로 확인했다.

브라우저 오류·예산 위반 없이 통과했다. 전투의 타워 30개·적 40개는 이전판과 같은 비교용 부하이며 공용 타워 플레이를 복원한 것이 아니다. 재현: `S2_PERF_VARIANTS=s1,previous,current S2_PERF_PREVIOUS_ROOT=<dabe689 저장소 스냅샷> S2_PERF_OUTPUT=검수/s2-010/performance node tests/performance.mjs`와 기존 `PW_MODULE`/`PW_EXECUTABLE_PATH` 설정을 사용한다.

## 적용 범위와 남은 확인

그리기 배율 .85·MSAA·AgX 노출 1.28과 기존 두 광원은 유지한다. 숨김 Chromium/SwiftShader 검사는 실제 노트북 FPS, 픽셀 부하의 실제 GPU 비용, 교실 21대의 통신 성능을 대신하지 않는다. 실제 노트북의 미술 선호·FPS는 사용자 테스트가 필요하다.

GitHub PR은 테스트판이며 머지·공개 배포와 구분한다. 이 클라우드 환경에서는 Windows 바탕화면 폴더에 접근할 수 없어 파일 복사는 수행하지 않았다.

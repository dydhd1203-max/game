# 좀비의 밤 시즌2 — 새벽 원정대

상태: **기획 초안 v0.1 · 실행 가능한 시즌2는 아직 없음**

작성일: 2026-10-13 (한국 시간)

18번째 밤을 이겨 낸 아이들이 이동 요새를 타고 다른 마을을 구하러 떠나는 협동 원정 게임을 제안한다. 낮에는 탐색·구조·수리하고 밤에는 요새를 지킨다. 구조한 주민과 복구한 시설이 쌓여 우리 반이 세상을 되찾는 모습을 보여 준다.

## 확정된 요청과 기획 가안

| 구분 | 내용 |
|---|---|
| 사용자 확정 | 시즌1을 내년 새 학급에서도 그대로 사용할 수 있게 보존한다. |
| 사용자 확정 | GitHub에 시즌2 폴더를 별도로 만들고 아이디어를 구체화한다. |
| 이번 작업 | 이 폴더에 기획·개발 순서 문서만 추가한다. |
| 기획 가안 | ‘새벽 원정대’라는 이름, 이동 요새, 숲→설원→도시, 18일 구성, 주민 구조와 치료 엔딩. |
| 조정할 항목 | 하루 길이, 난도, 자재 비용, 타워 수, 보상, 저장 UI, 실제 수업 분량. |

문서의 시스템·수치는 앞으로 구현하고 시험할 제안이다. 이미 게임에서 작동하는 기능으로 해석하지 않는다.

## 시즌1은 어디에 남는가

시즌1 원본은 [`../클로드/index.html`](../클로드/index.html), 배포용은 [`../클로드/배포용/index.html`](../클로드/배포용/index.html)이다. 기획 기준은 106차가 반영된 main 커밋 `89da73b`이며, 이번 작업은 두 파일과 기존 실행 주소·방·진행 기록을 바꾸지 않는다. 퀴즈나라 역시 별개다.

초기 시즌2는 별도 실행 주소와 방을 갖도록 설계한다. 선생님이 사용할 시즌의 주소를 열어 방을 만들면 학생도 같은 시즌 주소로 들어간다. 두 시즌을 고르는 통합 메뉴는 시즌2가 준비된 이후의 별도 작업으로 남긴다. 지금 시즌1 화면에 미완성 시즌2 버튼을 추가하지 않는다.

시즌1 클리어 기록이 없어도 시즌2 수업을 시작할 수 있게 한다. 기념 칭호·꾸미기 지급은 제안이며, 시즌1의 실제 영구 클리어 저장 여부를 확인하기 전에는 자동 연동을 약속하지 않는다.

## 어떤 재미를 만드는가

| 핵심 | 아이들이 실제로 하는 일 | 돌아오는 변화 |
|---|---|---|
| 원정 | 봉화를 켜고 길을 고치며 주민을 데려온다. | 막힌 길이 열리고 요새에 새 주민이 나타난다. |
| 방어 | 적이 오는 방향을 보고 벽·타워를 배치하고 직접 싸운다. | 밤을 넘긴 뒤 다음 구조 임무로 나아간다. |
| 협동 | 친구의 수리를 엄호하고, 필요한 자재를 전달하고, 쓰러진 친구를 돕는다. | 공격 외에도 모두가 기여할 일이 있다. |
| 성장 | 장비와 요새 시설을 개선하고 타워 조합을 익힌다. | 원정이 편해지고 새로운 공략을 선택할 수 있다. |

이동 요새는 첫 구현에서 각 지역의 고정 거점이다. 실제 이동은 장 사이의 안전한 전환으로 표현한다. 달리는 요새 위에서 전투하는 기능은 후속 확장으로 남긴다.

## 18일 여정의 큰 흐름

| 장 | 날짜 | 목표 | 마지막 밤 |
|---|---|---|---|
| 1장: 안개 낀 숲 | 1~6일 | 봉화와 구조 신호를 따라 첫 주민들을 구한다. | 숲의 길을 막는 보스와 협동 전투 |
| 2장: 얼어붙은 마을 | 7~12일 | 난로와 시설을 복구해 마을에 온기를 되돌린다. | 난방 시설을 지키며 보스의 얼음 갑옷 공략 |
| 3장: 폐허가 된 도시 | 13~18일 | 발전기를 복구하고 치료 장치를 완성한다. | 마지막 방어전 뒤 주민들과 새 마을 건설 |

한 장을 한 차시에 다루는 **35~45분 목표**를 시험한다. 가안은 낮 150초 + 밤 90초 + 정리 15초로, 6일의 기본 고리는 25분 30초다. 입장·설명·보스전 추가 시간·마무리를 포함한 실제 분량은 교실에서 조정한다. 선생님 일시정지와 다음 수업 이어하기를 기본 요구로 둔다.

## 가장 먼저 만들 분량

**숲의 1~3일을 21명이 함께 끝내는 시제품**을 먼저 만든다. 요새 한 곳, 화살탑·얼음탑, 봉화 한 곳, 구조 주민 한 명으로 원정과 방어의 연결을 확인한다. 저장·재접속·선생님 일시정지는 처음부터 확인한다.

물+얼음 타워 조합, 세 지역 전체, 좀비 치료, 시즌 간 꾸미기 연동은 이후 단계다. 첫 시제품에서 확인할 질문은 “아이들이 다음 행동을 알 수 있는가”, “여러 모둠이 함께 할 일이 있는가”, “후반에도 수업 기기에서 안정적인가”다.

# 좀비의 밤 시즌2 — 새벽원정대(가제)

시즌2의 새 방향은 **4인 모둠 협동 액션 RPG**다. 다섯 모둠이 서로 다른 던전 하나씩을 맡아 총 다섯 던전을 완료하고, 학생 20명이 합류해 마지막 보스를 처치하면 승리한다. 시즌1은 내년 수업에서도 그대로 사용할 수 있도록 보존한다.

## 현재 기획

- 다섯 던전은 **가시뿌리 숲·메아리 광산·잠긴 왕국의 수로·서리종 수도원·폭주 태엽공방**으로 정한다. 최종 합동 던전은 밤의 성채다.
- **층 클리어 → 포탈로 마을 귀환 → 회복·성장·장비 정비 → 다음 층**으로 진행한다. 초기안은 던전마다 3층이며 마지막 층 보스 처치 때 던전 완료를 센다. 모둠별로 귀환·출발하므로 다른 모둠을 기다리지 않는다.
- 직업: **수호기사·명사수·원소술사·발명가**. 모둠마다 한 명씩 맡는 구성을 기본안으로 한다.
- 전원 공용 건설을 없애고 발명가의 공격 포탑·지원 장치만 직업 스킬로 남긴다. 한 명당 1개씩, 합동전에서는 최대 10개다.
- 모둠 공유 경험치, 짧은 레벨 성장, 두 가지 강화 선택, 무기·유물 장비로 RPG 요소를 구성한다.
- 마을·던전 디자인, 효과음·배경음, 시즌1 수준의 노트북 성능을 우선한다. 캐릭터·기본 모션·카메라는 시즌1을 재사용한다.

## 현재 실행판과 과거 검수

**현재 실행판은 마을 건물·자연 조형물을 확대하고 빈 공간을 줄인 s2-008이다. 새 네 직업·다섯 던전·층별 마을 포탈·모둠별 전투·합동 보스는 아직 구현되지 않았다.** 먼저 마을을 검수하고 이후 던전을 하나씩 제작한다.

현재 테스트판은 대기실 → 마을 → 안개 숲 → 봉화 → 첫 보스 → 귀환으로 진행한다. 기본 공격으로 적을 물리치고 E로 봉화·보스 입구·친구 구조와 상호작용한다. 공용 타워 배치·포장·수리·보관함과 관련 안내는 제거했다. 발명가 직업은 아직 미구현이므로 현재는 누구에게도 타워 스킬이 없다. 시즌1 이동·점프·카메라와 원격 이동 보간은 유지한다.

s2-008은 기존 작업장을 보존하고 나머지 다섯 구조물을 상세화해 총 여섯 주요 구조물을 배치한다. 건물을 빙 둘렀던 원형 돌 테두리는 제거하고 풀·화단으로 주변을 연결했다. 마을 폭은 62m에서 41m로 줄이고 대기실·마을에서 접근 가능한 앞뒤 길이는 38.5m로 정리했다. 가지가 갈라진 나무·층진 바위·낮은 식재로 외곽과 빈 공간을 연결하며, 숲·첫 보스 구간은 유지한다. `npm run build`는 모델을 검증·변환해 단일 HTML에 포함하므로 실행 중 별도 모델 다운로드가 필요 없다.

s2-005의 작업장 원본, s2-006의 시즌1 밝기·달리기/점프 연결, s2-007의 공용 타워 제거는 유지한다. 지형·충돌이 달라져 실행판과 저장·통신 규격을 모두 s2-008로 분리했다. 함께 접속할 때는 모두 새 파일과 새 방 코드를 사용한다. 기존 저장은 원본을 보존하며 진행·보급을 이어받고, 바뀐 마을 경계 밖이나 건물 안에 있는 위치만 복구한다. 실제 적용·검증 범위와 미확인 항목은 아래 최신 검수 기록을 따른다.

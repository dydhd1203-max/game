# 좀비의 밤 시즌2 — 새벽 원정대

상태: **s2-001 첫 보스 테스트판 · 실제 교실 검수 전**

작성일: 2026-10-13 (한국 시간)

## 지금 테스트할 수 있는 범위

사용자 요청에 따라 대기실 → 안전한 정박 마을 → 숲길 전투 → 봉화 확보 → 첫 보스 ‘숲길 파수꾼’ → 마을 귀환을 한 원정으로 구현한다. 아래 18개 임무는 이후 확장 기획이다. 주민 구조·작업장 성장·설원·도시·나머지 보스는 이번 실행 범위에 포함하지 않는다.

**[독립 실행 파일](배포용/index.html)**을 내려받아 Chrome에서 연다. 혼자 체험은 설치·인터넷 없이 실행하며, 친구와 입장할 때는 인터넷이 필요하다. [테스트 안내](테스트안내.md)에 조작·저장·교실 방 입장 방법을 정리했다. 현재 검증 결과와 한계는 [구현·검수 기록](s2-001-구현검수.md)을 따른다.

친구들과 적진으로 전진하면서 타워를 펼치고 조합 공격으로 강한 보스를 공략하는 게임이다. 요새는 안전한 출발·보급·귀환 장소다. 길목을 돌파해 설치 지대를 확보하고, 탑을 옮겨 다음 전투를 준비한다.

## 사용자와 확정한 방향

| 확정 사항 | 적용 |
|---|---|
| 시즌1을 내년 수업에서도 그대로 사용 | 기존 실행·배포 파일과 저장을 보존 |
| 시즌2를 별도 GitHub 폴더에서 구체화 | 이 폴더에서 기획·개발 |
| 새로운 타워 조합과 강한 보스 공략을 우선 | 첫 시제품부터 화살+얼음 조합 하나를 검증 |
| 공격형 원정: 타워를 전진 배치하며 보스 공략 | 요새·문·수정의 체력을 지키는 승패 목표를 두지 않음 |
| 마을·사냥터·타워맵 디자인, 효과음·배경음, 성능 최적화를 최우선 | 작은 숲 원정의 화면·소리·21명 성능을 먼저 확인하고 콘텐츠 확장 |
| 캐릭터는 시즌1과 동일 | 시즌1 실제 모델·동작·꾸미기 재사용 |

‘새벽 원정대’라는 이름, 18개 원정, 후속 타워·보스는 확장 제안이다. 실행된 첫 보스 원정의 수치도 교실 피드백에 따라 조정한다.

## 한 원정은 이렇게 진행한다

1. **준비:** 요새에서 장비와 타워를 고른다.
2. **길목 돌파:** 직접 전투로 적을 정리하고 설치 지대를 확보한다.
3. **조합 배치:** 얼음탑의 서리 표식에 화살이 맞으면 ‘쇄빙’이 발동하도록 위치를 고른다.
4. **전진:** 탑을 포장해 다음 지대에 다시 펼친다. 이동 중 공격하지 못하는 탑을 친구가 엄호한다.
5. **목표 달성:** 거점 탈환·주민 구조·보스 공략을 마치고 요새로 돌아와 정산한다.

요새는 공격받는 목표물이 아니다. 적은 출격한 학생과 현장 타워를 위협한다. 일반 임무는 목표 달성, 보스 임무는 제압/치료 완료가 승리 조건이다. 일정 시간 생존만으로 자동 승리하지 않는다.

## 원정과 조합의 순서

| 구간 | 지역과 목표 | 조합 후보 | 마지막 공략 |
|---|---|---|---|
| 1~6일 | 안개 숲의 길목·봉화 탈환, 주민 구조 | 얼음 + 화살 → 쇄빙 | 돌진을 피하고 경직에 집중 공격 |
| 7~12일 | 설원의 길을 열고 난로를 복구 | 물 + 얼음 → 빙결지대 | 난로로 갑옷을 녹이고 충격파 회피 |
| 13~18일 | 도시 발전기 복구와 치료 시설 접근 | 물 + 전기 → 연쇄전격 | 주변 적을 정리하며 발전기·치료 장치 가동 |

‘일차’는 원정 임무 번호다. 낮·밤은 분위기와 이야기에 사용하고, 자동 방어 시간표로 진행하지 않는다. 한 장의 6개 임무를 한 차시 35~45분에 다루는 안을 시험한다. 일반 임무당 3~5분은 목표이며, 설명·보스·재도전 시간까지 실제 교실에서 검증해야 한다.

## 시즌1 보존과 첫 개발 범위

시즌1은 [`../클로드/index.html`](../클로드/index.html)과 [`../클로드/배포용/index.html`](../클로드/배포용/index.html)에 그대로 둔다. 기준 106차 파일을 수정하거나 시즌2로 덮어쓰지 않는다. 퀴즈나라 역시 별개다. 시즌2 실행 주소·방·저장은 이후 별도로 구성한다.

초기 ‘숲 1~3일’ 안에서 범위를 조정해 **첫 보스까지 이어지는 한 원정**을 먼저 테스트한다. 화살탑·얼음탑·쇄빙, 포장·재설치, 봉화와 보스 돌진 공략을 포함한다. 물탑·전기탑·주민 구조·세 지역 전체·치료 엔딩은 후속 단계다.

그 안에서도 먼저 **안전한 정박 마을 → 숲길 → 타워 전진 배치 → 귀환** 한 바퀴의 실제 미술·소리·성능을 확인한다. 시즌1의 검증된 코드와 자산은 필요한 부분부터 재사용해 새 제작과 반복 분석을 줄인다.

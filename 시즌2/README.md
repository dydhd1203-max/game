# 좀비의 밤 시즌2 — 새벽원정대(가제)

시즌2의 새 방향은 **4인 모둠 협동 액션 RPG**다. 다섯 모둠이 서로 다른 던전 하나씩을 맡아 총 다섯 던전을 완료하고, 학생 20명이 합류해 마지막 보스를 처치하면 승리한다. 시즌1은 내년 수업에서도 그대로 사용할 수 있도록 보존한다.

## 현재 기획

- 다섯 던전은 **가시뿌리 숲·메아리 광산·잠긴 왕국의 수로·서리종 수도원·폭주 태엽공방**으로 정한다. 최종 합동 던전은 밤의 성채다.
- **층 클리어 → 포탈로 마을 귀환 → 회복·성장·장비 정비 → 다음 층**으로 진행한다. 초기안은 던전마다 3층이며 마지막 층 보스 처치 때 던전 완료를 센다. 모둠별로 귀환·출발하므로 다른 모둠을 기다리지 않는다.
- 직업: **수호기사·명사수·원소술사·발명가**. 모둠마다 한 명씩 맡는 구성을 기본안으로 한다.
- 전원 공용 건설을 없애고 발명가의 공격 포탑·지원 장치만 직업 스킬로 남긴다. 한 명당 1개씩, 합동전에서는 최대 10개다.
- 모둠 공유 경험치, 짧은 레벨 성장, 두 가지 강화 선택, 무기·유물 장비로 RPG 요소를 구성한다.
- 마을·던전 디자인, 효과음·배경음, 시즌1 수준의 노트북 성능을 우선한다. 캐릭터·기본 모션·카메라는 시즌1을 재사용한다.

## 현재 실행판과 과거 검수

**실행 가능한 파일은 첫 보스 테스트판의 마을 미술을 개선한 s2-005다. 새 네 직업·다섯 던전·층별 마을 포탈·모둠별 전투·합동 보스는 아직 구현되지 않았다.** 작업장 한 채를 먼저 제작·검수하고 마을의 나머지 구조물, 던전 순서로 확장한다.

기존 테스트판은 대기실 → 마을 → 안개 숲 → 봉화 → 첫 보스 → 귀환으로 진행하며 공용 화살탑·얼음탑이 남아 있다. 시즌1 이동·점프·카메라와 원격 이동 보간을 이식한 상태다.

s2-005는 3D Jutsu에서 제작한 작업장 GLB를 게임의 정적 묶음에 적용하는 미술 변경이다. `npm run build`는 GLB를 검증·변환해 단일 HTML 안에 포함하므로 실행 중 별도 모델 다운로드가 필요 없다. 저장·통신 규격은 s2-004를 유지하며, 실제 적용·검증 범위와 미확인 항목은 아래 최신 검수 기록을 따른다.

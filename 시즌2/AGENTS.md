# 시즌2 작업 안내

이 폴더는 좀비의 밤 시즌2 전용이다. 먼저 [README](README.md), [기획안](기획안.md), [개발·성능계획](개발·성능계획.md)을 읽는다. 이식 범위는 [시즌1 재사용 기록](시즌1-재사용기록.md)에서 확인한다.

- 사용자 확정 요구: 시즌1을 내년에도 그대로 사용하고 시즌2를 별도 폴더에서 개발한다. 시즌1·퀴즈나라·기존 배포 설정과 저장 데이터를 변경하지 않는다.
- 현재 기획은 5모둠 × 4명, 모둠당 서로 다른 던전 하나, 총 5개 완료 후 학생 20명의 합동 보스전이다. 25회 클리어 구조로 되돌리지 않는다. 교사 관전 1명을 포함한 21클라이언트 성능을 검증한다.
- 사용자 확정 요구: 각 층 클리어 후 포탈로 마을에 돌아와 정비하고 다음 층에 출발한다. 초기안은 던전당 3층이며 층 완료와 던전 완료를 구분한다. 다섯 던전 콘셉트·층별 기믹은 기획안을 따른다. 모둠별 귀환으로 마을과 던전이 함께 사용되는 상태도 검증한다.
- 네 직업은 수호기사·명사수·원소술사·발명가다. 공용 건설은 폐기하고 발명가의 공격 포탑 1개·지원 장치 1개만 사용한다. 합동전의 장치는 최대 10개다.
- 기존 18개 임무·공용 타워·포장/운반 기획은 삭제했다. 과거 검수 기록·소스 계약·미술 참고를 새 기획 지침으로 되살리지 않는다.
- **현재 실행판 s2-004는 기존 대기실·마을·숲·봉화·첫 보스 테스트판이다. 새 RPG 규칙은 미구현이다.** 실행 확인에는 [테스트 안내](테스트안내.md)와 [s2-004 검수](s2-004-모션카메라검수.md)를 사용한다.
- 최우선 기준은 마을·던전 디자인, 효과음·배경음, 사용자 노트북의 시즌1 수준 성능이다. 맵을 멀리 떨어뜨리는 것만으로 모둠별 처리 분리가 됐다고 하지 않는다. 최종 합동전도 별도로 검증한다.
- 캐릭터는 시즌1 실제 모델·동작·꾸미기를 재사용한다. 비슷하게 새로 그린 모델로 교체하지 않는다. 시즌1을 먼저 공통 라이브러리로 리팩터링하지 않는다.
- 원본은 `index.html`, `style.css`, `src/`이며 `npm run build`로 독립 실행 `배포용/index.html`을 만든다. 실행 소스 변경 후 배포본을 재생성하고 브라우저로 확인한다.
- 새 기획에서 확정 방향과 세부 제안, 실제 구현을 구분한다. 통신·저장 버전과 권한을 확인한 뒤 변경하며 기존 시즌1 또는 테스트판 데이터를 덮어쓰지 않는다.
- 문서만 바뀐 작업은 상대 링크·기획 일관성·변경 범위와 시즌1 무변경을 확인한다. 실행 기능 변경은 실제 화면·동작·복구·성능을 검수한다.
- 성능은 21명 접속과 같은 화질에서 비교한다. 소프트웨어 렌더러의 작업량을 실제 노트북 FPS로 보고하지 않는다.
- 기획 문서나 브랜치 푸시를 게임 완성·배포 완료라고 보고하지 않는다.

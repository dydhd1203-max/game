# 시즌2 작업 안내

이 폴더는 좀비의 밤 시즌2 전용이다. 먼저 [README](README.md), 변경할 주제의 기획 문서, [개발계획](개발계획.md)을 읽는다.

- 사용자 확정 요구는 시즌1을 내년에도 그대로 사용할 수 있도록 유지하고, 시즌2를 별도 폴더에서 구체화하는 것이다.
- 사용자 최우선 기준은 마을·사냥터·타워맵 디자인, 효과음·배경음, 성능 최적화다. `맵-소리-성능.md`의 대표 장면을 검증한 뒤 콘텐츠를 확장하며, 시즌1 재사용은 `시즌1-재사용계획.md`를 따른다.
- 현재 실행 범위는 `s2-001` 대기실·마을·숲길·봉화·첫 보스 테스트판이다. [테스트 안내](테스트안내.md)와 [구현·검수 기록](s2-001-구현검수.md)을 먼저 확인한다. 18개 임무 전체 기획과 실제 구현 범위를 구분한다.
- 캐릭터는 사용자의 명시 요청에 따라 시즌1 실제 모델·동작·꾸미기를 재사용한다. 비슷하게 새로 그린 모델로 교체하지 않는다.
- 원본은 `index.html`, `style.css`, `src/`이며 `npm run build`로 독립 실행 `배포용/index.html`을 만든다. 소스 변경 후 배포본도 재생성하고 브라우저로 확인한다.
- 시즌2 개발 때문에 `../클로드/`, `../퀴즈나라/`, 기존 배포 설정이나 기존 저장 데이터를 변경하지 않는다. 실제 시즌2 코드를 추가할 때도 실행·통신·저장·배포 범위를 분리한다.
- 공통 코드를 추출하려고 시즌1을 먼저 리팩터링하지 않는다. 재사용 기준 버전과 이식한 기능을 시즌2에서 추적한다.
- 문서의 날짜별 임무·경제·저장 정책이 서로 어긋나지 않게 함께 확인한다. 새 기획은 제안 상태로 남기고 구현 상태는 별도로 적는다.
- 문서만 바뀐 작업은 상대 링크·범위·시즌1 무변경을 확인한다. 실행 기능을 바꾼 작업은 해당 기능의 실제 화면·동작·성능을 검수한다.
- 성능은 21명 수업과 같은 화질에서 검증한다. 소프트웨어 렌더러의 처리량을 실제 기기 FPS로 보고하지 않는다.
- 기획 문서나 브랜치 푸시를 시즌2 게임 완성·배포 완료라고 보고하지 않는다.

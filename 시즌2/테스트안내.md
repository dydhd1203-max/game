# 첫 보스 테스트판 s2-009 — 나무·바위·식재 개선

> 이 문서는 기존 테스트판의 실행 안내다. [새 협동 RPG 기획](기획안.md)의 네 직업·다섯 던전·합동 보스는 아직 구현되지 않았다. 공용 타워 기능은 제거했으며, 발명가 직업도 미구현이므로 현재는 누구도 타워 스킬을 사용할 수 없다.

마을과 기존 숲길의 공 모양 나무, 바위 위 초록 판, 줄 선 조약돌을 바꾼 판이다. 가지와 잎 무리의 틈을 살리고 돌·풀을 자연스러운 군집으로 정리한다. s2-008의 여섯 마을 구조물, 41m 폭과 접근 가능한 앞뒤 38.5m 동선, 시즌1 기준의 밝기·달리기·점프와 공용 타워 제거는 유지한다. 실제 화면·검사 결과는 [최신 자연 조형물 검수](s2-009-자연조형물검수.md)를 확인한다. [s2-008 마을 확대 검수](s2-008-마을확대검수.md)는 당시 기록이다. [s2-007 공용 타워 제거 검수](s2-007-공용타워제거검수.md), [s2-006 화면·모션 검수](s2-006-화면모션검수.md), [작업장 검수](s2-005-작업장검수.md), [모션 검수](s2-004-모션카메라검수.md)는 이전 단계의 기록이다.

이번 판은 충돌·스폰·규칙을 바꾸지 않아 저장·통신 규격은 s2-008을 유지한다. **s2-008에서 사용하던 방과 저장을 이어 쓸 수 있다.** 새 풍경을 함께 확인하려면 모두 s2-009 파일을 사용한다. s2-007 및 이전 판의 온라인 방에는 연결할 수 없으므로 그 판에서 넘어올 때는 새 방 코드가 필요하다. 같은 브라우저·같은 저장 범위의 이전 저장은 진행·보급을 이어받고, 바뀐 마을 건물 안이나 경계 밖에 있는 위치만 집결 지점으로 옮긴다. 다른 방 코드의 진행은 자동으로 옮겨지지 않는다.

시즌1 파일은 그대로 유지한다. 이 실행 파일은 좀비의 밤 시즌2 전용이다.

## 혼자 먼저 해 보기

1. [배포용/index.html](배포용/index.html)을 다운로드하고 Chrome으로 연다. GitHub 파일 화면의 **Download raw file**도 사용할 수 있다. 파일 이름을 `좀비의밤-시즌2.html`로 바꿔도 된다.
2. 이름·모둠·시즌1 꾸미기를 고르고 **혼자 체험**으로 입장한다.
3. 대기실에서 **마을로 출발**, 마을에서 **안개 숲으로 출격**을 누른다. 혼자 체험에서는 본인이 선생님 버튼을 사용한다.
4. 좌클릭 기본 공격으로 숲길의 적을 정리하고 봉화 가까이에서 E를 눌러 불을 밝힌다.
5. 다음 적 무리를 정리하고 앞쪽 숲길 입구에서 E를 누르면 첫 보스에 도전한다.
6. 보스의 붉은 돌진 길을 옆으로 피하고, 지쳐 멈춘 동안 친구들과 기본 공격을 집중한다. 처치 뒤 마을로 귀환한다.

관리형 브라우저에서 로컬 HTML을 차단하는 경우에는 아래 개발 환경의 localhost 실행 방법을 사용한다. s2-006에서는 단일 HTML을 제공하고 네트워크를 끈 브라우저에서 혼자 체험을 검수했다. 현재 판의 실행 방식·확인 결과는 최신 검수 기록을 따른다.

## 조작

| 입력 | 행동 |
|---|---|
| W A S D / 방향키 | 이동 |
| 마우스 / 우클릭 | 시점 회전 / 조준 전환. 시점 잠금이 안 되면 우클릭 드래그 |
| 휠 | 확대·축소 / 가장 가까이 당기면 1인칭 |
| 좌클릭 | 가까운 적에게 기본 공격; 길게 눌러 연속 공격. 마우스 시점 시작 |
| Shift | 달리기; 기력을 소모하고 쉬면 회복 |
| Space | 점프. 마을·원정에서 Space를 떼었다 다시 누르면 2단 공중제비. 대기실은 한 번만 |
| Esc | 마우스 시점 잠금 해제 |
| E | 봉화·보스 입구·쓰러진 친구와 상호작용 |

타워 배치·포장·수리·보관함과 1/2/T/R 단축키는 없다. 기본 공격으로 숲길과 첫 보스를 공략한다. 혼자 쓰러지면 재도전하며, 친구가 남아 있으면 구조 또는 잠시 뒤 복귀할 수 있다.

## 친구들과 테스트하기

선생님이 **선생님** 탭에서 기존 교사 암호와 방 코드를 입력하고 **교사 방 만들기**를 누른다. s2-008 방은 이어 쓸 수 있고 s2-007 이하에서 넘어올 때는 새 코드를 사용한다. 학생은 같은 시즌2 파일에서 **학생** 탭을 선택하고 그 코드를 입력한 뒤 **학생 입장**을 누른다. 선생님을 포함해 최대 21명이며, 입장 인원을 기준으로 원정 난이도를 고정한다. 새 참가자는 진행 중인 원정에 합류할 수 있다.

시즌2는 기존 Firebase 서버의 예약된 전용 경로 `sheepnight/season2_v1/rooms/<코드>`를 사용한다. 시즌1의 대문자 방 코드와 구분되며 기존 방·데이터·서버 규칙을 변경하지 않는다. 최초 후보 `sheepnight_s2`는 접근 권한이 없어 채택하지 않았다. 이는 서로 다른 저장 경로이며 별도 서버 인증 체계를 추가한 것은 아니다.

교사 연결이 끊기거나 교사가 탭을 떠나면 멈춘다. 돌아온 뒤 **재개**를 누른다. 호스트 복구 키는 방을 만든 브라우저에만 보관하므로 같은 브라우저로 돌아와야 한다. 학생 입력이 끊기면 인터넷과 교사 화면을 먼저 확인한다. 실제 21대 동시 통신은 교실 테스트가 필요하다.

## 저장·성능·소리

- **저장 / 불러오기:** 같은 브라우저·같은 방의 확정 지점을 사용한다. 처음 입장한 대기실에서 불러오면 지난 진행을 이어간다. 전투 중 저장은 원정 출발 지점 기준이며 중간 전투 프레임을 그대로 이어가는 기능이 아니다. 불러오기는 대기실·마을·결과 화면에서 사용한다.
- **이전 판 저장:** 새 저장은 `zns2:checkpoint:s2-008:<room>`에 쓴다. 새 키가 없으면 `zns2:checkpoint:s2-007:<room>`, `zns2:checkpoint:<room>` 순서로 읽어 복제한다. 이전 원본을 보존하며 진행·보급·외형은 유지하고 유효하지 않은 마을 위치만 복구한다. 공용 타워는 복원하지 않으며 타워 비용을 환불하지 않는다.
- **재도전:** 실패한 시도의 보상을 누적하지 않고 출발 상태로 돌아간다. 보스 클리어 후 다시 테스트하려면 새 방을 만들거나 혼자 체험에 새로 입장한다.
- **소리:** 오른쪽 설정에서 배경음·효과음을 따로 조절한다. 입장 클릭 후 재생된다. 21대에서 소리가 겹칠 때 경고음이 들리는지도 확인한다.
- **성능 기록:** 오른쪽 그래프 버튼에서 확인·내려받는다. 기본 화질은 그리기 배율 0.85다. 기록은 해당 기기의 FPS·프레임 시간·그리기 호출·삼각형·개체 수이며 GPU 시간은 아직 별도 수집하지 않는다.

이번 판에서는 기본 카메라로 마을 외곽부터 숲 진입·봉화·첫 보스 입구까지 나무 가지와 잎 사이의 틈, 크기와 기울기가 다른 바위 군집, 바위 밑과 틈의 식재를 확인한다. 공처럼 둥근 수관, 바위 위에 떠 있는 초록 판, 일정 간격의 조약돌 줄이 다시 보이지 않는지 가까이서도 본다. 기존 여섯 구조물의 처마·천막·도구·소품과 중앙 집결 공간도 유지되어야 한다. 중앙길과 건물 주변을 걷고 달리며 길이 막히거나 모델을 통과하는 곳이 없는지 본다. 점프·착지와 카메라 회전 중 캐릭터가 가려지는지도 확인한다. 마을의 밝기, 설정/도움말을 닫은 직후 Shift+이동, Space 두 번으로 공중제비, 친구의 달리기·공중제비 표시와 기존 숲·첫 보스 진행을 함께 확인한다. 대기실은 시즌1처럼 단일 점프이며 달리기·2단 점프는 마을과 원정에서 사용한다.

## 개발 환경에서 실행

`시즌2` 폴더에서 `npm ci` 후 `npm run build`로 독립 실행 파일을 다시 만든다. 소스 실행은 저장소 루트에서 `python -m http.server 8123`을 실행하고 `http://localhost:8123/시즌2/`로 접속한다. 기존 시즌1 배포 설정은 변경하지 않았다. 시즌2 공개 웹 주소는 아직 별도 배포하지 않았다.

# 첫 보스 테스트판 s2-004

시즌1 이동·모션·카메라를 이식한 판이다. [구현·검수 기록](s2-004-모션카메라검수.md)을 확인한다. 기존 s2-001/s2-002/s2-003 로컬 저장은 진행을 보존해 변환한다. 온라인은 모두 새 파일을 열고 **새 방 코드**를 사용한다.

시즌1 파일은 그대로 유지한다. 이 실행 파일은 좀비의 밤 시즌2 전용이다.

## 혼자 먼저 해 보기

1. [배포용/index.html](배포용/index.html)을 다운로드하고 Chrome으로 연다. GitHub 파일 화면의 **Download raw file**도 사용할 수 있다. 파일 이름을 `좀비의밤-시즌2.html`로 바꿔도 된다.
2. 이름·모둠·시즌1 꾸미기를 고르고 **혼자 체험**으로 입장한다.
3. 대기실에서 **마을로 시작**, 마을에서 **안개 숲으로 출격**을 누른다. 혼자 체험에서는 본인이 선생님 버튼을 사용한다.
4. 숲길 좀비를 정리하고 봉화 가까이에서 E를 눌러 얼음탑과 다음 설치 지대를 연다.
5. 다음 적 무리를 정리하고 앞쪽 숲길 입구에서 E를 누르면 첫 보스에 도전한다.
6. 보스의 붉은 돌진 길을 옆으로 피하고, 지쳐 멈춘 동안 직접 공격과 타워를 집중한다. 처치 뒤 마을로 귀환한다.

관리형 브라우저에서 로컬 HTML을 차단하는 경우에는 아래 개발 환경의 localhost 실행 방법을 사용한다. 검수 환경에서는 독립 실행 파일을 localhost로 열어 확인했다.

## 조작

| 입력 | 행동 |
|---|---|
| W A S D / 방향키 | 이동 |
| 마우스 / 우클릭 | 시점 회전 / 조준 전환. 시점 잠금이 안 되면 우클릭 드래그 |
| 휠 | 확대·축소 / 가장 가까이 당기면 1인칭 |
| 좌클릭 | 가까운 적에게 기본 공격; 길게 눌러 연속 공격. 마우스 시점 시작 |
| Shift | 달리기; 기력을 소모하고 쉬면 회복 |
| Space | 점프. 원정에서는 떨어지기 시작할 때 다시 눌러 2단 공중제비. 대기실은 한 번만 |
| 1 / 2 | 화살탑 / 얼음탑 선택. 좌클릭으로 배치 |
| Esc | 설치 선택 취소 · 마우스 시점 잠금 해제 |
| T | 가까운 우리 모둠 탑 포장; 운반 중이면 재설치 선택 |
| R | 가까운 타워 수리 |
| E | 봉화·보스 입구·쓰러진 친구와 상호작용 |

설치 지대 안에서도 중앙 통로·친구 자리·다른 타워와 겹치는 곳에는 설치하지 못한다. 가까이 이동해 미리보기가 허용 상태인지 확인한다. 얼음탑은 봉화를 켠 뒤 사용한다. 같은 타워를 포장해 옮기면 체력이 유지되고 새 비용을 내지 않는다. 보관함에서 회수한 탑도 다시 설치할 수 있다.

얼음 표식이 묻은 적을 화살탑이 맞히면 쇄빙이 발동한다. 기본 공격만으로도 첫 보스를 클리어할 수 있다. 혼자 쓰러지면 재도전하며, 친구가 남아 있으면 구조 또는 잠시 뒤 복귀할 수 있다.

## 친구들과 테스트하기

선생님이 **방 만들기**에서 기존 선생님 암호와 새 방 코드를 입력한다. 학생은 같은 시즌2 파일에서 **친구 방 입장**을 선택하고 그 코드를 입력한다. 선생님을 포함해 최대 21명이며, 입장 인원을 기준으로 원정 난이도를 고정한다. 새 참가자는 진행 중인 원정에 합류할 수 있다.

시즌2는 기존 Firebase 서버의 예약된 전용 경로 `sheepnight/season2_v1/rooms/<코드>`를 사용한다. 시즌1의 대문자 방 코드와 구분되며 기존 방·데이터·서버 규칙을 변경하지 않는다. 최초 후보 `sheepnight_s2`는 접근 권한이 없어 채택하지 않았다. 이는 서로 다른 저장 경로이며 별도 서버 인증 체계를 추가한 것은 아니다.

교사 연결이 끊기거나 교사가 탭을 떠나면 멈춘다. 돌아온 뒤 **재개**를 누른다. 호스트 복구 키는 방을 만든 브라우저에만 보관하므로 같은 브라우저로 돌아와야 한다. 학생 입력이 끊기면 인터넷과 교사 화면을 먼저 확인한다. 실제 21대 동시 통신은 교실 테스트가 필요하다.

## 저장·성능·소리

- **저장 / 불러오기:** 같은 브라우저·같은 방의 확정 지점을 사용한다. 처음 입장한 대기실에서 불러오면 지난 진행을 이어간다. 전투 중 저장은 원정 출발 지점 기준이며 중간 전투 프레임을 그대로 이어가는 기능이 아니다. 불러오기는 대기실·마을·결과 화면에서 사용한다.
- **재도전:** 실패한 시도의 자재·보상을 누적하지 않고 출발 상태로 돌아간다. 보스 클리어 후 다시 테스트하려면 새 방을 만들거나 혼자 체험에 새로 입장한다.
- **소리:** 오른쪽 설정에서 배경음·효과음을 따로 조절한다. 입장 클릭 후 재생된다. 21대에서 소리가 겹칠 때 경고음이 들리는지도 확인한다.
- **성능 기록:** 오른쪽 그래프 버튼에서 확인·내려받는다. 기본 화질은 그리기 배율 0.85다. 기록은 해당 기기의 FPS·프레임 시간·그리기 호출·삼각형·개체 수이며 GPU 시간은 아직 별도 수집하지 않는다.

테스트할 때 대기실 인원, 마을·숲 화면, 포장/재설치, 보스 예고가 잘 보이는지와 클리어 소요 시간을 알려 주면 다음 버전에 반영할 수 있다.

## 개발 환경에서 실행

`시즌2` 폴더에서 `npm ci` 후 `npm run build`로 독립 실행 파일을 다시 만든다. 소스 실행은 저장소 루트에서 `python -m http.server 8123`을 실행하고 `http://localhost:8123/시즌2/`로 접속한다. 기존 시즌1 배포 설정은 변경하지 않았다. 시즌2 공개 웹 주소는 아직 별도 배포하지 않았다.

# s2-010 숲 마을과 HUD 실제 시점 검수

## 요구와 방법

참고 이미지의 풀·꽃·활엽수와 침엽수·먼 산이 층을 이루는 풍경, 어두운 얼룩과 질감이 있는 지면, 작은 어두운 RPG HUD를 실제 플레이 시점으로 확인한다. 좌상단 목표, 우상단 원형 지도, 좌하단 체력·기력, 우하단 조작 안내가 월드와 함께 읽히는지 본다.

고정 기준판에서 실제 입장 → 마을 출발 → WASD 북쪽 → 남쪽 돌아보기 → 북서쪽 가장자리로 같은 경로를 걷는다. 시점은 실제 우클릭 드래그로 돌린다. 순간이동, 강제 카메라, 캐릭터/적 상태 수정, HUD 숨김, 일시정지로 만든 미술 사진은 없다. 기본 시즌1 카메라 3.2m, 그리기 배율 0.85, MSAA 4 samples, AgX/1.28을 유지한다.

숨김 Chromium/SwiftShader, 1366×768 DPR1을 사용한다. 최종 HUD는 820×600·560×700에서도 확인한다. 이는 실제 노트북 FPS·21대 동시 접속·주관적인 소리 품질 검사가 아니다. 도구 조작과 저장/불러오기·일시정지는 미술 경로 촬영을 끝낸 뒤 따로 검사한다.

## 2차 변경

안개와 산 연결, 잎 색·침엽수, 남쪽 장식 바위와 넓은 삼각 풀을 보완했다. [2차 보고서](after2/report.json)의 HTML SHA-256은 `23ed0d1949788c258985e2ed4c9ddcc18ef5fd227c6c209e2035b9f08b138f8d`다. [출발](after2/01-village-spawn.png), [북쪽](after2/02-village-north-woodland.png), [남쪽](after2/03-village-south-mountains.png) 세 장을 직접 열었다. 산 앞의 파란 나무 구멍이 사라졌고 녹색 안개로 연결된다. 잎은 더 진한 녹색으로 읽히고 남쪽 큰 돌벽을 낮춰 뒤쪽 숲이 보인다.

이 실행은 **부분 확인이며 전체 통과가 아니다**. 북서쪽 횡단 검수 중 프레임 단위 입력 해제의 이동 초과로 `z=-6` 목표가 `-6.344`가 됐다. 그 선을 옆으로 걸을 때 `(-9,-7.8)` 나무의 정상 충돌 반경에 걸려 04 촬영 전에 타임아웃했다. 기존 제품 충돌은 유지됐으며 검수 횡단선을 `z=-5`로 옮겨 입력 해제 오차의 여유를 확보했다. 실패 보고서를 그대로 보존한다. 후속 04는 이전 비교 사진보다 남쪽으로 약 1m 떨어진 실제 접근임을 구분한다.

## 최종 판: 침엽수 가지 방향·폭 보정

[마지막 보고서](after4/report.json): **4항목·1장 통과**. 실제 입장 후 북서쪽까지 WASD로 걸어 우클릭으로 돌린 [마지막 04 사진](after4/04-village-northwest-edge.png)을 직접 열었다. RELEASE `s2-010` / BUILD `s2-008`, 독립 HTML 4,675,969바이트, SHA-256은 **`53de75da8aeb2045b34fb3608e9ddefcbd269080816661c9da756adaf7fecf4d`**다.

직전 86cc1372 후보에서 가까운 침엽수 가지의 기울기 값 `0.97→1.78rad`와 폭 계수 `0.91→1.55` 두 수치만 보정했다. 가지가 아래와 옆으로 넓어져 위로 솟는 창 같은 인상이 줄고 줄기 옆으로 벌어진 잎층이 보인다. 같은 근접 시점의 작업량은 25 calls / 47,789 triangles로 유지됐다. 이 마지막 화면 역시 앞의 관목이 몸통을 가리는 자연물 근접 검수용 사진이다.

변경 범위가 두 미술 수치뿐이므로 UI 전체 조작과 숲 경로를 재실행하지 않았다. 1차의 전체 UI·모션, 86cc1372 후보의 실제 숲 진입·지도 겹침 보완, 마지막 53de75da 판의 가까운 침엽수 확인을 각각 해당 해시의 근거로 남긴다. 위 출발·북쪽·숲 사진은 **86cc1372 후보판에서 촬영한 것**이며 마지막 파일에서 다시 촬영했다고 표시하지 않는다. 이 단계에서는 제품 코드를 수정하거나 추가 기능 검사를 진행하지 않았다.

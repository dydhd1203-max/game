# 마을 실제 시점 검수 — 확대·자연·돌 테두리 제거

**최신 화면은 `final-no-curbs/`의 돌 테두리 제거판이다.** `baseline/`, `current/`, `final-contact/`의 사진은 테두리 제거 전 비교·이동·저장·접촉 검증의 중간 기록으로 보존한다. 이전 사진을 최신 미술 화면으로 사용하지 않는다.

이 자료는 숨김 Chromium/SwiftShader의 기본 시즌1 카메라(거리 3.2, 그리기 배율 0.85, 실제 MSAA 4 samples)로 입장한 뒤 실제 WASD와 우클릭 드래그로 촬영한 화면이다. 카메라를 위로 옮기거나 HUD를 숨겨 빈 공간을 감추지 않았다. 노트북 FPS·21대 실접속 성능은 측정하지 않는다.

## 최종 돌 테두리 제거판

[출발 화면](final-no-curbs/02-village-default-spawn.png)과 [대장간·작업장 근접 화면](final-no-curbs/03-smith-workshop-no-stone-curbs.png)을 실제 입장 → 마을 시작 → WASD → 우클릭 드래그로 촬영하고 직접 열어 확인했다. 건물 주위의 반복된 돌 테두리가 없어졌고 풀·관목과 실제 건물의 기초만 남아 있다. 지붕·공구·차양·작업대와 자연 배경은 유지된다.

최신 [보고서](final-no-curbs/report.json)는 **4항목·2장 통과**이며 독립 HTML 해시 `119c8742b209cfeb65685411dc3b82c1edae860c1051e76e3b241967f38769d3`, 크기 4,647,253바이트다. 0.85 그리기 배율·MSAA 4 samples·AgX/1.28은 그대로다. 두 장 모두 실제 3인칭 인물이 표시된다. 실행 오류와 커서 잠금은 없었다.

사진은 출발 및 대장간/작업장 앞을 직접 확인한 범위다. 여섯 부지 전체의 제거는 `src/village-a.mjs`의 공통 `plantPlot` 함수가 풀·관목만 만들고, 작업장과 나머지 다섯 모델에서 같은 함수를 호출하는 코드를 함께 확인했다. 제거된 돌은 6곳×36개=216개다. 건물 위치·충돌·조작 코드는 바뀌지 않아 아래 전체 경로·모션·21인 생성·저장 복구 검수는 중복 실행하지 않았다. 성능 수치는 별도 최종 성능 보고서를 따른다.

## 변경 전 직접 확인

- [출발](baseline/02-village-default-spawn.png): 작업장과 수레 사이의 포장 도로가 길고, 중앙 지평선에는 큰 하늘 공백이 보인다.
- [집결소](baseline/03-assembly-street-side.png): 게시판·화분은 있으나 넓은 정비 거점에 비해 목적지의 실루엣이 작다. 뒤쪽은 듬성한 둥근 나무와 평평한 바닥이다.
- [시장](baseline/04-market-street-side.png), [보급 마당](baseline/06-supplyYard-street-side.png): 천막 앞의 바닥 공백이 크고 단순한 나무가 반복된다.
- [북쪽 출구](baseline/09-north-exit-default.png): 숲길 양쪽의 넓은 풀밭이 비어 있고, 같은 모양의 나무가 줄지어 보인다.
- [마을을 돌아본 화면](baseline/10-north-return-street.png): 긴 중앙 바닥과 남쪽 지평선의 빈 공간이 눈에 띈다. 기존 작업장 후면의 넓은 회벽은 단순하다.
- [남쪽 경계](baseline/12-south-boundary.png): 납작한 바위 몇 개 뒤로 평평한 녹색 바닥과 하늘만 보인다. 이번 지형·식생 보강에서 가장 분명하게 개선해야 할 구간이다.

변경 전 자동 확인은 [보고서](baseline/report.json)의 4개 항목/12장으로 남겼다. 자동 통과와 미술 판단은 구분한다. 각 이미지의 실제 인물 위치와 카메라, 호출 수·삼각형 수, 읽은 소스 해시는 보고서에 있다.

## 확대·접촉 보완 단계 — 돌 테두리 제거 전

- [실제 출발](final-contact/02-village-default-spawn.png): 대장간의 처마·걸린 공구·작업대가 가까운 거리에서 읽힌다. 수레·차양·나무와 곡선 입구가 중앙 출구를 둘러싼다. 중앙 이동 공간은 계속 열린다.
- 집결소는 벤치와 게시판, 시장은 처진 차양·매단 도구·도자기, 보급소는 진열 선반·곡물 주머니, 수레는 휜 천막·바퀴살·차축으로 용도가 구별된다. 여섯 부지에 실제 키 입력으로 접근했으며 충돌 경계에서 멈췄다.
- [북쪽에서 돌아본 마을](current/10-north-return-street.png): 이전의 빈 남쪽 지평선이 바위턱과 뒤쪽 나무 군락으로 닫혔다. 마을 길 양옆이 가까워졌고, 풀·낮은 관목·바위가 건물과 자연을 잇는다.
- [남쪽 돌아보기](current/11-south-turnaround.png)와 [경계 정지](current/12-south-boundary.png): 이전의 빈 평면이 겹친 바위와 식생으로 바뀌었다. 광장 끝과 이동 경계가 실제 기본 시점에서 읽힌다.
- [2단 점프](current/motion-double-jump.png)·[착지](current/motion-landing.png): 실제 Space 입력으로 공중제비·먼지·착지 자세와 높이를 따라가는 카메라를 확인했다. 화면을 멈추거나 인물 자세를 바꾸지 않았다.
- [21명 배치 뒤 실제 이동](current/14-crowd-north-return.png): 생성된 21명 모두 새 마을 안의 유효한 좌표에 있고 최소 중심 간격은 1.6이다. 한 명을 실제 WASD로 북쪽까지 이동해 길을 확인했다. 이는 로컬 21인 상태이며 21대 네트워크 접속이 아니다.

세부 근접 확인은 [전체 검수 보고서](current/report.json)의 23장과 9개 확인 항목에 남겼다. 달리기·점프는 69개 실제 렌더 프레임을 읽기 전용으로 관찰했다. 구 s2-007 외곽 잔디에 21명이 있던 저장을 넣고 실제 **불러오기** 버튼으로 복구했으며 모두 새 맵의 유효한 위치로 옮겨졌다. **저장** 버튼은 s2-008 전용 키에 쓰고 s2-007 원본 바이트를 보존했다. 5회 마을/숲/보스 전환 뒤 GPU geometry는 41→41, texture는 6→6으로 누적되지 않았다.

전체 검수 도중 미술 모델의 등걸이·보급 간판 연결을 168삼각형으로 보완했다. 전체 검수는 이미 읽은 인라인 HTML `ce2c8757f84ac7771e24b8726fac54021d66ab301e4c8412e965dc65555d3c84`를 끝까지 사용했다. 위치·충돌·조작 코드는 바뀌지 않았다. 접촉 보완 HTML `6421ffedc5c3f3184486162c8cbee1c91756f39ca3c5d86d9eec5312174f9aa2`는 새 브라우저에서 별도로 입장하여 출발 화면, 변경된 네 건물, 남쪽 경계를 다시 확인했다. 접촉 보완 확인 결과는 [접촉 보완 검수](final-contact/report.json)와 해당 사진을 따른다.

전체 경로는 실제 첫 생성 위치의 왼쪽 열(x=-3.6)에서 출발한다. 그 열에서 오른쪽 건물을 돌아볼 때는 뒤쪽 건물에 닿은 시즌1 카메라가 인물 쪽으로 당겨져 인물을 숨기기도 한다(`camera.bodyHidden=true`). 접촉 보완 근접 재검수는 실제 A/D 이동으로 중앙 x≈0에 간 뒤 바라본다. 카메라를 검사 전용 좌표로 바꾸거나 충돌을 해제하지 않았다.

접촉 보완 확인은 4개 항목/12장 통과했다. 시장·집결소·대장간·보급소의 추가 지지대/등걸이와 남쪽 바위·식생 경계를 게임 화면에서 직접 열어 확인했다. 독립 HTML의 실제 해시는 `6421ffedc5c3f3184486162c8cbee1c91756f39ca3c5d86d9eec5312174f9aa2`다. 이후 돌 테두리를 제거한 변경의 실제 확인은 위 최종 검수와 `final-no-curbs/`를 따른다.

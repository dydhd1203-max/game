# s2-009 자연 조형물 실제 시점 검수

검수 범위는 마을과 숲 입구에서 보이는 세 가지다: **공처럼 뭉친 나무 수관**, **규칙적으로 반복되는 낮은 공/조약돌**, **바위 위의 별도 초록 덮개**. 실제 입장 → 마을 시작 → WASD 북쪽 이동 → 숲 출격 → 왼쪽 가장자리와 첫 바위 접근으로 같은 경로를 촬영한다. 순간이동·조망 카메라·HUD 숨김·인물 또는 적 상태 변경·일시정지는 사용하지 않는다.

숨김 Chromium/SwiftShader, 1366×768 DPR1, 그리기 배율 0.85, MSAA 4 samples, AgX/1.28을 유지한다. 초기 카메라는 시즌1의 3.2m 시점이며 각 장면에서 캐릭터 몸체가 보이는지 확인한다. 이 검수는 실제 노트북 FPS·21대 네트워크 접속을 측정하지 않는다.

## 변경 전

[보고서](before/report.json): 5항목·5장 통과. 독립 HTML 해시는 `119c8742b209cfeb65685411dc3b82c1edae860c1051e76e3b241967f38769d3`다.

- [마을 북쪽](before/02-village-north-trees.png): 숲 입구 왼쪽의 공 수관과 같은 크기의 낮은 조약돌이 한 줄로 이어진 모습이 명확하다.
- [숲 가장자리](before/04-forest-left-trees-and-edge.png): 둥근 수관 밑에 가지가 거의 보이지 않고 원통형 기둥과 납작한 원형 밑받침이 반복된다.
- [첫 바위](before/05-first-rock-surface.png): 둥근 항아리 같은 몸통 위에 얇은 초록 덮개가 따로 얹혀 있다.

전투는 정상 진행한다. 04 화면 오른쪽의 매우 큰 초록 공은 접근한 좀비의 머리이며 자연물이 아니다. 05에서도 적이 화면 우상단에 일부 보이고 체력은 67이다. 나무 전체 비교에는 적이 없는 02, 바위 표면 비교에는 05의 중앙 바위를 사용한다.

## 1차 수정 — 미술 재작업 대상으로 판단

[보고서](after1/report.json): 같은 5항목·5장 통과. HTML 해시는 `c5ccd8ecd8431a58a0da9a978a38de6d9ae5a6351bba22232de3689df6e1d112`다. 자동 검사 통과를 미술 승인으로 처리하지 않았다.

- [02 나무 전체](after1/02-village-north-trees.png)와 [04 근접](after1/04-forest-left-trees-and-edge.png)을 직접 열었다. 가지 구조는 읽히지만 잎이 얇은 선반처럼 여러 층으로 쌓여 보여 재작업이 필요하다. root와 자연물 제작 담당도 같은 문제를 확인했다.
- [05 바위](after1/05-first-rock-surface.png)는 초록 덮개가 사라졌고, 불규칙한 하나의 돌덩이로 읽힌다. 04의 낮은 장식도 같은 공을 늘어놓은 형태에서 바위·고사리 군집으로 바뀌었다.
- 1차 결과는 중간 기록이다. 최종 미술 화면으로 안내하지 않는다.

## 2차 수정 — 최종 검수

[최종 보고서](after2/report.json): 같은 실제 입력 경로의 **5항목·5장 통과**. RELEASE는 `s2-009`, 통신 BUILD는 `s2-008`이다. 검수한 독립 HTML은 4,653,314바이트, SHA-256은 `e1d7b01281f07cfed090b359e82f15110807dd7bc0e1c4adeb05307ad2163753`다.

잎 조각은 80삼각형을 유지하면서 높이 범위를 약 −0.163~+0.482로 넓히고 하부 폭, 모서리 높이와 치우친 봉우리를 조정했다. 최종 사진 5장을 모두 직접 열어 확인했으며 1차의 얇은 선반 같은 인상이 완화되고 가지와 두꺼운 잎 덩어리의 비대칭 윤곽이 읽힌다.

- [02 마을 북쪽 나무 전체](after2/02-village-north-trees.png): 최종 공유용 나무 사진. 가지와 수관의 상하 두께가 보이며, 낮은 공을 규칙적으로 늘어놓은 가장자리는 불규칙한 바위·고사리 군집으로 바뀌었다.
- [05 첫 바위 표면](after2/05-first-rock-surface.png): 최종 공유용 바위 사진. 분리된 초록 덮개가 사라지고 불규칙한 하나의 돌덩이와 밑동의 식물로 읽힌다. 뒤쪽 나무의 잎 두께도 확인할 수 있다.
- [01 기본 출발 시점](after2/01-village-spawn.png)과 [03 숲 입구](after2/03-forest-entry.png): 기존 건물·시즌1 카메라·캐릭터 몸체가 유지된 상태에서 새 자연물을 확인했다.
- [04 숲 가장자리 근접](after2/04-forest-left-trees-and-edge.png)은 **부분 검수 사진**이다. 중앙의 큰 초록 구형 물체는 카메라에 접근한 좀비 머리이며 자연물이 아니다. 왼쪽과 위쪽에서 잎 하부와 가지·지면 식물을 볼 수 있으나, 전체 형태를 안내할 때는 02와 05를 사용한다.

최종 05의 체력은 45로, 촬영 중 전투가 정상 진행했다. 인물·적·카메라 상태를 강제로 바꾸지 않았고 그리기 배율 0.85, MSAA 4 samples, AgX/1.28을 유지했다. 브라우저 실행·자산 오류는 없었다. 사진별 호출·삼각형 수는 보고서에 기록했지만, 이동·전투 타이밍에 따른 화면 차이가 있으므로 이 기록만으로 FPS 향상률을 산출하지 않는다. 실제 노트북 성능과 다인 접속 검증은 이 미술 검수의 범위에 포함되지 않는다.

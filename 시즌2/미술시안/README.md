# 선택한 미술 방향

> 기존 첫 보스 테스트판의 미술 참고 기록이다. [새 RPG 기획](../기획안.md)의 다섯 던전·최종 보스 미술로 확정된 자료는 아니다.

2026-10-13 사용자 선택: **마을 A · 새벽 작업장 마을 + 보스 1 · 가시등 멧돼지**.

- [마을 비교 시안](마을-비교.png)의 첫 번째 장면: 붉은 곡선 지붕, 석재·목재 작업장, 노란 천막, 이동 요새와 넓은 광장.
- [첫 보스 비교 시안](첫보스-비교.png)의 첫 번째 외형: 낮고 넓은 네발 몸, 나무껍질 갑옷, 두 개의 엄니, 부러진 등 가시. 돌진 준비 자세를 분명하게 구분한다.

두 이미지는 생성한 콘셉트 아트이며 실제 게임 화면이나 성능 측정 결과가 아니다. 시안 속 인물은 크기 참고용이고, 실제 플레이어는 시즌1 원본 모델·동작·꾸미기를 그대로 사용한다.

성능 기준은 사용자의 노트북에서 잘 동작하는 현재 시즌1 106차다. 그리기 해상도·안티앨리어싱을 낮춰 미술 비용을 상쇄하지 않는다. 정적 모델 묶음·공유 재질·시야 밖 제외와 제한된 애니메이션 메시로 실제 비용을 측정한다.

# s2-001 첫 보스 테스트판 — 구현과 검증

2026-10-13 · 실제 교실 검수 전

## 사용자 요청과 실행 범위

대기실·첫 마을·첫 보스 클리어까지를 먼저 구현했다. 캐릭터는 시즌1과 동일하게 재사용하며, 마을/사냥터/타워 디자인·효과음/배경음·성능을 우선한다. 시즌1과 퀴즈나라 실행 파일은 수정하지 않는다.

| 구현 | 위치·동작 |
|---|---|
| 대기실·모둠·꾸미기·교사 시작 | `src/ui.mjs`, `src/app.mjs`, `src/sim.mjs` |
| 시즌1과 동일한 사람 캐릭터 | `src/avatar-season1.mjs`; 원본 모델·재질·동작·17모자/12얼굴/14의상 이식 |
| 둥근 지붕 마을·숲길·설치 공터·봉화·보스 전장 | `src/scene.mjs`, `src/content.mjs`; 기본 카메라 화면 검수 |
| 화살/얼음탑·쇄빙·포장/재설치·공동 자재 | `src/sim.mjs`; 모듈 ID·체력 유지, 30개 전체 상한 |
| 보스 돌진 예고·회복 빈틈·클리어·귀환 | `src/sim.mjs`; 1명/21명 정상 입력 완주 검사 |
| 방·입력·상태·접속 복구 | `src/net.mjs`; 21명 상한, 입력 20Hz·상태 10Hz, 느린 쓰기 대기열 제한 |
| 마을/탐색/보스곡·전투 효과음 | `src/audio.mjs`; 시즌1 소리 처리 기반 이식, 상태별 새 합성 선율 |

이번 테스트판은 18개 임무 전체나 숲 1~6일을 구현한 것이 아니다. 두 번의 숲 전투와 봉화, 첫 보스를 한 원정으로 연결했다. 주민 구조에 따른 작업장 성장, 설원/도시, 추가 타워/보스는 후속이다.

## 검증 방법

- `tests/sim.test.mjs`: 교사 권한, 단계 건너뛰기, 이동/충돌, 설치/비용/개수, 모듈 보존, 쇄빙, 타워 피해/수리, 보스 경고/돌진 범위, 구조/전멸/단절, 보상·재도전, 원본 꾸미기 ID. 1명·21명 완주는 HP 변경이나 적 강제 제거 없이 허용 행동과 이동·공격 입력으로 수행한다.
- `tests/avatar-season1.test.mjs`: 원본 지오메트리·재질, 15가지 동작×36프레임 및 전체 꾸미기의 인스턴스 행렬·색을 직접 비교한다. 21명 상태·시야 제외·정리도 검사한다. 새로운 유사 모델로 재해석하지 않는다.
- `tests/net.test.mjs`: 가짜 Firebase를 통한 방 소유권·재접속·명령 중복·오래된 상태·접속 상한·대기열·정리 검사. 실제 21대 통신 검증과 구분한다.
- `tests/browser.mjs`: 숨김 Chromium의 실제 입장 양식·키 이동·시작·출격·저장 복구·음량 조절, 기본 시점 및 보스/타워 보조 장면, 렌더 자산 수, 시즌1 저장값 보존. 마우스 잠금 없이 실행한다.
- `tests/audio.test.mjs`: 실제 Chromium Web Audio와 8초 마을/숲/보스 WAV 생성. 클리핑·중복/과다 재생·전환·정리·저장 격리를 검사한다. 파형 결과로 듣기 좋은 음색을 확정하지 않는다.

실제 Firebase에서는 새 시즌2 예약 경로에 고유한 임시 검수 방 하나를 조건부 생성→읽기 일치→조건부 삭제→`null` 재확인했다. 기존 시즌1 방과 보안 규칙은 변경하지 않았다. 이는 경로 접근 검증이며 실제 SDK로 연결한 21명 수업 검증은 아니다.

독립 실행 HTML은 localhost HTTP로 실제 입장·플레이·저장 검사를 수행한다. 이 검사 환경의 관리형 Chromium은 `file://` 이동을 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단하여 파일 직접 열기 검사는 수행하지 못했다. 이 정책을 변경하거나 우회하지 않았다. 출력 HTML에 게임·스타일·Three를 모두 포함했으며, 실제 사용 기기의 파일 열기는 사용자 확인이 필요하다.

## 성능과 남은 확인

정적 월드는 구역별 공유 인스턴스로 보관하고, 캐릭터·타워·적은 개수 제한과 시야 판정 아래 그린다. 효과음·화면 효과·이벤트·통신 대기열도 제한한다. 성능 기록의 1% low는 가장 느린 1% 프레임 시간 평균을 FPS로 바꾸며, 일정 간격 표본을 대신 사용하지 않는다.

브라우저 부하 장면은 모의 21명·30탑·적 40을 사용한다. 최종 개체 수·호출·삼각형은 별도 결과 JSON에 기록한다. 소프트웨어 WebGL의 측정값으로 실제 LG gram FPS 향상을 주장하지 않는다. 실제 교실 21대, 최종 음색 선호, 네트워크 상태별 체감과 난이도는 사용자 테스트가 남아 있다.

시즌1 원본과 배포본은 106차 SHA-256 `91c2c21654161390e37d84b70c96d5736f56f07de0add7fea950a0ab15d1173f`를 유지한다. 이 환경에는 사용자 Windows 바탕화면이 마운트되지 않아 그 폴더의 파일은 교체하지 않는다. GitHub의 시즌2 실행 파일을 별도로 내려받아 테스트한다.

## 최종 검사 결과

- `npm test`: **42/42 통과** — 원본 아바타·시뮬레이션·통신·실제 Web Audio.
- 독립 실행 HTML의 HTTP 브라우저 검사: **13개 통과**, 페이지 실행 오류 없음.
- 모의 21명·30탑·적 40의 고정 장면: **112회 그리기·410,368삼각형**, 지오메트리 37/텍스처 30이 반복 렌더에서 유지됨. 실제 GPU FPS 검증이 아니다.
- 기본 그리기 배율 0.85. 검사 Chromium의 기본 프레임버퍼 AA는 4샘플이었으며, 실제 값은 성능 기록에 저장한다. 후속 s2-002 검사에서 시즌1의 중간 화질도 같은 기본 프레임버퍼 경로이며 실제 4샘플임을 확인했다. 메뉴 AA 2는 해당 경로의 실제 샘플 수와 다르다.
- 기본 마을 시점과 보스 예고 화면을 직접 열어 확인했고, 카메라 거리·출발 위치·바라보는 높이를 조정해 건물과 보스가 보이게 했다.

# 시즌2 개발·성능 계획

새 게임 규칙은 [기획안](기획안.md)을 기준으로 한다. 이 문서는 **앞으로 구현할 계획**이며, 새 직업·모둠별 던전·합동 보스가 이미 실행된다는 뜻이 아니다.

## 1. 현재 구현과 변경 범위

- 현재 `s2-007`은 작업장·밝기·달리기/점프 보완을 유지하고 공용 타워 배치·포장·수리·보관함·관련 단축키와 안내를 제거한 판이다. 기본 공격·봉화·친구 구조·첫 보스 진행은 유지한다. 실행판과 저장·통신 규격은 모두 `s2-007`이다. [최신 검수](s2-007-공용타워제거검수.md)를 따른다.
- 발명가를 포함한 네 직업은 아직 미구현이다. 현재 테스트판에서 타워 스킬을 사용하는 직업은 없으며, 공용 타워를 직업 스킬처럼 남겨 두지 않는다.
- 현재 온라인 전투는 한 호스트가 전체 월드를 판정한다. 이동은 60Hz, 입력 전송은 20Hz, 스냅샷은 10Hz이며 모둠별 전투 분리는 구현되지 않았다.
- 이번 RPG 전환은 `시즌2/` 안에서 진행한다. 시즌1·퀴즈나라·시즌1 배포 설정과 저장 데이터는 변경하지 않는다.
- 시즌1 캐릭터·꾸미기·모션·카메라와 검증된 최적화를 재사용한다. 이식한 범위와 한계는 [시즌1 재사용 기록](시즌1-재사용기록.md)을 따른다.

## 2. 모둠별 월드와 통신 — 신규 설계

| 단계 | 처리 범위 |
| --- | --- |
| 대기실·마을 | 학생 20명이 다섯 모둠을 구성한다. 층을 깬 모둠은 포탈로 귀환해 정비한다. 다른 모둠의 전투 중에도 마을을 함께 사용할 수 있다. 교사는 운영·관전 담당이다. |
| 모둠 던전 | 모둠마다 학생 4명·던전 1개를 맡고 현재 층만 실행한다. 초기안은 각 3층이다. 최대 5개 전투 층이 동시에 실행되며, 15개 층을 모두 계속 실행하지 않는다. |
| 합동 보스 | 서로 다른 던전 5개 완료 후 학생 20명이 하나의 보스 월드로 합류한다. 보스 처치가 승리다. |

- **맵 좌표를 멀리 떨어뜨리는 것만으로 분리하지 않는다.** 클라이언트는 현재 던전의 지형·적·충돌·소리·효과만 활성화하고 해당 모둠의 전투 데이터만 구독한다.
- 다른 모둠의 상태는 ‘진행 중/완료/연결 확인 필요’처럼 작은 요약으로 전달한다. 다른 던전의 적 AI·물리·렌더링을 매 프레임 실행하지 않는다.
- 교사 측 조정자는 모둠·직업·던전 예약·완료 기록을 관리하고, 모둠별 전투 호스트가 해당 던전의 적 AI·피해·보상을 판정하는 구조를 우선 검증한다.
- 학생 클라이언트는 자기 이동을 예측하고 권한 있는 호스트 결과로 보정한다. 호스트를 모둠별로 나누는 효과와 실제 수업망의 통신 비용을 측정한 뒤 구조를 확정한다.
- 합동 보스는 별도 단일 전투 호스트로 전환한다. 완료 기록과 확정된 캐릭터 상태를 인계하고, 이전 던전의 구독·AI·소리·장치를 종료한 뒤 입장한다.
- 기존 20Hz/10Hz를 출발점으로 삼되 새 구조에서 검증한다. 다른 모둠의 전체 상태를 매번 보내거나 동기화 비용을 숨기기 위해 움직임 품질을 낮추지 않는다.
- 여섯 던전은 모둠용 5개와 합동용 1개다. 합동전은 다섯 모둠 던전이 끝난 뒤 실행하며, 여섯 곳의 전투를 동시에 유지하지 않는다. 와이파이·서버는 공유하므로 성능 영향이 완전히 0이라고 약속하지 않는다.

### 층별 마을 왕복

- `층 진행 → 완료 확정 → 귀환 준비 → 마을 정비 → 다음 층 준비 → 출발`을 모둠별 상태로 관리한다. 생존·전투불능 학생 모두 같은 목적지로 귀환하며, 다음 층은 준비한 모둠이 함께 출발한다.
- 마을은 공통 공간이지만 현재 마을에 있는 인원만 표시하고 동기화한다. 다른 모둠 던전의 AI·효과는 처리하지 않는다. 한 모둠이 마을에서 정비하는 동안 다른 모둠의 전투 권한과 시간은 유지한다.
- 마을의 이동·정비 권한과 모둠 전투 권한을 구분한다. 귀환한 모둠 호스트가 마을 전체나 다른 모둠 전투의 호스트가 되지 않는다. 새 층 입장 시 새 전투 세션을 열고 이전 층의 요청은 거부한다.
- 완료 층·다음 층·성장·장비·지급 보상을 먼저 확정해 저장한 뒤 이전 층을 정리한다. 포탈 클릭·완료 확인·재접속이 겹쳐도 보상과 다음 층 해금은 한 번만 처리한다. 저장이 확인되지 않으면 전환을 보류한다.
- 전환 중 연결이 끊기면 마지막 확정 상태에서 마을 또는 진행 중인 층으로 복구한다. 잠깐 연결이 끊긴 상태를 층 완료로 처리하거나 진행 기록을 삭제하지 않는다.
- 마을 귀환 때 완료한 층의 적 AI·장치·구독·효과·타이머·소리를 종료한다. 공통 캐릭터·마을 자산은 제한된 캐시로 재사용하고 사용하지 않는 층의 전용 GPU 자산은 해제한다. 반복 왕복으로 층이 쌓이지 않게 한다.
- 포탈은 문양·색·이름과 간단한 효과로 구분한다. 다섯 포탈 안에 다른 던전의 실시간 화면을 각각 렌더링하지 않는다. 다음 층은 준비 단계에서 필요한 자산만 읽고 입장 전까지 전투를 실행하지 않는다.

## 3. 예약·재접속·권한 이전

- 던전 예약은 한 던전에 한 모둠만 성공하는 원자적 처리로 구현한다. 교사의 배정 변경은 출발 전에 허용하고, 진행 중 변경은 명시적인 재시작 절차를 거친다.
- 전투 세션에 실행 ID·던전 ID·층 ID·시도 ID·호스트 ID·권한 세대 번호를 둔다. 호스트 교체나 층 전환 후 이전 세션의 입력·피해·보상 처리를 거부해 이중 판정을 막는다.
- 호스트 연결이 끊기면 전투를 잠시 멈추고, 확인된 체크포인트와 처리한 행동 순번을 인계한다. 복구할 수 없는 경우 해당 모둠만 마지막 체크포인트에서 다시 시작한다.
- 재접속자는 자기 모둠·직업·장비·진행 상태를 복원하고 최신 월드 상태를 받은 뒤 조작한다. 다른 모둠의 완료 기록을 되돌리지 않는다.
- 층 완료·층 보상은 실행·던전·층·모둠에 연결된 고유 기록으로 한 번만 반영한다. 던전 완료·완료 보상은 마지막 층 보스 처치 때 별도로 기록한다. 재시도마다 다른 전투 ID를 발급해도 동일 층 보상은 다시 받지 못하게 한다. 초기 3층안의 층 완료 15회가 전체 던전 완료 `5/5` 집계와 섞이지 않아야 한다.
- 현재 온라인 경로는 `sheepnight/season2_v1/rooms/<코드>`이며 `BUILD`/`RELEASE`는 모두 `s2-007`이다. 구 `s2-004` 통신 규격을 사용한 실행판 `s2-004/005/006`과 버전이 다르면 연결을 거부한다. 향후 RPG용 프로토콜·저장도 별도 구분한다.
- 새 체크포인트는 `zns2:checkpoint:s2-007:<room>`에 쓰며, 이 키가 없을 때 기존 `zns2:checkpoint:<room>`를 읽는다. 구 `s2-001~004` 체크포인트는 복제본의 `towers`와 `_checkpoint.towers`를 비우고 진행·보급을 유지한다. 타워 비용은 환불하지 않으며 이전 키의 원본은 덮어쓰거나 지우지 않는다.
- 새 경로·예약·권한 이전 방식은 실제 Firebase 권한과 원자적 갱신 가능 여부를 확인한 뒤 확정한다. 현재 코드에 없는 서버 검증이나 보안 규칙이 존재한다고 가정하지 않는다.
- 시즌1 저장은 읽거나 지우지 않는다. 기존 시즌2 저장도 자동 덮어쓰기하지 않고 호환되지 않으면 안내한다.

## 4. 직업·발명가 장치의 비용 제한

- 네 직업은 수호기사·명사수·원소술사·발명가다. 클래스별 전투 판정과 시각 효과를 분리해 구현한다. s2-007에서 제거한 공용 타워 건설·포장·운반·재배치 경제를 발명가 스킬로 되살리지 않는다.
- 발명가 한 명은 **공격 포탑 1개 + 지원 장치 1개**만 유지한다. 같은 종류를 다시 설치하면 이전 장치를 교체한다. 최종전 발명가 5명 기준 활성 장치는 최대 10개다.
- 설치 위치·재사용 대기시간·소유자·장치 수를 전투 호스트가 검사한다. 장치 교체·던전 종료·재시작·소유자 이탈 정책에 맞춰 판정·메시·소리·통신 상태를 함께 정리한다.
- 공격 포탑은 명사수 표식을 우선하되 후보 탐색 결과를 같은 틱에서 공유한다. 여러 포탑이 각각 모든 적을 반복 탐색하지 않게 한다.
- 지원 장치 중첩은 무한 가산하지 않는다. 회복 주기와 중첩 상한을 명시하고, 보호막 강화 여부와 관계없이 기본 회복 기능은 유지한다. 세부 수치는 플레이 테스트로 조정한다.
- 투사체·타격 효과·피해 숫자는 풀링하고 장면별 표시 상한을 둔다. 효과 표시를 제한해도 피해·회복·경고 영역 등 게임 판정은 누락하지 않는다.

## 5. 마을·던전·소리의 제작 기준

- 마을과 다섯 던전은 동선·실루엣·재질·랜드마크로 구분한다. 장식 개수만 늘리지 말고 실제 플레이 카메라에서 빈 공간, 방향 찾기, 보스 공격 예고의 가독성을 함께 확인한다.
- 캐릭터와 카메라는 시즌1 기준을 유지한다. 직업 장비를 붙이더라도 몸 비율·이동 감각·점프와 착지·꾸미기 호환을 다시 확인한다.
- 반복 구조물은 지오메트리·재질을 공유하고 정적 배치를 묶어 그린다. 구역별 가시성 판정과 충돌용 단순 형태를 사용하되 눈에 보이는 형태·그림자를 보존한다.
- 공통 자산은 재사용하고 던전 전용 자산은 입장 전 준비한다. 월드 전환 시 구독·이벤트·타이머·오디오·GPU 자원을 소유권에 따라 해제하며, 공유 자산은 사용 중에 해제하지 않는다.
- 마을·탐색·교전·보스·승리의 배경음 전환과 직업별 공격·피격·보스 경고음을 설계한다. 다른 던전의 소리는 재생하지 않고 같은 소리의 동시 재생 수를 제한한다.
- 효과음·배경음은 실제 재생으로 음량·겹침·종료를 듣고 검사한다. 위험 신호는 색·형태·소리를 함께 써서 소리를 끈 학생도 파악하게 한다.

## 6. 시즌1과 비교하는 성능 검수

기준은 사용자의 노트북에서 잘 실행되는 현재 시즌1이다. 아래 조건을 맞춰 비교하기 전에는 특정 FPS 달성이나 개선율을 약속하지 않는다.

- 동일 기기·브라우저·해상도·그리기 배율·안티앨리어싱·그림자·카메라 조건을 기록한다. 해상도나 모델 품질을 낮춰서 통과시키지 않는다.
- 학생 20명과 교사/관전 1명, **21클라이언트**를 운영 기준으로 검증한다. 교사 관전도 실제로 구독·렌더링하는 장면의 비용에 포함한다.
- 대표 장면은 마을 전원 집결, 5개 던전 동시 교전, 모둠 보스, 전원 합동 보스, 반복 귀환·재입장이다. 모둠마다 다른 층에서 싸우거나 일부가 마을에 머무는 혼합 상태와 다섯 모둠의 동시 귀환도 검사한다. 합동전은 학생 20명·발명가 장치 10개·보스 패턴·직업 효과가 겹치는 최악 조건을 포함한다.
- 평균 FPS와 1% low, 프레임 시간 p95/p99, JS/CPU·GPU 시간, 그리기 호출·삼각형, 메모리·GPU 자원 수, 송수신량·지연을 기록한다. 실제 제공되지 않는 지표는 측정 불가로 적는다.
- 모둠 호스트·일반 학생·교사·합동전 호스트를 구분해서 측정한다. 교사 한 대가 던전 다섯 개를 계속 계산하고 있지 않은지도 확인한다.
- 반복 전환 뒤 리스너·오디오·장치·메모리가 누적되지 않아야 한다. 포탈 이중 클릭·저장 확인 지연·전환 중 재접속·호스트 이탈·중복 완료 전송에도 장치 상한과 보상 기록을 유지한다. 층 실패 후 마을에서 재출발할 때 이전 층 완료·확정 성장·장비가 보존되는지도 검사한다.
- 적 수·동시 효과 수·메모리·통신 예산은 첫 측정 결과로 정한다. 자동/소프트웨어 렌더링 결과와 실제 노트북·교실망 결과를 구분해 보고한다.

## 7. 구현 순서와 단계별 확인

사용자가 지정한 미술 제작 순서는 **첫 마을 → 던전 하나씩**이다. 먼저 마을 작업장 한 채를 3D Jutsu로 상세 제작하고 실제 게임에 적용해 미술·성능을 확인한 뒤 마을에 확대한다. 다음 구조·통신 검증은 개발용 장면에서 진행하며, 던전 완성품을 마을보다 먼저 제작하는 순서로 바꾸지 않는다.

1. **구조 검증:** 기존 테스트판을 보존한 채 새 규칙·프로토콜을 분리한다. 한 던전 틀을 5개 독립 인스턴스로 실행해 예약·통신 범위·권한 이전·종료와 모둠별 층→마을→다음 층 전환을 검증한다. 이는 개발용 시험이며 최종 게임에서 같은 던전만 반복한다는 규칙이 아니다.
2. **4인 플레이:** 가시뿌리 숲 3층을 첫 제작 대상으로 네 직업·발명가 장치·공유 경험치·레벨 1→5·무기/유물·보스·재도전까지 완성한다. 모든 층 사이 마을 정비와 포탈 목적지 표시를 검증한다. 실제 기본 카메라의 미술·전투 가독성·소리를 함께 확인한다.
3. **합동전 선검증:** 다른 네 던전의 세부 제작에 앞서 20명 합류·최대 10장치·보스 패턴으로 성능과 통신 한계를 측정한다. 기준 미달이면 병목을 수정하고 다시 확인한다.
4. **다섯 던전 제작:** 서로 다른 맵·기믹·보스로 확장한다. 한 모둠은 선택한 한 던전만 완료하며, 보상 등급과 예상 소요 시간을 비슷하게 맞춘다.
5. **수업 전체 검수:** 대기실→모둠 배정→층 클리어와 마을 정비 반복→다섯 던전 완료→합동 보스→승리 귀환을 21클라이언트로 확인한다. 실제 노트북 FPS·교실망·동작·소리 미확인 항목은 완료로 표시하지 않는다.

기획 문서 수정에는 링크·규칙 일치·시즌1 무변경 검사를 적용한다. 이후 실행 코드를 바꿀 때는 독립 배포본을 재생성하고 기능·브라우저·실기기 검수 기록을 별도로 남긴다.

현재 s2-007은 기존 s2-004 온라인 방 메타를 거절한다. 교사는 새 방 코드를 사용해야 하며, 다른 코드의 로컬 체크포인트를 자동으로 옮기는 기능은 없다. 구키 fallback은 같은 저장 범위에서만 작동하며, 혼자 체험의 기존 저장 이어하기는 유지한다.
